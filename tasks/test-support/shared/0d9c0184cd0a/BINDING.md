Открытый TaskBinding.java — изменяемый пример клиента для выбранного API стартера. Его имена не добавляют требований к решению. Для другого допустимого API согласуйте обычную Java-привязку; закрытый/локальный API предъявляется действительной демонстрацией и предметным чтением. Ошибка подготовки привязки не устанавливает неправильность решения.

Компилируйте исходники рекурсивно по авторскому README. Открытые проверки компилируются и запускаются по единственному canonical CHECKS.md. Только два опубликованных случая; успешная проверка не заменяет чтение исходника и беседу. Book/Car — один выбор, не две обязанности.

Object[], value и другие методы TaskBinding — представление проверяющего клиента, не обязательный API студента. Привязка переводит иной допустимый вид результата и собственное обозначение отсутствия совпадений в наблюдаемую подборку. Если перевод не подготовлен, согласуйте клиент или предъявите демонстрацию; это не новое ограничение типа результата.
