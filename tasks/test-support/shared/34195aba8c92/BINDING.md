# Открытые наблюдения

TaskBinding — редактируемый пример клиента выбранной заготовки. Имена,
типы, пакеты, формат и политики решения свободны в пределах условия.
Согласуйте обычные вызовы клиента с собственным решением; недоступное
внешнему клиенту API предъявите преподавателю через свою демонстрацию.
Неподготовленная привязка не доказывает ошибку решения и не даёт оценки.
PublicChecks исполняет только два опубликованных сценария. Исходник,
обязательные приёмы, выбранные политики и объяснение проверяются отдельно.
Параметр Gradle demoClass указывает выбранный класс запуска. Значение
по умолчанию Start относится только к незавершённому примеру.
