# Привязка открытых примеров

`src/test/java/TaskBinding.java` — редактируемый клиент примера стартера.
Его имена, параметры и представление результата не являются API задания.
При другой организации решения измените только обращения клиента к собственному
коду. Сверяйте лишь опубликованные случаи. Для решения с недоступными внешнему
клиенту операциями предъявите исходники и свою команду демонстрации преподавателю:
неподготовленная привязка не означает неверное решение и не даёт оценки.

Клиент показывает фактические значения и состояние объектов. Участие массива,
способ сортировки, создание результатов и объяснение проверяются также по коду;
успех клиента не подтверждает эти ручные критерии.
