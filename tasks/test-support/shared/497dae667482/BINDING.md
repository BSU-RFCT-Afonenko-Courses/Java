# Подготовка открытых наблюдений

PublicChecks проверяет только два опубликованных случая. TaskBinding —
редактируемый пример клиента выбранной заготовки, а не дополнительный API
задания. Согласуйте вызовы и чтение свободно оформленного результата со
своей реализацией. Имена, порядок аргументов, текст сообщений и формат
ограничены только условием. Если допустимый API недоступен внешнему
клиенту, предъявите выбранный запуск и исходник преподавателю.
Неподготовленная привязка не доказывает ошибку решения и не даёт оценки.
Обязательные средства, собственные данные и объяснение оцениваются отдельно.
