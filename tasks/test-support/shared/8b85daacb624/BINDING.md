# Привязка открытых наблюдений

TaskBinding — редактируемый клиент выбранного примера стартера. Его имена,
порядок параметров и типы относятся только к примеру. При другом устройстве
решения измените обращения к собственному коду; по условию свободны классы,
пакеты, видимость, main и формат предъявления. Обязательный метод вставки
остаётся методом с тремя смысловыми входами и строковым результатом.

Если операции недоступны внешнему клиенту, предъявите исходник и выбранную
демонстрацию преподавателю. Неподготовленная привязка не означает неверное
решение и не даёт оценки. Клиент не доказывает обязательный приём,
предъявление исходника или объяснение; их преподаватель оценивает отдельно.
