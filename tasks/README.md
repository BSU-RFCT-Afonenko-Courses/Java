# Задания по Java

Канонические условия хранятся в `bank/`, состав работ — в `labs/`, исследовательские темы — в `essays/`. Все 131 условия (128 коротких и три больших проекта) имеют один текст; лабораторные и практики ссылаются на банк.

Первая поставка PrairieLearn содержит 17 автоматизированных проектов первых трёх работ в `projects/` и отдельный ручной проект gradeapp и 14 обязательных позиций 6/4/4 при 7/5/5 кандидатах. В трёх случайных группах вариант назначается при создании экземпляра и сохраняется при отправках. Публичные стартеры/примеры отделены от reference/закрытых JUnit-тестов и ошибочных fixtures. Автоматическая проверка оценивает опубликованный протокол; обязательную технику исходника и объяснение проверяет преподаватель.

ЛР4–10 имеют ручное предъявление. В ЛР7 PECS30 заменяет swap30; в ЛР8 hash35/view45 заменяют digit-stack30/word-frequency50, выбор скобки либо polynomial60 сохраняется. В ЛР9 остаются пять позиций и две пары. В ЛР10 gradeapp120 заменяет две выбранные позиции по60; все семь снятых карточек остаются дополнительными в банке. Сумма основных работ1935; вводные10×30=300 отдельно. ЛР6=270, её135-минутная карточка уже включает90 подготовки очередей. Новые30/35/45/120 — гипотезы, студенческий pilot ещё нужен.

Gradeapp — manual exercise `exr-j25-files-gradeapp-report`, project `/projects/gradeapp`, public starter только `projects/gradeapp/student/`. Student/exception/bootstrap/build/CLI boundary/output helper готовые; parser/read/reports/run(Path,int) выполняет студент. Основная POSIX команда `sh ./build.sh test package`, Windows `.\build.cmd test package`; публичные `wrapper/maven-wrapper.properties` копируются предоставленным helper в локальное `.mvn`, которое не входит в starter ZIP. JAR `target/gradeapp.jar` запускается из другого каталога с двумя аргументами input/threshold. Windows counterpart поставляется; выполнение в Linux не заявляется. Closed tests/reference вне starter, project-check=java-labs и PL registration для gradeapp не добавляются.

Java25 без preview; helpers не добавляют самостоятельную реализацию или новые минуты. Для среды преподаватель заранее проверяет JDK25 и инструменты/caches официального Wrapper. Короткое содержательное объяснение входит в существующую защиту; новый письменный отчёт не нужен.

Поставка и проверка описаны в [документации лабораторных](../docs/prairielearn-labs.md); авторские правила — в [методике](../docs/authoring-methodology.md). Физические assets материализует M04 по принятому U05/U06, итоговую public/private доставку проверяет M05.
