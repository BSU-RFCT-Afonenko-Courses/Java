# Задания по Java

Канонические условия хранятся в `bank/`, состав лабораторных — в `labs/`,
исследовательские темы — в `essays/`. Страницы лабораторных и другие
потребители используют один текст задания из банка. Введение к каждой
лабораторной находится в `../practice/` и доступно студенту с сайта.

Авторскую работу начинайте с [рабочей документации](../docs/README.md).
Текущий пилот охватывает обобщения: его состав, рецензия и результаты
проверок описаны в [документе пилота](../docs/java-course-pilot.md).
Изменения прочих лабораторных в этот пилот не входят.

## Проекты и проверка

В `projects/` находятся стартовые проекты, публичные примеры, авторские
решения и закрытые проверки. Публичная поставка отделена от материалов
преподавателя. Автоматическая проверка оценивает наблюдаемое поведение;
обязательные приёмы исходника и объяснение проверяет преподаватель.

Первые три лабораторные подключены к PrairieLearn: 17 возможных вопросов
образуют 14 обязательных позиций по схеме 6/4/4. В случайных группах вариант
выбирается при создании экземпляра и сохраняется при повторных отправках.
Остальные работы используют ручную проверку. Подготовка среды, экспорт
и полный маршрут проверки описаны в
[документации лабораторных](../docs/prairielearn-labs.md).

Готовая среда сборки помогает запустить решение. Требуемый результат,
обязательные API и существенные ограничения определяет каноническое
условие конкретной задачи. После правки условия проверяются появившиеся
обязанности студента и соответствие используемых проверок этому условию.
