# Задания по Java

Канонические условия хранятся в `bank/`, состав лабораторных — в `labs/`, исследовательские темы — в `essays/`. Лабораторные и практики ссылаются на банк; `index.qmd` содержит оглавление работ.

Для первых трёх лабораторных подготовлены 17 проектов в `projects/`: стартовые программы, публичные примеры, эталоны, закрытые оцениваемые JUnit-тесты и предусмотренные ошибочные реализации. PrairieLearn назначает один вопрос каждой случайной позиции; для выполнения работ требуются 6, 4 и 4 обязательные позиции. Остальной банк сохраняет общий ручной режим проверки.

Порядок подготовки, проверки и подключения инструментов описан в [документации лабораторных](../docs/prairielearn-labs.md). Учебные правила находятся в [методике подготовки материалов](../docs/authoring-methodology.md).
