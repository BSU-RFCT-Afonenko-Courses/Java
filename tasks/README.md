# Задания первого семестра Java

`tasks/` — книга Quarto с текстовым банком, лабораторными работами и
самостоятельными исследованиями по Java 25 без preview.

| Файл или каталог | Назначение |
| --- | --- |
| `index.qmd` | Вход в банк и правила выбора |
| `bank/semester-one/*.qmd` | 127 канонических задач: 124 коротких и 3 проекта |
| `labs/semester-one/*.qmd` | 10 основных и 3 добровольные резервные работы |
| `essays.qmd` | Общие условия исследования и отдельной защиты |
| `essays/semester-one/*.qmd` | 11 тематических страниц с 30 постановками и страница источников |
| `teacher.qmd` | Организация назначения и защиты; приложение full |

## Авторский формат

У каждой банковской задачи свои смысловой ID, `difficulty` и положительное
`time` в минутах. Банк и рефераты имеют manual target и открытые условия.
Лабораторная назначает задачи банка штатными метаданными и ссылками;
парные слоты и обязательная нагрузка дополнительно пояснены в её тексте.

Рефераты имеют роль `independent-study`. Карточка сохраняет вопрос,
содержание, индивидуальную подготовку, практическую связь и источники.
Назначение темы не требует предварительно сдать связанные задачи или
другой реферат. Все 30 вариантов не составляют обязанность одного студента.
Положительные оценки 240 минут — пробные ориентиры подготовки без защиты.

Защита с тремя заданиями по выбранной теме — отдельная ручная процедура,
ожидающая разработки заданий, критериев и порядка проведения. Число работ
на студента и бюджет защиты открыты. Персональные назначения и результаты
учебного потока не хранятся в исходниках курса.

## Представления и проверка

Из корня курса:

```sh
quarto inspect --profile student
quarto inspect --profile full
quarto render --profile student --fail-if-warnings
quarto render --profile full --fail-if-warnings
```

Student и full содержат одинаковые открытые условия банка, лабораторных
и исследований. Full дополнительно включает организационную страницу
преподавателя. Проверяющие проекты к этому текстовому каталогу не объявлены.

Новые ID и структура заменяют старый каталог. Прежние материалы сохраняются
в истории Git; активные страницы не содержат aliases или таблиц совместимости.
Второй семестр требует отдельной разработки и в этот каталог не входит.

[Руководство инструментов](https://afonenko-course-tools.github.io/quarto-template-course/guide/index.html)
и [основной README](../README.md) описывают общие правила и зависимости.
