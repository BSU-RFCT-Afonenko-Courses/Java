## Удаление комментариев из Java-программы

Для вывода результатов создайте новую директорию и файл средствами класса File. Из текста Java-программы удалите все виды комментариев. Результат сохраните в новый текстовый файл.

В учебном входном файле нет текстовых блоков и Unicode-escape-последовательностей; обычные строковые и символьные литералы допускаются.

Подготовьте небольшой UTF-8-файл с комментариями `//`, `/* … */` и `/** … */`, а также с обычными строковыми/символьными литералами, содержащими слеши и кавычки. Комментарии внутри литералов удалять нельзя; перевод строки после однострочного комментария сохраняйте. Для предотвращения склейки соседних токенов замените удалённый блочный комментарий пробелом.

Вход — допустимый исходный текст Java в указанном подмножестве; незавершённые
литералы и комментарии вне входного договора. Сохраните весь текст вне
комментариев, включая пробелы и разделители строк. При удалении блочного
комментария оставьте один ASCII-пробел на его месте и сохраните находившиеся
внутри него разделители строк в исходном порядке. Поэтому `int/**/x;`
превращается в `int x;`. Для строкового литерала `"/* text */"` содержимое
остаётся прежним. Покажите экранированную кавычку и обратную косую черту
внутри литерала. Пути исходного и нового файла задайте явно; оба используют UTF-8. [1]


## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`; запуск выбранного вами класса `java -cp out <класс>`. Соблюдайте только явно заданные карточкой имена/каналы/методы; project ZIP не вводит новых Main/пакета/public/static/helperAPI. Данные в examples/; пути с пробелами передавайте одним аргументом, пустой аргумент POSIX — `''`. Если канал/порядок аргументов свободен, укажите выбранный способ в демонстрации.
