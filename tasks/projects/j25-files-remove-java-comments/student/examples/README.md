# Комментарии и литералы

`publicInput.txt` содержит блочный, документационный и однострочный
комментарии, строковый литерал `"/* text */"` и символьный литерал `'/'`.
`publicExpected.txt` задаёт ожидаемый результат этого входа.

`int/**/x;` превращается в `int x;`: пробел сохраняет границу токенов.
Содержимое литерала `"/* text */"` остаётся прежним. Разделитель строки
после `//` сохраняется. Для блочного комментария сохраняются один
замещающий ASCII-пробел и внутренние разделители строк в исходном порядке.

Дополните демонстрацию экранированной кавычкой и обратной косой чертой
внутри литерала. Входы не содержат текстовых блоков и Unicode-escape-последовательностей; незавершённые литералы и комментарии исключены условием.
