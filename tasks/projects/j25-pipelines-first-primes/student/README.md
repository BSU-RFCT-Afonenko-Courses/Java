## Первые N простых чисел

Выведите первые `N` простых чисел в возрастающем порядке. Вход `N` — целое число от `0` до `10000` включительно. Простое число — целое больше единицы, имеющее ровно два положительных делителя: единицу и себя.

Используйте последовательный Stream API и генератор последовательности (`iterate`, `generate` или их варианты для примитивных потоков). Способ проверки простоты выберите самостоятельно. Для `N = 5` результат `2 3 5 7 11`, для `N = 0` вывод пуст. Между числами допустимы пробелы или переводы строк. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Обязательные Stream API/лямбда/собственный интерфейс проверяются по исходнику.

## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`, демонстрируйте выбранным вами способом `java -cp out <класс>`. Форма main и имена этой поставкой не назначаются. Public examples в examples/README.md.
