# Распаковка: примеры

| Сжатая запись | Результат |
|---|---|
| `a12b` | `aaaaaaaaaaaab` |
| `hel2owo4rld` | `hellowoooorld` |
| `Z` | `Z` |
| `a2B3c` | `aaBBBc` |
| пустая строка | пустая строка |

У `a12b` число повторений содержит две цифры, а последняя буква `b`
не сопровождается числом. У `a2B3c` регистр `B` сохраняется.
Проверку повреждённой сжатой записи условие не требует.
