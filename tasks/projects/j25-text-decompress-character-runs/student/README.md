# Распаковка сжатого текста

Восстановите текст из корректной сжатой записи. Латинская буква A–Z/a–z
без числа обозначает одно вхождение; следующие за ней цифры до очередной
буквы задают десятичное число повторений не менее двух, без ведущих нулей.
Число повторений может быть многозначным. Регистр букв сохраняется.

Такую запись получают сжатием максимальных серий одинаковых соседних букв:
одиночная буква остаётся без числа, серия длиной от двух получает счётчик.
В исходном несжатом тексте присутствуют только латинские буквы.

`a12b` восстанавливается в двенадцать букв `a` и одну `b`;
`hel2owo4rld` — в `hellowoooorld`. Пустой вход даёт пустую строку.
Вход существует и заведомо корректен; распознавание и исправление
повреждённой записи не требуется.

## Сборка и демонстрация

Используйте JDK 25. Создайте исходные файлы в `src/` и скомпилируйте их:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
```

Затем выполните `java -cp out имя.класса`, подставив полное имя своего
класса запуска. Имя класса, пакет, методы, способ задания исходных данных
и оформление демонстрации выбирайте самостоятельно.
Ожидаемые результаты приведены в [примерах](examples/README.md).
