# gradeapp — учебное консольное приложение

Публичная скачиваемая заготовка находится только в `student/`.
Она содержит модель, исключение, Maven Wrapper, проверку аргументов
команды, метод вывода, пять методов с TODO в парсере, загрузчике, `Reports`
и `run(Path,int)`, четыре открытых примера и каталог `samples`. ZIP собирается только из 17 публичных файлов
каталога `student/`,
без локально созданных `.mvn/` и `target/`.

`reference/src/main/java/grade/` — учительская реализация.
`tests/junit/` — 29 закрытых компонентных проверок; вместе с четырьмя
открытыми они проверяют 33 случая. `tests/api/GradeAppApi.java` проверяет
опубликованный API через `PlatformApiPrecheck` до компиляции
зависимых JUnit-тестов. Эти файлы, `tests/fixtures/`, `tools/` и учительскую
реализацию нельзя включать в публичный ZIP заготовки или открытые ресурсы курса.

Преподаватель проверяет проект вручную и с помощью автоматических проверок.
Регистрации PrairieLearn и `project-check="java-labs"` здесь нет.
Пояснение студента и чтение исходника остаются необходимыми: например,
место обнаружения дубля, закрытие файлового ресурса до возврата результата
и граница начала полезного stdout. Автоматический результат не заменяет
эту часть предъявления.

## Локальная проверка преподавателя

Нужны JDK 25, Python 3 и штатный каталог
`platform/runtime/java25-junit-v1` с закреплёнными JUnit, json-simple и
`PlatformApiPrecheck.java`. Из каталога проекта:

```bash
python tools/check.py \
  --runtime /absolute/path/platform/runtime/java25-junit-v1 \
  --work /tmp/gradeapp-reference
python tools/check-cases.py \
  --runtime /absolute/path/platform/runtime/java25-junit-v1 \
  --work /tmp/gradeapp-cases
```

Первый вызов по умолчанию проверяет `reference/src/main/java`.
Для заготовки добавьте `--sources student/src/main/java`: её исходники
компилируются, API соответствует договору, проверки поведения не проходят
из-за TODO. `--public-only` выбирает только открытые проверки. `--work`
указывает новый, ещё не существующий каталог артефактов вне проекта,
исходников и среды проверок; для повторного запуска выберите новый путь.
Существующие каталоги не очищаются. Неизвестный `--only` и пустая выборка
отклоняются до создания артефактов. `JAVA_HOME` задаёт
JDK; альтернативный путь доступен через `--java-home` в `check.py`.

`check.py` сохраняет команды, stdout/stderr, хеши исходников, результат проверки API
и классификацию исхода в `report.json`. Сначала компилируются исходники решения,
затем проверяется API,
компилируются зависимые тесты и проверяется поведение. Отсутствующий API не маскируется
ошибкой JUnit-компиляции. `Main.run(Path,int)` проверяется обычным типизированным
клиентом из пакета `grade`; допустимо совместимое сужение перечня
проверяемых исключений в `throws`.
Проверка обобщённого типа `List<Student>` использует настоящую компиляцию
положительных и отрицательных клиентов и не задаёт алгоритм коллекции.

`tests/contract-cases.json` содержит 34 самостоятельных варианта:
6 несовместимых API, 1 ошибку компиляции решения, 25 нарушений поведения
и 2 допустимых решения. Каждый вариант подставляется
в отдельную копию учительской реализации
и исполняется независимо. Допустимые варианты показывают цикл с сортировкой
вместо Stream и совместимое сужение перечня проверяемых исключений
в `throws`. Проверки не задают
новых требований к входам со значением `null` или вспомогательным API.

Сборка скачиваемого проекта выполняется его готовыми `build.sh`/`build.cmd`.
Maven Wrapper 3.3.4 закрепляет Maven 3.9.16 и SHA-256 дистрибутива; JAR имеет
`Main-Class: grade.Main`. Первичная загрузка Maven и зависимостей требует
доступного Maven Central либо заранее подготовленного локального кэша.
Windows-скрипты поставлены; их фактическое исполнение должно проверяться
в Windows и не выводится из успеха POSIX-сборки.

Проверки защиты путей и фильтров выполняются отдельно от Java:

```bash
GRADEAPP_RUNTIME=/absolute/path/platform/runtime/java25-junit-v1 \
  python tests/test_checker_guards.py
```

Эти проверки защиты используют временные копии и не передают живой проект
в качестве рабочего каталога. Они проверяют сохранность чужих файлов,
перекрытие путей в обоих направлениях и ошибочный выбор идентификаторов вариантов.
