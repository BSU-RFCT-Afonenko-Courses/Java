# gradeapp — учебное консольное приложение

Публичная скачиваемая заготовка находится только в `student/`.
Она содержит модель/исключение, Maven Wrapper, CLI-границу, helper вывода,
TODO для parser/loader/Reports/run(Path,int), открытые примеры и samples.
`reference/src/main/java/grade/` — учительская реализация;
`tests/junit/GradeAppContractTest.java` — закрытые локальные проверки.
Их нельзя включать в публичный starter ZIP или public resources.
Проект проверяется вручную; новая регистрация PrairieLearn и
`project-check="java-labs"` здесь не предусмотрены.
