# Пары файлов для сравнения

Создайте два UTF-8-файла с одинаковым текстом `Java text` и третью версию
`Java test`. Первая пара совпадает, пара с третьим файлом различается.
Пара `Java` и `Java text` проверяет одинаковое начало при разной длине.

Два пустых файла совпадают; пустой и непустой различаются. Отсутствующий
файл должен привести к сообщению об отказе чтения без вывода о равенстве.
Оба входных файла после запуска сохраняют прежнее содержимое.
