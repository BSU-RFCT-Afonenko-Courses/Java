# Проект: replace-word-letter

## Замена k-й буквы слова

Слово — максимальная непрерывная последовательность букв A–Z/a–z
и А–Я/а–я с Ё/ё. Цифры, пробельные символы и пунктуация разделяют слова.
Общие допустимые данные: раздел «Данные и границы текста» ниже.

В каждом слове текста k-ю букву заменить заданным символом. Вход: текст,
положительное целое `k` в диапазоне `int` и один символ допустимого алфавита. Буквы внутри
каждого исходного слова нумеруются с единицы. Если `k` больше длины слова,
слово не изменять. Границы определяются до замены; разделители сохраняются.
Например, при `k = 2` и замене на `'*'` текст `"кот, я!"` даёт `"к*т, я!"`.

Оформите отдельную программу, запускаемую командой `java Main` в Java 25. Форму точки входа выберите самостоятельно; она должна обеспечивать описанную ниже работу с аргументами командной строки.
Передайте ровно три аргумента: исходный текст целиком, десятичное `k`
и строку из одного заменяющего символа. Аргументы заведомо корректны;
стандартный ввод не используется. Выведите только преобразованный текст
и завершающий перевод строки. Например,
`java Main "кот, я!" 2 "*"` выводит `к*т, я!`.
Команда `java Main "" 2 "*"` передаёт пустой текст; результатом служит
пустая строка вывода. В `java Main "кот дом" 2 "*"` текст с пробелом
также занимает один аргумент, результат — `к*т д*м`.
Алгоритм, вспомогательные методы и их имена выберите самостоятельно.


## Данные и границы текста

Если карточка не задаёт более узкий алфавит, входные строки состоят из
латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9,
знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные
сочетания Unicode не допускаются. Строки не равны `null`; пустая строка
допустима. Символ и единица длины здесь — один `char`.

Слово — максимальная непустая последовательность букв указанного алфавита.
Цифры и все небуквенные символы разделяют слова. В преобразованиях слов
сохраняйте исходный порядок и все разделители, если карточка не требует
иного. Регистр учитывается, кроме явно оговорённого сравнения без регистра.
В отсутствие слов преобразование слов оставляет текст прежним, поиск слов
по длине выводит сообщение «Слов нет», подсчёт вхождений слова возвращает ноль.

Сборка Java 25: `javac --release 25 -encoding UTF-8 -d out student/src/main/java/*.java`.
Запуск: `java -cp out Main` с аргументами из условия.
Публичные примеры находятся в `student/src/test/java/`.

Для преподавателя: `reference/` — эталон, `tests/junit/` — закрытые проверки.
`tests/contract-cases.json` перечисляет только ошибочные реализации.
Ручной разбор, указанный условием, остаётся самостоятельной частью приёмки.
