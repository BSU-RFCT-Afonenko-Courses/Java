## Стек символов Stack

Создайте класс `Stack` с открытым конструктором `Stack(int capacity)` и методами `public void push(char value)`, `public char pop()`. Закрытый массив хранит символы; положительная ёмкость задаётся конструктором и остаётся постоянной. `push` помещает символ на вершину, `pop` возвращает и удаляет последний помещённый символ. В этой задаче конструктору передают только положительную ёмкость.

Неудачный `push` печатает отдельную строку `Стек переполнен`; неудачный `pop` печатает `Стек пуст` и возвращает `'\0'`. Успешные операции ничего не печатают. Допустим любой `char`, кроме нулевого символа: он зарезервирован для отказа. Отказ сохраняет хранимые символы, их порядок и вершину. Покажите заполнение, оба отказа и порядок извлечения. Например, ёмкость 2: `push('A')`, `push('B')`, отказ `push('C')`, затем `pop()` даёт B, A, а следующий отказ — `'\0'`. Внутренние индексы и вспомогательные методы выбирайте самостоятельно. ## Работа с проектом

Разместите исходные Java-файлы в `src/`. Требуемые классы и методы указаны
в условии выше; остальные имена, пакеты, вспомогательные методы и способ
запуска выбирайте самостоятельно. В `examples/scenarios.json` приведены
данные и наблюдения для демонстрации. Формат ввода определяется вашим решением
в пределах условия.

Для компиляции нужен JDK 25. Если исходники находятся непосредственно
в `src/`, а демонстрация — в `src/Main.java` без объявления пакета,
команды имеют вид:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Main
```

Подставьте фактическое имя своего класса запуска. Для вложенных каталогов
перечислите нужные исходные файлы в команде компиляции.
Для класса в пакете команда запуска использует полное имя, например
`java -cp out demo.Main`.

Представьте исходники и демонстрацию обычных и существенных граничных случаев,
описанных в условии. Объясните выбранные типы, порядок действий и результат.
Обязательные приёмы проверяются по коду и в беседе с преподавателем.

Состав основной работы и выбор между моделями `Book` и `Car`:
