## Стек символов Stack

Создайте класс `Stack` с открытым конструктором `Stack(int capacity)` и методами `public void push(char value)`, `public char pop()`. Закрытый массив хранит символы; положительная ёмкость задаётся конструктором и остаётся постоянной. `push` помещает символ на вершину, `pop` возвращает и удаляет последний помещённый символ. В этой задаче конструктору передают только положительную ёмкость.

Неудачный `push` печатает отдельную строку `Стек переполнен`; неудачный `pop` печатает `Стек пуст` и возвращает `'\0'`. Успешные операции ничего не печатают. Допустим любой `char`, кроме нулевого символа: он зарезервирован для отказа. Отказ сохраняет хранимые символы, их порядок и вершину. Покажите заполнение, оба отказа и порядок извлечения. Например, ёмкость 2: `push('A')`, `push('B')`, отказ `push('C')`, затем `pop()` даёт B, A, а следующий отказ — `'\0'`. Внутренние индексы и вспомогательные методы выбирайте самостоятельно.
