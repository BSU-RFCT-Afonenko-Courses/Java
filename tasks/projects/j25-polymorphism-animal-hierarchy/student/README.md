## Иерархия животных

Создайте иерархию `Animal` → `Dog` → `Puppy`. Конструктор каждого класса принимает имя типа `String`; имя ненулевое, непустое и сохраняется после создания.

Объект умеет подавать голос; для собаки доступны бег и укус, для щенка — прыжок. Имена методов действий выберите самостоятельно и используйте одну сигнатуру для голоса во всей иерархии. Каждый класс переопределяет голос; сообщения должны различать вид животного и его имя. Точный текст свободен. Покажите вызовы голоса для трёх видов через ссылки `Animal` и собственные действия собаки и щенка.

Определите равенство по точному классу и имени, реализуйте согласованные `equals`, `hashCode`, `toString`. Объясните, почему собака и щенок с одинаковым именем при таком контракте не равны. Равенство с `null` ложно; равные объекты имеют одинаковый хеш. `toString()` должен позволять увидеть класс и имя, его оформление свободно. Определение равенства и связь с хешем: [Равенство и хеш по значению](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/data-classes.html#sec-j25-theory-data-classes-value). ## Работа с проектом

Разместите Java-файлы в `src/`. Имена вспомогательных классов, методы и пакеты выбирайте самостоятельно в пределах явно заданного API. Нужен JDK 25.

Например, если вы назвали свой класс демонстрации `Demo` и расположили все исходники непосредственно в `src/` без объявления пакета, из корня проекта выполните:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Demo
```

При другом имени укажите его в команде запуска. При использовании пакетов перечислите нужные исходники и укажите в команде запуска полное имя класса с пакетом.

Открытые сценарии в `examples/scenarios.json` описывают действия и ожидаемые наблюдения. Способ ввода данных для собственной демонстрации выбирайте самостоятельно.
