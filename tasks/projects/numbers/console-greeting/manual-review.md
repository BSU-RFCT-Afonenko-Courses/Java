# Рубрика: приветствие пользователя

ID: `exr-numbers-console-greeting`. Редакция условия и её SHA256 указаны
в [контракте](contract.md). Применяется закрытая общая основа
`teacher/common/rubric-template.md`. Критерии не задают баллов и весов.

| Часть | Критерий | Достаточное свидетельство |
|---|---|---|
| Результат на допустимых данных | Приветствие использует первый аргумент; отсутствие аргументов даёт объявленное сообщение | Запуск с именем и без него, сопоставление вывода с условием |
| Ограничения и состояние | Строка имени сохранена, лишние аргументы игнорируются, stdin не участвует | Имя с пробелами и Unicode; чтение участка, который выбирает данные для сообщения |
| Обязательные приёмы | Соблюдены JDK 25 и заданная точка входа; отдельный вид ветвления не обязателен | Компиляция, команда запуска, объявление входного метода |
| Объяснение решения и границы | Студент различает пустой список аргументов и переданное имя; объясняет роль кавычек оболочки | Объяснение двух показанных запусков и передачи имени с пробелами |
| Воспроизводимость предъявления | Представленные исходники дают показанный результат | Повторная компиляция и запуск из указанного каталога |

Смысловой ориентир: кавычки группируют символы в один аргумент и обычно
не входят в само имя. Проверка количества аргументов защищает обращение
к первому элементу; пустая строка в первом элементе остаётся аргументом.
Получение имени из stdin, склейка всех аргументов и `trim` меняют договор.
Конкретная форма ветвления, конкатенации или печати на оценку не влияет.
От студента достаточно исходников, демонстрации и объяснения.

Автоматическая часть — 80%, ручная часть — 20%. API-допуск и открытые примеры баллов не дают. Ручные критерии исходной рубрики сохранены.
