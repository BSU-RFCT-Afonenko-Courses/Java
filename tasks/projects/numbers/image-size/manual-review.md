# Рубрика: размер изображения

ID: `exr-numbers-image-size`. Редакция условия и её SHA256 указаны
в [контракте](contract.md). Основа — `teacher/common/rubric-template.md`.
Критерии не задают баллов и весов.

| Часть | Критерий | Достаточное свидетельство |
|---|---|---|
| Результат на допустимых данных | Точное целое количество байтов и размер в МиБ в установленном допуске | Оба опубликованных примера и один пиксель |
| Ограничения и состояние | Промежуточное вычисление сохраняет точность на всём диапазоне; единицы не смешиваются | Исходные выражения, их типы и разбор большого входа |
| Обязательные приёмы | Заданная точка входа и JDK 25 соблюдены; конкретный числовой тип условием не назначен | Объявление метода, компиляция и выбранные числовые операции |
| Объяснение решения и границы | Студент объясняет тип каждой промежуточной операции и потерю точности при неверном выборе | Ответ по фактическому выражению и сравнению малого и большого примеров |
| Воспроизводимость предъявления | Исходники и команда со stdin воспроизводят показанные числа | Повторная компиляция и запуск из комплекта |

Смысловой ориентир: тип переменной результата не исправляет уже
переполнившееся произведение более узкого типа. Большой пример даёт
7500000000 байт и различает такие вычисления. Деление для МиБ должно
сохранить дробную часть; делитель 1000000 означает другую единицу.
Для одного пикселя с одним байтом результат — 1 байт и
0.00000095367431640625 МиБ. Допустимы разные представления чисел
и разные корректные способы обеспечить точность; решение не оценивается
по совпадению с выбранной преподавателем формой выражения.

Автоматическая часть — 80%, ручная часть — 20%. API-допуск и открытые примеры баллов не дают. Ручные критерии исходной рубрики сохранены.
