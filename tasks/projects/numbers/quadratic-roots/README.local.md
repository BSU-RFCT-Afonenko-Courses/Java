Класс запуска — `Main` без пакета; допустима любая форма `main`, поддерживаемая JDK 25 при запуске `java -cp out Main`. Вспомогательные типы внутри перечисленных файлов, методы и алгоритм выбирайте самостоятельно. Стандартный ввод для чисел не используется. Заготовка компилируется и проходит API-допуск, но не реализует вычисление.

`gradle test` запускает две открытые проверки для самопроверки. Они и API-допуск баллов не дают. Полный достоверный оценочный набор содержит 11 самостоятельных равновесных случаев; автоматическая часть — `80 × passed/total` процентов максимума. Ручные 20% проверяются отдельно по условию и исходнику. Ошибка компиляции решения или нарушение опубликованного API дают ноль текущей попытки до JUnit; инфраструктурный отказ оставляет результат неустановленным.

Прежние признанные полные зачёты, успешный код, выдача и контексты сохраняются по своей редакции. Новый launcher и формат относятся к новым решениям; они не делают законный старый код ошибочным. Эта дополнительная задача не расширяет обязательный состав лабораторной.
