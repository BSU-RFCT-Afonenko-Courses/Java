Преподавательский документ. ID: `exr-numbers-quadratic-roots`.
SHA256 условия: `ec09e82759e90a6b6d47cc1eaf6bdfa703fd8042cdc9200422cf874a97f0dea4`.
Основа — `teacher/common/rubric-template.md`; полный договор — соседний
`contract.md`. Оцениваются опубликованные действия, а не форма решения
конкретного эталона. Числа баллов, веса и попытки здесь не назначаются.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Количество и значения действительных корней соответствуют знаку D и допуску. | Запуск и сопоставление значений с условием. |
| Ограничения и состояние | Точный знак D, допустимый диапазон коэффициентов и произвольный порядок двух корней сохранены. | Вывод, исходное состояние и разбор объявленных границ. |
| Обязательные приёмы | Конкретная формула или API не обязательны; корни вычисляются как вещественные. | Исходник; правильный вывод сам по себе не доказывает приём. |
| Объяснение решения и границы | Объяснены три случая D и типы промежуточных выражений. | Предметное объяснение по собственному исходнику и примерам. |
| Воспроизводимость предъявления | Показаны положительный, нулевой и отрицательный D с аргументами запуска. | Исходники и повторяемая команда запуска на JDK 25. |

Публичные наблюдения помогают увидеть часть результата; они не заменяют
чтение обязательных приёмов и объяснение. Самостоятельный большой отчёт,
новые API или требования из соседних карточек не добавляются.

## Уточнение для новой редакции

Содержание исходной рубрики сохраняется; для новых решений свободный запуск/оформление заменены только явно опубликованными требованиями актуальной карточки. Прежний законный код проверяется по исходному договору в `historical-contract.md`. Автоматическая часть — 80%, ручная часть — 20%; API и demo баллов не дают.

- Объяснение всех трёх случаев D, типов промежуточных выражений и соблюдения допуска.
- Показ положительного, нулевого и отрицательного D.
