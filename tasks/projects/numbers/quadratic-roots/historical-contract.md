## Учебный результат и интерфейс

Различение трёх случаев дискриминанта и численное представление действительных корней.

Имена классов, пакеты, методы, видимость, static и допустимая форма запуска свободны. `Main` в README — пример, не новый API.

## Вход, результат и границы

Применяется принятое уточнение фазы 1 из author-contracts, пункт quadratic-roots: ровно три целых коэффициента a,b,c в [-10000,10000], a!=0, переданы args. Корни вещественные. Знак D определяется точно для этих исходных целых; D<0 — смысловое сообщение об отсутствии действительных корней, D=0 — один корень, D>0 — два в любом порядке. Каждый выведенный корень r сравнивается с математическим x по |r−x|<=1e-8+1e-12*|x|.

## Допустимые решения и ограничения наблюдения

Уточнение заменяет прежнее неопределённое множество конечных вещественных коэффициентов. Не расширять вход к a=0, дробным коэффициентам, NaN/Infinity, произвольной длине или некорректным args. Вычислительный способ, типы, имена, пакеты и форма запуска свободны. Не навязывать единственную формулу, порядок двух корней, точный текст отсутствия корней или число знаков. В принятых границах max b²=100000000, |4ac|<=400000000, |D|<=500000000; точность знака можно обеспечить разными допустимыми способами. Готовый корневой API не вводится.

Преподаватель проверяет объяснение трёх случаев, типы промежуточных выражений и точность результата. Свободное оформление оценивается по смыслу; технический клиент не подменяет имена ради проверяющего клиента.
