# Рубрика: Сумма и произведение аргументов

Преподавательский документ. ID: `exr-numbers-argument-sum-product`.
SHA256 условия: `0f69e41b9052894e43ba052b127131cabf2307ff8dc8bc932a34cd29d79d0894`.
Основа — `teacher/common/rubric-template.md`; полный договор — соседний
`contract.md`. Оцениваются опубликованные действия, а не форма решения
конкретного эталона. Числа баллов, веса и попытки здесь не назначаются.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Сумма и произведение верны для допустимых long, в том числе пустого набора. | Запуск и сопоставление значений с условием. |
| Ограничения и состояние | Все аргументы учитываются; ноль в наборе отличается от отсутствия аргументов. | Вывод, исходное состояние и разбор объявленных границ. |
| Обязательные приёмы | Аргументы разбираются как long, требование конкретного алгоритма отсутствует. | Исходник; правильный вывод сам по себе не доказывает приём. |
| Объяснение решения и границы | Объяснены начальные значения и промежуточные типы. | Предметное объяснение по собственному исходнику и примерам. |
| Воспроизводимость предъявления | Обычный и пустой запуск воспроизводимы с выбранной студентом формой main. | Исходники и повторяемая команда запуска на JDK 25. |

Публичные наблюдения помогают увидеть часть результата; они не заменяют
чтение обязательных приёмов и объяснение. Самостоятельный большой отчёт,
новые API или требования из соседних карточек не добавляются.

## Уточнение для новой редакции

Содержание исходной рубрики сохраняется; для новых решений свободный запуск/оформление заменены только явно опубликованными требованиями актуальной карточки. Прежний законный код проверяется по исходному договору в `historical-contract.md`. Автоматическая часть — 80%, ручная часть — 20%; API и demo баллов не дают.

- Разбор long, типы промежуточных выражений и объяснение нейтральных 0/1.
- Показ обычного и пустого запуска по своему исходнику.
