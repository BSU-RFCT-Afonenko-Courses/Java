# Предметный договор: Сумма и произведение аргументов

Действующая карточка: [условие](../../../bank/numbers.qmd#exr-numbers-argument-sum-product). Предметная дельта пяти задач написана отдельным Astra/high автором и принята другим Astra/high рецензентом; техническую реализацию отдельно проверяет Sol/high. Исходный договор сохранён в `historical-contract.md`.

Учебная цель: Разбор аргументов long и вычисление суммы и произведения, включая пустой набор.

Класс запуска Main без пакета, все законные формы main для обычного запуска JDK 25. Дополнительные обязательные методы отсутствуют. Алгоритм и вспомогательные классы свободны. Условие и канонический стартер задают обязательную часть интерфейса.

Полный набор: 7 равновесных случаев, 80% автоматических и 20% ручных; API и две открытые проверки вне знаменателя. Прежние зачёты/код сохраняются по прежней редакции.
