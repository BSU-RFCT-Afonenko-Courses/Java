# Сумма и произведение аргументов

Разместите исходники в `src/main/java`. Классы, пакеты, вспомогательные
методы и допустимую форму запуска выберите самостоятельно.

Нужен JDK 25. Из каталога с этим README и папкой `src` скомпилируйте
все Java-исходники под `src/main/java`, включая вложенные пакеты.

В Linux, Bash:

```bash
find src/main/java -type f -name '*.java' -exec javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java {} +
```

В PowerShell 7:

```powershell
$sources = @(Get-ChildItem -LiteralPath 'src/main/java' -Recurse -File -Filter '*.java' |
    ForEach-Object { $_.FullName })
javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java $sources
```

Для выбранного класса `Main` без пакета примеры запуска имеют вид:

```console
java -cp out Main 3 -2 4
java -cp out Main
```

Подставьте фактическое полное имя своего класса. Имя `Main` не является
требованием. Первый запуск показывает сумму `5` и произведение `-24`,
второй — сумму `0` и произведение `1`. Каждое число передаётся отдельным
аргументом; стандартный ввод для чисел не используется.
Оформление двух результатов выберите самостоятельно.

После изменения исходников повторите компиляцию. `out` создаётся
при компиляции и в исходный комплект не включается.

После запуска решения выполните публичную самопроверку по инструкциям
в предоставленном [CHECKS.md](CHECKS.md).

Открытые проверки в `src/test/java` можно адаптировать к допустимому
API решения; пример привязки находится в `src/test/java/PublicBinding.java`.
Его имена и вид результата не задают дополнительных требований.
Для другого допустимого API согласуйте с преподавателем обычную
Java-привязку. Если локальные или закрытые элементы недоступны отдельному
проверяющему классу, предъявите их работу и исходник преподавателю.
Отсутствие готовой привязки само по себе не означает ошибку в решении.

Два открытых наблюдения помогают проверить результат. Обязательные
приёмы, исходник и объяснение оценивает преподаватель.

Покажите запуск с числами и без аргументов. Объясните выбор начальных
значений суммы и произведения и тип промежуточных вычислений.

Предъявите исходники и демонстрацию. Объяснение проводится по коду
и результатам запуска; дополнительный письменный отчёт не требуется.
