## Учебный результат и интерфейс

Разбор целых аргументов long и вычисление двух агрегатов, включая пустой набор.

Имена классов, пакеты, методы, видимость, static и допустимая форма запуска свободны. `Main` в README — пример, не новый API.

## Вход, результат и границы

Каждый аргумент командной строки — корректно записанное long. Данные гарантируют, что все промежуточные результаты помещаются в long. Требуется вычислить сумму и произведение; для пустого набора соответственно 0 и 1. Для 3,-2,4 — сумма 5, произведение -24. Стандартный ввод для этих чисел не используется.

## Допустимые решения и ограничения наблюдения

Разбор как long обязателен; ограничение значениями int недопустимо. Конкретный парсер, цикл или Stream, хранение аргументов, имена, пакеты и допустимая форма main свободны. Формат результата свободен по исходному README/examples: подписи и осмысленное представление допустимы, нельзя тестировать единственные две голые строки или единственный порядок сериализации. Арифметическое переполнение и некорректный текст вне опубликованной области. Старые TaskBinding.run/String... и Study.compute — интерфейсы старого проверяющего клиента, не API студента.

Сопоставить тип разбора и выражений с long; попросить объяснить 0 и 1 как начальные значения. Для свободного запуска технический исполнитель использует объявленную команду либо преподавательское наблюдение, не фиксирует Study/Main/RunExample.
