# Рубрика: Случайные числа в консоли

Преподавательский документ. ID: `exr-numbers-random-console-values`.
SHA256 условия: `71370d3b8faed4bb97cf301a6547a7781348fb6588ad91d524eca1a0bbcfe800`.
Основа — `teacher/common/rubric-template.md`; полный договор — соседний
`contract.md`. Оцениваются опубликованные действия, а не форма решения
конкретного эталона. Числа баллов, веса и попытки здесь не назначаются.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Выведено десять требуемых значений, обе формы сохраняют один порядок. | Запуск и сопоставление значений с условием. |
| Ограничения и состояние | Каждое число принадлежит 0..99; во второй форме одно число в строке. | Вывод, исходное состояние и разбор объявленных границ. |
| Обязательные приёмы | Использованы java.util.Random, seed 42 и nextInt(100); способ хранения свободен. | Исходник; правильный вывод сам по себе не доказывает приём. |
| Объяснение решения и границы | Объяснены воспроизводимость генератора и исключённая верхняя граница nextInt. | Предметное объяснение по собственному исходнику и примерам. |
| Воспроизводимость предъявления | Запуск и показ обеих форм воспроизводимы; имена классов и форма запуска не фиксируются. | Исходники и повторяемая команда запуска на JDK 25. |

Публичные наблюдения помогают увидеть часть результата; они не заменяют
чтение обязательных приёмов и объяснение. Самостоятельный большой отчёт,
новые API или требования из соседних карточек не добавляются.

## Уточнение для новой редакции

Содержание исходной рубрики сохраняется; для новых решений свободный запуск/оформление заменены только явно опубликованными требованиями актуальной карточки. Прежний законный код проверяется по исходному договору в `historical-contract.md`. Автоматическая часть — 80%, ручная часть — 20%; API и demo баллов не дают.

- По исходнику проверить java.util.Random, seed 42, nextInt(100); правильная константная распечатка не доказывает этот приём.
- Объяснение воспроизводимости, верхней исключённой границы и сохранения порядка.
