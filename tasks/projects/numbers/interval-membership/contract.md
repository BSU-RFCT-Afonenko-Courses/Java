## Учебный результат и данные

Студент различает включённую и исключённую границу промежутка
и связывает её с результатом строгого или нестрогого сравнения.
JDK 25, точка входа `Main.main(String[] args)`.
Три токена stdin — значения типа `int` в порядке `n m k`;
выполняется `n < m`. Формат входа корректен.

Результат — четыре значения `true` или `false` в порядке
`(n, m]`, `[n, m)`, `(n, m)`, `[n, m]`. Круглая скобка исключает
границу, квадратная включает. Результаты разделяются пробельными
символами; подписи и приглашения не выводятся.

## Допустимые решения и наблюдение

Свободны чтение, вспомогательные методы, ветвления и способ вычисления.
Условие не требует `&&`, конкретного числа сравнений или отдельного
метода для каждого интервала. Некорректный ввод и `n >= m`
не проверяются. Значения не ограничиваются малыми числами.

Техническая проверка наблюдает четыре логических результата:
для нижней границы — `false true false true`, для верхней —
`true false false true`, для внутренней точки — четыре `true`,
для любой внешней — четыре `false`. Существенны также соседние
целые границы, когда внутреннего целого нет, и крайние значения `int`.
Если вычисление использует разности, переполнение не должно менять
принадлежность. Предпочтительный алгоритм вместо этого свойства
проверка не навязывает.

Преподаватель получает показ обеих границ, внутренней точки и значений
снаружи. По выбранному сравнению студент объясняет, почему результат
на границе отличается. Внутреннюю точку для демонстрации студент
выбирает у интервала, где такая целая точка существует.
Дополнительный письменный отчёт не требуется.
