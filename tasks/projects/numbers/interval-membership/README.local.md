Сохраните опубликованную точку входа `Main.main(String[] args)`. Вспомогательные классы и методы, способ чтения и вычислений выбирайте самостоятельно. Заготовка компилируется и проходит API-допуск, но предметное вычисление не реализовано.

`gradle test` запускает открытые примеры. Они и API-допуск не входят в оценочный знаменатель. Полный достоверный набор содержит 11 самостоятельных равновесных случаев: автоматическая часть равна `80 × passed/total` процентов максимума. Ручные 20% проверяются отдельно по условию. Ошибка компиляции решения или нарушение опубликованного API дают ноль текущей попытки до JUnit; инфраструктурный отказ оставляет результат неустановленным.

Прежний признанный полный зачёт и успешный код сохраняются по своей редакции.

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `src/main/java/Main.java`

Форма PrairieLearn: штатные редакторы. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
В полях ответа пути исходников задаются относительно `src/main/java`.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.
