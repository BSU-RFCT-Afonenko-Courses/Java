# Рубрика: принадлежность интервалам

ID: `exr-numbers-interval-membership`. Редакция условия и её SHA256 указаны
в [контракте](contract.md). Основа — `teacher/common/rubric-template.md`.
Критерии не задают баллов и весов.

| Часть | Критерий | Достаточное свидетельство |
|---|---|---|
| Результат на допустимых данных | Четыре результата соответствуют четырём интервалам в объявленном порядке | Обе границы, внутренняя точка и значения по обе стороны интервала |
| Ограничения и состояние | Включение концов различается правильно; полный диапазон `int` не нарушает сравнения | Разбор используемых сравнений и существенного граничного случая |
| Обязательные приёмы | Соблюдены JDK 25 и `Main.main`; особый логический оператор не обязателен | Компиляция и исходник |
| Объяснение решения и границы | Студент связывает каждую скобку с включением соответствующего конца | Объяснение результата при `k = n` и при `k = m` |
| Воспроизводимость предъявления | Исходники и передача трёх чисел воспроизводят результат | Повторная компиляция и запуск по README |

Смысловой ориентир: `n < m` гарантирует порядок концов, но не существование
целого между ними. При `n = -2`, `m = 4` внутренняя точка `0` принадлежит
всем четырём интервалам; `-3` и `5` не принадлежат ни одному.
На нижней границе включение определяется левой скобкой, на верхней —
правой. Перестановка результатов не исправляется их общим количеством.
Прямые сравнения, корректные ветвления и другие эквивалентные способы
принимаются без требования повторять преподавательскую запись.

Автоматическая часть — 80%, ручная часть — 20%. API-допуск и открытые примеры баллов не дают. Ручные критерии исходной рубрики сохранены.
