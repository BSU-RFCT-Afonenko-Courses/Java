# Предметный договор: Таблица истинности со значениями 1 и 0

Действующая карточка: [условие](../../../bank/numbers.qmd#exr-numbers-binary-truth-table). Предметная дельта пяти задач написана отдельным Astra/high автором и принята другим Astra/high рецензентом; техническую реализацию отдельно проверяет Sol/high. Исходный договор сохранён в `historical-contract.md`.

Учебная цель: Представление результатов логических операций числами 1 и 0.

Класс запуска Main без пакета, все законные формы main для обычного запуска JDK 25. Дополнительные обязательные методы отсутствуют. Алгоритм и вспомогательные классы свободны. Условие и канонический стартер задают обязательную часть интерфейса.

Полный набор: 4 равновесных случаев, 80% автоматических и 20% ручных; API и две открытые проверки вне знаменателя. Прежние зачёты/код сохраняются по прежней редакции.
