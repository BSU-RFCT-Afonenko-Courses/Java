# Рубрика: Таблица истинности со значениями 1 и 0

Преподавательский документ. ID: `exr-numbers-binary-truth-table`.
SHA256 условия: `079105df5d3fbcefe01d34e8a55d88370049a9fb8a352ba65b249d483008d9cd`.
Основа — `teacher/common/rubric-template.md`; полный договор — соседний
`contract.md`. Оцениваются опубликованные действия, а не форма решения
конкретного эталона. Числа баллов, веса и попытки здесь не назначаются.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Все четыре сочетания и результаты AND/OR/XOR/NOT представлены верно. | Запуск и сопоставление значений с условием. |
| Ограничения и состояние | Истина — 1, ложь — 0; NOT относится к P, таблица содержит заголовок и четыре строки. | Вывод, исходное состояние и разбор объявленных границ. |
| Обязательные приёмы | Особый оператор преобразования и формат табуляции не обязательны. | Исходник; правильный вывод сам по себе не доказывает приём. |
| Объяснение решения и границы | Студент объясняет логические результаты и их числовое представление. | Предметное объяснение по собственному исходнику и примерам. |
| Воспроизводимость предъявления | Целая таблица демонстрируется с выбранным запуском, исходники доступны. | Исходники и повторяемая команда запуска на JDK 25. |

Публичные наблюдения помогают увидеть часть результата; они не заменяют
чтение обязательных приёмов и объяснение. Самостоятельный большой отчёт,
новые API или требования из соседних карточек не добавляются.

## Уточнение для новой редакции

Содержание исходной рубрики сохраняется; для новых решений свободный запуск/оформление заменены только явно опубликованными требованиями актуальной карточки. Прежний законный код проверяется по исходному договору в `historical-contract.md`. Автоматическая часть — 80%, ручная часть — 20%; API и demo баллов не дают.

- Объяснение соответствия логических результатов значениям 1/0, включая NOT(P).
- Показ всей таблицы по своему исходнику.
