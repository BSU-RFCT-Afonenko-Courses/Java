## Учебный результат и интерфейс

Применение условного вычисления && для безопасной проверки целочисленного частного.

Задана точка входа `Main.main(String[] args)`. Остальные классы, методы и разбиение свободны.

## Вход, результат и границы

В stdin два int: числитель и делитель; либо пустой завершённый ввод, означающий демонстрационную пару 7,0. Результат true только при ненулевом делителе и положительном результате деления int, иначе false. Для 7,2 — true, для 1,2 — false, для 7,0 и EOF — false без ArithmeticException.

## Допустимые решения и ограничения наблюдения

Обязателен &&, причём делитель проверяется до деления. Подмена условного вычисления обработкой ArithmeticException, только вложенным if или & не выполняет учебный приём, даже при верном выводе. Не навязывать имена локальных переменных и форму вспомогательных методов. Весь диапазон int сохраняется: деление Integer.MIN_VALUE на -1 в Java даёт Integer.MIN_VALUE, поэтому проверка ложна; нельзя молча заменить операцию математическим частным long. Некорректный текст, неполная пара и NaN вне договора.

По исходнику и объяснению проверить порядок операндов &&, пропуск деления при нуле и целочисленное усечение. Автоматический false не доказывает наличие &&.
