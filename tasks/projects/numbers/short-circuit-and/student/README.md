# Проверка положительного частного

Определите, является ли целочисленное частное положительным, если операция допустима. При нулевом делителе результат проверки считается ложным.

Вход и результат: стандартный ввод содержит два числа типа `int`: числитель и делитель. Выведите `true`, если делитель не равен нулю и целочисленное частное положительно; иначе — `false`. Для `7 0` результат — `false` без исключения, для `7 2` — `true`, для `1 2` — `false`. При пустом вводе продемонстрируйте пару `7 0`.

Реализуйте условие с помощью `&&`, чтобы применить правило условного вычисления операндов. Объясните порядок проверок для нулевого делителя.

## Исходник и запуск

В `src/main/java/Main.java` находится заготовка с `TODO`. Успешная
компиляция заготовки не означает, что решение готово: требуемое поведение
ещё нужно реализовать. Сохраните
точку входа `Main.main(String[] args)`; вспомогательные методы и классы
разрешены.

Откройте каталог, содержащий этот `README.md` и `src`. Выполните команды
инструментами JDK 25. После изменения исходника повторите компиляцию:

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/*.java
printf '7 0' | java -cp out Main
printf '1 2' | java -cp out Main
printf '' | java -cp out Main
```

Все три запуска должны дать `false`. В первом и третьем случаях деление на ноль не должно выполняться; во втором целочисленное частное равно нулю. Пустой завершённый ввод включает предусмотренную условием демонстрацию `7 0`.

В примерах вход передаётся командой `printf` оболочки POSIX (например, bash).
В другой оболочке можно сохранить тот же ввод в файле UTF-8 и перенаправить
его в программу. `printf ''` создаёт пустой поток с EOF.

Публичные примеры находятся в `src/test/java/PublicExamplesTest.java`
и используют JUnit 5. Они охватывают часть случаев; полные требования
задаёт условие выше. Компиляция не проверяет соответствие поведения
программы условию.
