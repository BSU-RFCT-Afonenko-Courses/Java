# Позиционная запись целого числа

Получите позиционную запись неотрицательного целого числа в системе
с основанием от 2 до 36. Число в десятичной записи и основание передайте
аргументами командной строки. Цифры со значениями от 10 до 35 обозначаются
последовательными латинскими буквами; допустим единообразный верхний
или нижний регистр. Результат не содержит ведущих нулей, кроме записи самого
нуля `0`. Например, число `31` при основании `16` даёт `1F` или `1f`,
при основании `2` — `11111`. Диапазон исходного числа не ограничен
типом `long`; представление должно сохранять введённое целое значение.
Покажите также преобразование нуля.

## Исходники и запуск

Используйте JDK 25. Классы, пакеты, вспомогательные методы и допустимую
форму `main` выберите самостоятельно. `src/RunExample.java` содержит
заготовку запуска, которую можно заменить; её метод выбрасывает
`UnsupportedOperationException` с просьбой реализовать условие.
`src/Решение.java` содержит только комментарии. Поэтому успешная
компиляция исходной заготовки ещё не означает готового решения.

Разместите свои исходники в `src`. Если вы сохраняете имя `RunExample`
и файлы непосредственно в `src`, выполняйте из каталога этого `README.md`:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out RunExample 31 16
java -cp out RunExample 0 36
```

Первый запуск должен дать `1F` либо `1f`, второй — `0`. Оба исходных значения передаются после имени класса. Порядок аргументов: число в десятичной записи, затем основание.

Если выбраны другое имя или пакет, укажите в команде полное имя своего
класса; при другой структуре каталогов перечислите нужные исходники
в команде `javac`. Требования к входу и результату от этого не меняются.
Число и основание передаются двумя отдельными аргументами запуска.
Дополнительные примеры: [examples/README.md](examples/README.md).
