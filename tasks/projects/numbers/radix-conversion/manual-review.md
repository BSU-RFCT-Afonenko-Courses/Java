# Рубрика: Позиционная запись целого числа

Преподавательский документ. ID: `exr-numbers-radix-conversion`.
SHA256 условия: `fac0b9cf0c2beada1963f3ef4df216e728a0603c1701a12f871fb47d55f4700b`.
Основа — `teacher/common/rubric-template.md`; полный договор — соседний
`contract.md`. Оцениваются опубликованные действия, а не форма решения
конкретного эталона. Числа баллов, веса и попытки здесь не назначаются.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Результат представляет исходное целое в выбранном основании. | Запуск и сопоставление значений с условием. |
| Ограничения и состояние | Основания 2 и 36 допустимы; нуль записывается как 0, ведущих нулей нет, регистр един. | Вывод, исходное состояние и разбор объявленных границ. |
| Обязательные приёмы | Сохранение числа произвольной длины обязательно; библиотечные и самостоятельные решения допустимы. | Исходник; правильный вывод сам по себе не доказывает приём. |
| Объяснение решения и границы | Студент объясняет чтение и преобразование без потери значения. | Предметное объяснение по собственному исходнику и примерам. |
| Воспроизводимость предъявления | Показаны нуль и число больше Long.MAX_VALUE; выбранная команда запуска воспроизводима. | Исходники и повторяемая команда запуска на JDK 25. |

Публичные наблюдения помогают увидеть часть результата; они не заменяют
чтение обязательных приёмов и объяснение. Самостоятельный большой отчёт,
новые API или требования из соседних карточек не добавляются.

## Уточнение для новой редакции

Содержание исходной рубрики сохраняется; для новых решений свободный запуск/оформление заменены только явно опубликованными требованиями актуальной карточки. Прежний законный код проверяется по исходному договору в `historical-contract.md`. Автоматическая часть — 80%, ручная часть — 20%; API и demo баллов не дают.

- По исходнику и объяснению проверить сохранение целого при чтении и преобразовании.
- Показ нуля и числа выше Long.MAX_VALUE.
