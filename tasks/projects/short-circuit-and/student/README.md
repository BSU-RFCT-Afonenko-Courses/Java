# Проект: short-circuit-and

Покажите в работающей Java-программе, как короткозамкнутая операция И предотвращает ошибку целочисленного деления на ноль.

Протокол проверки: стандартный ввод содержит два числа типа `int`: числитель и делитель. Выведите `true`, если делитель не равен нулю и целочисленное частное положительно; иначе — `false`. Для `7 0` результат — `false` без исключения, для `7 2` — `true`, для `1 2` — `false`. При пустом вводе продемонстрируйте пару `7 0`.

Критерий преподавательской проверки: защиту реализуйте именно оператором `&&` и объясните, почему правая часть не вычисляется при нулевом делителе. Автотесты проверяют результат и отсутствие стандартной JVM-диагностики неперехваченного исключения. Они не доказывают использование `&&` и отсутствие скрытых или перехваченных исключений в программе.

Соберите `src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out src/main/java/*.java`, затем запустите `java -cp out Main`. Для дополнительного входа передайте текст через stdin; без входа закройте stdin (EOF). Java 25. Вспомогательные методы и классы разрешены.

Публичные примеры: `src/test/java/PublicExamplesTest.java`. Их можно запускать JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.
