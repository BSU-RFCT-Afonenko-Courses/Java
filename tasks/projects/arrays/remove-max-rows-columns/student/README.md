# Удаление строк и столбцов с максимумом

В квадратной матрице `int[][]` найдите общее максимальное значение.
Исключите все строки и столбцы, содержащие хотя бы одно его вхождение.
Сохраните взаимный порядок оставшихся строк и столбцов. Покажите размеры
и содержимое полученной матрицы.

Обязательный исходный пример имеет размер 3×3:

```text
-3  0  3
 2 -1  0
 1  3 -2
```

Все позиции максимума определяются в исходной матрице. Возможны результаты
без строк или без столбцов; покажите также такой случай. Количество
оставшихся строк и количество оставшихся столбцов имеют самостоятельный
смысл даже при отсутствии элементов результата.

## Сборка и демонстрация

Используйте JDK 25. Создайте исходные файлы в `src/` и скомпилируйте их:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
```

Затем выполните `java -cp out имя.класса`, подставив полное имя своего
класса запуска. Имя класса, пакет, методы, способ задания исходных данных
и оформление демонстрации выбирайте самостоятельно.
Ожидаемые результаты приведены в [примерах](examples/README.md).
