Для необязательной сборки нужен JDK 25 и Gradle 9.8. Откройте каталог с `settings.gradle` как Gradle-проект. `gradle classes` компилирует исходники; `gradle --console=plain -q run -PmainClass=ИмяКласса` запускает выбранный демонстрационный класс.

У задания полностью ручная оценка. Здесь нет оценочных автотестов и API-допуска. Успешная сборка не подтверждает решение; предъявите преподавателю исходники, результат и воспроизводимую команду по полному условию. JUnit и внешние зависимости не нужны. Не сдавайте `build`, `.gradle` и кеши IDE.
