# Ручная часть sort-array

Ручные 20%: Соседние сравнения/обмены именно пузырькового алгоритма; Показ исходного массива; Завершение проходов, обычный и короткие случаи.

Автоматические случаи проверяют значения и опубликованные свойства результата. Ручная часть требует исходников и собственной демонстрации согласно полному условию. Библиотечная сортировка может пройти все числовые проверки, но не удовлетворяет требованию пузырькового приёма. Нет дополнительных требований к helper API, конструкторам Study, checked throws, форме main или внутреннему хранению. Редкое полное ручное исключение требует сохранённого индивидуального основания по решению 81.
