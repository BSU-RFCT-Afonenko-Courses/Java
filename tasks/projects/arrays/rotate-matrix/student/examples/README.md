# Поворот: примеры

Исходная матрица:

```text
-3  0  3
 2 -1  0
 1  3 -2
```

Поворот на 90 градусов против часовой стрелки:

```text
 3  0 -2
 0 -1  3
-3  2  1
```

Поворот на 180 градусов:

```text
-2  3  1
 0 -1  2
 3  0 -3
```

Поворот на 270 градусов против часовой стрелки:

```text
 1  2 -3
 3 -1  0
-2  0  3
```

Каждый результат соответствует повороту исходной матрицы на указанный угол.
После вычисления исходные числа и их позиции сохраняются.
