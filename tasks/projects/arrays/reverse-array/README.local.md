Заготовка содержит только незавершённый `Main.main(String[] args)`. Реализуйте чтение `n` и `n` целых значений, вывод в обратном порядке и выбранный вами демонстрационный массив при пустом завершённом stdin. `n=0` означает пустой массив и пустой числовой вывод; это отдельная ветвь от пустого ввода.

По желанию используйте `gradle test` для открытого примера `4 7 -2 7 0` → `0 7 -2 7`. Пример и API-допуск не входят в оценочный знаменатель. После реализации можно запустить `gradle --console=plain -q run` с входом `0`, `1 -8` либо собственным массивом. Запуск без ввода проверяет выбранный вами пример; его значения не навязываются тестами.

Автоматические 80% оценивают отдельные случаи вывода. Ручные 20% по сданному коду проверяют использование массива, отсутствие изменений его компонентов в ходе вывода и правильность ветви демонстрационного массива. Дополнительный отчёт, печать исходного массива и доказательство запуска самопроверки не требуются.
