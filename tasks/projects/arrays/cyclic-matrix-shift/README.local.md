Каноническая заготовка содержит обязательный базовый API и незавершённое вычисление. Сохраните опубликованные объявления; вспомогательные классы, пакеты и методы, форму `main` и собственную демонстрацию выберите самостоятельно. Готового алгоритма в заготовке нет.

Для компиляции достаточно JDK 25: `javac -d out src/main/java/*.java`. Gradle необязателен; `gradle test` запускает один открытый пример. Незавершённая заготовка компилируется и проходит API-допуск, но пример завершается исключением. Собственный запуск: `java -cp out ИмяКласса` или `gradle -PmainClass=ИмяКласса run`.

Полный достоверный набор содержит 27 самостоятельных равновесных случаев: автоматическая часть равна `80 × passed/total` процентов максимума. API и открытый пример не входят в знаменатель; ручные 20% оцениваются отдельно по условию. Собственная ошибка компиляции и нарушение опубликованного API новой редакции дают ноль текущей попытки до JUnit. Инфраструктурный отказ или неполный отчёт оставляют результат неустановленным.

Исторически законные решения оцениваются по своей редакции, признанный полный зачёт сохраняется. Полная ручная оценка допустима лишь как индивидуально обоснованное исключение, когда законное решение невозможно достоверно проверить без изменения его кода; сбой grader и игнорирование нового API такого основания не дают.
