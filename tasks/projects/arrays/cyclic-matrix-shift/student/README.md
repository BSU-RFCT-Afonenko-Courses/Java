# Циклический сдвиг матрицы

Выполните циклический сдвиг квадратной матрицы `int[][]` на неотрицательное
число позиций `k`: вправо, влево, вверх или вниз. При горизонтальном сдвиге
сохраняется номер строки, при вертикальном — номер столбца. Элемент,
вышедший за край, возвращается с противоположной стороны. Покажите результат.

Демонстрационная матрица имеет размер 3×3:

```text
-3  0  3
 2 -1  0
 1  3 -2
```

Для `k = 1` покажите все четыре направления. Преобразование должно учитывать
и произвольное неотрицательное `k`, включая несколько полных оборотов;
число строк и столбцов сохраняется.

## Сборка и демонстрация

Используйте JDK 25. Создайте исходные файлы в `src/` и скомпилируйте их:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
```

Затем выполните `java -cp out имя.класса`, подставив полное имя своего
класса запуска. Имя класса, пакет, методы, способ задания исходных данных
и оформление демонстрации выбирайте самостоятельно.
Ожидаемые результаты приведены в [примерах](examples/README.md).
