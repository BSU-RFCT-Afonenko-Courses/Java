# Ручная часть array-average

Механический перенос действующей карточки `tasks/bank/arrays.qmd#exr-arrays-array-average` и исходной авторской рубрики. Автоматические 80% составляют самостоятельные равновесные случаи `ContractTest`; API-допуск и открытые `DemoTest` не входят в знаменатель. Ручные 20% проверяют следующие свойства.

Участие массива и всех его десяти значений в расчёте, допустимый собственный демонстрационный набор и обе ветви запуска. Контроль without-array печатает правильные результаты без массива и потому не проходит ручной критерий.

Нет обязательного вспомогательного API или нового отчёта. Проверка допуска использует выбор main JDK 25 и допускает разрешённый instance main(String[]); корректный вывод с последующим System.exit не отвергается из-за кода завершения. API mismatch не даёт студенту нулевой предметный результат: зависимые проверки ещё не запускались. Сбой инфраструктуры/неполный отчёт также не оцениваются как student0.
