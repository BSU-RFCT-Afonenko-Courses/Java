Реализуйте вычисление среднего десяти чисел с участием массива. При пустом завершённом stdin используйте выбранные вами десять конечных демонстрационных значений из области условия. Значения этого массива не навязываются проверкой.

Заготовка Main.main(String[] args) компилируется, но не реализует решение. Алгоритм и вспомогательные классы разработайте самостоятельно. Необязательные открытые примеры запускаются командой `gradle test`; они и API-допуск не входят в оценочный знаменатель. Автоматические 80% проверяют отдельные равновесные случаи результата; ручные 20% — исходник и объяснение по условию. Корректный вывод сам по себе не доказывает соблюдение приёмов. Дополнительный письменный отчёт не требуется.
