# Полностью ручная оценка saddle-points

100% оцениваются преподавателем по действующему условию: одновременные нестрогие минимум строки и максимум столбца, подсчёт каждой позиции при равенстве; фиксированный результат 0; объяснение отклонённого кандидата с одним выполненным условием. Исходники и воспроизводимый запуск обязательны. Автотестов, API-допуска, автоматических баллов и фиктивного PASS нет.
