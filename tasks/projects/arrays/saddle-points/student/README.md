# Седловые точки матрицы

Разместите исходники под `src/main/java`. Имена классов, пакеты, методы
и форму `main` выберите самостоятельно. Подготовьте запуск демонстрации
с данными из условия.

Нужен JDK 25. Из каталога с этим README и папкой `src` скомпилируйте
все Java-исходники под `src/main/java`, включая вложенные пакеты.

В Linux, Bash:

```bash
find src/main/java -type f -name '*.java' -exec javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java {} +
```

В PowerShell 7:

```powershell
$sources = @(Get-ChildItem -LiteralPath 'src/main/java' -Recurse -File -Filter '*.java' |
    ForEach-Object { $_.FullName })
javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java $sources
```

Запустите подготовленную демонстрацию. Для класса `Main` без пакета:

```text
java -cp out Main
```

`Main` здесь — пример. Подставьте полное имя выбранного класса запуска
и, если ваше решение их использует, свои аргументы. Укажите фактическую
команду запуска при предъявлении работы. Формат ввода и вывода свободен
в пределах условия.

После изменения исходников повторите компиляцию. `out` создаётся
при компиляции и в исходный комплект не включается.

Предъявите преподавателю фактические результаты двух открытых сценариев,
исходник и объяснение. Открытый клиент `src/test/java/PublicChecks.java`
и пример `src/test/java/PublicBinding.java` можно адаптировать к допустимому
API решения. Имена привязки и её вид результата не задают дополнительных требований.
Для другого допустимого API согласуйте с преподавателем обычную
Java-привязку. Недоступные отдельному клиенту элементы покажите
в своей демонстрации и исходнике. Отсутствие готовой привязки
само по себе не означает ошибку в решении.
Результаты с условием сопоставляет преподаватель; код завершения 0
клиента означает только завершённое предъявление.

Для подготовки показа используйте предоставленный
[PRESENTATION.md](PRESENTATION.md).

Покажите результат для фиксированной матрицы. Объясните совместное
выполнение двух нестрогих условий и учёт подходящих позиций.

Предъявите исходники и демонстрацию. Объяснение проводится по коду
и результатам работы; дополнительный письменный отчёт не требуется.
