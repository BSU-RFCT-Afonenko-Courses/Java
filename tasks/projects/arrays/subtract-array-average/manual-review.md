# Ручная часть subtract-array-average

Механический перенос действующей карточки `tasks/bank/arrays.qmd#exr-arrays-subtract-array-average` и исходной авторской рубрики. Автоматические 80% составляют самостоятельные равновесные случаи `ContractTest`; API-допуск и открытые `DemoTest` не входят в знаменатель. Ручные 20% проверяют следующие свойства.

Отдельный double[][] результата, отсутствие изменения исходной матрицы, дробные средние и объяснение поверхностного matrix.clone(). Контроль mutates-source сохраняет правильный stdout, но меняет исходные строки и потому не проходит ручной критерий.

Нет обязательного вспомогательного API или нового отчёта. Проверка допуска использует выбор main JDK 25 и допускает разрешённый instance main(String[]); корректный вывод с последующим System.exit не отвергается из-за кода завершения. API mismatch не даёт студенту нулевой предметный результат: зависимые проверки ещё не запускались. Сбой инфраструктуры/неполный отчёт также не оцениваются как student0.
