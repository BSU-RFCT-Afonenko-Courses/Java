Сохраните опубликованную точку входа `Main.main(String[] args)`. Способ чтения, алгоритм, вспомогательные классы и методы выбирайте самостоятельно. Заготовка компилируется и проходит API-допуск, но вычисление в ней не реализовано.

`gradle test` запускает два открытых примера. Они и API-допуск не входят в оценочный знаменатель. Полный достоверный набор содержит 8 самостоятельных равновесных случаев: автоматическая часть равна `80 × passed/total` процентов максимума. Ручные 20% проверяются отдельно по условию. Ошибка компиляции решения или нарушение опубликованного API дают ноль текущей попытки до JUnit; инфраструктурный отказ оставляет результат неустановленным.

Прежний признанный полный зачёт и успешный код сохраняются по своей редакции. Полная ручная оценка возможна только как индивидуально обоснованное исключение, если законное решение нельзя достоверно проверить без изменения его кода.

Имена пакетов сохраняются по заготовке: `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
В полях ответа пути исходников задаются относительно `src/main/java`.
