Для необязательной сборки в IDE нужны JDK 25 и установленный Gradle 9.8. Откройте извлечённый каталог с `settings.gradle` как Gradle-проект. Команда `gradle classes` компилирует исходники; `gradle -PmainClass=ИмяКласса run` запускает указанный класс и передаёт стандартный ввод.

Задание оценивается преподавателем полностью вручную. API-допуска и оценочных JUnit-тестов в этом проекте нет. Успех компиляции не подтверждает выполнение условия. Сдавайте свои исходники и команды запуска без `build`, `.gradle` и кешей IDE.
