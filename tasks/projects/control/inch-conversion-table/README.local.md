Для работы нужен JDK 25. Gradle 9.8 необязателен. Для рекурсивной компиляции: `find src/main/java -name "*.java" -print > sources.txt`, затем `javac -encoding UTF-8 -d out @sources.txt`; запуск — `java -cp out ИмяКласса`. Пакет указывается в полном имени класса.

Оценивание полностью ручное (100%). Дополнительные типы и вспомогательные методы внутри фиксированных файлов свободны; класс запуска заготовки сохраняется, законную форму запуска JDK 25 выберите самостоятельно. Алгоритм и демонстрацию разработайте самостоятельно.

`gradle classes` компилирует исходники; `gradle -PmainClass=ИмяКласса run` запускает выбранный класс. Команда `gradle test` не содержит оценочных тестов и не подтверждает выполнение задачи. Преподаватель оценивает исходники, действительную демонстрацию и объяснение по полному условию.

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `src/main/java/Main.java`

Форма PrairieLearn: штатные редакторы. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
Имена файлов ответа соответствуют указанным путям в комплекте.
