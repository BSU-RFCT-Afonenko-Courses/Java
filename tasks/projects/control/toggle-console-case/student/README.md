# Изменение регистра символов

Реализуйте программу в `src/main/java/Main.java`, сохранив точку входа
`Main.main(String[] args)`. Вспомогательные методы и классы разрешены.

Нужен JDK 25. Из каталога с этим README и папкой `src` скомпилируйте
все Java-исходники под `src/main/java`, включая вложенные пакеты.

В Linux, Bash:

```bash
find src/main/java -type f -name '*.java' -exec javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java {} +
```

В PowerShell 7:

```powershell
$sources = @(Get-ChildItem -LiteralPath 'src/main/java' -Recurse -File -Filter '*.java' |
    ForEach-Object { $_.FullName })
javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java $sources
```

Примеры запуска в Bash:

```bash
printf 'AБяz 👋🙂.' | java -cp out Main
printf '.' | java -cp out Main
printf '' | java -cp out Main
```

Первый запуск выводит текст `aБяZ 👋🙂`, дополнительный перевод строки,
число `2` и перевод строки. Каждый из двух остальных выводит пустую
строку, затем `0` с переводом строки. `printf` завершает передаваемый
поток; кириллица и эмодзи передаются в UTF-8. Ввод без точки
обрабатывается до EOF.

После изменения исходников повторите компиляцию. `out` создаётся
при компиляции и в исходный комплект не включается.

После запуска решения выполните публичную самопроверку по инструкциям
в предоставленном [CHECKS.md](CHECKS.md).

Два открытых наблюдения помогают проверить результат. Обязательные
приёмы, исходник и объяснение оценивает преподаватель.

Покажите ASCII-буквы рядом с кириллицей и эмодзи, точку в начале,
завершение по EOF и данные после точки. Объясните изменение счётчика
и применение разницы кодов только внутри указанных ASCII-диапазонов.

Предъявите исходники и демонстрацию. Объяснение проводится по коду
и результатам работы; дополнительный письменный отчёт не требуется.
