Сохраните запускаемый класс `Main` без пакета и запуск `java -cp out Main` без аргументов. Можно использовать любую форму `main`, допускаемую таким запуском в JDK 25. Алгоритм, чтение, вспомогательные методы и остальные классы выбирайте самостоятельно. В заготовке дана только пустая main-обвязка; предметный результат студент реализует сам.

`gradle test` запускает два прежних открытых наблюдения для самопроверки. API-допуск и самопроверка не дают баллов и не добавляются в оценочный знаменатель. Число самостоятельных равновесных случаев в полном достоверном наборе: 5. Автоматическая часть — `80 × passed/total` процентов максимума; ручные 20% оцениваются по исходнику, демонстрации и объяснению из условия. Ошибка компиляции решения или нарушение опубликованного API дают ноль текущей попытки до JUnit; инфраструктурный отказ оставляет результат неустановленным.

Новая обязанность имени запуска относится к новой редакции задания. Признанные зачёты, прежние ручные результаты и законные старые решения сохраняются. Индивидуальная полная ручная оценка требует основания по решению 81; отсутствие старой привязки или сбой grader такого основания не дают.
