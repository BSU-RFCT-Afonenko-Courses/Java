# Подсчёт слова с заданным правилом сравнения

Определите количество вхождений заданного слова в текст. При сравнении
игнорируйте регистр и считайте одинаковыми буквы в каждой из пар «е/ё» и «и/й».
Сравниваются целые слова: для поиска `"елка"` текст
`"Ёлка, елка; елками"` даёт `2`. Преобразования нужны только для сравнения;
исходный текст сохраняется. Если слов нет, результат равен нулю.

Слово — максимальная непустая последовательность латинских букв A–Z/a–z
или русских букв А–Я/а–я с Ё/ё. Искомое слово непустое и состоит из этих букв.
Во входном тексте также допустимы цифры 0–9, знаки препинания ASCII,
пробелы, табуляции и переводы строки; все они разделяют слова. Строки
существуют, текст может быть пустым. Каждая единица этого алфавита занимает
один `char`; составные сочетания Unicode в допустимый алфавит не входят.

## Сборка и демонстрация

Используйте JDK 25. Создайте исходные файлы в `src/` и скомпилируйте их:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
```

Затем выполните `java -cp out имя.класса`, подставив полное имя своего
класса запуска. Имя класса, пакет, методы, способ задания исходных данных
и оформление демонстрации выбирайте самостоятельно.
Ожидаемые результаты приведены в [примерах](examples/README.md).
