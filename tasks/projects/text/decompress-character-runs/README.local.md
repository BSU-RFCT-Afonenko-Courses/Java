Реализуйте операцию в каноническом стартере, сохранив её базовый интерфейс. Вспомогательные типы размещайте внутри перечисленных исходников; их устройство выберите самостоятельно. Подготовьте демонстрацию с данными из полного условия и укажите команду её запуска. Обязательный Main не требуется.

`gradle test` выполняет две открытые самопроверки. API-допуск и demo не дают баллов. Полный закрытый набор содержит 7 самостоятельных равновесных случаев; автоматические 80% рассчитываются только по завершённому достоверному passed/total. Ручные 20% проверяют исходник, приёмы и объяснение полного условия. Инфраструктурный отказ оставляет результат неустановленным. Прежние признанные зачёты, код и ручная часть сохраняются по их редакции.

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `src/main/java/Study.java`

Форма PrairieLearn: штатные редакторы. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
В полях ответа пути исходников задаются относительно `src/main/java`.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.
