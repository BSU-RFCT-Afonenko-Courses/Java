# Самые длинные и короткие слова

Слово — максимальная непрерывная последовательность букв A–Z/a–z
и А–Я/а–я с Ё/ё. Длина — количество букв; в этом алфавите каждая занимает
один `char`. Цифры, пробельные символы и пунктуация разделяют слова.
Допустимый алфавит описан ниже.

Найдите и напечатайте все слова максимальной и все слова минимальной
длины в тексте. Выведите два подписанных списка: сначала максимумы, затем минимумы;
в каждом сохраняйте порядок появления и все повторные вхождения. Если все
слова одной длины, оба списка совпадают. Для `"кот, дом и кот!"` максимумы —
`кот, дом, кот`, минимум — `и`; без слов выведите «Слов нет».

Оформите отдельную программу, запускаемую командой `java Main` в Java 25. Форму точки входа выберите самостоятельно; она должна обеспечивать описанную ниже работу с аргументами командной строки.
Единственный аргумент — исходный текст целиком; стандартный ввод
не используется. Аргумент всегда передан, в том числе для пустого текста.
Если слова есть, выведите две строки: `Максимумы: ` и список слов через
один обычный пробел, затем `Минимумы: ` и соответствующий список.
После последнего слова пробела нет. Для приведённого
примера вывод:

```text
Максимумы: кот дом кот
Минимумы: и
```

Если слов нет, выведите одну строку `Слов нет`.
Команда `java Main "кот, дом и кот!"` передаёт один аргумент с пробелами;
`java Main ""` передаёт один пустой аргумент и выводит `Слов нет`.
Алгоритм и вспомогательные методы выберите самостоятельно.

## Допустимый текст

Вход состоит из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё,
цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки.
Каждая единица такого текста занимает один `char`; составные сочетания
Unicode в этот алфавит не входят. Строка существует и может быть пустой.

## Сборка и запуск

В корне проекта с JDK 25 выполните:

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/*.java
java -cp out Main "кот, дом и кот!"
```

Кавычки оболочки сохраняют пробелы внутри одного аргумента; `""` передаёт
один пустой аргумент. Программа получает аргументы после имени класса.
Публичные примеры на JUnit 5 находятся в
[src/test/java/PublicExamplesTest.java](src/test/java/PublicExamplesTest.java).
