## Массив объектов без дубликатов

Разработайте метод, который через Stream API получает массив объектов и возвращает новый массив без дубликатов. Используйте лямбду или ссылку на конструктор массива при получении результата.

Выберите собственную модель с полями `int id` и ненулевым `String name`. Два объекта равны, когда совпадают оба поля; регистр имени значим. Обеспечьте согласованные `equals` и `hashCode`: можно реализовать их в обычном классе либо использовать подходящий `record`.

Массив и его элементы ненулевые. Сохраните порядок первого появления и ссылку на первый объект из каждой группы равных. Для отдельных объектов `(1, "A")`, `(2, "B")`, `(1, "A")` результат содержит первые два объекта. Исходный массив и объекты не меняются; пустой массив даёт новый пустой массив. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Обязательные Stream API/лямбда/собственный интерфейс проверяются по исходнику.

## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`, демонстрируйте выбранным вами способом `java -cp out <класс>`. Форма main и имена этой поставкой не назначаются. Public examples в examples/README.md.
