## Комплексные числа

Определить класс Комплекс. Реализовать методы сложения, вычитания, умножения и деления объектов. Создать массив размерности n из комплексных координат. Передать его в метод, который выполнит сложение/умножение его элементов.

Действительная и мнимая части — `double`. Для демонстрации возьмите целые компоненты от −10 до 10; делитель не равен комплексному нулю. Массив ненулевой, содержит от 0 до 6 ненулевых объектов. Операции над массивом сохраняют его элементы: сумма пустого массива равна `0 + 0i`, произведение — `1 + 0i`. Для `[1 + i, 1 - i]` оба результата равны `2 + 0i`.

Покажите каждую арифметическую операцию, сумму и произведение массива. Для каждой вычисленной компоненты абсолютная погрешность относительно математического результата не должна превышать `1e-8`. Имена и сигнатуры, представление результата и оформление текста выбирайте самостоятельно; действительную и мнимую части должно быть возможно различить. [Источник 1]
