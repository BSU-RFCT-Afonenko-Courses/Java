## Book: отбор книг

Создайте класс `Book` со свойствами: id, название, авторы, издательство, год издания, количество страниц, цена, тип переплёта. Поля класса закрытые. Предусмотрите два конструктора с разными наборами параметров, методы чтения и изменения свойств и `toString()`. Отбор оформите отдельными методами для массива объектов. Строковые критерии сравнивайте целиком с учётом регистра; покажите полученную подборку, включая случай без совпадений.

Для данных используйте положительные целые id и количество страниц, год в диапазоне 1..9999 и конечную неотрицательную цену. Список авторов содержит хотя бы одно непустое имя; название, издательство и тип переплёта также непустые. Представление списка авторов и наборы параметров двух конструкторов выберите самостоятельно; оба способа создания должны давать такую книгу. Проверять неверные исходные данные в этой задаче не требуется.

Создайте массив объектов. Выведите:

- список книг заданного автора;
- список книг, выпущенных заданным издательством;
- список книг, выпущенных после заданного года.

Книга подходит автору, если заданная строка совпала с одним из имён в её списке авторов; порядок результата совпадает с исходным массивом. Покажите две подходящие автору книги в исходном порядке, неизвестного автора с пустым результатом и книгу с годом, равным границе: отбор «после» её исключает.

Массив может быть пустым; он, его элементы и текстовые значения не равны `null`. Отбор сохраняет исходный массив и объекты. Если один объект встречается в массиве несколько раз, каждое подходящее вхождение остаётся в результате. Имена методов отбора, тип возвращаемой подборки и оформление вывода выбирайте самостоятельно: результат должен позволять различить записи и проверить их порядок. Для пустой подборки достаточно явного сообщения об отсутствии совпадений; его текст свободен. [Источник 1]

## Работа с проектом

Разместите исходные Java-файлы в `src/`. Требуемые классы и методы указаны
в условии выше; остальные имена, пакеты, вспомогательные методы и способ
запуска выбирайте самостоятельно. В `examples/scenarios.json` приведены
данные и наблюдения для демонстрации. Формат ввода определяется вашим решением
в пределах условия.

Для компиляции нужен JDK 25. Если исходники находятся непосредственно
в `src/`, а демонстрация — в `src/Main.java` без объявления пакета,
команды имеют вид:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Main
```

Подставьте фактическое имя своего класса запуска. Для вложенных каталогов
перечислите нужные исходные файлы в команде компиляции.
Для класса в пакете команда запуска использует полное имя, например
`java -cp out demo.Main`.

Представьте исходники и демонстрацию обычных и существенных граничных случаев,
описанных в условии. Объясните выбранные типы, порядок действий и результат.
Обязательные приёмы проверяются по коду и в беседе с преподавателем.

Состав основной работы и выбор между моделями `Book` и `Car`:
[лабораторная «Классы»](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/labs/objects.html#sec-j25-lab-objects).
