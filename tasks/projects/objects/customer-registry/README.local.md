Создайте решение в `src/main/java`, сохраните входы `Study`.

Создайте собственный Customer с указанными свойствами и методами. Через входы стартера проверяются настоящие объекты и две подборки. Упорядочение по фамилии, имени, отчеству сохраняет исходный порядок при полном совпадении тройки. Подборка по карточке включает обе границы и все вхождения; её порядок свободен. Входной массив и состояние его объектов сохраняются.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
