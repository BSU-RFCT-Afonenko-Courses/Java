# Рубрика: Стек символов Stack

ID `exr-objects-character-stack`. Точный снимок условия закреплён
в [контракте](contract.md). Пять частей — из
`teacher/common/rubric-template.md`.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Возврат и удаление последнего char, точные сообщения отказов | LIFO и последовательность сообщений |
| Ограничения и состояние | Отказы сохраняют состояние, ёмкость постоянна | Продолжение после переполнения и пустого pop |
| Обязательные приёмы | Закрытый массив и указанный открытый API | Исходник Stack и объявлений |
| Объяснение решения и границы | Показано, почему отказ push сохраняет будущий порядок B/A | Разбор ёмкости 2 по состоянию |
| Воспроизводимость предъявления | Демонстрация отделяет сообщения операций от возвращённых значений | Запуск в JDK 25 и понятные наблюдения |

Формат демонстрации и свободные части API не сравниваются с одним
образцом. Поведение и обязательные приёмы устанавливаются отдельно.
Привязка проверяющего клиента не создаёт новых обязанностей студента.
Ненаблюдённая часть требует разбора, а не выдуманного автоматического PASS.
Баллы, веса, попытки и письменный отчёт не назначены.
