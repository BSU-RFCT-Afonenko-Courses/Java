# Контракт: Обмен содержимым двух объектов Test

Цель — изменить поля существующих объектов и объяснить передачу ссылок.
Требуются класс Test, его состояние int a, конструктор Test(int i),
присваивающий a значение i, и метод void swap(Test first, Test second).
Метод может быть статическим либо экземплярным. Пакет, содержащий
метод класс, видимость и способ доступа к полю не закрепляются
дополнительной проверяющей договорённостью.

Оба аргумента не равны null; допустимы разные объекты и две ссылки
на один объект. После swap значения a обменены; объекты и ссылки
вызывающего кода сохранены. Самопередача сохраняет исходное a.
Значения поля — int; ни положительность, ни ограничение маленькими
числами не объявлены предусловием. Вспомогательные переменные
и алгоритм свободны при выполнении договора.

Публичные наблюдения: разные Test(3), Test(8) дают 8 и 3 через прежние
ссылки; swap(x,x) для Test(-2) сохраняет -2. Возвращаемого результата
у swap нет; новое значение наблюдается в старых объектах.
Преподаватель получает объяснение, почему локальная перестановка
параметров не меняет поля. Создание двух новых объектов вместо изменения
полей исходных не выполняет требование. Getter с придуманным проверкой
именем и единственный public/static вариант не навязываются.

Среда — JDK 25 и консоль. Student-комплект не требует Gradle, Wrapper,
JUnit или Python. Размещение исходников в комплекте — src/main/java,
рекурсивные команды компиляции из проверенного технического фрагмента.
Имя Main в README является примером запуска, а не обязательным классом.
Пакеты и остальные свободные части организации сохраняются.
