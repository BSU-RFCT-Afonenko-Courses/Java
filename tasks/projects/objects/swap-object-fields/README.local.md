Создайте решение в `src/main/java`, сохраните входы `Study`.

Сохраняются Test, поле int a, конструктор Test(int) и swap(Test,Test). Технический вход стартера создаёт эти объекты, читает их текущее a и вызывает обмен. Наблюдаются прежние объекты; имена дополнительных getters и static/instance вариант не назначаются.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
