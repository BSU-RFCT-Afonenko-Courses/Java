# Рубрика: Обмен содержимым двух объектов Test

ID `exr-objects-swap-object-fields`. Точный снимок условия закреплён
в [контракте](contract.md). Пять частей — из
`teacher/common/rubric-template.md`.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Значения a обменены в прежних объектах | Наблюдение через сохранённые ссылки |
| Ограничения и состояние | Самопередача сохраняет a и identity | swap(x,x), сравнение состояния |
| Обязательные приёмы | Созданы Test, int a, требуемые конструктор и swap | Исходник и допустимый клиент |
| Объяснение решения и границы | Различаются изменение полей и локальная перестановка ссылок | Объяснение по показанному обмену |
| Воспроизводимость предъявления | Оба случая показаны в JDK 25 | Исходники и собственная демонстрация |

Формат демонстрации и свободные части API не сравниваются с одним
образцом. Поведение и обязательные приёмы устанавливаются отдельно.
Привязка проверяющего клиента не создаёт новых обязанностей студента.
Ненаблюдённая часть требует разбора, а не выдуманного автоматического PASS.
Баллы, веса, попытки и письменный отчёт не назначены.
