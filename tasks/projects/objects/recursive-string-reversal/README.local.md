Создайте решение в `src/main/java`, сохраните входы `Study`.

Вход стартера вызывает вашу рекурсивную печать строки. Проверка снимает только вывод этого вызова, а не весь вывод Main. Все значимые символы, включая пробелы и внутренние переводы строки, сохраняются в обратном порядке; после результата разрешён один завершающий LF или CRLF.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
