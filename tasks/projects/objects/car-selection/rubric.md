# Рубрика: Car: отбор автомобилей

ID `exr-objects-car-selection`. Точный снимок условия закреплён
в [контракте](contract.md). Пять частей — из
`teacher/common/rubric-template.md`.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Три отбора учитывают заданные марку, модель/возраст, год/цену | Свойства записей и пустая подборка |
| Ограничения и состояние | Строгие границы, точные строки, исходные данные, порядок и повторы сохранены | Равный возраст/цена, повтор одного Car, сравнение входа |
| Обязательные приёмы | Собственная Car, закрытые поля, два конструктора, доступ/изменение и toString; отдельные методы; текущий год параметром | Исходник и допустимые вызовы |
| Объяснение решения и границы | Разность годов и сравнение цены объясняют состав | Предметный ответ при выбранном разборе |
| Воспроизводимость предъявления | Результат не зависит от даты запуска при том же параметре | JDK 25, заданный текущий год и понятная демонстрация |

Формат демонстрации и свободные части API не сравниваются с одним
образцом. Поведение и обязательные приёмы устанавливаются отдельно.
Привязка проверяющего клиента не создаёт новых обязанностей студента.
Ненаблюдённая часть требует разбора, а не выдуманного автоматического PASS.
Баллы, веса, попытки и письменный отчёт не назначены.

Рубрика применяется к выбранному студентом варианту пары Book/Car.
Сдача обеих задач и повторная оценка одной единицы выбора не требуются.
