Создайте решение в `src/main/java`, сохраните входы `Study`.

Создайте собственный класс дроби и его четыре операции. Входы стартера предоставляют проверке реальные дроби и массив, включая повторные ссылки. Арифметика может менять получателя или возвращать новый объект: назовите выбранный договор в демонстрации; вход возвращает полученный результат. Преобразование массива использует прежние значения позиций, изменяя только чётные позиции с правым соседом. Сохраните предусмотренные ввод и вывод элементов массива.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
