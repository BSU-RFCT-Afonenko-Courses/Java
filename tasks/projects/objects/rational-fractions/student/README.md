## Рациональная дробь и массив дробей

Создайте класс для представления рациональной дроби парой чисел m и n. Реализуйте методы сложения, вычитания, умножения и деления объектов. Объявите и инициализируйте массив из k дробей, организуйте ввод и вывод его элементов. Передайте массив в метод, который прибавляет к каждому элементу с чётным индексом следующий за ним элемент.

Числитель и знаменатель — целые числа; знаменатели ненулевые, делитель не представляет ноль. Подберите данные, для которых промежуточные целочисленные результаты вашего способа вычисления помещаются в `long`. Значение результата должно совпадать с математической дробью; сокращение и расположение знака в этой карточке свободны.

Массив и его элементы не равны `null`, k может быть нулём. У чётного индекса 0, 2, 4, … новое значение равно сумме прежнего значения и следующей дроби. Нечётные элементы и последний чётный элемент без соседа сохраняют значения. Например, `[1/2, 1/3, 2/5]` превращается в `[5/6, 1/3, 2/5]`. Операции могут менять получателя либо возвращать новый объект: выберите один договор и явно укажите его в демонстрации. Преобразование массива должно выполнять описанное изменение значений и при повторяющихся ссылках на один объект. Сигнатуры и имена класса и методов выбирайте самостоятельно. [Источник 1]

## Работа с проектом

Разместите исходные Java-файлы в `src/`. Требуемые классы и методы указаны
в условии выше; остальные имена, пакеты, вспомогательные методы и способ
запуска выбирайте самостоятельно. В `examples/scenarios.json` приведены
данные и наблюдения для демонстрации. Формат ввода определяется вашим решением
в пределах условия.

Для компиляции нужен JDK 25. Если исходники находятся непосредственно
в `src/`, а демонстрация — в `src/Main.java` без объявления пакета,
команды имеют вид:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Main
```

Подставьте фактическое имя своего класса запуска. Для вложенных каталогов
перечислите нужные исходные файлы в команде компиляции.
Для класса в пакете команда запуска использует полное имя, например
`java -cp out demo.Main`.

Представьте исходники и демонстрацию обычных и существенных граничных случаев,
описанных в условии. Объясните выбранные типы, порядок действий и результат.
Обязательные приёмы проверяются по коду и в беседе с преподавателем.

Задача доступна как самостоятельный добровольный вариант.
