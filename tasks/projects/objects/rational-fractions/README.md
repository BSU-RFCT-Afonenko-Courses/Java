# rational-fractions

Каноническое условие: [карточка банка](../../../bank/objects.qmd#exr-objects-rational-fractions). Канонический стартер и состав выдачи заданы в `_metadata.yml`; `student/` сохраняет прежнюю редакцию.

Реализуйте своё решение через входы Study. Создайте обязательные предметные модели самостоятельно; внутренние классы, методы и пакеты свободны в пределах условия. Полный договор и допустимые результаты находятся в условии и комментариях стартера.

`gradle test` выполняет два открытых случая normal/boundary после API-допуска. Автоматическая часть: 80 × passed/total по 4 равным группам; прежняя ручная часть — 20. API и дополнительная демонстрация баллов не дают. Инфраструктурный отказ не превращается в ноль студента. Прежние признанные оценки и код сохраняются.
