## Учебный результат

Представить комплексное число и выполнить арифметику, сумму и произведение массива с установленной точностью.

## Вход

Компоненты double; для демонстрации — целые значения от −10 до 10. Делитель не равен комплексному нулю. Массив ненулевой, длина от 0 до 6, все элементы — ненулевые объекты; повторные ссылки не исключены. Валидация недопустимых данных не добавляется.

## Результат

Четыре арифметические операции, сумма и произведение массива соответствуют математике с абсолютной ошибкой каждой компоненты не более 1e-8. У пустого массива сумма 0+0i, произведение 1+0i. Для [1+i,1−i] сумма и произведение равны 2+0i. Действительная и мнимая части различимы.

## Допустимые решения и API

Имена, сигнатуры, пакеты, представление результата и оформление текста свободны. Класс Complex, методы real/imaginary/sum/product и фиксированный Main из исторических клиентов не являются опубликованным API. Условие сохраняет элементы при операциях над массивом; оно не требует единой политики мутации для любой одиночной арифметической операции.

## Обязательные приёмы

Собственный класс комплексного числа с четырьмя операциями, массив объектов и передача его методу вычисления суммы и произведения. В демонстрации присутствует каждая операция.

## Состояние и проверяемые свойства

Вычисление суммы и произведения сохраняет значения элементов исходного массива, в том числе при повторных ссылках. Нулевое произведение по пустому массиву недопустимо. Для компонент используются математический результат и абсолютный допуск 1e-8, а не совпадение текстовой записи.

## Предъявление и объяснение

Объяснить вычисление одной арифметической операции, начальные значения суммы/произведения пустого массива и сохранность исходных элементов.

Прочитать модель, операции и проход по массиву. По демонстрации сопоставить действительные и мнимые компоненты до и после; один правильный текст не подтверждает работу всех операций и сохранность объектов.
