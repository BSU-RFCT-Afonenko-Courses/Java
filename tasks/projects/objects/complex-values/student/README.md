## Комплексные числа

Создайте класс для представления комплексного числа. Реализуйте методы сложения, вычитания, умножения и деления объектов. Создайте массив из n комплексных чисел и передайте его в метод для вычисления суммы и произведения элементов.

Действительная и мнимая части — `double`. Для демонстрации возьмите целые компоненты от −10 до 10; делитель не равен комплексному нулю. Массив ненулевой, содержит от 0 до 6 ненулевых объектов. Операции над массивом сохраняют его элементы: сумма пустого массива равна `0 + 0i`, произведение — `1 + 0i`. Для `[1 + i, 1 - i]` оба результата равны `2 + 0i`.

Покажите каждую арифметическую операцию, сумму и произведение массива. Для каждой вычисленной компоненты абсолютная погрешность относительно математического результата не должна превышать `1e-8`. Имена и сигнатуры, представление результата и оформление текста выбирайте самостоятельно; действительную и мнимую части должно быть возможно различить. [Источник 1]

## Работа с проектом

Разместите исходные Java-файлы в `src/`. Требуемые классы и методы указаны
в условии выше; остальные имена, пакеты, вспомогательные методы и способ
запуска выбирайте самостоятельно. В `examples/scenarios.json` приведены
данные и наблюдения для демонстрации. Формат ввода определяется вашим решением
в пределах условия.

Для компиляции нужен JDK 25. Если исходники находятся непосредственно
в `src/`, а демонстрация — в `src/Main.java` без объявления пакета,
команды имеют вид:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Main
```

Подставьте фактическое имя своего класса запуска. Для вложенных каталогов
перечислите нужные исходные файлы в команде компиляции.
Для класса в пакете команда запуска использует полное имя, например
`java -cp out demo.Main`.

Представьте исходники и демонстрацию обычных и существенных граничных случаев,
описанных в условии. Объясните выбранные типы, порядок действий и результат.
Обязательные приёмы проверяются по коду и в беседе с преподавателем.

Задача доступна как самостоятельный добровольный вариант.
