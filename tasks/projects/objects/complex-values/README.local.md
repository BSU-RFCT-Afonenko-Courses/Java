Создайте решение в `src/main/java`, сохраните входы `Study`.

Создайте собственный класс комплексного числа и предусмотренные операции. Через входы стартера наблюдаются реальные объекты, их компоненты и результаты четырёх операций, суммы и произведения массива. Операции над массивом сохраняют значения всех его элементов, в том числе при повторных ссылках; пустые сумма и произведение равны соответственно 0+0i и 1+0i.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
