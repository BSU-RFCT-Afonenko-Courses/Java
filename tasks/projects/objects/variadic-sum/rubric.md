# Рубрика: Метод sum() с аргументом переменной длины

ID `exr-objects-variadic-sum`. Точный снимок условия закреплён
в [контракте](contract.md). Пять частей — из
`teacher/common/rubric-template.md`.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Сумма int, пустой вызов возвращает 0 | Возвращаемые значения обычного и пустого вызовов |
| Ограничения и состояние | Переданный массив сохранён; испытания соблюдают предусловия | Значения массива до и после |
| Обязательные приёмы | Объявлен параметр переменной длины int... | Исходник и API метода |
| Объяснение решения и границы | Студент связывает аргументы с результатом и пустым случаем | Предметный ответ при выбранном разборе |
| Воспроизводимость предъявления | Исходники и демонстрация запускаются в JDK 25 | Команда выбранного класса запуска |

Формат демонстрации и свободные части API не сравниваются с одним
образцом. Поведение и обязательные приёмы устанавливаются отдельно.
Привязка проверяющего клиента не создаёт новых обязанностей студента.
Ненаблюдённая часть требует разбора, а не выдуманного автоматического PASS.
Баллы, веса, попытки и письменный отчёт не назначены.
