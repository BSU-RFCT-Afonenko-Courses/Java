Цель — объявить и применить параметр переменной длины, получить сумму
и сохранить вход. Обязательная сигнатура результата/параметра —
int sum(int... values). Содержащий класс, static либо экземплярный
метод, видимость и способ обхода свободны. Обычный int[] без объявления
varargs не заменяет требуемый приём, даже если вычисляет ту же сумму.

Вход — ненулевой массив значений int либо список аргументов;
в демонстрации все промежуточные суммы помещаются в int.
Результат — int сумма, для пустого вызова 0. Переданный массив
после вызова содержит прежние значения. Пустой массив допустим;
null и переполнение не становятся неопубликованными испытаниями.
Обход индексами, enhanced-for и другие удовлетворяющие условию
решения допустимы. Не требуется единственная локальная переменная,
имя класса Arithmetic или дополнительный overload.

Обычный публичный сценарий: [3, -2, 4] даёт 5 и сохраняет массив.
Граничный: sum() даёт 0. Формат печати демонстрации свободен;
наблюдается возвращаемое значение и вход. Параметр varargs
устанавливается по исходнику/API, а не только по числу в выводе.

Среда — JDK 25 и консоль. Student-комплект не требует Gradle, Wrapper,
JUnit или Python. Размещение исходников в комплекте — src/main/java,
рекурсивные команды компиляции из проверенного технического фрагмента.
Имя Main в README является примером запуска, а не обязательным классом.
Пакеты и остальные свободные части организации сохраняются.
