# Проект: lunar-weight

Напишите программу, вычисляющую силу тяжести на Луне как 17% силы тяжести на Земле. Исходное значение — неотрицательное конечное `double` в ньютонах; результат также выражается в ньютонах. Масса тела при перемещении на Луну не меняется. В исходнике задайте положительный пример и покажите также нулевое значение.

Протокол проверки: если стандартный ввод содержит одно число, вычислите результат для него и выведите только полученное число. Для ввода `100` результат — `17`, для `0` — `0`, для `7.5` — `1.275`. При пустом стандартном вводе покажите два результата: для нуля и выбранного положительного примера, по одному числу в строке. Числовые аргументы командной строки не требуются.

Вещественные результаты можно выводить в десятичной или экспоненциальной форме с точкой. Автоматическая проверка допускает абсолютную погрешность `1e-8`; количество знаков после точки не фиксируется.

Соберите `src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out src/main/java/*.java`, затем запустите `java -cp out Main`. Для дополнительного входа передайте текст через stdin; без входа закройте stdin (EOF). Java 25 без preview. Вспомогательные методы и классы разрешены.

Публичные примеры: `src/test/java/PublicExamplesTest.java`. Их можно запускать JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.
