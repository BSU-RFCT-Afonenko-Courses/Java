# Вес на Луне

Напишите программу, вычисляющую силу тяжести на Луне как 17% силы тяжести на Земле. Исходное значение — неотрицательное конечное `double` в ньютонах; результат также выражается в ньютонах. Масса тела при перемещении на Луну не меняется. В исходнике задайте положительный пример и покажите также нулевое значение.

Вход и результат: если стандартный ввод содержит одно число, вычислите результат для него и выведите только полученное число. Для ввода `100` результат — `17`, для `0` — `0`, для `7.5` — `1.275`. При пустом стандартном вводе покажите два результата: для нуля и выбранного положительного примера, по одному числу в строке. Числовые аргументы командной строки не требуются.

Обозначим входное значение `double` через $x$, а математический результат
$17x/100$ — через $y$. Выведенное число $r$ должно быть конечным.
Абсолютная ошибка — это $|r-y|$, измеренная в ньютонах. В этой задаче предел
ошибки равен большему из двух значений: `1e-8` Н и `1e-12` от величины $|y|$:

$$
|r-y| \leq \max(10^{-8},\;10^{-12}|y|).
$$

Первый предел сохраняет допуск в окрестности нуля, второй учитывает масштаб
результата. Способ вычисления выберите самостоятельно. Результат можно
выводить в десятичной или экспоненциальной форме с точкой; количество знаков
после точки не фиксируется.

## Исходник и запуск

В `src/main/java/Main.java` находится заготовка с `TODO`. Успешная
компиляция заготовки не означает, что решение готово: требуемое поведение
ещё нужно реализовать. Сохраните
точку входа `Main.main(String[] args)`; вспомогательные методы и классы
разрешены.

Откройте каталог, содержащий этот `README.md` и `src`. Выполните команды
инструментами JDK 25. После изменения исходника повторите компиляцию:

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/*.java
printf '7.5' | java -cp out Main
printf '' | java -cp out Main
```

Первый запуск должен дать `1.275`. Второй получает EOF без данных и должен вывести два числа: ноль и результат для положительного примера, выбранного в программе. Пока пустой поток остаётся открытым, чтение может ожидать данные; EOF означает завершение потока.

В примерах вход передаётся командой `printf` оболочки POSIX (например, bash).
В другой оболочке можно сохранить тот же ввод в файле UTF-8 и перенаправить
его в программу. `printf ''` создаёт пустой поток с EOF.

Публичные примеры находятся в `src/test/java/PublicExamplesTest.java`
и используют JUnit 5. Они охватывают часть случаев; полные требования
задаёт условие выше. Компиляция не проверяет соответствие поведения
программы условию.
