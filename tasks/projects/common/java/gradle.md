Для сборки нужен JDK 25 и установленный Gradle 9.8. Откройте извлечённую папку с `settings.gradle` как Gradle-проект в IDE. Зависимость JUnit объявлена только в `build.gradle`; первое получение зависимости требует сети, последующие сборки доступны с `--offline` после заполнения кеша.

Из корня проекта можно выполнить `gradle classes`, `gradle apiCheck` и, по желанию, `gradle test`. Самопроверка доступна для работы над решением; её запуск и установка Gradle не являются условием зачёта. Незавершённая заготовка компилируется и проходит допуск API, но ожидаемо не проходит предметные тесты.

Способ передачи данных указан в условии. Если программа читает стандартный ввод, запустите `gradle --console=plain -q run`, передайте данные и завершите ввод. Аргументы командной строки передаются отдельно: например, для задачи о сумме и произведении аргументов выполните `gradle --console=plain -q run --args="3 -2 4"`; ввод этих чисел через стандартный ввод аргументы не заменяет. Для собственного демонстрационного класса используйте `gradle --console=plain -q run -PmainClass=ИмяКласса`. Это удобство локального запуска, а не обязательное имя класса для задач без заданной точки входа.

Команда `gradle classes` помещает классы решения в `build/classes/java/main`. Для прямого запуска после такой сборки укажите этот путь: например, `java -cp build/classes/java/main Main 3 -2 4` для задачи о сумме и произведении аргументов.

Если в условии показан запуск `java -cp out Main`, сначала скомпилируйте исходники в `out`. Из корня проекта в оболочке Linux или macOS выполните:

```sh
mkdir -p out
find src/main/java -type f -name '*.java' -exec javac -d out --source-path src/main/java {} +
```

Команда включает вспомогательные классы во вложенных пакетах. Затем выполните команду запуска из условия, например `java -cp out Main 3 -2 4`. В Windows можно собрать тот же каталог исходников средствами IDE и указать `out` как каталог классов либо воспользоваться запуском через Gradle.

Сдавайте свой исходный код. Не включайте `.gradle`, `build`, `out`, кеши IDE и скачанные зависимости.
