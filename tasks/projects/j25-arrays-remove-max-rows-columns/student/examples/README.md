# Удаление строк и столбцов: примеры

В исходной матрице

```text
-3  0  3
 2 -1  0
 1  3 -2
```

максимум `3` находится в позициях `(0, 2)` и `(2, 1)`; нумерация начинается с нуля.
Удаляются строки 0 и 2 и столбцы 1 и 2. Остаётся матрица размера 1×1
с единственным значением `2`.

Размеры результатов при отсутствии элементов:

| Исходные строки | Оставшиеся строки × столбцы |
|---|---|
| `[3, 3]`, `[3, 3]` | 0×0 |
| `[9, 1]`, `[9, 2]` | 0×1 |
| `[9, 9]`, `[1, 2]` | 1×0 |

В случае 0×1 сохранился второй столбец, но обе строки исключены.
В случае 1×0 сохранилась вторая строка, но оба столбца исключены.
Покажите обе размерности выбранным вами способом.
