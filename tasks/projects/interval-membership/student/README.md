# Проект: interval-membership

Для целых `n`, `m`, `k`, где `n < m`, определите принадлежность `k` каждому из интервалов `(n, m]`, `[n, m)`, `(n, m)`, `[n, m]`. Проверьте обе границы, внутреннюю точку и значения снаружи.

Протокол проверки: стандартный ввод содержит `n m k` типа `int`, разделённые пробельными символами. Выведите четыре значения `true` или `false` в указанном порядке. Например, `-2 4 -2` даёт `false true false true`; `-2 4 4` — `true false false true`. Некорректный ввод и случай `n >= m` не проверяются.

Соберите `src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out src/main/java/*.java`, затем запустите `java -cp out Main`. Для дополнительного входа передайте текст через stdin; без входа закройте stdin (EOF). Вспомогательные методы и классы разрешены.

Публичные примеры: `src/test/java/PublicExamplesTest.java`. Их можно запускать JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.
