## Интерфейс IVehicle

Создайте класс `Vehicle` с целочисленными характеристиками `passengers` (число пассажиров), `fuelcap` (запас топлива в галлонах), `mpg` (мили на галлон). Число пассажиров неотрицательно; два остальных значения положительны. Конструктор принимает три значения, методы доступа читают и изменяют их с сохранением ограничений. Метод `range()` возвращает дальность, `fuelNeeded(int miles)` — топливо типа `double` для неотрицательного расстояния. Исходные данные и допустимые изменения выбираются так, чтобы `fuelcap * mpg` помещалось в `int`; обработка переполнения вне условия.

Выделите в `IVehicle` следующие операции и реализуйте их открытыми методами `Vehicle`:

```java
int getPassengers();
void setPassengers(int value);
int getFuelcap();
void setFuelcap(int value);
int getMpg();
void setMpg(int value);
int range();
double fuelNeeded(int miles);
```

Открытый конструктор `Vehicle(int passengers, int fuelcap, int mpg)` создаёт состояние, поля закрыты. Дальность равна `fuelcap * mpg`, необходимое топливо — отношению `miles` к `mpg` с вещественным результатом; абсолютная погрешность этого результата не больше `1e-6`. Покажите вызовы через `IVehicle`. Конструктор частью интерфейса не является. [Источник 1]

Неверные параметры конструктора, метода изменения или отрицательное расстояние отклоняются через `IllegalArgumentException`. Метод изменения проверяет значение до записи: после отказа все характеристики прежние.

Покажите `Vehicle(2, 10, 25)`: дальность 250, топливо для 50 миль 2.0; отказ изменения `fuelcap` на `0` сохраняет дальность 250, отрицательное расстояние вызывает исключение.

## Работа с проектом

Разместите Java-файлы в `src/`. Имена вспомогательных классов, методы и пакеты выбирайте самостоятельно в пределах явно заданного API. Нужен JDK 25.

Например, если вы назвали свой класс демонстрации `Demo` и расположили все исходники непосредственно в `src/` без объявления пакета, из корня проекта выполните:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Demo
```

При другом имени укажите его в команде запуска. При использовании пакетов перечислите нужные исходники и укажите в команде запуска полное имя класса с пакетом.

Открытые сценарии в `examples/scenarios.json` описывают действия и ожидаемые наблюдения. Способ ввода данных для собственной демонстрации выбирайте самостоятельно.

Покажите чтение и изменение характеристик через `IVehicle`, расчёт дальности и топлива. После отказа `setFuelcap(0)` прочитайте прежние характеристики и дальность; отдельно покажите отказ для отрицательного расстояния.

Представьте исходники и демонстрацию обычных и существенных граничных случаев. Обязательные приёмы проверяются по исходнику; выбор решения объясняется в беседе с преподавателем.
