# Пакет qpack

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `src/main/java/IQDemo.java`
- `src/main/java/qpack/CircularQueue.java`
- `src/main/java/qpack/DynQueue.java`
- `src/main/java/qpack/FixedQueue.java`
- `src/main/java/qpack/ICharQ.java`

Форма PrairieLearn: один ZIP с сохранением путей. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `qpack`, `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
В полях ответа пути исходников задаются относительно `src/main/java`.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.


Самостоятельная добровольная задача из меню `reserve-models`.
В комплекте дан `src/main/java/qpack/ICharQ.java`. Добавьте реализации
`FixedQueue`, `CircularQueue`, `DynQueue` в пакет `qpack`, а `IQDemo`
оставьте в безымянном пакете. Вспомогательные объявления выберите сами.

Общий договор — [QUEUE-CONTRACT.md](QUEUE-CONTRACT.md). Он задаёт
операции, хранение и отказы всех трёх очередей.

Нужен JDK 25. Откройте терминал в каталоге с этим README и папкой `src`.
Скомпилируйте все Java-исходники под `src/main/java`, включая вложенные пакеты.

В Linux, Bash:

```bash
find src/main/java -type f -name '*.java' -exec javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java {} +
```

В PowerShell 7:

```powershell
$sources = @(Get-ChildItem -LiteralPath 'src/main/java' -Recurse -File -Filter '*.java' |
    ForEach-Object { $_.FullName })
javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java $sources
```

Запустите демонстрационный класс `IQDemo` из безымянного пакета:

```console
java -cp out IQDemo
```

После изменения исходников повторите компиляцию. Каталог `out` создаётся
при компиляции и в исходный комплект не включается.

После запуска решения выполните публичную самопроверку по инструкциям
в предоставленном [CHECKS.md](CHECKS.md).

Открытые проверки в `src/test/java` можно адаптировать к допустимому
API решения; пример привязки находится в `src/test/java/TaskBinding.java`.
Его имена и вид результата не задают дополнительных требований.
Для другого допустимого API согласуйте с преподавателем обычную
Java-привязку. Если локальные или закрытые элементы недоступны отдельному
проверяющему классу, предъявите их работу и исходник преподавателю.
Отсутствие готовой привязки само по себе не означает ошибку в решении.

После подготовки привязки открытый клиент проверяет результаты двух
опубликованных сценариев. Подробнее — в [BINDING.md](BINDING.md).
Обязательные приёмы и объяснение преподаватель оценивает по исходнику
и демонстрации; успешная публичная проверка не заменяет эту оценку.

Открытые наблюдения находятся в [examples/scenarios.json](examples/scenarios.json).
Это описание примеров; JSON не задаёт обязательного формата входа.

Покажите структуру Java-файлов, команды компиляции и запуска, импорт и вызовы
через `ICharQ` для всех трёх очередей. Объясните доступ между пакетами.
Предъявите исходники. Обязательные приёмы проверяются по коду, объяснение —
в беседе с преподавателем. Дополнительный письменный отчёт не требуется.
