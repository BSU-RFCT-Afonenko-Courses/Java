## Подкласс Circle

Объявите абстрактный `TwoDShape` с закрытыми полями `double width`, `double height`, `String name`, конструктором `TwoDShape(double width, double height, String name)`, открытыми методами `double getWidth()`, `double getHeight()`, `String getName()` и абстрактным `public double area()`.

Создайте подкласс `Circle` с открытым конструктором `Circle(double radius)`. Допустимый радиус — конечное `double` в диапазоне `0 < radius <= 1e150`; неверные входы проверять не требуется. Через `super` передайте в базовый класс ширину и высоту, равные диаметру, и имя `"circle"`. Реализуйте площадь круга.

Покажите вызов `area()` через ссылку `TwoDShape`; размеры и площадь должны соответствовать одному радиусу. Для радиуса 2 размеры равны 4, площадь приблизительно 12.566370614359172.

Результат площади должен быть конечным. Допускается абсолютная погрешность до `1e-9` для малых значений либо относительная до `1e-12` для больших: если математическая площадь равна y = πr², возвращённое значение a удовлетворяет `|a - y| <= max(1e-9, 1e-12 * |y|)`. Способ вычисления выбирайте самостоятельно. [Источник 1]

## Работа с проектом

Разместите Java-файлы в `src/`. Имена вспомогательных классов, методы и пакеты выбирайте самостоятельно в пределах явно заданного API. Нужен JDK 25.

Например, если вы назвали свой класс демонстрации `Demo` и расположили все исходники непосредственно в `src/` без объявления пакета, из корня проекта выполните:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Demo
```

При другом имени укажите его в команде запуска. При использовании пакетов перечислите нужные исходники и укажите в команде запуска полное имя класса с пакетом.

Открытые сценарии в `examples/scenarios.json` описывают действия и ожидаемые наблюдения. Способ ввода данных для собственной демонстрации выбирайте самостоятельно.
