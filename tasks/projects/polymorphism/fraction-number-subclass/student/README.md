## Рациональное число

Создайте абстрактный класс `NumberValue` и подкласс `Fraction` для рационального числа с целыми числителем и ненулевым знаменателем. Нормализуйте знак и сокращайте дробь; входы подбираются так, чтобы промежуточные результаты помещались в `long`.

Определите сложение, вычитание, умножение и деление дробей с возвращением нового значения. Нулевой знаменатель конструктора и деление на нулевую дробь отклоняются через `ArithmeticException`. Ноль нормализуется как `0/1`, знаменатель нормализованного значения положителен. Операнды ненулевые и после операции сохраняются.

Обоснуйте, какие операции принадлежат базовому классу, реализуйте `equals`, `hashCode`, `toString` по значению и покажите, что `1/2` равно `2/4`. Имена методов арифметики, сигнатуры конструкторов и представление базовой операции выбирайте самостоятельно; сравнение с `null` ложно. `NumberValue` — собственный учебный класс, независимый от `java.lang.Number`. ## Работа с проектом

Это отдельная добровольная задача. Другие задачи резервной работы перед ней выполнять не требуется.

Разместите Java-файлы в `src/`. Имена вспомогательных классов, методы и пакеты выбирайте самостоятельно в пределах явно заданного API. Нужен JDK 25.

Например, если вы назвали свой класс демонстрации `Demo` и расположили все исходники непосредственно в `src/` без объявления пакета, из корня проекта выполните:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Demo
```

При другом имени укажите его в команде запуска. При использовании пакетов перечислите нужные исходники и укажите в команде запуска полное имя класса с пакетом.

Открытые сценарии в `examples/scenarios.json` описывают действия и ожидаемые наблюдения. Способ ввода данных для собственной демонстрации выбирайте самостоятельно.

## Предъявление решения

Покажите нормализацию знака и нуля, равенство `1/2` и `2/4`, четыре арифметические операции с сохранением операндов. Продемонстрируйте `ArithmeticException` для нулевого знаменателя и деления на нулевую дробь. Обоснуйте выбранные операции `NumberValue`.

Представьте исходники и демонстрацию обычных и существенных граничных случаев. Обязательные приёмы проверяются по исходнику; выбор решения объясняется в беседе с преподавателем.
