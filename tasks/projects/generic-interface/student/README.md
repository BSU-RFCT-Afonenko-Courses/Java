## Работа с проектом

Это отдельная добровольная задача. Другие пункты резервного меню перед ней выполнять не требуется; необходимая подготовка дана в условии. Разместите исходные Java-файлы в `src/` с выбранной структурой. Имена и API фиксируются только там, где они явно даны в условии. Примеры в `examples/scenarios.json` описывают наблюдения, а не обязательный формат ввода программы.

Нужен JDK25. Пример компиляции: `javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java`; перечислите все исходники и учтите собственные пакеты. Для задачи qpack сохраняются её явно заданные package/class names; для остальных незаданные имена и точку запуска выбирайте самостоятельно. Предъявите исходники и демонстрацию; техника и объяснение остаются частью обычной защиты.

## Общий контекст резервной работы


Очереди используют [Очереди символов](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/bank/polymorphism.html#sec-j25-bank-character-queues); generic-очереди — собственный опубликованный контракт переданного массива и [Arrays.copyOf для ссылочных компонентов](https://bsu-rfct-afonenko-courses.github.io/Java/handbook/entries/arrays.html#sec-api-arrays-copy-of). Граф, ближайшее значение и многочлены требуют коллекций; compareTo — [String.compareTo и знак порядка](https://bsu-rfct-afonenko-courses.github.io/Java/handbook/entries/strings.html#sec-api-strings-compare-to). Выбор самостоятельного внутреннего хранения свободен в пределах явно требуемой техники карточки; например, кольцевая очередь допускает счётчик размера или различение индексов отдельным состоянием. Предъявите обычный случай и границу выбранной модели. Проект расписания и проект кодирования имеют собственные условия; их выполнение не требуется для остальных задач.
