## Обмен содержимым двух объектов Test

Создайте класс `Test` с полем `int a` и конструктором `Test(int i)`, присваивающим полю `a` значение `i`. Метод `void swap(Test first, Test second)` меняет местами значения полей двух ненулевых объектов. Можно сделать метод статическим или экземплярным, сохранив указанные параметры.

Для разных объектов со значениями 3 и 8 результат — 8 и 3; ссылки вызывающего кода указывают на прежние объекты. `swap(x, x)` сохраняет значение `x.a`. Объясните, почему перестановка локальных параметров сама по себе не меняет содержимое объектов. Вспомогательные переменные и доступ к полям выбирайте самостоятельно. [Источник 1]
