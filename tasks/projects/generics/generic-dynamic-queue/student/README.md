# Обобщённая растущая очередь

Реализуйте `DynQueue<T>` с методами `void put(T value)` и `T get()` и порядком FIFO.
Хранилище — массив; при исчерпании свободного места создаётся больший массив с
сохранением порядка оставшихся элементов. Конструктор принимает непустой массив
`T[]`; исходная очередь пуста независимо от содержимого переданного массива, после
передачи клиент не использует массив напрямую. Фактический тип компонента массива
совпадает с аргументом типа очереди. Для увеличения можно использовать
`Arrays.copyOf(T[], int)`, сохраняющий фактический тип массива.

Входные элементы отличны от `null`. При пустой очереди `get` выводит сообщение и
возвращает `null`, сохраняя состояние. Текст сообщения об отказе и коэффициент
увеличения массива выберите самостоятельно. Продемонстрируйте несколько увеличений
вместимости, чередование добавления и извлечения и два типа элементов.

## Работа с проектом

Это отдельное дополнительное задание. Поля, способ увеличения массива и коэффициент
роста выберите самостоятельно. После увеличения массива оставшиеся элементы
извлекаются в прежнем порядке. Тексты сообщений об отказах выберите самостоятельно;
другие сообщения программы также допустимы.

Разместите Java-файлы в `src/`. Имена файлов должны совпадать с именами объявленных
в них открытых классов. Для компиляции всех своих исходников из корня проекта нужен
JDK 25:

```bash
find src -name '*.java' -print > sources.txt
javac --release 25 -encoding UTF-8 -d out @sources.txt
```

Точку запуска выберите самостоятельно. Например, класс `Demo` с `main` в безымянном
пакете запускается командой `java -cp out Demo`; для класса в пакете укажите его
полное имя.

Файл `examples/scenarios.json` описывает случаи для проверки решения. Формат ввода
вашей программы выбирайте самостоятельно. Представьте исходники и демонстрацию
случаев из условия; объясните связи типов и причины ожидаемых результатов. Отдельный
большой отчёт не требуется.
