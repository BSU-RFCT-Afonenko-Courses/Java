# Обобщённая очередь

Реализуйте `GenericQueue<T>` фиксированной вместимости с операциями
`void put(T value) throws QueueFullException` и
`T get() throws QueueEmptyException`. Класс, конструктор `GenericQueue(T[])` и обе
операции объявите `public`: контейнер предоставляет API клиенту. Имя пакета, если он
используется, выберите самостоятельно. `get` возвращает и удаляет самый ранний из
ещё хранимых элементов — порядок FIFO. Вместимость ограничивает число элементов,
хранимых одновременно: извлечение освобождает место для нового добавления. Способ
размещения элементов в массиве выберите самостоятельно.

Хранилище — массив `T[]`, переданный конструктору; его положительная длина задаёт
вместимость. Новая очередь пуста независимо от содержимого переданного массива.
Фактический тип компонента массива совпадает с аргументом типа очереди: для
`GenericQueue<Number>` передаётся `Number[]`. Фактический `Integer[]` допускал бы
запись только ссылок на `Integer` или `null`. Клиент после передачи не использует
массив напрямую и не добавляет `null`. Это предпосылки использования; проверять их
программно не требуется.

В заполненном контейнере `put` выбрасывает проверяемое `QueueFullException`, в
пустом контейнере `get` — проверяемое `QueueEmptyException`. Определите эти классы
исключений как открытые проверяемые наследники `Exception`. Конструктор не объявляет
проверяемых исключений; каждая операция объявляет указанный для неё проверяемый
отказ; дополнительных проверяемых отказов операций не вводится. Отказ не меняет
состояние очереди. Способ формирования и текст сообщения исключения выберите
самостоятельно. Новые операции сверх конструктора, `put` и `get` не требуются.

Покажите работу со строками и целыми числами, обработку обоих отказов и повторное
добавление после извлечения из заполненной очереди. Подготовка к объявлениям и
обработке отказов: раздел теории курса
[«Проверяемый отказ операции»](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/exceptions.html#sec-j25-theory-exceptions-early-checked).

## Работа с проектом

Заготовки находятся в `src/main/java`. Завершите реализацию контейнера и исключений.
Конструкторы исключений в заготовке можно изменить: условие задаёт типы отказов и
поведение операций. Пакет выбирайте самостоятельно. Открытые примеры использования
находятся в `src/test/java`.

Для компиляции своих исходников из корня проекта нужен JDK 25:

```bash
find src/main/java -name '*.java' -print > sources.txt
javac --release 25 -encoding UTF-8 -d out @sources.txt
```

Демонстрационный класс с `main` создайте в `src/main/java`. Если это `Demo` в
безымянном пакете, запустите `java -cp out Demo`; для класса в пакете укажите его
полное имя. Покажите последовательность помещений, извлечений и отказов для двух
типов элементов. Объясните, как извлечение освобождает место и почему отказ
сохраняет состояние.
