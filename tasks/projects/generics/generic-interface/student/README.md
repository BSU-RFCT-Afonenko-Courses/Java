# Реализация обобщённого интерфейса

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `negative/src/main/java/Bad.java`
- `positive/src/main/java/Good.java`
- `src/main/java/IGenIF.java`
- `src/main/java/MyClass.java`

Форма PrairieLearn: один ZIP с сохранением путей. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
Имена файлов ответа соответствуют указанным путям в комплекте.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.

Корректное решение и оба компиляционных опыта сохраняются раздельно.
Команды выполняются из корня комплекта под JDK 25:

```bash
javac --release 25 -encoding UTF-8 -d out/positive src/main/java/IGenIF.java src/main/java/MyClass.java positive/src/main/java/Good.java
javac --release 25 -encoding UTF-8 -d out/negative src/main/java/IGenIF.java src/main/java/MyClass.java negative/src/main/java/Bad.java
```

После реализации `MyClass` первая команда должна завершиться успешно, вторая —
отказом именно из-за нарушения зависимости параметров типов. Не включайте
`Bad.java` в корректный набор исходников. При дополнительном параметре типа
адаптируйте оба опыта, сохранив требуемую зависимость. `gradle classes` собирает
только корректное решение из `src/main/java`; успешная сборка не подменяет
отрицательный опыт и объяснение. Не добавляйте третью копию реализации.
