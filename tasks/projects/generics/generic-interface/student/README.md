# Реализация обобщённого интерфейса

Дан интерфейс `IGenIF<T, V extends T>` без методов. Объявите обобщённый класс
`MyClass`, реализующий этот интерфейс и сохраняющий указанное отношение между
параметрами типов. Покажите допустимую параметризацию `Number, Integer` и объясните
отказ компилятора для `Integer, Number`.

## Работа с проектом

Это отдельное дополнительное задание. Данный интерфейс находится в
`src/IGenIF.java`. Пакет согласуйте со своими файлами. Конструкторы, модификаторы
доступа и имена параметров типов класса условием не заданы; дополнительные параметры
класса допустимы при сохранении требуемого отношения типов.

Разместите Java-файлы в `src/`. Имена файлов должны совпадать с именами объявленных
в них открытых классов. Для компиляции всех своих исходников из корня проекта нужен
JDK 25:

```bash
find src -name '*.java' -print > sources.txt
javac --release 25 -encoding UTF-8 -d out @sources.txt
```

Точку запуска выберите самостоятельно. Например, класс `Demo` с `main` в безымянном
пакете запускается командой `java -cp out Demo`; для класса в пакете укажите его
полное имя.

Файл `examples/scenarios.json` описывает случаи для проверки решения. Формат ввода
вашей программы выбирайте самостоятельно. Представьте исходники и демонстрацию
случаев из условия; объясните связи типов и причины ожидаемых результатов. Отдельный
большой отчёт не требуется.

Вариант с нарушенной границей компилируйте отдельно от допустимой программы:
ожидаемый результат этого опыта — диагностика компилятора.
