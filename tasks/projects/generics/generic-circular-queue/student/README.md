# Обобщённая кольцевая очередь

Реализуйте `CircularQueue<T>` с операциями `void put(T value)` и `T get()` на
массиве `T[]`, переданном конструктору. Длина массива положительна и задаёт
вместимость. Новая очередь пуста независимо от содержимого переданного массива.
Клиент после передачи не использует массив напрямую; фактический тип компонента
совпадает с аргументом типа очереди. Освободившиеся позиции используются повторно;
порядок извлечения — FIFO.

Добавляемые элементы отличны от `null`. В заполненном контейнере `put` выводит
сообщение и не меняет очередь; в пустом контейнере `get` выводит сообщение и
возвращает `null`, сохраняя состояние. Текст сообщения об отказе выберите
самостоятельно. Покажите переход индексов через конец массива, повторное
использование места и работу с двумя типами элементов.

## Работа с проектом

Это отдельное дополнительное задание. Поля и способ различения пустого и полного
состояний выберите самостоятельно. Длина переданного массива целиком доступна для
элементов; тексты сообщений об отказах выберите самостоятельно. Другие сообщения
программы также допустимы.

Разместите Java-файлы в `src/`. Имена файлов должны совпадать с именами объявленных
в них открытых классов. Для компиляции всех своих исходников из корня проекта нужен
JDK 25:

```bash
find src -name '*.java' -print > sources.txt
javac --release 25 -encoding UTF-8 -d out @sources.txt
```

Точку запуска выберите самостоятельно. Например, класс `Demo` с `main` в безымянном
пакете запускается командой `java -cp out Demo`; для класса в пакете укажите его
полное имя.

Файл `examples/scenarios.json` описывает случаи для проверки решения. Формат ввода
вашей программы выбирайте самостоятельно. Представьте исходники и демонстрацию
случаев из условия; объясните связи типов и причины ожидаемых результатов. Отдельный
большой отчёт не требуется.
