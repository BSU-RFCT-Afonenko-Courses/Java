# Обобщённый стек

Определите интерфейс `IGenStack<T>` с операциями
`void push(T value) throws StackFullException` и
`T pop() throws StackEmptyException`, затем реализуйте его для стека фиксированной
вместимости. `pop` возвращает и удаляет последний помещённый элемент — порядок LIFO.
После извлечения место доступно для нового добавления.

Хранилище — массив `T[]`, переданный конструктору; его положительная длина задаёт
вместимость. Новый стек пуст независимо от содержимого переданного массива.
Фактический тип компонента массива совпадает с аргументом типа стека. Клиент после
передачи не использует массив напрямую и не добавляет `null`. Это предпосылки
использования; проверять их программно не требуется.

В заполненном контейнере `push` выбрасывает проверяемое `StackFullException`, в
пустом контейнере `pop` — проверяемое `StackEmptyException`. Определите эти классы
как наследников `Exception`. Дополнительные проверяемые отказы операций не вводятся;
объявления в реализации должны соответствовать интерфейсу. Отказ сохраняет прежние
элементы и порядок их извлечения. Внутренние поля и вспомогательные методы выберите
самостоятельно.

Покажите работу со строками и целыми числами, обработку обоих отказов и повторное
добавление после извлечения из заполненного стека. Подготовка к объявлениям и
обработке отказов: раздел теории курса
[«Проверяемый отказ операции»](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/exceptions.html#sec-j25-theory-exceptions-early-checked).

## Работа с проектом

Имя класса реализации, его поля, вспомогательные методы и устройство конструкторов
исключений выберите самостоятельно. Соблюдайте заданные операции интерфейса и
поведение стека. Проверяйте состояние последовательностью вызовов клиента.

Разместите Java-файлы в `src/`. Имена файлов должны совпадать с именами объявленных
в них открытых классов. Для компиляции всех своих исходников из корня проекта нужен
JDK 25:

```bash
find src -name '*.java' -print > sources.txt
javac --release 25 -encoding UTF-8 -d out @sources.txt
```

Точку запуска выберите самостоятельно. Например, класс `Demo` с `main` в безымянном
пакете запускается командой `java -cp out Demo`; для класса в пакете укажите его
полное имя.

Файл `examples/scenarios.json` описывает случаи для проверки решения. Формат ввода
вашей программы выбирайте самостоятельно. Представьте исходники и демонстрацию
случаев из условия; объясните связи типов и причины ожидаемых результатов. Отдельный
большой отчёт не требуется.
