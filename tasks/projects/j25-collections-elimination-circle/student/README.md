## Вычеркивание каждого второго

В круге стоят `N` человек с номерами от `1` до `N`, где `1 <= N <= 10000`.
Счёт начинается с человека 1: первый остаётся, второй вычёркивается.
После удаления счёт продолжается со следующего оставшегося человека;
после конца круга возвращается к его началу. Удаляйте каждого второго,
пока не останется один. Получите порядок выбывания и номер оставшегося.

Для `N = 5` выбывают `2, 4, 1, 5`, остаётся `3`; при `N = 1` удалений нет,
остаётся `1`. Создайте две реализации процесса: на `ArrayList` и на
`LinkedList`. Они должны давать одинаковые результаты.

Сопоставьте время на одинаковых `N`, выполнив несколько повторов после
прогрева. Вывод результатов исключите из измерения; укажите, входит ли
создание списка в измеряемый участок. Объясните стоимость удаления и поиска
следующей позиции в своём алгоритме. Конкретные времена и заранее выбранный
«победитель» условием не задаются. [Источник 1]
