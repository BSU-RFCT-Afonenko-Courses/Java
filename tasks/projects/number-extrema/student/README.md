# Наибольшее и наименьшее число

Сначала введите положительное целое `n`, затем ровно `n` значений типа `int`. Найдите наибольшее и наименьшее значение; при `n = 1` они совпадают. Нулевое или отрицательное `n` отклоните, не читая последовательность: пустая последовательность не имеет экстремумов.

Вход и результат: числа стандартного ввода разделены пробельными символами. Для допустимого набора выведите `Максимум: <значение>`, затем `Минимум: <значение>`. Например, `4 7 -3 0 7` даёт `Максимум: 7` и `Минимум: -3`. Для `n <= 0` выведите `Количество должно быть положительным`. Для положительного `n` гарантирован полный корректный набор чисел.

## Исходник и запуск

В `src/main/java/Main.java` находится заготовка с `TODO`. Успешная
компиляция заготовки не означает, что решение готово: требуемое поведение
ещё нужно реализовать. Сохраните
точку входа `Main.main(String[] args)`; вспомогательные методы и классы
разрешены.

Откройте каталог, содержащий этот `README.md` и `src`. Выполните команды
инструментами JDK 25. После изменения исходника повторите компиляцию:

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/*.java
printf '4 7 -3 0 7' | java -cp out Main
printf '0' | java -cp out Main
```

Первый запуск должен дать две строки: `Максимум: 7` и `Минимум: -3`. Второй — `Количество должно быть положительным`; читать значения последовательности при нулевом количестве не нужно.

В примерах вход передаётся командой `printf` оболочки POSIX (например, bash).
В другой оболочке можно сохранить тот же ввод в файле UTF-8 и перенаправить
его в программу. `printf ''` создаёт пустой поток с EOF.

Публичные примеры находятся в `src/test/java/PublicExamplesTest.java`
и используют JUnit 5. Они охватывают часть случаев; полные требования
задаёт условие выше. Компиляция не проверяет соответствие поведения
программы условию.
