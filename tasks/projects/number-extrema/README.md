# Проект: number-extrema

Сначала введите положительное целое `n`, затем ровно `n` значений типа `int`. Найдите наибольшее и наименьшее значение; при `n = 1` они совпадают. Нулевое или отрицательное `n` отклоните, не читая последовательность: пустая последовательность не имеет экстремумов.

Протокол проверки: числа стандартного ввода разделены пробельными символами. Для допустимого набора выведите `Максимум: <значение>`, затем `Минимум: <значение>`. Например, `4 7 -3 0 7` даёт `Максимум: 7` и `Минимум: -3`. Для `n <= 0` выведите `Количество должно быть положительным`. Для положительного `n` гарантирован полный корректный набор чисел.

Соберите `student/src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out student/src/main/java/*.java`, затем запустите `java -cp out Main`. Для дополнительного входа передайте текст через stdin; без входа закройте stdin (EOF). Вспомогательные методы и классы разрешены.

Публичные примеры: `student/src/test/java/PublicExamplesTest.java`. Их можно запускать JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.

Для преподавателя: `reference/Main.java` — авторское решение, `tests/junit/ContractTest.java` — закрытые проверки, `tests/fixtures/` — ошибочные решения, `tests/contract-cases.json` — обязательные ожидаемые результаты их проверки. Компиляция starter успешна; его поведенческие тесты должны выявить незавершённое решение. Авторское решение должно пройти публичные и закрытые тесты. Каждый ошибочный пример должен скомпилироваться и дать хотя бы один поведенческий отказ. Фактические результаты полного прогона сохраняются в выводе штатной проверки вне исходного репозитория; порядок проверки описан в [текущей документации](../../../docs/prairielearn-labs.md).
