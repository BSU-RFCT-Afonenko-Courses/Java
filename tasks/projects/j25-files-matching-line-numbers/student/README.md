## Номера совпадающих строк

Для вывода результатов создайте новый каталог и файл средствами класса `File`. Входной файл содержит текстовые строки. Найдите номера строк, совпадающих с заданной строкой. Имя файла и строка для поиска — аргументы командной строки. Выведите строки файла и номера строк, совпадающих с заданной.

Входной UTF-8-файл: строки «alpha», «beta», «alpha». Нумерация с 1, сравнение всей строки с учётом регистра. Для строки «alpha» совпадают номера 1 и 3.

Сравнивайте текст, полученный через `readLine()`, с аргументом поиска
без изменения регистра и пробелов. Пустая строка поиска допустима
и совпадает с пустыми физическими строками. Выведите все строки входа
в прежнем порядке и отдельно список совпавших номеров по возрастанию;
для отсутствия совпадений явно покажите пустой список. Форму двух разделов
результата выберите самостоятельно и сохраните в новом UTF-8-файле.
Путь результата задайте в программе или дополнительным аргументом
и укажите при демонстрации. Для POSIX-оболочки пустой аргумент передаётся
как `''`, строка с пробелом — как `'alpha beta'`. [1]

## Компиляция и запуск

Сохраните исходники `.java` в `src/`. Из корня проекта с установленным
JDK 25 выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out <класс>
```

Имя класса запуска и вспомогательные методы выберите самостоятельно. Добавьте к команде аргументы,
указанные условием. Если объявлен пакет, используйте полное имя класса.
После добавления вложенных каталогов перечислите соответствующие исходники
в команде компиляции.

Проверочные данные и ожидаемые наблюдения описаны в
[examples/README.md](examples/README.md). Пути с пробелами передавайте
одним аргументом в кавычках; пустой аргумент в POSIX-оболочке — `''`.
Если условие оставляет порядок аргументов или форму результата свободными,
укажите свой выбор в демонстрации.
