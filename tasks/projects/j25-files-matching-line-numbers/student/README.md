## Номера совпадающих строк

Для вывода результатов создайте новую директорию и файл средствами класса File. В файле содержится совокупность строк. Найдите номера строк, совпадающих с заданной строкой. Имя файла и строка для поиска — аргументы командной строки. Выведите строки файла и номера строк, совпадающих с заданной.

Входной UTF-8-файл: строки «alpha», «beta», «alpha». Нумерация с 1, сравнение всей строки с учётом регистра. Для строки «alpha» совпадают номера 1 и 3.

Сравнивайте текст, полученный через `readLine()`, с аргументом поиска
без изменения регистра и пробелов. Пустая строка поиска допустима
и совпадает с пустыми физическими строками. Выведите все строки входа
в прежнем порядке и отдельно список совпавших номеров по возрастанию;
для отсутствия совпадений явно покажите пустой список. Форму двух разделов
результата выберите самостоятельно и сохраните в новом UTF-8-файле.
Путь результата задайте в программе или дополнительным аргументом
и укажите при демонстрации. Для POSIX-оболочки пустой аргумент передаётся
как `''`, строка с пробелом — как `'alpha beta'`. [1]


## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`; запуск выбранного вами класса `java -cp out <класс>`. Соблюдайте только явно заданные карточкой имена/каналы/методы; project ZIP не вводит новых Main/пакета/public/static/helperAPI. Данные в examples/; пути с пробелами передавайте одним аргументом, пустой аргумент POSIX — `''`. Если канал/порядок аргументов свободен, укажите выбранный способ в демонстрации.
