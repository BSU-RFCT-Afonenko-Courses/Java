# Совпадение целой строки

Создайте UTF-8-файл:

```text
alpha
beta
alpha
```

Поиск `alpha` даёт номера 1 и 3. Результат также содержит все три исходные
строки в прежнем порядке. Поиск `Alpha` даёт пустой список номеров.

Добавьте пустую физическую строку и выполните поиск пустой строки.
Она должна совпасть именно с этой строкой. В POSIX-оболочке пустой аргумент
передаётся как `''`. Краевые пробелы поиска и строк входа сохраняются.
