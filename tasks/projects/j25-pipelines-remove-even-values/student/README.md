## Удаление четных элементов массива

В переданном ненулевом `int[]` оставьте нечётные элементы в исходном порядке, а оставшийся хвост заполните нулями. Отбор выполните через Stream API. Вход может быть пустым и содержать любые значения `int`, включая отрицательные и ноль; все повторы нечётных значений сохраняются.

Измените тот же массив, сохранив его размер. Временный массив или коллекция допустимы. `{2, 3, 4, 3}` превращается в `{3, 3, 0, 0}`, `{-3, 0, -2, -1}` — в `{-3, -1, 0, 0}`. Пустой массив остаётся пустым; массив без нечётных элементов заполняется нулями целиком. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Обязательные Stream API/лямбда/собственный интерфейс проверяются по исходнику.

## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`, демонстрируйте выбранным вами способом `java -cp out <класс>`. Форма main и имена этой поставкой не назначаются. Public examples в examples/README.md.
