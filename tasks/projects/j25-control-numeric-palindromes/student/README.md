# Числа-палиндромы

Сначала введите неотрицательное целое `n`, затем ровно `n` чисел типа `int`.
Выведите в исходном порядке числа, десятичная запись модуля которых
одинакова при чтении слева направо и справа налево. Знак не учитывается;
`-121`, `121`, `7` и `0` подходят, `10` — нет. Сохраняйте знак и все
повторные вхождения. Если подходящих чисел нет, в том числе при `n = 0`,
выведите «Подходящих чисел нет».

## Исходники и запуск

Используйте JDK 25. Классы, пакеты, вспомогательные методы и допустимую
форму `main` выберите самостоятельно. `src/RunExample.java` содержит
заготовку запуска, которую можно заменить; её метод выбрасывает
`UnsupportedOperationException` с просьбой реализовать условие.
`src/Решение.java` содержит только комментарии. Поэтому успешная
компиляция исходной заготовки ещё не означает готового решения.

Разместите свои исходники в `src`. Если вы сохраняете имя `RunExample`
и файлы непосредственно в `src`, выполняйте из каталога этого `README.md`:

```bash
javac -encoding UTF-8 -d out src/*.java
printf '5 -121 121 7 0 10' | java -cp out RunExample
printf '0' | java -cp out RunExample
```

Первый запуск должен вывести `-121 121 7 0` в исходном порядке; второй — `Подходящих чисел нет`. Первое число ввода обозначает количество последующих значений.

Если выбраны другое имя или пакет, укажите в команде полное имя своего
класса; при другой структуре каталогов перечислите нужные исходники
в команде `javac`. Требования к входу и результату от этого не меняются.
Числа стандартного ввода разделяются пробельными символами.
Дополнительные примеры: [examples/README.md](examples/README.md).

Команды `printf` приведены для оболочки POSIX. В другой оболочке подайте
тот же текст через перенаправление стандартного ввода из файла.
