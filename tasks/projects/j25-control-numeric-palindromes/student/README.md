## Числа-палиндромы

Сначала введите неотрицательное целое `n`, затем ровно `n` чисел типа `int`.
Выведите в исходном порядке числа, десятичная запись модуля которых
одинакова при чтении слева направо и справа налево. Знак не учитывается;
`-121`, `121`, `7` и `0` подходят, `10` — нет. Сохраняйте знак и все
повторные вхождения. Если подходящих чисел нет, в том числе при `n = 0`,
выведите «Подходящих чисел нет». [1]


## Общий контекст

Поставка ZIP сама по себе не задаёт имён классов/пакетов, static/instance, доступности main или обязательного параметра String[]. Используйте допустимый запуск Java25 выбранного вами класса. Канал данных задаётся самой карточкой: ввод последовательности у палиндромов, реальные аргументы командной строки у суммы/произведения и позиционной записи. Для матриц новый stdin/argv протокол не установлен. Числа опубликованного консольного протокола разделяются пробельными символами.

## Локальная работа

Используйте JDK25. Создайте свои .java в src/, компилируйте их в отдельный out: `javac -encoding UTF-8 -d out src/*.java`. Демонстрируйте решение обычным запуском выбранного класса `java -cp out <класс>`. Выбирайте класс запуска самостоятельно; заготовка RunExample (если есть) — заменяемый пример формы Java25, а не дополнительный API. Канал ввода и предметные результаты остаются из условия. Примеры в examples/README.md.
