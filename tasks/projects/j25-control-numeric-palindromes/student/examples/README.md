# Примеры отбора палиндромов

Ввод начинается с количества значений. Следующие числа — элементы набора;
их знак сохраняется в результате, а при проверке записи не учитывается.

| Стандартный ввод | Ожидаемый результат |
|---|---|
| `5 -121 121 7 0 10` | `-121 121 7 0` |
| `4 121 10 121 -121` | `121 121 -121` |
| `2 10 -12` | `Подходящих чисел нет` |
| `0` | `Подходящих чисел нет` |

Вторая строка показывает, что повторные вхождения сохраняются. Для
`n = 0` после количества нет значений, которые нужно читать.
Порядок компиляции и запуска указан в [README.md](../README.md).
