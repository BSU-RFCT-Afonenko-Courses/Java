# Проект: compress-character-runs

## Сжатие повторяющихся символов

Сожмите строку, состоящую только из латинских букв A–Z/a–z. Каждую
максимальную серию одинаковых соседних букв длины не менее двух замените
одной такой буквой и десятичным числом повторений без ведущих нулей.
Одиночная буква записывается без числа; регистр различается. Числа могут быть
многозначными: `aa` даёт `a2`, двенадцать `a` — `a12`. Цифры в исходной
строке запрещены, поэтому результат можно однозначно распаковать.
`hellowoooorld` даёт `hel2owo4rld`; пустая строка даёт пустую строку.

Оформите отдельную программу, запускаемую командой `java Main` в Java 25. Форму точки входа выберите самостоятельно; она должна обеспечивать описанную ниже работу с аргументами командной строки.
Единственный аргумент — исходная строка целиком, включая возможную пустую
строку. Вход заведомо соответствует алфавиту; стандартный ввод не используется.
Выведите только сжатый текст и завершающий перевод строки:
`java Main "aaBBa"` даёт `a2B2a`. Команда `java Main ""` передаёт пустую
строку и выводит пустую строку. Алгоритм и вспомогательные методы свободны.


## Данные и границы текста

Если карточка не задаёт более узкий алфавит, входные строки состоят из
латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9,
знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные
сочетания Unicode не допускаются. Строки не равны `null`; пустая строка
допустима. Символ и единица длины здесь — один `char`.

Слово — максимальная непустая последовательность букв указанного алфавита.
Цифры и все небуквенные символы разделяют слова. В преобразованиях слов
сохраняйте исходный порядок и все разделители, если карточка не требует
иного. Регистр учитывается, кроме явно оговорённого сравнения без регистра.
В отсутствие слов преобразование слов оставляет текст прежним, поиск слов
по длине выводит сообщение «Слов нет», подсчёт вхождений слова возвращает ноль.

Сборка Java 25: `javac --release 25 -encoding UTF-8 -d out src/main/java/*.java`.
Запуск: `java -cp out Main` с аргументами из условия.
Публичные примеры находятся в `src/test/java/`.
