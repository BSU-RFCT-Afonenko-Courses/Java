# character-file-copy — заготовка Java25

Программа получает два аргумента: путь входного файла и путь выходного.
Каждый путь передаётся одним аргументом; пути с пробелами заключайте в кавычки.
Относительные пути относятся к рабочему каталогу процесса.

Копируйте конечный корректный UTF-8-текст, заменяя только обычный пробел
U+0020 на дефис U+002D. Сохраните табуляции, другие пробельные символы,
Unicode, CR/LF/CRLF и отсутствие последнего перевода строки. Пустой вход допустим.
Используйте Reader/Writer, явную UTF-8 и try-with-resources.

Вход открывается до выхода. Новый выход создаётся, существующий заменяется.
Отсутствие входа сохраняет прежний выход и не создаёт новый. Если пути
обозначают один существующий файл, откажите до открытия выхода, сохранив вход;
разные записи пути и поддержанные файловые ссылки могут обозначать тот же файл.
При IO-ошибке сообщите причину, не объявляйте успешное копирование.
Частичный выход при отказе записи допустим. Текст/канал диагностики и
код завершения свободны; System.exit допустим.

Main.java — только предложенная начальная заготовка. Можно менять имя файла,
класс, пакет, поддерживаемую Java25 форму main и внутренние методы.
Никакого обязательного copy(...) или другого helper API нет. Для исходной
заготовки из этого каталога:

```bash
javac --release 25 -encoding UTF-8 -d out Main.java
java -cp out Main samples/public-text-input.txt result.txt
```

После переименования используйте своё имя класса и перечислите все
дополнительные .java при компиляции. Пакет указывается в launch class.
Первая компиляция TODO проходит, копирование до реализации отказывает.

В samples находятся три пары input/expected: обычный текст без конечного LF,
пустой файл, табуляция/NBSP/CRLF. Сравните полученный файл с соответствующим
expected побайтно. Дополнительно предъявите отказ при отсутствующем входе
и самокопировании, сохранность файлов и объясните порядок открытия/закрытия.
Корректные bytes не заменяют чтение исходника с требуемой техникой ресурсов.
