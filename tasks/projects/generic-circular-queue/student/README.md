## Обобщённая кольцевая очередь

Реализуйте `CircularQueue<T>` с операциями `void put(T value)` и `T get()`
на массиве `T[]`, переданном конструктору. Длина массива положительна
и задаёт вместимость; исходная очередь пуста. Клиент после передачи
не использует массив напрямую; фактический тип компонента совпадает
с аргументом типа очереди. Освободившиеся позиции используются повторно;
порядок извлечения — FIFO.

Добавляемые элементы отличны от `null`. При полном состоянии `put` выводит
сообщение и не меняет очередь; при пустом `get` выводит сообщение
и возвращает `null`, сохраняя состояние. Текст сообщения об отказе свободен.
Покажите переход индексов через конец массива,
повторное использование места и работу с двумя типами элементов.
Готовая символьная очередь для выполнения не требуется.
