# Размер изображения

Программа вычисляет объём несжатого изображения в байтах и мебибайтах по ширине, высоте и
числу байтов на пиксель.

Данные, результаты и обязательные средства Java приведены в [условии
задания](../../bank/numbers.qmd#exr-numbers-image-size). [Инструкция к стартовому
проекту](student/README.md) содержит порядок работы и требования к предъявлению решения.

## Работа с проектом

Исходники заготовки находятся в `student/src/main/java/`. Для сборки нужен JDK 25. Следующие
команды выполняются из каталога этого проекта:

```bash
javac --release 25 -encoding UTF-8 -d out student/src/main/java/*.java
printf '50000 50000 3' | java -cp out Main
```

Команда `printf` передаёт данные на стандартный ввод программы и завершает поток. Другие
допустимые данные и ожидаемые результаты приведены в условии.

Открытые примеры JUnit 5 находятся в `student/src/test/java/PublicExamplesTest.java`. После
реализации сопоставьте результаты с этими примерами и остальными требованиями условия.

## Проверка преподавателем

Преподавательская реализация находится в `reference/`, закрытые проверки — в `tests/junit/`.
В `tests/fixtures/` хранятся варианты для проверки самих тестов; ожидаемые исходы указаны в
`tests/contract-cases.json`. Для выдачи студенту используется только каталог `student/`.

Проверьте точность промежуточных вычислений на всём диапазоне входных данных, включая объём,
превосходящий диапазон `int`.

Проверьте компиляцию исходников решения отдельно от тестов, затем запустите открытые и
закрытые проверки. Применение требуемых средств Java и объяснение решения оцените по
исходнику и демонстрации. Порядок работы со средой проверок описан в [документации
курса](../../../docs/prairielearn-labs.md).
