# Размер изображения

В стандартном вводе заданы три целых числа: width height bytesPerPixel.
Ширина и высота находятся в диапазоне 1..100000, число байтов на пиксель — 1..8.
Вход заведомо корректен; его валидация не требуется. Сжатия и служебных заголовков нет.
Выведите точное количество байтов целым числом, затем размер в мебибайтах
дробным числом с точкой. 1 МиБ = 1 048 576 байт. Для второго результата допустима
абсолютная ошибка 1e-8; количество десятичных знаков не фиксировано.
Результаты разделяются пробельными символами, приглашения к вводу не требуются.

Примеры: 1024 1024 4 → 4194304 4.0; 50000 50000 3 → 7500000000 7152.557373046875.
Проверьте также один пиксель и границы объявленного диапазона. Типы промежуточных
вычислений должны сохранять точность. Имена вспомогательных методов, разбиение
программы и способ вычисления выбирайте самостоятельно.

Java 25 без preview, точка входа Main.main(String[] args). Публичные примеры
показывают часть контракта и не заменяют все требования условия.

Компиляция: `javac --release 25 -encoding UTF-8 -d out src/main/java/*.java`.
Запуск: `java -cp out Main`; передайте вход в stdin.
Публичные проверки: `src/test/java/PublicExamplesTest.java` (JUnit 5).
