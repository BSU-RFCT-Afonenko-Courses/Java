## Подкласс Circle

Объявите абстрактный `TwoDShape` с закрытыми полями `double width`, `double height`, `String name`, конструктором `TwoDShape(double width, double height, String name)`, открытыми методами `double getWidth()`, `double getHeight()`, `String getName()` и абстрактным `public double area()`.

Создайте подкласс `Circle` с открытым конструктором `Circle(double radius)`. Допустимый радиус — конечное `double` в диапазоне `0 < radius <= 1e150`; неверные входы проверять не требуется. Через `super` передайте в базовый класс ширину и высоту, равные диаметру, и имя `"circle"`. Реализуйте площадь круга. Покажите вызов `area()` через ссылку `TwoDShape`; размеры и площадь должны соответствовать одному радиусу. Для радиуса 2 размеры равны 4, площадь приблизительно 12.566370614359172.

Результат площади должен быть конечным. Допускается абсолютная погрешность до `1e-9` для малых значений либо относительная до `1e-12` для больших: если математическая площадь равна y = πr², возвращённое значение a удовлетворяет `|a - y| <= max(1e-9, 1e-12 * |y|)`.
