## Выбор более длинной строки

Определите собственный функциональный интерфейс с одним абстрактным методом из двух `String` в `String`. Реализуйте его лямбдой, выбирающей более длинную строку; длина измеряется кодовыми единицами `char` через `String.length()`.

Оба аргумента ненулевые, пустые строки допустимы. При равной длине верните значение первой строки. Например, для `"ab"` и `"XYZ"` результат `"XYZ"`, для `"ab"` и `"cd"` — `"ab"`, для двух пустых строк — пустая строка. Имена интерфейса и метода свободны. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Обязательные Stream API/лямбда/собственный интерфейс проверяются по исходнику.

## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`, демонстрируйте выбранным вами способом `java -cp out <класс>`. Форма main и имена этой поставкой не назначаются. Public examples в examples/README.md.
