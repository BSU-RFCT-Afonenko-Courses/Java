# Открытые сценарии

1. vals длины 10: присваивание vals[18]=10 вызывает обработчик. Длина 20: в ячейке 18 значение 10.
2. Метод throws A бросает A: общий обработчик; затем B: специальный обработчик B.
3. throw new MyClass(): MyClass проверяемое исключение; показать catch либо throws.

Формат сообщения и запуска свободен. Объясните три исходные причины ошибки компиляции.
