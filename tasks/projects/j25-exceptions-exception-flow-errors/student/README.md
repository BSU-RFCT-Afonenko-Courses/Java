## Ошибки в обработке и генерации исключений

Подготовьте три независимые небольшие программы, исправив описанные ошибки.
Добавьте необходимый контекст классов и методов, сохранив предмет каждого фрагмента.

1. После присваивания `vals[18] = 10;` непосредственно расположен `catch (ArrayIndexOutOfBoundsException exc) { /* обработать ошибку */ }`. Добавьте недостающую конструкцию обработки исключения. Создайте массив `int` длины 10, чтобы присваивание вызвало исключение,
и покажите работу обработчика; затем повторите опыт с длиной 20 и успешным присваиванием.
2. Даны классы `A extends Exception` и `B extends A`. За блоком `try` расположен сначала обработчик `catch (A exc)`, затем `catch (B exc)`. Исправьте расположение обработчиков, сохранив обработку обоих типов; поместите в `try` вызов метода, объявленного с `throws A`.
В двух запусках этот метод выбрасывает соответственно `A` и `B`;
покажите, какой обработчик выбирается.
3. Объявлен обычный класс `MyClass`, а затем выполняется `throw new MyClass();`. Исправьте объявление класса и окружающий код, чтобы объект этого класса можно было использовать как проверяемое исключение.
Покажите его обработку либо допустимую передачу через `throws`.

Имена дополнительных классов и методов выберите самостоятельно.
Для каждой программы объясните исходную причину ошибки компиляции
и наблюдаемый путь выполнения после исправления. [1]


## Локальная работа

JDK 25; сохраните три независимые программы в отдельных каталогах, компилируйте каждую `javac -encoding UTF-8 -d out <исходники>` и запускайте выбранный класс `java -cp out <класс>`. Можете использовать свои методы, имена/пакеты и вывод. Примеры в examples/README.md. Не объединяйте ошибочные исходные фрагменты с исправленными при обычной компиляции.
