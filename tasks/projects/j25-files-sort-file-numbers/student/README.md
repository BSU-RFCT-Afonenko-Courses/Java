## Сортировка чисел в файле

Для вывода результатов создайте новую директорию и файл средствами класса File. В текстовом файле содержатся целые числа. Прочитайте их и запишите содержимое в новый файл, отсортировав по возрастанию.

Входной UTF-8-файл содержит строку «7 −2 7 0 3 −5»; в фактическом файле используйте обычный ASCII-минус. Разделитель — пробельные символы, результат содержит те же числа и повторы.

Допустимы целые значения диапазона `int`, разделённые одним или несколькими
ASCII-пробелами, табуляциями либо переводами строк. Пустой вход допустим.
Выведите числа через один пробел в возрастающем порядке, сохранив повторы;
последний перевод строки необязателен. Пример даёт `-5 -2 0 3 7 7`.
Пути входа и нового результата задайте явно в демонстрации. Открывайте
результат после чтения входа; при ошибке чтения новый файл не создаётся. [1]


## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`; запуск выбранного вами класса `java -cp out <класс>`. Соблюдайте только явно заданные карточкой имена/каналы/методы; project ZIP не вводит новых Main/пакета/public/static/helperAPI. Данные в examples/; пути с пробелами передавайте одним аргументом, пустой аргумент POSIX — `''`. Если канал/порядок аргументов свободен, укажите выбранный способ в демонстрации.
