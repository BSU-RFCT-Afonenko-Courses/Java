## Сортировка чисел в файле

Для вывода результатов создайте новый каталог и файл средствами класса `File`. В текстовом файле содержатся целые числа. Прочитайте их и запишите содержимое в новый файл, отсортировав по возрастанию.

Входной UTF-8-файл содержит строку «7 −2 7 0 3 −5»; в фактическом файле используйте обычный ASCII-минус. Разделитель — пробельные символы, результат содержит те же числа и повторы.

Допустимы целые значения диапазона `int`, разделённые одним или несколькими
ASCII-пробелами, табуляциями либо переводами строк. Пустой вход допустим.
Выведите числа через один пробел в возрастающем порядке, сохранив повторы;
последний перевод строки необязателен. Пример даёт `-5 -2 0 3 7 7`.
Пути входа и нового результата задайте явно в демонстрации. Открывайте
результат после чтения входа; при ошибке чтения новый файл не создаётся. [1]

## Компиляция и запуск

Сохраните исходники `.java` в `src/`. Из корня проекта с установленным
JDK 25 выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out <класс>
```

Имя класса запуска и вспомогательные методы выберите самостоятельно. Добавьте к команде аргументы,
указанные условием. Если объявлен пакет, используйте полное имя класса.
После добавления вложенных каталогов перечислите соответствующие исходники
в команде компиляции.

Проверочные данные и ожидаемые наблюдения описаны в
[examples/README.md](examples/README.md). Пути с пробелами передавайте
одним аргументом в кавычках; пустой аргумент в POSIX-оболочке — `''`.
Если условие оставляет порядок аргументов или форму результата свободными,
укажите свой выбор в демонстрации.
