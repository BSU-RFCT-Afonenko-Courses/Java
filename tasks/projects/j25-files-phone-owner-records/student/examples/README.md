# Отбор телефонных записей

Создайте UTF-8-файл:

```text
291234567;Анна
331234567;Борис
441234567;Вера
```

При префиксах `29` и `33` выход содержит первые две строки в прежнем порядке.
При одинаковых префиксах `29` и `29` первая строка выводится один раз.
Если первая запись повторена во входе, оба её появления проходят отбор.
Префиксы, не совпавшие ни с одним телефоном, дают пустой результат.
