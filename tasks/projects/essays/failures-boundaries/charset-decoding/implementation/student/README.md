# Реализация строгого декодирования полного сообщения

Реализуйте метод `Utf8Decoder.decodeStrict(byte[] bytes)`. Вход не равен `null`, содержит полное сообщение UTF-8 и имеет длину от 0 до 4096 байт. Для корректного входа верните точную строку, включая пустую строку и буквальный символ U+FFFD; для недопустимой или незавершённой последовательности выбросьте `CharacterCodingException`. Не изменяйте исходный массив ни при успешном декодировании, ни при отказе. Используйте явное указание UTF-8; выбор алгоритма и допустимого подкласса исключения остаётся за вами. Сигнатуру метода сохраните, вывод в консоль не требуется.

## Локальный запуск

Нужны JDK 25 и совместимый Gradle. Из корня этого архива выполните:

```sh
gradle test
```

Исходники: `src/main/java`; открытые проверки: `src/test/java`.
Отчёт JUnit: `build/reports/tests/test/index.html`. Открытые примеры служат
для подготовки; официальная проверка использует отдельный доверенный набор.
