# Тестирование контракта строгого декодирования

В файле `Utf8DecoderTest.java` разработайте тесты JUnit 5 для метода `Utf8Decoder.decodeStrict(byte[] bytes)`. Вход не равен `null`, содержит полное сообщение и имеет длину от 0 до 4096 байт. Метод возвращает точную строку для корректного UTF-8 и выбрасывает `CharacterCodingException` для любой недопустимой последовательности, в том числе незавершённой в конце; исходный массив сохраняется при любом исходе. Обоснуйте тестами обработку пустого входа, символов с двух-, трёх- и четырёхбайтовым представлением, корректно закодированного U+FFFD, недопустимой последовательности внутри сообщения и оборванного окончания. Проверяйте контракт, не конкретный подкласс исключения или текст диагностики.

Изменяйте только `Utf8DecoderTest.java`; представленный декодер намеренно заменяет повреждённые последовательности и служит для локального испытания. Полный набор тестов должен обнаруживать этот дефект; отказ соответствующих локальных тестов ожидаем. При оценивании ваши тесты выполняются с корректной реализацией и с реализациями, нарушающими перечисленные свойства; корректная должна пройти весь набор, каждое нарушение должно обнаруживаться хотя бы одним тестом. Используйте вызов указанного API и проверки JUnit, без пропуска тестов или зависимости от окружения и внутреннего устройства реализации.

## Полный проект

`student/` содержит заготовку и открытые JUnit-примеры; `reference/` — авторское
решение; `tests/` — доверенный контракт и отрицательные fixtures. Нужны JDK 25
и совместимый Gradle. Из корня полного комплекта выполните:

```sh
gradle -p student test
gradle -p student -Preference -Pgrading test
```

Для implementation задания первая команда характеризует заготовку, вторая —
эталон. В test-design ошибочные реализации должны быть обнаружены тестами.
Отказы незавершённого ответа ожидаемы и не означают сбой инструмента.

Официальное оценивание и полная авторская проверка используют опубликованный
Platform runner по объявленному `project-check`; переданный student Gradle
не выполняется в grading job.
