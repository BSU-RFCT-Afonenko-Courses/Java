## Последние слова последних строк

Для вывода результатов создайте новую директорию и файл средствами класса File. Введите из текстового файла, связанного с входным потоком, последовательность строк. Выберите и сохраните m последних слов в каждой из последних n строк.

Входной UTF-8-файл: строки «one two three», «four five», «six seven eight nine»; параметры m = 2, n = 2. Если слов или строк меньше, сохраняйте все доступные; разделитель слов — пробел.

Параметры `m` и `n` — неотрицательные целые числа. Слово — непустая
последовательность символов между ASCII-пробелами; последовательные
пробелы разделяют слова и не создают пустых слов. Пустые физические строки
учитываются среди последних `n` строк. Сохраните порядок выбранных строк
и слов, разделяя оставшиеся слова одним пробелом. При `m == 0` каждая
выбранная строка пуста; при `n == 0` выход пуст. Для примера результат —
строки `four five` и `eight nine`. Покажите также пустой файл. [1]


## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`; запуск выбранного вами класса `java -cp out <класс>`. Соблюдайте только явно заданные карточкой имена/каналы/методы; project ZIP не вводит новых Main/пакета/public/static/helperAPI. Данные в examples/; пути с пробелами передавайте одним аргументом, пустой аргумент POSIX — `''`. Если канал/порядок аргументов свободен, укажите выбранный способ в демонстрации.
