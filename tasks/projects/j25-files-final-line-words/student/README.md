## Последние слова последних строк

Для вывода результатов создайте новый каталог и файл средствами класса `File`. Прочитайте строки текстового файла. Выберите и сохраните `m` последних слов в каждой из последних `n` строк.

Входной UTF-8-файл: строки «one two three», «four five», «six seven eight nine»; параметры m = 2, n = 2. Если слов или строк меньше, сохраняйте все доступные; разделитель слов — пробел.

Параметры `m` и `n` — неотрицательные целые числа. Слово — непустая
последовательность символов между ASCII-пробелами; последовательные
пробелы разделяют слова и не создают пустых слов. Пустые физические строки
учитываются среди последних `n` строк. Сохраните порядок выбранных строк
и слов, разделяя оставшиеся слова одним пробелом. При `m == 0` каждая
выбранная строка пуста; при `n == 0` выход пуст. Для примера результат —
строки `four five` и `eight nine`. Покажите также пустой файл. [1]

## Компиляция и запуск

Сохраните исходники `.java` в `src/`. Из корня проекта с установленным
JDK 25 выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out <класс>
```

Имя класса запуска и вспомогательные методы выберите самостоятельно. Добавьте к команде аргументы,
указанные условием. Если объявлен пакет, используйте полное имя класса.
После добавления вложенных каталогов перечислите соответствующие исходники
в команде компиляции.

Проверочные данные и ожидаемые наблюдения описаны в
[examples/README.md](examples/README.md). Пути с пробелами передавайте
одним аргументом в кавычках; пустой аргумент в POSIX-оболочке — `''`.
Если условие оставляет порядок аргументов или форму результата свободными,
укажите свой выбор в демонстрации.
