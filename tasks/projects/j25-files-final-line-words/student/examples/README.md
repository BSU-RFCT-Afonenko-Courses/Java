# Выбор последних слов и строк

Создайте UTF-8-файл:

```text
one two three
four five
six seven eight nine
```

При `m = 2`, `n = 2` выход содержит:

```text
four five
eight nine
```

При недостатке слов или строк сохраняются все доступные. Пустые физические
строки учитываются в числе последних `n`. При `m = 0` каждая выбранная
строка пуста; при `n = 0` и при пустом входе выход пуст.
