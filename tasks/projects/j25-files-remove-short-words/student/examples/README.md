# Удаление коротких слов

Создайте UTF-8-файл с двумя строками:

```text
one two elephant four
a cat dog bee house
```

Ожидаемый результат:

```text
elephant four
a
```

В первой строке подходят три слова; удаляются два первых подходящих слова.
Во второй подходят четыре слова, поэтому удаляются все четыре. Строка без
подходящих слов сохраняет слова в прежнем порядке. Пустой файл даёт пустой
выход; полностью очищенная строка остаётся пустой строкой.
