## Удаление чётного количества коротких слов

Для вывода результатов создайте новую директорию и файл средствами класса File. Из файла удалите все слова, содержащие от трёх до пяти символов, но при этом из каждой строки должно быть удалено только максимальное чётное количество таких слов.

Вход: строки «one two elephant four», «a cat dog bee house». Разделитель — пробел. Если подходящих слов нечётное количество, оставьте последнее подходящее слово, чтобы число удалённых было максимальным чётным; порядок остальных слов сохраняйте.

Вход — UTF-8-текст; длину слова считайте в кодовых точках Unicode.
Слово — непустая последовательность между ASCII-пробелами; несколько
пробелов дают одну границу. Пунктуация внутри такой последовательности
участвует в длине. Выводите сохранившиеся слова каждой строки через один
пробел; полностью очищенная строка остаётся пустой. Для примера получатся
`elephant four` и `a`. Добавьте строку без подходящих слов и пустой файл. [1]


## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`; запуск выбранного вами класса `java -cp out <класс>`. Соблюдайте только явно заданные карточкой имена/каналы/методы; project ZIP не вводит новых Main/пакета/public/static/helperAPI. Данные в examples/; пути с пробелами передавайте одним аргументом, пустой аргумент POSIX — `''`. Если канал/порядок аргументов свободен, укажите выбранный способ в демонстрации.
