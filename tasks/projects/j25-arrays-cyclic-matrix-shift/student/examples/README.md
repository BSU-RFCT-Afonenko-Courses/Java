# Циклический сдвиг: примеры

Исходная матрица:

```text
-3  0  3
 2 -1  0
 1  3 -2
```

Сдвиг вправо на одну позицию:

```text
 3 -3  0
 0  2 -1
-2  1  3
```

Сдвиг влево на одну позицию:

```text
 0  3 -3
-1  0  2
 3 -2  1
```

Сдвиг вверх на одну позицию:

```text
 2 -1  0
 1  3 -2
-3  0  3
```

Сдвиг вниз на одну позицию:

```text
 1  3 -2
-3  0  3
 2 -1  0
```

Каждое преобразование применяется к исходной матрице. Для размера 3 сдвиг
на 3 позиции сохраняет расположение, а сдвиг на 4 даёт тот же результат,
что сдвиг на 1 в выбранном направлении. Способ обозначить направление
в программе выбирайте самостоятельно.
