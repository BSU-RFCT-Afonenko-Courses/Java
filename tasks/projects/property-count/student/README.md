## Подсчёт элементов с заданным свойством

Напишите обобщённый метод подсчёта элементов массива, удовлетворяющих
переданному свойству. Само свойство задайте обобщённым интерфейсом
с методом `boolean test(T value)`. Метод подсчёта получает массив
и объект, реализующий этот интерфейс; конкретное свойство не должно
быть встроено в алгоритм подсчёта.

Реализуйте два разных свойства обычными классами и примените один метод
подсчёта к двум типам элементов. Например, можно считать нечётные целые
числа и строки длиннее трёх символов. Названия и устройство классов
выберите самостоятельно; лямбды и потоки в этой задаче не используются.

Массив, элементы и объект проверки отличны от `null`; проверка свойства не меняет
элемент. Программная проверка этих предпосылок не требуется. Метод
не изменяет массив, для пустого массива возвращает ноль. Покажите случаи,
когда свойству удовлетворяют некоторые элементы, все элементы и ни один.

## Работа с проектом

Разместите исходные Java-файлы в `src/` с выбранными именами и структурой пакетов. Для компиляции нужен JDK 25: `javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java`; для нескольких файлов перечислите все исходники. Способ запуска демонстрации выбирайте самостоятельно. `examples/scenarios.json` содержит открытые наблюдения.

Преподаватель привязывает конкретное решение обычным Java-клиентом; его `TaskBinding` и выбранные в reference имена не являются дополнительным StudentAPI. Недоступное private/nested размещение сохраняет ручную проверку. Обязательная техника и объяснение проверяются по исходнику и на защите.

## Предъявление лабораторной


Представьте исходные Java-файлы и продемонстрируйте случаи, указанные
в условиях. Объясните, какие места связывает каждый параметр типа,
какие операции разрешает его граница или интерфейс и что происходит
с состоянием выбранного контейнера при отказе.

Устройство программы выбирайте самостоятельно в пределах условий
заданий. Для запуска используется JDK 25. Отдельный большой
отчёт не требуется.
