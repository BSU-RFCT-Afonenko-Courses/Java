# Подсчёт элементов с заданным свойством

Напишите обобщённый метод подсчёта элементов массива, удовлетворяющих переданному
свойству. Само свойство задайте обобщённым интерфейсом с методом
`boolean test(T value)`. Метод подсчёта получает массив и объект, реализующий этот
интерфейс; конкретное свойство не должно быть встроено в алгоритм подсчёта.

Реализуйте два разных свойства обычными классами и примените один метод подсчёта к
двум типам элементов. Например, можно считать нечётные целые числа и строки длиннее
трёх символов. Названия и устройство классов выберите самостоятельно; лямбды и
потоки в этой задаче не используются.

Массив, элементы и объект проверки отличны от `null`; проверка свойства не меняет
элемент. Программная проверка этих предпосылок не требуется. Метод не изменяет
массив, для пустого массива возвращает ноль. Покажите случаи, когда свойству
удовлетворяют некоторые элементы, все элементы и ни один.

## Работа с проектом

Имена интерфейса, классов свойств и метода подсчёта выберите самостоятельно. Для
каждого свойства до запуска укажите входные данные и ожидаемое количество подходящих
элементов. Форма операции `test` задана условием.

Разместите Java-файлы в `src/`. Имена файлов должны совпадать с именами объявленных
в них открытых классов. Для компиляции всех своих исходников из корня проекта нужен
JDK 25:

```bash
find src -name '*.java' -print > sources.txt
javac --release 25 -encoding UTF-8 -d out @sources.txt
```

Точку запуска выберите самостоятельно. Например, класс `Demo` с `main` в безымянном
пакете запускается командой `java -cp out Demo`; для класса в пакете укажите его
полное имя.

Файл `examples/scenarios.json` описывает случаи для проверки решения. Формат ввода
вашей программы выбирайте самостоятельно. Представьте исходники и демонстрацию
случаев из условия; объясните связи типов и причины ожидаемых результатов. Отдельный
большой отчёт не требуется.
