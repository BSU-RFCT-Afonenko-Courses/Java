# Нули после остальных элементов строки

Преобразуйте каждую строку матрицы 3×3 так, чтобы нули располагались после всех ненулевых элементов. Взаимный порядок ненулевых элементов сохраняется. Допустимы преобразование на месте и создание нового массива.

Обязательный исходный пример: строки `(−3, 0, 3)`, `(2, −1, 0)`, `(1, 3, −2)`. При пустом стандартном вводе используйте именно его. Для дополнительной проверки разрешены любые матрицы **3×3 с целыми значениями −3…3**: передайте девять чисел через стандартный ввод построчно. Допустимы существующие матрицы 3×3 с существующими строками и значениями в указанном диапазоне.

Выведите три строки по три числа, без подписей. Для обязательного примера результат: `(−3, 3, 0)`, `(2, −1, 0)`, `(1, 3, −2)`. Проверьте также строку, начинающуюся с нулей, строку без нулей и полностью нулевую строку.

## Сборка и запуск

В корне проекта с JDK 25 выполните:

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/*.java
java -cp out Main
```

Точка входа — `Main.main(String[] args)`. Вспомогательные классы и методы
выбирайте самостоятельно. Введите данные и завершите стандартный ввод;
пустой ввод запускает демонстрационный пример. В терминале Linux нажмите Ctrl+D
в начале пустой строки, чтобы завершить ввод.

Для повторного запуска данные можно сохранить в текстовом файле `input.txt`:

```bash
java -cp out Main < input.txt
```

Публичные примеры на JUnit 5 находятся в
[src/test/java/PublicExamplesTest.java](src/test/java/PublicExamplesTest.java).
Они задают конкретные входы и ожидаемые результаты; полный договор задачи
приведён выше.
