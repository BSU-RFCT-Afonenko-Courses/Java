## Расписание занятий: управление через интерфейсы

Предварительная подготовка: классы ([Классы, инкапсуляция и инициализация](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/classes.html#sec-j25-theory-classes)), интерфейсы
([Интерфейсы, композиция и делегирование](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/interfaces.html#sec-j25-theory-interfaces)) и коллекции ([Коллекции и способы хранения объектов](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/collections.html#sec-j25-theory-collections)).

Разработать проект управления процессами на основе создания и реализации интерфейсов для предметной области «Расписание занятий».

Возможности: создать/удалить расписание; создать/изменить/удалить предмет/преподавателя; отобразить расписание для конкретного преподавателя/конкретной группы; отобразить список всех предметов/преподавателей; изменить аудиторию; отменить занятие; добавить дополнительное занятие; добавить выходной; посчитать количество занятий у преподавателя/группы. Добавить специализированные методы для Расписания занятий в школе, Расписания занятий в автошколе.

Занятие содержит дату, время, предмет, преподавателя, группу и аудиторию; у предметов/преподавателей/групп уникальные идентификаторы. Сначала задайте два предмета, двух преподавателей, две группы и четыре занятия. Выборки и подсчёты работают для текущего расписания после изменений; удаление сущности, связанной с занятиями, должно иметь явно выбранную политику. Добавление выходного исключает занятия указанной даты согласно этой политике. Для школьной специализации добавьте выборку по классу и проверку числа уроков за день; для автошколы — выделение теоретических/практических занятий и проверку наличия учебного автомобиля для практики. Пределы уроков и модель автомобилей задайте и объясните самостоятельно. Реализуйте все перечисленные операции; интерфейсы и типы проектируются самостоятельно. [Источник 1]
