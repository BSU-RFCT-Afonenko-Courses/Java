## Сложение многочленов в HashMap

Сложите два многочлена, представленные `HashMap<Integer, Double>`.
Ключ — неотрицательная целая степень, значение — конечный коэффициент.
Карты, ключи и значения отличны от `null`. Отсутствующая степень имеет
коэффициент ноль; пустая карта представляет нулевой многочлен.
Для входов гарантируется, что математическая сумма двух коэффициентов
каждой степени по модулю не превосходит `Double.MAX_VALUE`.

Результат — самостоятельная `HashMap` с суммой коэффициентов для каждой
степени; исходные карты сохраняются. Нулевые коэффициенты можно хранить
явно или удалять. Для проверки чисел пусть `r` — математическая сумма двух
входных коэффициентов этой степени, `a` — полученный коэффициент. Допустима
погрешность `abs(a - r) <= 1e-9 + 1e-12 * abs(r)`. Отсутствующий коэффициент
результата при сравнении считается нулём. Порядок обхода карты свободен.

Для `{0: 1, 2: 3}` и `{1: 2, 2: -3}` получается `{0: 1, 1: 2}`; также
допустима пара `2: 0`. Покажите пустой вход и степени, встречающиеся только
в одной карте. Допустимы `merge` или явный `getOrDefault`/`put`.
