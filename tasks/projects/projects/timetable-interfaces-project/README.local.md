Реализуйте задание по полному условию. Минимальная заготовка содержит только обязательные объявления и TODO. Собственную модель, алгоритм и вспомогательные типы внутри фиксированного комплекта выберите в пределах условия.

Даты/время/id/модель автомобиля внутри свободны; транспорт переводит только представление. Число и имена интерфейсов/классов/методов, хранение, GUI/консольный запуск, порядок выборок свободны. Политики удаления/выходного и предел школы объявляются заранее; reject/cascade лишь примеры.

API баллов не даёт; инфраструктурный отказ оставляет результат неустановленным. Признанные прежние оценки и решения сохраняются.
