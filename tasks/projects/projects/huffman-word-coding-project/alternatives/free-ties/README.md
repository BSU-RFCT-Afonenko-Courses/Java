Равные веса упорядочиваются по лексикографически первому слову поддерева, включая промежуточные узлы. Левое ребро — 1, правое — 0. Таблица частот сохраняет порядок первого появления слов. `Main` печатает таблицу и биты; первый аргумент метода encode — настоящий исходный текст. Пустой и однословный случаи обрабатываются отдельно.
