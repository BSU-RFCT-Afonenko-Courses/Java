# Префиксное кодирование слов по алгоритму Хаффмена

[Условие задания](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/bank/projects.html#exr-projects-huffman-word-coding-project)
задаёт результат, обязательные приёмы и демонстрацию. Перед работой без сети
сохраните страницу условия. Команды ниже выполняются из каталога этого README.

Нужны JDK 25 и установленный Gradle, поддерживающий этот JDK.
Исходники решения находятся в `src/main/java`, открытый клиент —
в `src/test/java`. Дополните заготовки или используйте своё устройство
программы в пределах условия. Конфигурация использует встроенный Java-плагин
Gradle; внешние библиотеки для этих команд не нужны.

Скомпилируйте решение и открытый клиент без запуска незавершённых частей:

```console
gradle --offline classes testClasses
```

Подготовьте свою демонстрацию и вызовы решения в
[TaskBinding.java](src/test/java/TaskBinding.java). Границы этой привязки
объяснены в [BINDING.md](BINDING.md): имена заготовок и форма наблюдений
не ограничивают допустимое решение. Затем выполните:

```console
gradle --offline demo
gradle --offline publicChecks
```

Задача `demo` по умолчанию запускает `Start`. Если выбран другой класс,
передайте его полное имя через `-PdemoClass=имя.пакета.Класс` вместо запуска
по умолчанию. До реализации `Start` и методов решения заготовка сообщает
о незавершённой работе. После правок Gradle пересобирает изменённые исходники.

Файл [CHECKS.md](CHECKS.md) содержит общий пример проверки через JDK
с классами в `out`. В этом Gradle-комплекте вместо его команд компиляции
и запуска используйте указанную выше команду Gradle `publicChecks`.
Команды из `CHECKS.md` после неё не выполняйте.

`publicChecks` запускает два открытых сценария. Задача `build` тоже включает
их через `check`; преподаватель отдельно проверяет обязательные приёмы
и объяснение по условию. Для этих команд Gradle создаёт каталог `build`,
каталог `out` подготавливать не требуется.

[Сценарии](examples/scenarios.json) описывают обычный и граничные случаи;
JSON служит памяткой и не задаёт обязательный формат входа программы.
Перед реализацией разберите дерево Хаффмена на небольшой таблице частот.
Предъявите исходники и заранее назовите правило равных частот. Покажите
таблицы и биты для исходного текста и границ из условия; сопоставьте
с ними восстановление порядка слов. Отдельная операция декодирования
не требуется.
