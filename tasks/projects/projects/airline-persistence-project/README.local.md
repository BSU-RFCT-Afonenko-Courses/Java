Реализуйте задание по полному условию. Минимальная заготовка содержит только обязательные объявления и TODO. Собственную модель, алгоритм и вспомогательные типы внутри фиксированного комплекта выберите в пределах условия.

Это вызывающий порт, не заданная иерархия и не бизнес-интерфейс. Реальные классы/конструкторы/сигнатуры, виды, идентификаторы, массив/коллекция/сортировка на месте или отдельная, static/instance и сериализация Java свободны. find проецирует один, несколько или отсутствие; все совпадения не обязательны. Дополнительные static/transient-наблюдения настраиваются по выбранным реальным полям, без обязательных setter в модели.

Открытая проверка: JDK 25, `gradle test`. Два публичных случая входят в прежние 4 равных оценочных групп. Автоматическая часть: `80 × passed/total`, прежняя ручная часть — 20%. API баллов не даёт; инфраструктурный отказ оставляет результат неустановленным. Признанные прежние оценки и решения сохраняются.

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `src/main/java/Study.java`
- `src/main/java/airline/Airline.java`
- `src/main/java/airline/Cargo.java`
- `src/main/java/airline/Connector.java`
- `src/main/java/airline/Passenger.java`
- `src/main/java/airline/Plane.java`

Форма PrairieLearn: один ZIP с сохранением путей. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `airline`, `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
В полях ответа пути исходников задаются относительно `src/main/java`.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.
