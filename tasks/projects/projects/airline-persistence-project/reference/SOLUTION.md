Дальность сортируется по возрастанию. Вместимость — места, грузоподъёмность — тонны, дальность — километры, потребление — литры в час. Поиск возвращает один подходящий самолёт. Стандартная сериализация Java сохраняет модель в fleet.bin внутри предоставленного каталога. Connector отдельно читает, меняет и записывает модель. `instances` — static-счётчик созданных объектов, он не восстанавливается сериализацией; `cached` — transient-кэш, после чтения равен 0. Main содержит консольное меню.
