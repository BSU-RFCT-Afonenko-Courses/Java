# Состояние авиакомпании после сохранения

Для трёх самолётов из условия суммарная вместимость равна `232` местам,
грузоподъёмность — `38` т. При сортировке по возрастанию дальности
получается последовательность `1800`, `3000`, `4500` км; можно выбрать
и объяснить обратное направление.

В диапазон потребления `[1500, 2400]` входят два пассажирских самолёта
с граничными значениями `1500` и `2400` л/ч. Грузовой самолёт
с потреблением `3000` л/ч в этот диапазон не входит. Поиск должен
находить соответствующий диапазону самолёт; способ представления
результата выберите самостоятельно.

Последовательность проверки сохранения:

1. Создайте исходный парк и получите результаты вычислений, сортировки
   и поиска.
2. Сохраните его через коннектор и загрузите из файла. Сопоставьте виды
   самолётов и их параметры с исходными данными.
3. Измените параметр самолёта через коннектор и повторно загрузите модель.
   Полученное значение должно соответствовать сохранённому изменению.
4. Объясните наблюдаемые значения выбранных `static`- и `transient`-полей.

При стандартной сериализации обычных классов `Serializable` в поток
записываются нестатические поля без `transient`, объявленные в этих
классах. При загрузке значения этих полей восстанавливаются из потока.
Объявленные в этих классах `transient`-поля первоначально получают
значения по умолчанию своего типа; собственный код восстановления может
задать им другие значения. Поле `static` принадлежит классу и сохраняет
текущее значение в JVM; в стандартный набор сериализуемых полей оно
не входит.

При десериализации такой иерархии вызывается конструктор без аргументов
первого несериализуемого суперкласса. Его поля экземпляра инициализируются
при выполнении конструктора.
[Спецификация сериализации Java, §3.1, шаг 12](https://docs.oracle.com/en/java/javase/25/docs/specs/serialization/input.html#the-objectinputstream-class).
При собственной записи и восстановлении состояния объясните выбранные действия.

Правило состава полей: [спецификация сериализации Java, разделы 1.5 и 1.7](https://docs.oracle.com/en/java/javase/25/docs/specs/serialization/serial-arch.html#defining-serializable-fields-for-a-class).
Имена файлов, классов и операций коннектора выберите сами.
