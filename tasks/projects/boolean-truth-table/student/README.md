# Проект: boolean-truth-table

Отобразите таблицу истинности для логических операций Java. Колонки: P, Q, AND, OR, XOR, NOT; NOT означает отрицание P. Используйте табуляцию между колонками и включите все четыре сочетания P и Q.

Протокол проверки: первая строка — `P	Q	AND	OR	XOR	NOT` (между именами настоящая табуляция). Далее четыре строки по шесть значений `true` или `false`, также разделённых табуляцией. Порядок строк выберите самостоятельно. Например, для P = `true`, Q = `false` строка содержит `true false false true true false`. Ввод не требуется.

Соберите `src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out src/main/java/*.java`, затем запустите `java -cp out Main`. Для дополнительного входа передайте текст через stdin; без входа закройте stdin (EOF). Java 25 без preview. Вспомогательные методы и классы разрешены.

Публичные примеры: `src/test/java/PublicExamplesTest.java`. Их можно запускать JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.
