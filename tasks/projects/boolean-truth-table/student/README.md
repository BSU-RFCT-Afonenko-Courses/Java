# Таблица истинности для логических операций

Отобразите таблицу истинности для логических операций Java. Колонки: P, Q, AND, OR, XOR, NOT; NOT означает отрицание P. Используйте табуляцию между колонками и включите все четыре сочетания P и Q.

Вход и результат: первая строка — `P	Q	AND	OR	XOR	NOT` (между именами настоящая табуляция). Далее четыре строки по шесть значений `true` или `false`, также разделённых табуляцией. Порядок строк выберите самостоятельно. Например, для P = `true`, Q = `false` строка содержит `true false false true true false`. Ввод не требуется.

## Исходник и запуск

В `src/main/java/Main.java` находится заготовка с `TODO`. Успешная
компиляция заготовки не означает, что решение готово: требуемое поведение
ещё нужно реализовать. Сохраните
точку входа `Main.main(String[] args)`; вспомогательные методы и классы
разрешены.

Откройте каталог, содержащий этот `README.md` и `src`. Выполните команды
инструментами JDK 25. После изменения исходника повторите компиляцию:

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/*.java
java -cp out Main
```

Ожидаются заголовок и четыре строки данных. В строке для `P = true`, `Q = false` значения равны `true`, `false`, `false`, `true`, `true`, `false`; между ними должна быть табуляция. Стандартный ввод не используется.

Публичные примеры находятся в `src/test/java/PublicExamplesTest.java`
и используют JUnit 5. Они охватывают часть случаев; полные требования
задаёт условие выше. Компиляция не проверяет соответствие поведения
программы условию.
