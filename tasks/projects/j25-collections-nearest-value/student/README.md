## Число, ближайшее к заданному

На базе коллекций реализуйте хранение чисел с добавлением, удалением
и поиском ближайшего к запросу. В этой задаче хранимые значения и запросы —
конечные `double` с модулем не больше `1e150`. Расстоянием считается
результат Java-выражения `Math.abs(value - query)`; указанная граница
исключает переполнение разности. Выберите хранимое значение с наименьшим
таким расстоянием; при равенстве вычисленных расстояний — меньшее по
`Double.compare`. Правило применяется ко всем хранимым значениям, включая
случаи, когда округление даёт одинаковое расстояние для разных чисел.

Дубликат определяется результатом `Double.compare(a, b) == 0`:
повторное добавление сохраняет состав, удаление отсутствующего числа также
сохраняет его. `-0.0` и `+0.0` различаются; при равном расстоянии выбирается
`-0.0`. Для пустого хранилища верните `OptionalDouble.empty()`, для непустого —
выбранное число в `OptionalDouble`. Покажите поиск по обе стороны от запроса,
равные расстояния и отсутствие элементов. Имена методов и устройство
хранилища свободны; ограничение стоимости поиска не задаётся.
