## Построение функции ternaryOperator

Напишите обобщённый метод `ternaryOperator`, который получает условие и две функции и возвращает функцию выбора результата. Его типовые параметры и параметры метода:

```java
<T, R> Function<T, R> ternaryOperator(
        Predicate<? super T> condition,
        Function<? super T, ? extends R> ifTrue,
        Function<? super T, ? extends R> ifFalse)
```

Это объявление задаёт имя метода и его типовой договор. Класс, пакет, видимость и наличие `static` выбирайте в своей программе. Все три переданные функции ненулевые. Ограничений на типы `T` и `R` нет; допустимые аргументы определяются переданными функциями. В частности, `null` допустим, если условие и выбранная ветвь его принимают. Результат выбранной ветви, включая `null`, передаётся вызывающему коду.

При создании результирующей функции ни один из трёх участников не вызывается. Каждый последующий `apply` ровно один раз проверяет `condition` на переданном аргументе и ровно один раз вызывает на том же аргументе выбранную ветвь: `ifTrue` для `true`, `ifFalse` для `false`. Невыбранная ветвь не вызывается. Повторный `apply` выполняет выбор заново. Если условие или выбранная ветвь выбрасывает исключение времени выполнения, оно передаётся вызывающему коду без замены; дальнейшие вызовы участников при этом прекращаются.

Покажите пример для ненулевых строк: условие проверяет пустоту, истинная ветвь возвращает `0`, ложная — длину. Покажите обе ветви, повторные вызовы и случай, в котором невыбранная ветвь выбросила бы исключение. Проверьте отдельно создание функции и её вызов. Вспомогательные методы свободны. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Публичные ограничения отдельной карточки действуют вместе с её условием. Обязательное применение Stream API, лямбды или собственного интерфейса проверяется по исходному коду.

## Локальная работа

Используйте JDK 25. Добавьте собственные .java в src; компилируйте все исходники в отдельный каталог, например `javac -encoding UTF-8 -d out src/*.java`. Запускайте выбранный вами класс обычной командой `java -cp out <ваш.класс>` либо показывайте функцию из своей демонстрации. Имена запуска и методы этой поставкой не закрепляются. Примеры в examples/README.md доступны до сдачи. Объясните применение требуемого приёма по исходному коду.
