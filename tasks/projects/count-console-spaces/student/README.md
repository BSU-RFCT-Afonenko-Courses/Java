# Проект: count-console-spaces

Читайте символы из стандартного ввода до первой точки или конца ввода и подсчитайте обычные пробелы U+0020. Точка завершает обработку и не учитывается; всё после неё игнорируется. Табуляция и переводы строки не считаются пробелами. Допустимо объявить `throws IOException` в `main`.

Протокол проверки: стандартный ввод — текст в UTF-8; выведите только целое количество пробелов. Например, `a b c.after dot  ` даёт `2`, немедленная точка или пустой ввод — `0`.

Соберите `src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out src/main/java/*.java`, затем запустите `java -cp out Main`. Для дополнительного входа передайте текст через stdin; без входа закройте stdin (EOF). Java 25 без preview. Вспомогательные методы и классы разрешены.

Публичные примеры: `src/test/java/PublicExamplesTest.java`. Их можно запускать JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.
