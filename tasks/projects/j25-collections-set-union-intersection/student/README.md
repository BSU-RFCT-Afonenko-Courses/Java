## Пересечение и объединение множеств

Напишите отдельные методы пересечения и объединения двух множеств `Integer`.
Входные множества отличны от `null`, их элементы также отличны от `null`; пустое
множество допустимо. Каждый результат имеет самостоятельный состав;
оба входа после вызова сохраняются. Объединение содержит все различные
элементы обоих входов, пересечение — только общие.

Для `{1, 2}` и `{2, 3}` результаты — `{1, 2, 3}` и `{2}`. Покажите также
одинаковые, пустые и непересекающиеся множества. Сравнивайте состав через
равенство множеств: порядок вывода не задан. Допустимы изменяемая копия с
`addAll`/`retainAll` и явный обход с `contains`/`add`.

## Работа с проектом

Разместите исходные Java-файлы в `src/` с выбранными именами и структурой пакетов. Для компиляции нужен JDK 25: `javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java`; для нескольких файлов перечислите все исходники. Способ запуска демонстрации выбирайте самостоятельно. `examples/scenarios.json` содержит открытые наблюдения.

Преподаватель привязывает конкретное решение обычным Java-клиентом; его `TaskBinding` и выбранные в reference имена не являются дополнительным StudentAPI. Недоступное private/nested размещение сохраняет ручную проверку. Обязательная техника и объяснение проверяются по исходнику и на защите.

## Предъявление лабораторной


Представьте исходные Java-файлы и продемонстрируйте обычные и граничные
случаи из условий. Учёт должен обрабатывать произвольный массив кодов;
покажите повторные обращения и поиск отдельным равным ключом.
Для своего владельца списка отдельно объясните защиту входного состава,
живое представление, изменяемую копию и снимок. Изменение общей книги
проследите отдельно от добавления второй книги.

Пересечение и объединение сохраняют оба входных множества. Для скобок
обязателен стек; для сложения многочленов — `HashMap`, с числовым договором
из карточки. Имена свободных методов, классы демонстрации и формат показа
результатов выбирайте самостоятельно. Техника проверяется по исходнику,
объяснение — в беседе с преподавателем. Используется JDK 25; отдельный
большой отчёт не требуется.
