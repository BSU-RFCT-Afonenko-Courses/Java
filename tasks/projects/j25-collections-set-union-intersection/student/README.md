## Пересечение и объединение множеств

Напишите отдельные методы пересечения и объединения двух множеств `Integer`.
Входные множества отличны от `null`, их элементы также отличны от `null`; пустое
множество допустимо. Каждый результат имеет самостоятельный состав;
оба входа после вызова сохраняются. Объединение содержит все различные
элементы обоих входов, пересечение — только общие.

Для `{1, 2}` и `{2, 3}` результаты — `{1, 2, 3}` и `{2}`. Покажите также
одинаковые, пустые и непересекающиеся множества. Сравнивайте состав через
равенство множеств: порядок вывода не задан. Допустимы изменяемая копия с
`addAll`/`retainAll` и явный обход с `contains`/`add`.

## Работа с проектом

Условие определяет отдельное задание. Полный состав лабораторной и выбор
альтернативы указаны на странице [«Коллекции»](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/labs/collections.html#sec-j25-lab-collections).

Разместите исходные Java-файлы в `src/`. Имена и сигнатуры выбирайте
самостоятельно, кроме явно заданных условием. Для компиляции нужен JDK 25:

```bash
javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java
```

Замените `ИМЯ.java` своим именем файла; при нескольких файлах перечислите
их все и учтите выбранные пакеты. Класс и способ запуска демонстрации
выбирайте самостоятельно. `examples/scenarios.json` описывает проверяемые
наблюдения; способ передачи входных данных определяется вашим решением.

## Представление решения

Представьте исходники и короткую демонстрацию случаев из условия.
Сопоставьте составы через `Set.equals`; отдельно покажите сохранение обоих входов после каждого метода.
Обязательная техника проверяется по исходнику, объяснение — в беседе
с преподавателем. Отдельный большой отчёт не требуется.
