## Сортировка массива по убыванию

Отсортируйте переданный `Integer[]` по убыванию числовых значений, используя лямбда-компаратор. Массив и его элементы ненулевые; допустим весь диапазон `int`, пустой массив и повторы.

Результат записывается в исходный массив. Все элементы и число их повторений сохраняются. Для `{2, -1, 2, 0}` результат `{2, 2, 0, -1}`. Проверьте также крайние значения `Integer.MIN_VALUE` и `Integer.MAX_VALUE`. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Обязательные Stream API/лямбда/собственный интерфейс проверяются по исходнику.

## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`, демонстрируйте выбранным вами способом `java -cp out <класс>`. Форма main и имена этой поставкой не назначаются. Public examples в examples/README.md.
