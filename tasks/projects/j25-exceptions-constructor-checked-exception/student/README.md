## Конструктор подкласса и проверяемое исключение

Даны классы `A` и `B`: конструктор `A()` объявлен с `throws IOException`, а класс `B extends A` пока не содержит собственного конструктора. Добавьте в `B` конструктор, при котором оба класса компилируются. Покажите два допустимых варианта объявления в двух независимых версиях программы и добавьте вызывающий код, обрабатывающий объявленное проверяемое исключение. [1]


## Локальная работа

Для работы нужен JDK 25. Разместите две независимые версии в отдельных
каталогах. Имена дополнительных классов, пакеты и способ запуска выберите
самостоятельно. Для каждой версии используйте собственный каталог `out`:

```bash
javac -encoding UTF-8 -d out <исходники-одной-версии>
```

Вместо `<исходники-одной-версии>` укажите имена файлов выбранной версии.
Заданные классы находятся в [original.java.txt](examples/original.java.txt),
порядок сопоставления версий — в [сценариях](examples/README.md).
