## Конструктор подкласса и проверяемое исключение

Даны классы `A` и `B`: конструктор `A()` объявлен с `throws IOException`, а класс `B extends A` пока не содержит собственного конструктора. Добавьте в `B` конструктор, при котором оба класса компилируются. Покажите два допустимых варианта объявления в двух независимых версиях программы и добавьте вызывающий код, обрабатывающий объявленное проверяемое исключение. [1]


## Локальная работа

Java25. Разместите независимые версии в отдельных каталогах, выбрав имена внешних классов/пакеты/launchers самостоятельно. Компилируйте каждую версию в отдельный out. Имя Main или дополнительные helper методы не назначаются ZIP-поставкой. Пример исходного контекста — examples/original.java.txt.
