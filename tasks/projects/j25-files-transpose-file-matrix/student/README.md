## Матрица из файла и транспонирование

Для вывода результатов создайте новую директорию и файл средствами класса File. Входной файл содержит совокупность строк. Строка файла содержит строку квадратной матрицы. Введите матрицу в двумерный массив, самостоятельно определив её размер. Выведите исходную матрицу и результат её транспонирования.

Входной файл UTF-8: три строки «1 2 3», «4 5 6», «7 8 9»; числа разделены пробелами. Для самостоятельной проверки используйте квадратную матрицу, число строк совпадает с числом чисел в каждой строке. Пути входного файла, нового выходного каталога и результата в нём задайте явно в демонстрации и передайте программе аргументами. Создание каталога и файла выполняется средствами File, как требуется выше. Выход отличается от входа: самокопирование отклоните до открытия выхода; отсутствие входа не изменяет прежний результат. Вход сначала полностью прочитайте как допустимую квадратную матрицу, затем сохраните исходную и транспонированную матрицы в выходе с различимыми подписями. Для примера транспонирование даёт строки `1 4 7`, `2 5 8`, `3 6 9`; покажите также квадратную матрицу 1×1. Допустимый вход — непустая квадратная матрица целых `int`;
прямоугольный и повреждённый файлы находятся вне этого договора. При IO-отказе сообщите причину, при отказе записи возможен частичный выход; атомарность не требуется. [1]


## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`; запуск выбранного вами класса `java -cp out <класс>`. Соблюдайте только явно заданные карточкой имена/каналы/методы; project ZIP не вводит новых Main/пакета/public/static/helperAPI. Данные в examples/; пути с пробелами передавайте одним аргументом, пустой аргумент POSIX — `''`. Если канал/порядок аргументов свободен, укажите выбранный способ в демонстрации.
