# Проверочные матрицы

Создайте UTF-8-файл с тремя строками:

```text
1 2 3
4 5 6
7 8 9
```

В выходе должны быть исходная матрица и транспонированная:

```text
1 4 7
2 5 8
3 6 9
```

Различите две матрицы подписями. Для матрицы 1×1 транспонирование сохраняет
единственный элемент. Покажите отказ при одинаковом входном и выходном
файле и сохранение прежнего результата при отсутствующем входе.
