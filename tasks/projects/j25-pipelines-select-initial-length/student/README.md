## Строки на заданную букву длины `N`

Через Stream API получите новый массив всех строк, которые начинаются на заданную букву и имеют длину `N`. Вход — ненулевой `String[]` без `null`; строки состоят из латинских букв `A`–`Z`, `a`–`z` и могут быть пустыми. Начальная буква принадлежит тому же алфавиту, `N` — неотрицательный `int`, сравнение чувствительно к регистру.

Сохраните исходный порядок и повторы, исходный массив не меняйте. Пустая строка не начинается ни с какой буквы, поэтому при `N = 0` результат пуст. Для `{"Ab", "ac", "Ab", "A", ""}`, буквы `'A'` и `N = 2` результат `{"Ab", "Ab"}`. Пустой вход и отсутствие совпадений дают новый пустой `String[]`. [1]

Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения.
Применение Stream API, лямбды или собственного интерфейса проверяется
по исходному коду там, где это требуется условием.

## Локальная работа

Используйте JDK 25. Разместите свои `.java` в `src` и из каталога проекта выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
```

Если демонстрация оформлена через `main`, запустите её командой
`java -cp out <ваш.класс>`, подставив выбранное полное имя класса.
Имена, форма демонстрации и способ передачи данных остаются вашим выбором
в пределах условия. Сценарии: [examples/README.md](examples/README.md).
