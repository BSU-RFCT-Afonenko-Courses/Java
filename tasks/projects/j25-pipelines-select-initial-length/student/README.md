## Строки на заданную букву длины N

Через Stream API получите новый массив всех строк, которые начинаются на заданную букву и имеют длину `N`. Вход — ненулевой `String[]` без `null`; строки состоят из латинских букв `A`–`Z`, `a`–`z` и могут быть пустыми. Начальная буква принадлежит тому же алфавиту, `N` — неотрицательный `int`, сравнение чувствительно к регистру.

Сохраните исходный порядок и повторы, исходный массив не меняйте. Пустая строка не начинается ни с какой буквы, поэтому при `N = 0` результат пуст. Для `{"Ab", "ac", "Ab", "A", ""}`, буквы `'A'` и `N = 2` результат `{"Ab", "Ab"}`. Пустой вход и отсутствие совпадений дают новый пустой `String[]`. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Обязательные Stream API/лямбда/собственный интерфейс проверяются по исходнику.

## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`, демонстрируйте выбранным вами способом `java -cp out <класс>`. Форма main и имена этой поставкой не назначаются. Public examples в examples/README.md.
