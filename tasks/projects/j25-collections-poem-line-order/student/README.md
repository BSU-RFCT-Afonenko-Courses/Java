## Строки стихотворения по длине

Поместите строки короткого стихотворения из общественного достояния в список;
укажите автора, название и источник. Отсортируйте копию списка по возрастанию
длины строки в единицах `char`. Исходный порядок сохраните отдельно для
сравнения. При равной длине сохраняется взаимный порядок исходных вхождений;
повторяющиеся строки остаются в результате столько же раз.

Все строки отличны от `null`; пустые строки допустимы. Алгоритм должен работать
также для пустого списка. Покажите исходную и полученную последовательности.

## Работа с проектом

Это отдельная добровольная задача. Остальные задания резервного меню
перед ней выполнять не требуется.

Разместите исходные Java-файлы в `src/`. Имена и сигнатуры выбирайте
самостоятельно, кроме явно заданных условием. Для компиляции нужен JDK 25:

```bash
javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java
```

Замените `ИМЯ.java` своим именем файла; при нескольких файлах перечислите
их все и учтите выбранные пакеты. Класс и способ запуска демонстрации
выбирайте самостоятельно. `examples/scenarios.json` описывает проверяемые
наблюдения; способ передачи входных данных определяется вашим решением.

## Представление решения

Представьте исходники и короткую демонстрацию случаев из условия.
Покажите исходную последовательность и результат; сопоставьте позиции строк одной длины и число повторений.
Использование требуемых средств проверяется по исходнику, объяснение —
в беседе с преподавателем. Отдельный большой отчёт не требуется.
