# Проект: reverse-array

Выведите элементы заданного `int[]` от последнего к первому, не изменяя сам массив. Покажите обычный массив, пустой массив и массив из одного элемента. Обратный вывод и перестановка элементов массива — разные операции.

Протокол проверки: стандартный ввод содержит неотрицательную длину `n`, затем ровно `n` значений `int`. Выведите только элементы в обратном порядке через пробельные символы. Для `4 7 -2 7 0` вывод — `0 7 -2 7`, для `0` вывод не содержит чисел. При пустом стандартном вводе используйте демонстрационный массив из исходника.

Сохранение исходного массива и его использование проверяет преподаватель: по одному выводу нельзя доказать, что исходные данные не переставлялись.

Соберите `src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out src/main/java/*.java`, затем запустите `java -cp out Main`. Для дополнительного входа передайте текст через stdin; без входа закройте stdin (EOF). Java 25. Вспомогательные методы и классы разрешены.

Публичные примеры: `src/test/java/PublicExamplesTest.java`. Их можно запускать JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.
