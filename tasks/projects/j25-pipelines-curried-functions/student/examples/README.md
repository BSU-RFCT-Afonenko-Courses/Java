# Примеры

- Сохраните функцию прибавления `7`. Для аргументов `-2` и `3` она даёт `5` и `10`.
- Сохраните проверку по шаблону `[A-Z]+`. Для `"ABC"` результат `true`, для `"Ab"` — `false`.
- Сохраните разбиение по запятой `","`. Для `"a,,b,"` результат `{"a", "", "b", ""}`.

Сценарии можно воспроизвести из своей программы. Способ передачи данных
и формат демонстрации выбирайте в пределах условия задачи.
