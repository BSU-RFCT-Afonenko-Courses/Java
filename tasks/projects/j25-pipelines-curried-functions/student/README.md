## Каррирование функций

Каррированная функция принимает первый аргумент и возвращает функцию, которая принимает второй. Реализуйте лямбдами три таких операции; выбор имён и вспомогательных методов свободен.

1. Сложение двух целых чисел: оба аргумента от `-1000000` до `1000000`, результат — их точная сумма. Например, применение первого аргумента `7` создаёт функцию, которая для `-2` возвращает `5`. Подойдут `Function<Integer, Function<Integer, Integer>>` или эквивалентная форма с примитивными функциональными интерфейсами.
2. Проверка строки по регулярному выражению: первый аргумент — корректное ненулевое Java-регулярное выражение, второй — ненулевая строка. Проверяется совпадение всей строки, как у `String.matches`. Для шаблона `[A-Z]+` строка `"ABC"` подходит, `"Ab"` — нет.
3. Разбиение строки: первый аргумент — корректное ненулевое Java-регулярное выражение, второй — ненулевая строка. Результат соответствует `String.split(regex, -1)`, включая сохранение пустых частей в конце. Для `","` и `"a,,b,"` результат `{"a", "", "b", ""}`.

Во всех трёх случаях сохраните полученную после первого аргумента функцию и примените её к нескольким вторым аргументам. Пустые строки допустимы; некорректные регулярные выражения за пределами входного договора. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Обязательные Stream API/лямбда/собственный интерфейс проверяются по исходнику.

## Локальная работа

JDK25: создайте свои .java в src, компилируйте все `javac -encoding UTF-8 -d out src/*.java`, демонстрируйте выбранным вами способом `java -cp out <класс>`. Форма main и имена этой поставкой не назначаются. Public examples в examples/README.md.
