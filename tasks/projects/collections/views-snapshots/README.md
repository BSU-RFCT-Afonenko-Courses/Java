# views-snapshots

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `src/main/java/Catalogue.java`
- `src/main/java/course/examples/objects/Book.java`

Форма PrairieLearn: штатные редакторы. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `course.examples.objects`, `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
Имена файлов ответа соответствуют указанным путям в комплекте.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.


Полное условие: [карточка банка](../../../bank/collections.qmd#exr-collections-views-snapshots). Задание целиком проверяет преподаватель по прежней рубрике; автоматических баллов и нового Study нет. Канонический комплект задан в `_metadata.yml`. Предоставленные классы сохранены без изменения; исходники, демонстрация и объяснение выполняются по условию. Старый диагностический клиент не задаёт обязательные имена решения.
