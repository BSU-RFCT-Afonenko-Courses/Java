# Инструкция к комплекту

Актуальное условие и команды находятся в корневом `README.md`, который
формируется для самостоятельной выдачи. Исходники и package фиксированы
заготовкой; произвольный отдельный `Main.java` добавлять не требуется.
Дополнительные типы и демонстрацию размещайте внутри разрешённых файлов.
Преподаватель проверяет исходники, наблюдения и объяснение по условию;
старый пример запуска `Main` не является дополнительным договором.
