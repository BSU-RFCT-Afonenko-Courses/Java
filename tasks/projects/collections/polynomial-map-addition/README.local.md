Создайте решение в `src/main/java`, сохраните входы `Study`.

Вход стартера возвращает самостоятельную HashMap суммы. Входы сохраняются, отсутствие степени означает ноль; явные нулевые коэффициенты разрешены. Для каждой степени применяется опубликованный смешанный допуск, в том числе при больших конечных коэффициентах.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
