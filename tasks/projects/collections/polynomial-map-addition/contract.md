Цель — сложить коэффициенты одинаковых степеней с обязательным HashMap.
Два входа HashMap<Integer,Double>, карты/ключи/значения не null;
степени неотрицательны, коэффициенты конечны. Математическая сумма
коэффициентов каждой степени по модулю <=Double.MAX_VALUE.
Валидация нарушений этих предпосылок не требуется. Отсутствующая
степень означает ноль; пустая карта — нулевой многочлен.

Результат — самостоятельная HashMap, оба входа сохраняются.
Сумма каждой степени сравнивается по abs(a-r)<=1e-9+1e-12*abs(r),
где r математическая сумма исходных коэффициентов. Отсутствующий
коэффициент результата при сравнении равен нулю. Явные нули допустимы;
не требуется точное совпадение набора нулевых пар или String-карты.
Порядок обхода свободен. Проверка не заменяет опубликованный смешанный
допуск только абсолютным; бесконечность/NaN результата не удовлетворяют
числовому договору при допустимых входах.

Допустимы merge и getOrDefault/put. Не навязывается сортировка,
нормализация удалением нулей, класс Polynomial, имя add, видимость,
static, пакет или форма ввода. Возвращается именно HashMap,
включая допустимое наследование, а не произвольная альтернативная Map.
Состав результата независим; исходные карты не используются как
изменяемый результат. Коэффициенты Double неизменяемы.

Предъявляются общая степень, степень только одного входа,
взаимное уничтожение коэффициентов и пустой вход, сохранность карт
и предметное применение числового допуска. Публичный обычный сценарий
использует исходные карты примера; граничный — два пустых входа.

Среда — JDK 25 и консоль, без студенческих Gradle/Wrapper/JUnit.
README содержит точные проверенные рекурсивные команды; Main — пример.
Технический клиент адаптируется к свободному API допустимого решения;
ошибка привязки означает необходимость настройки, не ошибку студента.
