## Учебный результат

Переставить элементы в существующей структуре с сохранением состава и заданным разделением.

## Вход

Изменяемый список Integer без null и значение int X; сам список не null. Пустой список допустим. Предъявляемая операция работает с этим объектом списка.

## Результат

В начале все элементы <=X, после них все элементы >X. Тот же объект, прежний размер и прежняя кратность каждого значения. Внутренний порядок обеих групп свободен. Для пустого списка результат пуст.

## Допустимые решения и API

Отдельные индексы, ссылки и временно переставляемое значение. Конкретный алгоритм, число проходов, имена API и вывод свободны. Стабильность или сортировка групп не требуются.

## Обязательные приёмы

Изменение того же списка без методов сортировки и без дополнительных массивов либо коллекций. Дополнительный контейнер нельзя объявлять обязательным вспомогательным приёмом проверяющего клиента решения.

## Состояние и проверяемые свойства

Все элементы сохраняются с кратностями; ни один >X не предшествует элементу <=X. Нельзя заменить вход другим списком. Наличие или отсутствие одной группы допустимо.

## Предъявление и объяснение

Показать, какие позиции рассматриваются на одном шаге, почему перестановка сохраняет кратности и как распознаётся конец обработки.

Состояние и идентичность списка, группы и кратности; исходник для ограничения на сортировку/дополнительное хранение. Единственный ожидаемый порядок внутри групп не назначается.

Просмотреть отсутствие сортировки и дополнительных массивов/коллекций. Наблюдение правильного результата само по себе не подтверждает это ограничение.
