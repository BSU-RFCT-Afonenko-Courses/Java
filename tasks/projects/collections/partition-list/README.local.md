Создайте решение в `src/main/java`, сохраните входы `Study`.

Вход стартера переставляет значения в переданном объекте списка: сначала <=X, затем >X, сохраняя размер и кратности. Порядок внутри групп свободен. Ограничения на сортировку и дополнительные контейнеры распространяются на решение и его вход для проверки.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
