Создайте решение в `src/main/java`, сохраните входы `Study`.

Два входа стартера запускают процесс для ArrayList и LinkedList. Каждый возвращает последовательность из N чисел: сначала N−1 удалённых в порядке выбывания, затем оставшийся. Это способ наблюдать оба результата; внутреннюю форму результата и собственную демонстрацию выберите сами. Измерения и объяснение стоимости операций сохраняются.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
