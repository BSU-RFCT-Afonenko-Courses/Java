## Учебный результат

Сопоставить состояние коллекции и точное правило выбора ближайшего double, учитывающее округление и знаковые нули.

## Вход

Хранимые числа и запросы — конечные double с |x|<=1e150. Операции: добавление, удаление и поиск. Равенство для дубликатов — Double.compare(a,b)==0; -0.0 и +0.0 различны.

## Результат

Минимум по вычисленному Math.abs(value-query) среди всех хранимых значений. При равенстве вычисленных расстояний выбирается меньшее по Double.compare, включая округлённые равенства и -0.0. Пустота → OptionalDouble.empty(); иначе OptionalDouble выбранного числа.

## Допустимые решения и API

Коллекция, хранение, имена классов/методов, способ передачи данных и стоимость поиска свободны. Полный просмотр допустим. Навигационные соседи сами по себе не заменяют проверку исходного правила для всех значений при округлённой ничьей. Нельзя навязывать TreeSet или логарифмический поиск.

## Обязательные приёмы

Хранение на базе коллекций, добавление/удаление и выбор по опубликованным Java double выражениям. Результат поиска — OptionalDouble. Обязательный конкретный метод сравнения структуры или тип ключа не назначается сверх договора.

## Состояние и проверяемые свойства

Повторное добавление и удаление отсутствующего сохраняют состав. Знаковые нули — два разных значения; при равном расстоянии выигрывает -0.0. Вне договора NaN, бесконечности и |x|>1e150. Новая погрешность сравнения расстояний не вводится.

## Предъявление и объяснение

Разобрать выбор при обычной ничьей, при округлении расстояний для -100/0/100 и запроса 1e150, а также отсутствие результата в OptionalDouble.

Состояние коллекции, результаты поиска и исходник сравнения; для знакового нуля проверяется Double.compare либо эквивалентное наблюдение знака, а не только ==.

Не принимать как доказательство одного запуска свойство всех расстояний; прочитать правило ничьей. Не вводить ограничение скорости, уникальные имена методов или обязательную сериализацию OptionalDouble.
