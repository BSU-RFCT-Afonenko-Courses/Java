Создайте решение в `src/main/java`, сохраните входы `Study`.

Входы стартера создают ваше хранилище и вызывают добавление, удаление и поиск. Ближайшее определяется среди всех значений по вычисленному в Java Math.abs(value-query); равные вычисленные расстояния разрешаются через меньшее значение по Double.compare. Сравнение выполняется без нового допуска.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
