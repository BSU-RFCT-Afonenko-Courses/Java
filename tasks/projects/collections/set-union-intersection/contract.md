Договор закрытый, пути от внешней контрольной области.

Цель — две самостоятельные операции над составом множеств Integer.
Оба множества и их элементы не null; пустые допустимы. Никакой новой
валидации неверных входов не требуется. Объединение содержит все
различные элементы, пересечение — общие. После каждого метода входы
сохранены, состав каждого результата независим от дальнейшего состава
входов. Новая объектная идентичность при любых входах и изменяемость
результата не требуются; независимость не проверяется принудительным
добавлением в результат, если он возвращён неизменяемым.

Порядок обхода и вывода свободен; сравнивается Set.equals/состав.
Сортировка и конкретный класс результата не навязаны. Допустимы
изменяемая копия с addAll/retainAll и явный обход contains/add.
Имена методов и содержащих классов, видимость, static, пакеты
и передача данных свободны. SetOps/union/intersection в bindings —
имена образца, не обязательный API.

Предъявляются обычные, одинаковые, пустые и непересекающиеся входы,
сохранность каждого входа после обеих операций. Объясняется независимость
состава. Публичная граница использует пустой и непустой изменяемый вход:
последующее изменение входа клиентом не меняет уже полученные результаты.

Среда — JDK 25 и консоль, без студенческих Gradle/Wrapper/JUnit.
README содержит точные проверенные рекурсивные команды; Main — пример.
Технический клиент адаптируется к свободному API допустимого решения;
ошибка привязки означает необходимость настройки, не ошибку студента.
Вывод демонстрации не получает единственной сериализации ради checker.
