Создайте решение в `src/main/java`, сохраните входы `Study`.

Два входа стартера возвращают объединение и пересечение. Переданные множества сохраняются; последующее изменение их состава не меняет уже полученный результат. Сравнивается состав множеств, без требования порядка или изменяемости результата.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.

методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
