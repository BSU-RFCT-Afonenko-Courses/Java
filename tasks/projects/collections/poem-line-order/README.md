# poem-line-order

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `src/main/java/Study.java`

Форма PrairieLearn: штатные редакторы. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
В полях ответа пути исходников задаются относительно `src/main/java`.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.


Каноническое условие: [карточка банка](../../../bank/collections.qmd#exr-collections-poem-line-order). Канонический стартер и состав выдачи заданы в `_metadata.yml`; `student/` сохраняет прежнюю редакцию.

Реализуйте своё решение через входы Study. Создайте обязательные предметные модели самостоятельно; внутренние типы и методы внутри перечисленных файлов свободны в пределах условия. Полный договор и допустимые результаты находятся в условии и комментариях стартера.

`gradle test` выполняет два открытых случая normal/boundary после API-допуска. Автоматическая часть: 80 × passed/total по 4 равным группам; прежняя ручная часть — 20. API и дополнительная демонстрация баллов не дают. Инфраструктурный отказ не превращается в ноль студента. Прежние признанные оценки и код сохраняются.
