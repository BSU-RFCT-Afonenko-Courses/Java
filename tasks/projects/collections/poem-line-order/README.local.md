Создайте решение в `src/main/java`, сохраните входы `Study`.

Вход стартера принимает список строк и возвращает его устойчиво упорядоченную по длине копию. Отдельный вход предоставляет строки выбранного вами стихотворения для той же операции; это ваши исходные данные, без готового упорядочения. Выбор произведения, указание автора, названия и источника сохраняются.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
