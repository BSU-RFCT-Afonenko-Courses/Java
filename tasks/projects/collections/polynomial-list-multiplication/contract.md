## Учебный результат

Получить коэффициенты произведения из пар степеней и сохранить структуру списочного представления.

## Вход

Два списка Double длиной 0..64, списки и элементы не null. Конечные коэффициенты по модулю<=1000. Индекс i соответствует степени i; пустой список — нулевой многочлен.

## Результат

Самостоятельный список. Для непустых входов длиной m,n его длина m+n−1, включая нулевые старшие коэффициенты; если хотя бы один вход пуст, результат пуст. Коэффициент k — математическая сумма a[i]*b[j] для i+j=k. Допуск abs(result−r)<=1e-6+1e-12*abs(r).

## Допустимые решения и API

Имена API/классов/пакетов, способ организации вычисления и тип списочной реализации свободны. Конкретная форма двойного цикла не обязательна. Оформление результата свободно при различимых индексах и коэффициентах. Нельзя отрезать старшие нули ради иной нормальной формы многочлена.

## Обязательные приёмы

Работа с двумя списками коэффициентов и получение самостоятельного результата по сумме произведений. Входные списки сохраняются. Не требуется отдельный класс одночлена, HashMap или готовый метод с именем multiply.

## Состояние и проверяемые свойства

Сохраняются оба исходника, порядок степеней и заданная длина. Нулевые коэффициенты и компенсация слагаемых допустимы. Проверка самостоятельности относится к составу результата; неизменяемые Double могут быть общими объектами.

## Предъявление и объяснение

Показать пары степеней для коэффициента при x, объяснить m+n−1, пустой вход, нулевой старший коэффициент и допустимую численную погрешность.

Входы до/после, самостоятельный результат, длина и коэффициенты с исходным допуском; чтение выбранного вычисления и объяснение одной суммы.

Не подменять списочную модель картой из соседней обязательной карточки. Не назначать единственный порядок суммирования или ужесточённую точность; не требовать мутационного метода, если выбран законный возвращающий результат API.
