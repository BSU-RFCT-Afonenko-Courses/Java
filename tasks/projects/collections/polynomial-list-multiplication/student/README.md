## Умножение многочленов в списках

Умножьте многочлены, заданные двумя списками `Double`: элемент с индексом `i`
является коэффициентом степени `i`. Списки и элементы отличны от `null`, длина каждого
списка от 0 до 64, коэффициенты конечны и по модулю не больше 1000.
Пустой список представляет нулевой многочлен.

Для непустых входов длиной `m` и `n` получите самостоятельный список длиной
`m + n - 1`, включая нулевые старшие коэффициенты. Если хотя бы один вход
пуст, результат — пустой список. Исходные списки сохраняются.
Коэффициент результата степени `k` равен сумме произведений `a[i] * b[j]`
по всем допустимым парам с `i + j = k`. При сравнении с этой математической
суммой `r` допустима погрешность `abs(result - r) <= 1e-6 + 1e-12 * abs(r)`.

Например, `[1, 2]` и `[3, 4]` дают `[3, 10, 8]`. Покажите также пустой вход,
нулевые коэффициенты и взаимное уничтожение слагаемых.
