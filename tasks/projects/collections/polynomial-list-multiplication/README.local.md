Создайте решение в `src/main/java`, сохраните входы `Study`.

Вход стартера возвращает самостоятельный список коэффициентов произведения. Сохраняются оба входа, длина m+n−1 для непустых входов и старшие нули; если хотя бы один вход пуст, результат пуст. Сравнение каждого коэффициента использует опубликованный смешанный допуск.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
