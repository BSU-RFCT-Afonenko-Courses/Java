Цель — проверить соответствие видов и вложенности скобок с помощью стека.
Вход не null и состоит только из шести символов ()[]{}. Прочие символы
и null не становятся дополнительными проверками. Результат boolean,
строка сохраняется. Последняя открытая пара закрывается первой.
Пустая строка корректна. ([]{}), соседние пары и допустимая вложенность
дают true; ([)], одиночная закрывающая ) и незакрытое (( дают false.

Обязателен стек: допустимы Deque/ArrayDeque или собственная реализация.
Один правильный boolean не доказывает его использование. Не навязывается
java.util.Stack, фиксированное число проходов, имя метода/класса,
видимость, static, пакет и протокол ввода. Brackets.valid из binding
не является студенческим API. Дополнительное исключение для неправильной
последовательности не требуется: её результат false.

Нужно показать все опубликованные границы и соседние пары; проследить
состояние стека до первой ошибки вложенности и при корректном завершении.
Публичные сценарии дают корректную вложенную строку, а на границе —
пустой вход и одиночную закрывающую. Они не отменяют прочие обязательные
случаи собственной демонстрации.

Среда — JDK 25 и консоль, без студенческих Gradle/Wrapper/JUnit.
README содержит точные проверенные рекурсивные команды; Main — пример.
Технический клиент адаптируется к свободному API допустимого решения;
ошибка привязки означает необходимость настройки, не ошибку студента.
Вывод демонстрации не получает единственной сериализации ради checker.

и русскую диагностику готовит technical. Если наблюдение оценивается
вручную, оно остаётся действительным предъявлением, без фиктивного
автоматического успеха. Обязательные средства читаются в исходнике,
объяснение оценивается в беседе. Дополнительный отчёт и собственные
числовые настройки не назначаются; глобальная политика остаётся technical.

Скобки и многочлены — два видимых кандидата одной обязательной единицы;
студент завершает одну альтернативу. Выполнение обеих не требуется.
