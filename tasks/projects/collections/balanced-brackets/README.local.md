Создайте решение в `src/main/java`, сохраните входы `Study`.

Вход стартера возвращает признак правильной расстановки для строки из шести скобочных символов. Пустая строка правильна; несовпадение типа, лишнее закрытие и незакрытое открытие дают false. Требуемый стек реализуйте самостоятельно или используйте Deque/ArrayDeque.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
