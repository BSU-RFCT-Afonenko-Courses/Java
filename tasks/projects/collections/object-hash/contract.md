Цель — учёт произвольного массива обращений через собственный устойчивый
ключ. Массив и строки не null; пустой массив и пустой строковый код
допустимы. Каждый элемент — обращение. Коды сравниваются точно по значению
String с учётом регистра, без strip/trim/иной нормализации.
Входной массив сохраняет значения и порядок.

Нужен собственный обычный класс с неизменяемым строковым кодом,
согласованными equals/hashCode. Имя класса, способ доступа к коду,
видимость и организация результата свободны. Модификатор final как единственный
способ записи неизменяемости не навязывается. Готовые String/record
вместо требуемого класса не подходят. У CodeKey/Audit/Result из bindings
нет статуса обязательных имён или формы результата.

Обязательны HashSet собственных ключей и HashMap с такими ключами
для частот по всему массиву. Отдельные ключи повторного кода равны;
новый равный ключ находит прежнюю частоту. Для пустого входа оба
результата пусты. Допустимы getOrDefault/put и merge. Состав и частоты
сравниваются независимо от порядка; ни сортировка, ни единственный
формат строки или способ упаковки двух результатов не назначаются.

Коды Aa и BB различны и оба должны сохраниться. Равенство их исходных
String-хешей не требует равенства хешей собственного класса: любой
согласованный алгоритм допустим, коллизии не означают равенства.
Нужно объяснить согласование равенства/хеша и устойчивость кода.

Готовый grade.Student сравнивает полное значение id/name/score.
Новая версия с иным score не равна прежней, хотя id тот же.
Собственный ключ выражает другой выбор сведений — только код.
Student не переписывается; его strip и проверки конструктора
не переносятся на произвольные строковые коды этой задачи.
Готовый источник для чтения: handbook/examples/collections/grade/Student.java;
canonical при интеграции — tasks/common/src/main/java/grade/Student.java.
Технический исполнитель даёт generated copy и доступное объяснение модели.

Исходная карточка явно target=manual. Предъявление собственной модели,
HashSet/HashMap и объяснение оцениваются преподавателем. Публичные
наблюдения не означают наличия автоматического оценивания и не дают
фиктивного успеха за вывод. Смена технического grading.method
не выполняется этой авторской партией.

Среда — JDK 25 и консоль, без студенческих Gradle/Wrapper/JUnit.
README содержит точные проверенные рекурсивные команды; Main — пример.
Технический клиент адаптируется к свободному API допустимого решения;
ошибка привязки означает необходимость настройки, не ошибку студента.
Вывод демонстрации не получает единственной сериализации ради checker.
