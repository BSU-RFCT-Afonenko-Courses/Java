# object-hash

Полное условие: [карточка банка](../../../bank/collections.qmd#exr-collections-object-hash). Задание целиком проверяет преподаватель по прежней рубрике; автоматических баллов и нового Study нет. Канонический комплект задан в `_metadata.yml`. Предоставленные классы сохранены без изменения; исходники, демонстрация и объяснение выполняются по условию. Старый диагностический клиент не задаёт обязательные имена решения.
