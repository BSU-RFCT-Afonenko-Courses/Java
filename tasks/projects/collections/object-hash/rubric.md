# Рубрика: Учёт обращений по устойчивому коду

ID `exr-collections-object-hash`. Точный SHA256 условия закреплён
в [контракте](contract.md). Основа — teacher/common/rubric-template.md.

| Часть | Критерий | Свидетельство |
|---|---|---|
| Результат на допустимых данных | Множество кодов и частоты соответствуют всему массиву | Повторы, Aa/BB, новый равный ключ и пустой вход |
| Ограничения и состояние | Код устойчив, нет нормализации, вход сохраняется | Исходник ключа и наблюдение данных |
| Обязательные приёмы | Собственный обычный ключ, HashSet, HashMap, equals/hashCode | Предметное чтение исходника |
| Объяснение решения и границы | Различаются равенство ключа по коду и полное значение Student | Беседа о смене score и сохранении id |
| Воспроизводимость предъявления | Оформление результата свободно, состав и частоты наблюдаемы | JDK25, демонстрация и готовая модель Student |

Приёмы и объяснение не подменяются одним правильным выводом.
Свободные имена и порядок результата сохраняются в пределах условия.
Ошибки технической привязки не считаются ошибками решения.
Дополнительный отчёт и собственные числовые настройки не назначаются.
