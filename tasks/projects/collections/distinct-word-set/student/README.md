## Различные слова в HashSet

Для готовой строки, отличной от `null`, получите `HashSet` различных английских слов
без учёта регистра. Слово — максимальная непустая последовательность букв
`A`–`Z` и `a`–`z`; остальные символы разделяют слова. В результате каждое
слово записано строчными английскими буквами. Преобразование регистра должно
давать один результат независимо от языка среды запуска, например при
использовании `Locale.ROOT`.

Для `one, ONE! two` множество содержит `one` и `two`. Пустая строка и строка
без английских букв дают пустое множество. Исходный текст сохраняется;
порядок вывода множества свободен. [Источник 1]

## Работа с проектом

Это отдельная добровольная задача. Остальные задания резервного меню
перед ней выполнять не требуется.

Разместите исходные Java-файлы в `src/`. Имена и сигнатуры выбирайте
самостоятельно, кроме явно заданных условием. Для компиляции нужен JDK 25:

```bash
javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java
```

Замените `ИМЯ.java` своим именем файла; при нескольких файлах перечислите
их все и учтите выбранные пакеты. Класс и способ запуска демонстрации
выбирайте самостоятельно. `examples/scenarios.json` описывает проверяемые
наблюдения; способ передачи входных данных определяется вашим решением.
