## Учебный результат

Выделять различные слова с заданной нормализацией и хранить их в HashSet.

## Вход

Готовая строка, отличная от null. Слово — максимальная непустая последовательность A–Z/a–z; остальные символы разделяют слова. Пустая строка допустима.

## Результат

HashSet всех различных английских слов, каждое записано строчными английскими буквами. one, ONE! two даёт состав {one,two}. Пустая строка и строка без английских букв дают пустое множество. Порядок предъявления свободен.

## Допустимые решения и API

Способ выделения слов, имена API/классов/пакетов и формат показа свободны. Locale.ROOT — пример корректной реализации нормализации, а не единственный обязательный вызов. Допустим другой способ, независимый от локали, в пределах английского алфавита.

## Обязательные приёмы

Используется HashSet; выполнена нормализация только по опубликованному английскому алфавиту с одинаковым результатом при разных языках среды.

## Состояние и проверяемые свойства

Исходная строка сохраняется; нет пустых элементов и повторов. Unicode-буквы вне A–Z/a–z остаются разделителями. Вариант i не превращается в турецкую ı из-за локали.

## Предъявление и объяснение

Пояснить границы слов и причину одинакового результата для I/i при иной локали; связать повторное добавление с уникальностью множества.

Исходник HashSet и нормализации, состав множества на обычном и существенном граничном входе. Не сравнивать строковую сериализацию множества как единственную правильную.

Проверить требуемую коллекцию и локаленезависимое правило по коду. Для локали технический исполнитель готовит контролируемую среду; студенту не добавляется обязанность устанавливать вторую ОС или писать команды конфигурации.
