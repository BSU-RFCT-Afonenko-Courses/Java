## Класс Graph

Реализуйте `Graph` — простой неориентированный граф. Конструктор получает
число вершин `n >= 0`; вершины обозначаются индексами `0..n-1`, начальных
рёбер нет. Операции добавления и удаления получают разные допустимые
индексы: обработка неверных индексов и петель не требуется.
Повторное добавление ребра и удаление отсутствующего сохраняют граф.

Клиент должен уметь установить наличие ребра и получить соседей вершины.
Имена и сигнатуры операций выберите самостоятельно. Ребро между `u` и `v`
наблюдается с обеих сторон; удаление ребра сохраняет сами вершины.

Выберите хранение, при котором добавление и удаление не требуют просмотра
всех рёбер графа. Объясните стоимость операций для своего представления,
например матрицы смежности или набора множеств соседей. Покажите изолированную
вершину, повторное добавление, удаление и симметрию соседства.

## Работа с проектом

Это отдельная добровольная задача. Остальные задания резервного меню
перед ней выполнять не требуется.

Разместите исходные Java-файлы в `src/`. Имена и сигнатуры выбирайте
самостоятельно, кроме явно заданных условием. Для компиляции нужен JDK 25:

```bash
javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java
```

Замените `ИМЯ.java` своим именем файла; при нескольких файлах перечислите
их все и учтите выбранные пакеты. Класс и способ запуска демонстрации
выбирайте самостоятельно. `examples/scenarios.json` описывает проверяемые
наблюдения; способ передачи входных данных определяется вашим решением.
