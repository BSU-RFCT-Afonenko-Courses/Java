Создайте решение в `src/main/java`, сохраните входы `Study`.

Входы стартера создают ваш Graph и вызывают добавление, удаление, наличие ребра и чтение соседей. Объект, возвращённый фабрикой, — настоящий Graph вашего решения. Порядок соседей и внутреннее представление свободны; новый метод подсчёта вершин не требуется.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
