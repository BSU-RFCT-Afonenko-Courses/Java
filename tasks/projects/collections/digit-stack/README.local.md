Создайте решение в `src/main/java`, сохраните входы `Study`.

Для автоматической проверки предусмотрен вход стартера, принимающий число и возвращающий полученную последовательность цифр. Выполните обработку через стек; показ результата в собственной демонстрации сохраняется. Возврат строки не разрешает заменить требуемый стек готовым обращением строки.

Собственную демонстрацию и объяснение выполните по полному условию; обязательного Main и формата CLI нет. Открытые проверки находятся в `src/test/java`. Используйте JDK 25 и `gradle test`.
