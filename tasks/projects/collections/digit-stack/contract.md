## Учебный результат

Связать порядок помещения и извлечения из стека с разворотом десятичной записи.

## Вход

Одно неотрицательное целое 0..Long.MAX_VALUE. Обычная десятичная запись — только цифры, без начальных нулей; ноль представлен одной цифрой 0. Способ передачи значения свободен.

## Результат

Последовательность всех цифр входа в обратном порядке, без промежутков между цифрами и без удаления нулей: 120 → 021, 0 → 0. Это последовательность цифр, поэтому её нельзя подменять числом 21. Канал получения данных, имена программы и методов, окружающее оформление демонстрации и обязательный завершающий перевод строки не фиксируются.

## Допустимые решения и API

Арифметическое выделение цифр или работа с записью и другие допустимые способы. Порядок обработки выбирает студент при сохранении итогового разворота и настоящего использования стека. Свободны классы, методы, пакеты и тип вспомогательных переменных в пределах диапазона.

## Обязательные приёмы

Deque/ArrayDeque используется как стек для цифр. Для нуля в стек помещается одна цифра. Один только разворот строки без требуемого стека не предъявляет приём.

## Состояние и проверяемые свойства

Каждая исходная цифра участвует один раз. Нулевые цифры сохраняются, в том числе в начале результата. Отрицательные числа, переполнение диапазона и запись с начальными нулями вне опубликованного входа.

## Предъявление и объяснение

Проследить порядок цифр 1,2,0 при выбранном способе помещения в стек; объяснить обработку нуля и отсутствие промежутков в результате.

Исходник, последовательность цифр в демонстрации, объяснение одного прохода по стеку. Произвольный вывод сам по себе не доказывает использование Deque.

Проверить реальное использование стека, обработку нуля и связь порядка операций с результатом. Не назначать единственный способ выделения цифр, обязательный argv/stdin или имя Main.
