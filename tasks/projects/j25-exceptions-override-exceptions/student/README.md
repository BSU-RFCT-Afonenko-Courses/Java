## Переопределение метода и исключения

В классе A объявлен метод void f() throws FileNotFoundException, а класс B extends A пока пуст. Переопределите f() в классе B тремя допустимыми способами, не вызывающими ошибку компиляции. Каждый вариант оформите как отдельную небольшую программу. [1]


## Локальная работа

Java25. Разместите независимые версии в отдельных каталогах, выбрав имена внешних классов/пакеты/launchers самостоятельно. Компилируйте каждую версию в отдельный out. Имя Main или дополнительные helper методы не назначаются ZIP-поставкой. Пример исходного контекста — examples/original.java.txt.
