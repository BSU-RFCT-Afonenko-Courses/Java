# Открытые compiler-сценарии

Исходный контекст в original.java.txt соответствует условию. Каждая исправленная версия компилируется в своём каталоге: `javac -encoding UTF-8 -d out <файлы-одной-версии>`. Смешивание независимых A/B не является проверкой этой задачи. Поясните checked declarations и причину первоначальной ошибки/отличие override от overload. Обязательного stdout/status/runtime-результата не дано; вывод сообщения javac может отличаться между JDK.
