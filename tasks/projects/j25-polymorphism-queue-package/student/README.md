## Общий договор символьных очередей

Для задач этого раздела интерфейс `ICharQ` объявляет `void put(char ch)` и
`char get()`. Реализации `FixedQueue`, `CircularQueue`, `DynQueue` имеют
открытые конструкторы с одним параметром `int capacity` и открытые методы
интерфейса. Конструктору передаётся положительная начальная ёмкость.
Вспомогательные поля и методы выбирайте самостоятельно.

Очередь хранит символы в закрытом массиве в порядке FIFO: первым извлекается
самый ранний из ещё не извлечённых символов. `FixedQueue` использует линейные
индексы и до сброса не переиспользует освобождённые позиции; после `capacity`
успешных помещений очередное помещение отказывает даже при частичном
извлечении. `CircularQueue` повторно использует освободившиеся позиции и
отказывает только при `capacity` хранимых символах. `DynQueue` увеличивает
массив по необходимости, сохраняя порядок; коэффициент роста свободен.

Неудачный `put` печатает строку `Очередь переполнена`, неудачный `get` —
`Очередь пуста` и возвращает `'\0'`. Успешные операции ничего не печатают.
Отказ сохраняет данные и состояние индексов. Допустим любой `char`, кроме
`'\0'`: этот символ зарезервирован для отказа. Извлечение из пустой очереди
отклоняют все реализации; при переполнении отказывают `FixedQueue`
и `CircularQueue`.
Для `DynQueue` в пределах доступной памяти вместо отказа происходит рост.

Например, `DynQueue(2)` принимает A, B, C и возвращает их в этом порядке;
следующее извлечение печатает `Очередь пуста` и возвращает `'\0'`.
В `FixedQueue(2)` после помещения A, B и извлечения A помещение C отказывает;
в `CircularQueue(2)` тот же сценарий оставляет в очереди B, C.

Каждое задание выполняется самостоятельно: создайте нужные реализации по
этому договору либо используйте свои ранее написанные реализации.
Требования общей части применяются вместе с выбранной карточкой.

## Работа с проектом

Это отдельная добровольная задача. Другие задачи резервной работы перед ней выполнять не требуется.

Разместите Java-файлы в `src/`. Имена вспомогательных классов, методы и пакеты выбирайте самостоятельно в пределах явно заданного API. Нужен JDK 25.

Интерфейс уже находится в `src/qpack/ICharQ.java`. Добавьте реализации в `src/qpack/`, а `IQDemo.java` — непосредственно в `src/`. Для этой структуры команды из корня проекта:

```bash
javac --release 25 -encoding UTF-8 -d out src/qpack/*.java src/IQDemo.java
java -cp out IQDemo
```

Открытые сценарии в `examples/scenarios.json` описывают действия и ожидаемые наблюдения. Способ ввода данных для собственной демонстрации выбирайте самостоятельно.
