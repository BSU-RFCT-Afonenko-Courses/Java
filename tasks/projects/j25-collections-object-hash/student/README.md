## Учёт обращений по устойчивому коду

Программа получает произвольный ненулевой массив строк-кодов без `null`,
в том числе пустой. Каждый элемент — одно обращение; повторный код означает
новое обращение к той же записи. Коды сравниваются с учётом регистра, без
обрезки пробелов и иной нормализации.

Создайте собственный обычный класс ключа с неизменяемым строковым кодом,
согласованными `equals` и `hashCode`. Имя класса и способы чтения данных
выберите самостоятельно. Используйте его экземпляры в `HashSet` для
множества посещённых записей и в `HashMap` для числа обращений к каждой
записи. Состав множества и все частоты должны соответствовать всему массиву;
вход сохраняется. Для пустого массива оба результата пусты.

Покажите вход `s17, s18, s17`: различных записей 2, частоты `s17 → 2`,
`s18 → 1`. Создавайте отдельные объекты ключей для повторных вхождений.
Поиск новым равным ключом должен находить прежнюю частоту. Добавьте также
разные коды `Aa` и `BB`: оба ключа должны сохраниться. У строк этих кодов
одинаковые хеши; собственный класс вправе выбирать любой согласованный хеш.
Порядок перечисления результатов и формат вывода свободны. Допустимы
`getOrDefault`/`put` и `merge`.

Объясните, почему создание новой версии с другим `score` для
`grade.Student(String id, String name, int score)` даёт другое полное значение,
сохраняя его код каталога. Тип ключа в этой задаче выражает равенство по коду;
готовые строки и `record` не заменяют требуемый собственный обычный класс.
Подготовка: [Равенство записи и уникальность кода](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/equality.html#sec-j25-theory-equality-domain),
[Равенство и хеш](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/equality.html#sec-j25-theory-equality-hash), [Карты](https://bsu-rfct-afonenko-courses.github.io/Java/handbook/entries/sets-maps.html#sec-j25-api-sets-maps-map).

## Работа с проектом

Условие определяет отдельное задание. Полный состав лабораторной и выбор
альтернативы указаны на странице [«Коллекции»](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/labs/collections.html#sec-j25-lab-collections).

Разместите исходные Java-файлы в `src/`. Имена и сигнатуры выбирайте
самостоятельно, кроме явно заданных условием. Для компиляции нужен JDK 25:

```bash
javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java
```

Замените `ИМЯ.java` своим именем файла; при нескольких файлах перечислите
их все и учтите выбранные пакеты. Класс и способ запуска демонстрации
выбирайте самостоятельно. `examples/scenarios.json` описывает проверяемые
наблюдения; способ передачи входных данных определяется вашим решением.

## Представление решения

Представьте исходники и короткую демонстрацию случаев из условия.
Покажите отдельные объекты ключей одного кода и поиск новым равным ключом. Объясните согласование `equals` и `hashCode` и устойчивость полей ключа во время хранения.
Обязательная техника проверяется по исходнику, объяснение — в беседе
с преподавателем. Отдельный большой отчёт не требуется.
