# Примеры позиционной записи

Два аргумента запуска задают исходное число в десятичной записи
и основание результата, в этом порядке.

| Аргументы | Ожидаемая запись |
|---|---|
| `31 16` | `1F` либо `1f` |
| `31 2` | `11111` |
| `0 36` | `0` |
| `35 36` | `Z` либо `z` |
| `9223372036854775808 16` | `8000000000000000` |

В последнем примере исходное число превосходит `Long.MAX_VALUE`.
Значение должно сохраняться при чтении и преобразовании. Ведущие нули
в результате не добавляются. Регистр букв выбирается единообразно.
Команды — в [README.md](../README.md).
