Правила выделения слов и регистра описываются в решении свободным текстом, без нового JSON/API политики. Техническая проверка настраивается по ним; пример Unicode/lowercase не назначает единственный выбор. Map.Entry — только неизменённая проекция данных отчёта.

Читатель свободного отчёта размещён на стороне открытой проверки в TaskBinding. При другом законном оформлении его согласуют с фактически записанным отчётом; исходный вход ему не передаётся. Дублировать этот читатель в решении не требуется.
