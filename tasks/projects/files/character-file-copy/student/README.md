# Копирование файла с заменой пробелов

Программа получает два аргумента: путь входного файла и путь выходного.
Копируйте допустимый конечный UTF-8-текст, заменяя только пробел U+0020
на дефис U+002D. Все остальные символы, включая разделители строк, сохраняются:
табуляции, кириллица, LF, CR, CRLF и отсутствие последнего перевода строки.
Пустой вход допустим. Используйте `Reader` и `Writer` с явно указанной UTF-8 и `try` с ресурсами.

Вход открывается до выхода. Отсутствующий выход создаётся, существующий
перезаписывается. Если пути обозначают один существующий файл,
отклоните операцию до открытия выхода и сохраните вход. Учитывайте разные
записи пути к одному файлу, включая поддерживаемые файловые ссылки.
Во время проверки файлы не меняются извне. Отсутствие входа сохраняет
прежний выход и не создаёт новый.

При отказе чтения, записи или закрытия сообщите причину. После отказа
записи допускается частичный выход. Сообщение об успехе допустимо после
успешного завершения операции. Текст и канал диагностики, коды завершения,
имена классов и вспомогательных методов выбираете самостоятельно.
Допустимо читать по одному значению или порциями в буфер.

## Компиляция и запуск

Предоставленный `Main.java` содержит начальную заготовку. Исходник
компилируется, а при запуске выбрасывается `UnsupportedOperationException`, пока копирование
не реализовано. С установленным JDK 25 выполните из этого каталога:

```bash
javac --release 25 -encoding UTF-8 -d out Main.java
java -cp out Main samples/public-text-input.txt result.txt
```

Можно изменить имя класса, объявить пакет и добавить вспомогательные методы.
При компиляции перечислите свои исходники `.java`, при запуске укажите полное
имя главного класса. Относительные пути относятся к рабочему каталогу
процесса. Путь с пробелами передавайте одним аргументом в кавычках.

## Входы для сравнения

В `samples/` находятся пары файлов с окончаниями `-input.txt` и
`-expected.txt`:

- `public-text` — текст с кириллицей без конечного LF;
- `public-empty` — пустой файл;
- `public-whitespace` — табуляция, неразрывный пробел и CRLF.

Сравните выход с соответствующим ожидаемым файлом побайтно. Покажите
также отсутствующий вход при прежнем выходе и отказ самокопирования.
Предъявите исходник и файлы; объясните порядок открытия и закрытия ресурсов.
