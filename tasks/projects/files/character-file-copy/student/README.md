# Копирование файла: символьные потоки

[Условие задания](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/bank/files.html#exr-files-character-file-copy)
задаёт результат, обязательные приёмы и демонстрацию. Перед работой без сети
сохраните страницу условия. Команды ниже выполняются из каталога этого README.

Нужен JDK 25. Исходники решения находятся в `src/main/java`, включая вложенные
пакеты. Имена и устройство программы выбирайте в пределах условия.

Компиляция в Linux, Bash:

```bash
find src/main/java -type f -name '*.java' -exec javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java {} +
```

Компиляция в PowerShell 7:

```powershell
$sources = @(Get-ChildItem -LiteralPath 'src/main/java' -Recurse -File -Filter '*.java' |
    ForEach-Object { $_.FullName })
javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java $sources
```

После реализации запустите копирование на готовом примере:

```console
java -cp out Main samples/public-text-input.txt out/copied.txt
```

Аргументов два: входной и выходной пути; относительные пути считаются
от текущего каталога. Пути с пробелами заключайте в кавычки. Если выбрано
другое имя класса, замените `Main` полным именем своего класса запуска.
Сравните созданный файл с [ожидаемым результатом](samples/public-text-expected.txt).
В `samples` есть также пары `public-empty-input.txt` / `public-empty-expected.txt`
и `public-whitespace-input.txt` / `public-whitespace-expected.txt`.
После изменения исходников повторите компиляцию. Каталог `out` создаётся
при компиляции; зависимости для локальной работы загружать не требуется.

Вызовы в [TaskBinding.java](src/test/java/TaskBinding.java) связывают открытый
клиент с заготовкой. При другом допустимом API согласуйте эти вызовы со своим
решением; имена заготовки не добавляют требований к условию. Недоступные
внешнему клиенту операции покажите в собственной демонстрации.

После реализации и подготовки привязки выполните команды из
[CHECKS.md](CHECKS.md): они компилируют открытый клиент и запускают `PublicChecks`.
Два открытых сценария помогают проверить результат; обязательные приёмы
и объяснение преподаватель оценивает по исходникам и демонстрации.

Используйте `Reader`/`Writer` с UTF-8 и try-with-resources.
Порядок открытия файлов, отказ самокопирования и поведение при ошибках
описаны в условии по ссылке выше. Предъявите исходник и оба файла
для сравнения; покажите также пустой файл, табуляцию, разные разделители
строк, отсутствие входа при существующем выходе и отказ самокопирования.
