## Удаление комментариев из Java-программы

Для вывода результатов создайте новый каталог и файл средствами класса `File`. Из текста Java-программы удалите все виды комментариев. Результат сохраните в новый текстовый файл.

В учебном входном файле нет текстовых блоков и Unicode-escape-последовательностей; обычные строковые и символьные литералы допускаются.

Подготовьте небольшой UTF-8-файл с комментариями `//`, `/* … */` и `/** … */`, а также с обычными строковыми и символьными литералами, содержащими слеши и кавычки. Последовательности, похожие на комментарии, внутри литералов удалять нельзя; перевод строки после однострочного комментария сохраняйте. Для предотвращения склейки соседних токенов замените удалённый блочный комментарий пробелом.

Вход — допустимый исходный текст Java в указанном подмножестве; незавершённые
литералы и комментарии вне входного договора. Сохраните весь текст вне
комментариев, включая пробелы и разделители строк. При удалении блочного
комментария оставьте один ASCII-пробел на его месте и сохраните находившиеся
внутри него разделители строк в исходном порядке. Поэтому `int/**/x;`
превращается в `int x;`. Для строкового литерала `"/* text */"` содержимое
остаётся прежним. Покажите экранированную кавычку и обратную косую черту
внутри литерала. Пути исходного и нового файла задайте явно; оба используют UTF-8. [1]

## Компиляция и запуск

Сохраните исходники `.java` в `src/`. Из корня проекта с установленным
JDK 25 выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out <класс>
```

Имя класса запуска и вспомогательные методы выберите самостоятельно. Добавьте к команде аргументы,
указанные условием. Если объявлен пакет, используйте полное имя класса.
После добавления вложенных каталогов перечислите соответствующие исходники
в команде компиляции.

Проверочные данные и ожидаемые наблюдения описаны в
[examples/README.md](examples/README.md). Пути с пробелами передавайте
одним аргументом в кавычках; пустой аргумент в POSIX-оболочке — `''`.
Если условие оставляет порядок аргументов или форму результата свободными,
укажите свой выбор в демонстрации.
