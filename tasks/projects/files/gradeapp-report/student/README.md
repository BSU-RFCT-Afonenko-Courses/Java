# Отчёт по студентам: завершение gradeapp

[Условие задания](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/bank/files.html#exr-files-gradeapp-report)
задаёт результат, обязательные приёмы и демонстрацию. Перед работой без сети
сохраните страницу условия. Команды ниже выполняются из каталога этого README.

Нужны установленный Gradle 9.8.0 и JDK 25; `JAVA_HOME` указывает на JDK.
Один раз подготовьте зависимости через сеть:

```console
gradle prepareDependencies
```

В `src/main/java/grade` реализуйте пять методов, перечисленных в условии,
сохранив заданные сигнатуры и доступ. Предоставленные `Student`,
`DataFormatException` и готовые части `Main` обеспечивают общий договор.
До реализации TODO соберите JAR и скомпилируйте тесты без проверки поведения:

```console
gradle --offline assemble testClasses
```

После реализации выполните сборку с открытыми проверками и запустите пример:

```console
gradle --offline clean build
java -jar build/libs/gradeapp.jar samples/students.txt 80
```

JAR создаётся при сборке. Приложению нужны ровно два аргумента: путь
UTF-8-файла и целый порог 0–100. Пути с пробелами заключайте в кавычки;
относительный путь считается от текущего каталога. Для запуска из другого
каталога укажите абсолютные пути к JAR и входному файлу.

Готовые данные: [обычный каталог](samples/students.txt),
[пробельный файл](samples/blank.txt) и [повтор кода](samples/duplicate.txt).
Для обычного каталога при пороге 80 выводятся `s10;Ada;90` и `s3;Ann;90`
в этом порядке. Вывод, коды завершения и требования к диагностике заданы
в условии.

Открытые проверки в `src/test/java` запускаются задачей `test`, входящей
в `build`; часть из них наблюдает настоящий JAR из другого рабочего
каталога. После первоначальной подготовки эти команды работают
с `--offline`. Успех открытых проверок не заменяет демонстрацию и объяснение.

Предъявите работающий JAR, входные файлы и граничные примеры из условия.
Покажите также запуск из другого каталога; объясните уникальность кодов,
самостоятельность результата `selected` и момент начала вывода отчёта.
