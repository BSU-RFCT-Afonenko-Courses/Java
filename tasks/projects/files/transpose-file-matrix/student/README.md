## Матрица из файла и транспонирование

Для вывода результатов создайте новый каталог и файл средствами класса `File`. Входной файл содержит квадратную матрицу: каждая строка файла задаёт одну строку матрицы. Прочитайте матрицу в двумерный массив, самостоятельно определив её размер. Выведите исходную матрицу и результат её транспонирования.

Допустимый вход — непустая квадратная матрица целых `int` в UTF-8:
каждая физическая строка содержит одну строку матрицы, числа разделены
пробелами. Размер определите из входа. Прямоугольный и повреждённый
файлы находятся вне договора задачи.

Передайте программе аргументами пути входного файла, нового выходного
каталога и результата в нём; укажите их при демонстрации. Вход сначала
полностью прочитайте, затем сохраните исходную и транспонированную
матрицы с различимыми подписями. Для строк `1 2 3`, `4 5 6`, `7 8 9`
транспонирование даёт `1 4 7`, `2 5 8`, `3 6 9`. Покажите также матрицу 1×1.

Выход отличается от входа: самокопирование отклоните до открытия выхода.
Отсутствие входа сохраняет прежний результат. При отказе ввода-вывода
сообщите причину; при отказе записи возможен частичный выход,
атомарность не требуется. [1]

## Компиляция и запуск

Сохраните исходники `.java` в `src/`. Из корня проекта с установленным
JDK 25 выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out <класс>
```

Имя класса запуска и вспомогательные методы выберите самостоятельно. Добавьте к команде аргументы,
указанные условием. Если объявлен пакет, используйте полное имя класса.
После добавления вложенных каталогов перечислите соответствующие исходники
в команде компиляции.

Проверочные данные и ожидаемые наблюдения описаны в
[examples/README.md](examples/README.md). Пути с пробелами передавайте
одним аргументом в кавычках; пустой аргумент в POSIX-оболочке — `''`.
Если условие оставляет порядок аргументов или форму результата свободными,
укажите свой выбор в демонстрации.
