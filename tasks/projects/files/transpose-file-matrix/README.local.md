Реализуйте задание по полному условию. Минимальная заготовка содержит только обязательные объявления и TODO. Собственную модель, алгоритм, пакеты и помощники выберите в пределах условия.

Алгоритм транспонирования, классы, подписи и способ представления двух матриц свободны. Читатель отчёта не пересчитывает транспонирование из входа и не возвращает заранее известный образец.

Открытая проверка: JDK 25, `gradle test`. Два публичных случая входят в прежние 5 равных оценочных групп. Автоматическая часть: `80 × passed/total`, прежняя ручная часть — 20%. API баллов не даёт; инфраструктурный отказ оставляет результат неустановленным. Признанные прежние оценки и решения сохраняются.

Читатель свободного отчёта размещён на стороне открытой проверки в TaskBinding. При другом законном оформлении его согласуют с фактически записанным отчётом; исходный вход ему не передаётся. Дублировать этот читатель в решении не требуется.
