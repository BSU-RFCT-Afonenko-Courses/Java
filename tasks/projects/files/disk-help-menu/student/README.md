## Справочная система, использующая диск

Создайте справочную систему, которая хранит сведения в обычном текстовом файле `helpfile.txt`, позволяя изменять и расширять справку без изменения кода программы. Пользователь вводит название темы; программа находит эту тему в файле и отображает соответствующую информацию.

Каждый раздел начинается отдельной строкой `#название-темы`. Затем идут строки справочной информации; между разделами находится пустая строка. В конце строк справки нет пробелов.

Создайте класс `Help`, которому имя справочного файла передаётся через конструктор. Метод `helpOn(String what)` ищет тему, выводит сведения и возвращает признак того, что тема найдена; ошибки файлового ввода/вывода обрабатывает сам метод. Метод `getSelection()` получает название темы от пользователя. Программу запуска разместите в `FileHelp.java`.

Для самостоятельного `helpfile.txt` в UTF-8 создайте разделы `if`, `switch`, `for`, `while`, `do`, `break`, `continue` по описанному формату. Каждой теме достаточно краткого описания синтаксиса; тексты справки составляйте самостоятельно по изученным управляющим конструкциям. Отсутствие темы и ошибка чтения должны различаться в сообщении.

Названия тем уникальны, непусты и сравниваются с учётом регистра.
Пустая строка завершает текст раздела; сведения внутри раздела сохраняют
порядок. Для неизвестной темы `helpOn` возвращает `false` и сообщает
об отсутствии темы; при ошибке чтения тоже возвращает `false`, но сообщение
поясняет файловый отказ. При найденной теме метод печатает её текст
и возвращает `true`. Способ завершения интерактивного ввода выберите
и покажите пользователю. Общий `System.in` остаётся доступным для меню. [1]

## Компиляция и запуск

Сохраните исходники `.java` в `src/`. В заготовке `src/FileHelp.java`
класс запуска называется `HelpMenu`. После реализации выполните из корня
проекта с установленным JDK 25:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out HelpMenu
```

Условие задаёт файл `FileHelp.java`; имя класса и форму запуска выбираете
самостоятельно. Если вы изменили имя класса, замените `HelpMenu` в команде
своим именем. Если объявлен пакет, используйте полное имя класса.
После добавления вложенных каталогов перечислите соответствующие исходники
в команде компиляции.

Проверочные данные и ожидаемые наблюдения описаны в
[examples/README.md](examples/README.md). Пути с пробелами передавайте
одним аргументом в кавычках; пустой аргумент в POSIX-оболочке — `''`.
Если условие оставляет порядок аргументов или форму результата свободными,
укажите свой выбор в демонстрации.
