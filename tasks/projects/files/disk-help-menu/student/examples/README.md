# Файл справки и последовательные запросы

В `helpfile.txt` находятся темы `if`, `switch`, `for`, `while`, `do`,
`break` и `continue`. Запрос `if` выводит текст этой темы и возвращает `true`
из `helpOn`; запрос `If` не находит тему и возвращает `false`.

При отсутствующем справочном файле `helpOn` также возвращает `false`,
а сообщение поясняет ошибку чтения. Меню должно позволять последовательные
запросы: после первого выбора общий `System.in` остаётся открытым.
Покажите выбранный способ завершения меню и при необходимости дополните
справку собственным текстом по управляющим конструкциям.
