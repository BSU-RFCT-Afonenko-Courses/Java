# Справочная система, использующая диск

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `src/main/java/Study.java`
- `src/main/java/Help.java`
- `src/main/java/FileHelp.java`

Форма PrairieLearn: штатный файловый диалог. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
В полях ответа пути исходников задаются относительно `src/main/java`.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.

Данные, результаты и обязательные средства Java приведены в [условии
задания](../../../bank/files.qmd#exr-files-disk-help-menu). Канонические исходники находятся в [заготовке](starter/). Порядок сборки и запуска приведён в [общей инструкции](../../common/java/gradle.md). Допустимые варианты и местные условия уточняет [локальное дополнение](README.local.md). [API комплекта](api/) и [открытые примеры](demo/) относятся к этой заготовке. Обязательные объявления и состав ответа сохраняйте по условию и стартеру. Самопроверка не заменяет предусмотренные условием демонстрацию, обязательные приёмы и объяснение.

Программа запуска находится в `FileHelp.java`. Собственный `helpfile.txt` предъявляется при демонстрации и защите; в три Java-файла ответа он не включается.
