## Удаление чётного количества коротких слов

Для вывода результатов создайте новый каталог и файл средствами класса `File`. Из каждой строки файла удалите максимальное чётное количество слов длиной от трёх до пяти символов.

Вход: строки «one two elephant four», «a cat dog bee house». Разделитель — пробел. Если подходящих слов нечётное количество, оставьте последнее подходящее слово, чтобы число удалённых было максимальным чётным; порядок остальных слов сохраняйте.

Вход — UTF-8-текст; длину слова считайте в кодовых точках Unicode.
Слово — непустая последовательность между ASCII-пробелами; несколько
пробелов дают одну границу. Пунктуация внутри такой последовательности
участвует в длине. Выводите сохранившиеся слова каждой строки через один
пробел; полностью очищенная строка остаётся пустой. Для примера получатся
`elephant four` и `a`. Добавьте строку без подходящих слов и пустой файл. [1]

## Компиляция и запуск

Сохраните исходники `.java` в `src/`. Из корня проекта с установленным
JDK 25 выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out <класс>
```

Имя класса запуска и вспомогательные методы выберите самостоятельно. Добавьте к команде аргументы,
указанные условием. Если объявлен пакет, используйте полное имя класса.
После добавления вложенных каталогов перечислите соответствующие исходники
в команде компиляции.

Проверочные данные и ожидаемые наблюдения описаны в
[examples/README.md](examples/README.md). Пути с пробелами передавайте
одним аргументом в кавычках; пустой аргумент в POSIX-оболочке — `''`.
Если условие оставляет порядок аргументов или форму результата свободными,
укажите свой выбор в демонстрации.
