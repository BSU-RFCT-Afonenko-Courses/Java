## Телефоны и владельцы

Для вывода результатов создайте новый каталог и файл средствами класса `File`. Сохраните в файл записи о телефонах и их владельцах. Выведите в файл отобранные записи, телефоны в которых начинаются с префикса `k` или `j`.

Формат UTF-8: одна запись в строке, телефон и владелец разделены точкой с запятой; например «291234567;Анна», «331234567;Борис», «441234567;Вера». Телефон храните строкой; `k` и `j` — строковые префиксы «29» и «33». Порядок результатов совпадает с порядком записей.

Телефон состоит из цифр ASCII, имя владельца непустое и не содержит
`;`, CR и LF. Префиксы `k` и `j` — непустые строки цифр, передаваемые
вместе с именами файлов выбранным вами способом. В отбор входит запись,
телефон которой начинается хотя бы с одного префикса. Совпадение с обоими
не дублирует запись. Сохраните выбранные строки в том же формате UTF-8.
Покажите совпадающие префиксы, отсутствие результатов и повторную запись:
повтор входа сохраняется в результате, если проходит отбор. [1]

## Компиляция и запуск

Сохраните исходники `.java` в `src/`. Из корня проекта с установленным
JDK 25 выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out <класс>
```

Имя класса запуска и вспомогательные методы выберите самостоятельно. Добавьте к команде аргументы,
указанные условием. Если объявлен пакет, используйте полное имя класса.
После добавления вложенных каталогов перечислите соответствующие исходники
в команде компиляции.

Проверочные данные и ожидаемые наблюдения описаны в
[examples/README.md](examples/README.md). Пути с пробелами передавайте
одним аргументом в кавычках; пустой аргумент в POSIX-оболочке — `''`.
Если условие оставляет порядок аргументов или форму результата свободными,
укажите свой выбор в демонстрации.
