# Числа для сортировки

Создайте UTF-8-файл с числами:

```text
7 -2 7 0 3 -5
```

Ожидаемый результат:

```text
-5 -2 0 3 7 7
```

Повтор числа 7 сохраняется. Разделите тот же вход табуляциями и переводами
строк: порядок результата останется прежним. Пустой вход даёт пустой выход.
Используйте обычный ASCII-минус в отрицательных числах.
