# Максимальный элемент диапазона

Напишите обобщённый метод, возвращающий максимальный элемент диапазона
`[begin, end)` массива. Начальный индекс включается, конечный — нет. Сравнение
выполняется через `Comparable`; результат сохраняет тип элемента. Метод не изменяет
массив и возвращает один из элементов выбранного диапазона. Если максимальных
элементов несколько, можно вернуть любой из них.

Массив и его элементы отличны от `null`; диапазон непуст и находится в границах
массива: `0 <= begin < end <= array.length`. Это условия входных данных, программно
проверять их в этой задаче не требуется. Допустимы простая граница `Comparable<T>` и
гибкая `Comparable<? super T>`.

Примените один метод к массиву целых чисел и массиву строк. Среди примеров покажите
часть массива, не содержащую максимума всего массива, диапазон из одного элемента и
случай с несколькими равными максимумами.

## Работа с проектом

Имя метода, имя содержащего его класса и структуру пакетов выберите самостоятельно.
Знак результата `compareTo` определяет порядок. Соблюдайте предпосылки из условия;
среди равных максимумов можно выбрать любой.

Разместите Java-файлы в `src/`. Имена файлов должны совпадать с именами объявленных
в них открытых классов. Для компиляции всех своих исходников из корня проекта нужен
JDK 25:

```bash
find src -name '*.java' -print > sources.txt
javac --release 25 -encoding UTF-8 -d out @sources.txt
```

Точку запуска выберите самостоятельно. Например, класс `Demo` с `main` в безымянном
пакете запускается командой `java -cp out Demo`; для класса в пакете укажите его
полное имя.

Файл `examples/scenarios.json` описывает случаи для проверки решения. Формат ввода
вашей программы выбирайте самостоятельно. Представьте исходники и демонстрацию
случаев из условия; объясните связи типов и причины ожидаемых результатов. Отдельный
большой отчёт не требуется.
