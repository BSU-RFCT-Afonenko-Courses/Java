## Максимальный элемент диапазона

Напишите обобщённый метод, возвращающий максимальный элемент диапазона
`[begin, end)` массива. Начальный индекс включается, конечный — нет.
Сравнение выполняется через `Comparable`; результат сохраняет тип элемента.
Метод не изменяет массив. Если максимальных элементов несколько, можно
вернуть любой из них.

Массив и его элементы отличны от `null`; диапазон непуст и допустим:
`0 <= begin < end <= array.length`. Это условия входных данных,
программно проверять их в этой задаче не требуется. Простая граница
`Comparable<T>` и гибкая `Comparable<? super T>` допустимы.

Примените один метод к массиву целых чисел и массиву строк. Среди примеров
покажите часть массива, не содержащую его общего максимума, диапазон
из одного элемента и несколько равных максимумов. [Источник 1]

## Работа с проектом

Разместите исходные Java-файлы в `src/` с выбранными именами и структурой пакетов. Для компиляции нужен JDK 25: `javac --release 25 -encoding UTF-8 -d out src/ИМЯ.java`; для нескольких файлов перечислите все исходники. Способ запуска демонстрации выбирайте самостоятельно. `examples/scenarios.json` содержит открытые наблюдения.

Преподаватель привязывает конкретное решение обычным Java-клиентом; его `TaskBinding` и выбранные в reference имена не являются дополнительным StudentAPI. Недоступное private/nested размещение сохраняет ручную проверку. Обязательная техника и объяснение проверяются по исходнику и на защите.

отчёт не требуется.
