## Сжатие английского текста по алгоритму Хаффмена

Предварительная подготовка: классы ([Классы, инкапсуляция и инициализация](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/classes.html#sec-j25-theory-classes)), коллекции
([Коллекции и способы хранения объектов](https://bsu-rfct-afonenko-courses.github.io/Java/theory/chapters/collections.html#sec-j25-theory-collections)) и очередь с приоритетами. Перед реализацией
разберите построение дерева и префиксных кодов по алгоритму Хаффмена;
выполнение других задач резервной лабораторной не требуется.

Написать программу, осуществляющую сжатие английского текста. Построить для каждого слова в тексте оптимальный префиксный код по алгоритму Хаффмена. Использовать класс PriorityQueue.

Вход: «one two two three three three». Символами алфавита кодирования служат слова, разделённые пробелами; регистр сохраняется. При равных частотах применяйте выбранный воспроизводимый порядок и объясните его. Пустой вход даёт пустой кодированный текст, для единственного различного слова используйте код 0. Выведите таблицу «слово — частота — код» и последовательность битов как текст из 0/1; двоичный файл и отдельная обвязка записи битов не требуются. [Источник 1]
