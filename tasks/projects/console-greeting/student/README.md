# Приветствие пользователя

Приветствуйте пользователя, чьё имя передано первым аргументом `main(String[] args)`. Имя сохраните без изменения; последующие аргументы не учитывайте. Без аргументов сообщите, что имя требуется.

Вход и результат: `java Main "Анна"` выводит одну строку `Здравствуйте, Анна!`; запуск без аргументов — `Укажите имя.`. Имя может содержать кириллицу, пробелы и эмодзи. Стандартный ввод не используется.

## Исходник и запуск

В `src/main/java/Main.java` находится заготовка с `TODO`. Успешная
компиляция заготовки не означает, что решение готово: требуемое поведение
ещё нужно реализовать. Сохраните
точку входа `Main.main(String[] args)`; вспомогательные методы и классы
разрешены.

Откройте каталог, содержащий этот `README.md` и `src`. Выполните команды
инструментами JDK 25. После изменения исходника повторите компиляцию:

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/*.java
java -cp out Main "Анна"
java -cp out Main
```

Первый запуск должен напечатать `Здравствуйте, Анна!`, второй — `Укажите имя.`. Имя передаётся после имени класса. Стандартный ввод эта программа не читает.

Публичные примеры находятся в `src/test/java/PublicExamplesTest.java`
и используют JUnit 5. Они охватывают часть случаев; полные требования
задаёт условие выше. Компиляция не проверяет соответствие поведения
программы условию.
