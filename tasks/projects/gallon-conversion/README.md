# Проект: gallon-conversion

Преобразуйте 10 галлонов в литры, используя коэффициент 3,7854 литра на галлон. Начальное количество и коэффициент задайте в программе.

Вход и результат: запуск без входных данных выводит два числа — количество галлонов и эквивалентное количество литров, в этом порядке. Результат: `10 37.854`. Числовые аргументы командной строки не требуются.

Выберите числовые типы, сохраняющие дробную часть результата. Количество переменных и конкретные типы выберите самостоятельно с учётом требуемой точности.

Вещественные результаты можно выводить в десятичной или экспоненциальной форме с точкой. Автоматическая проверка допускает абсолютную погрешность `1e-8`; количество знаков после точки не фиксируется.

Из каталога проекта, содержащего `student`, соберите `student/src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out student/src/main/java/*.java`, затем запустите `java -cp out Main`. Команды используют JDK 25. Стандартный ввод не используется; начальные значения заданы в программе. Точка входа — `Main.main(String[] args)`; вспомогательные методы и классы разрешены.

Публичные примеры: `student/src/test/java/PublicExamplesTest.java`. Их можно запускать с помощью JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.

Для преподавателя: `reference/Main.java` — авторское решение, `tests/junit/ContractTest.java` — закрытые проверки, `tests/fixtures/` — ошибочные решения, `tests/contract-cases.json` — обязательные ожидаемые результаты их проверки.
