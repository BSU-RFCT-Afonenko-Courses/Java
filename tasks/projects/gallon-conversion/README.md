# Проект: gallon-conversion

Преобразуйте 10 галлонов в литры, используя коэффициент 3,7854 литра на галлон. Начальное количество и коэффициент задайте в программе.

Протокол проверки: запуск без входных данных выводит два числа — количество галлонов и эквивалентное количество литров, в этом порядке. Результат: `10 37.854`. Числовые аргументы командной строки не требуются.

Критерий преподавательской проверки: объявите две переменные типа `double`, для галлонов и литров. Автотесты проверяют числа в выводе, но не доказывают типы и количество переменных в исходнике.

Соберите `student/src/main/java/Main.java` командой `javac --release 25 -encoding UTF-8 -d out student/src/main/java/*.java`, затем запустите `java -cp out Main`. Для дополнительного входа передайте текст через stdin; без входа закройте stdin (EOF). Java 25 без preview. Вспомогательные методы и классы разрешены.

Публичные примеры: `student/src/test/java/PublicExamplesTest.java`. Их можно запускать JUnit 5 вместе с вашей программой; они показывают часть контракта и не заменяют все требования условия.

Для преподавателя: `reference/Main.java` — авторское решение, `tests/junit/ContractTest.java` — закрытые проверки, `tests/fixtures/` — ошибочные решения, `tests/contract-cases.json` — обязательные ожидаемые результаты их проверки. Компиляция starter успешна; его поведенческие тесты должны выявить незавершённое решение. Авторское решение должно пройти публичные и закрытые тесты. Каждый ошибочный пример должен скомпилироваться и дать хотя бы один поведенческий отказ; точные результаты фактического прогона указаны в `tests/verification-results.json`.
