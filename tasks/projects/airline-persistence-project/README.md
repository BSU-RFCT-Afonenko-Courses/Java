# Авиакомпания: техническая manual-поставка

Условие tasks/bank/projects.qmd, c9d05aea901fb819a5fcbb44bbf8a117caaeb9b2. Только student/ публичен; вся reference/tests закрыта. У решения свободны модели/пакеты/сигнатуры/меню/формат Java serialization. TaskBinding — обычная преподавательская привязка, не Student API. Source отдельно компилируется, затем binding/JUnit, затем наблюдения; неизвестный private/nested API требует ручной адресации без score.

Primary company.model/company.persistence/company.app: String IDs, Serializable hierarchy, static connector, ascending range, all qualifying fuel results. Default serialization не сохраняет static globalLabel и transient menuCount. Alternate flights.domain/flights.storage/flights.console: int IDs, instance FileStore, descending range, Optional одного подходящего; Company implements Externalizable и явно пишет/читает static station и transient selections. Это законный явно объявленный иной формат: модификатор transient исключает default field serialization, но не запрещает ручной writeExternal. Оба меню до демонстрации объясняют политику. Binding не требует от иной сдачи этих полей/политик: expectedGlobal/expectedTransient — teacher metadata выбранной формы. Техника/пояснения проверяются по исходнику.

Тесты используют минимальные три самолёта, totals 232/38, sorted monotonic в выбранном направлении, inclusive bounds и отсутствие результата. Все предъявленные результаты должны подходить; all-match API при условии «найти самолёт» не навязан. Round-trip сравнивает бизнес-поля/виды по ID без требования порядка/identity/бинарных bytes. Connector реально обновляет сохранённую модель; adapter только вызывает его операцию, не реализует update/save алгоритм. Source malformed file/новые validation/status правила не добавляются. OOP/осмысленность иерархии/пакеты/Code Conventions/Java serialization и различие static/transient — ручная часть, не claim из совпавших bytes.

Реальные мутации: пропущен cargo в сумме, exclusive range, no sorting, update без сохранения, потеря business field после загрузки.
