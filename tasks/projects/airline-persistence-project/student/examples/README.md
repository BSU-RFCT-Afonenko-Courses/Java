# Открытый сценарий

Минимальные три самолёта из условия дают 232 места и грузоподъёмность 38 т. Покажите сортировку по дальности в объявленном направлении и поиск в диапазоне потребления [1500, 2400] с включёнными границами. Сохраните и загрузите модель, измените параметр самолёта через коннектор и повторно загрузите. Объясните static/transient после загрузки для выбранного формата Java serialization. CSV, JSON, имя Main и helper API этим примером не задаются.
