# Сумма и среднее двух целых чисел

Исправьте класс `IntegerArithmetic`, чтобы следующие методы работали для
**любых** двух значений типа `int`:

```java
public static long sum(int a, int b)
public static double mean(int a, int b)
```

`sum` возвращает математическую сумму без переполнения. `mean` возвращает
арифметическое среднее, сохраняя дробную часть. Для `1` и `2` ожидается `1.5`,
для `Integer.MAX_VALUE` и `Integer.MAX_VALUE` сумма равна `4294967294L`.
Входные значения всегда допустимы; дополнительные исключения не требуются.


В заготовке изменяйте `src/main/java/IntegerArithmetic.java`; сохраните имя
public-класса без package и сигнатуры методов. Запустите `gradle test` из
каталога скачанного проекта. Добавьте свои JUnit-проверки нуля, отрицательных
значений, нечётной суммы и крайних значений int. Для самостоятельной подготовки объясните, на каком этапе
вычисления происходит расширение типа и почему расширение уже полученного
результата сложения не устраняет переполнение.

Отчёт JUnit находится в `build/reports/tests/test/index.html`. При изменении
API тесты укажут ожидаемый класс или метод. Если Java-код не компилируется,
сначала исправьте ошибку по имени файла и строке в сообщении компилятора.

## Локальный запуск

Нужны JDK 25 и совместимый Gradle. Из корня этого архива выполните:

```sh
gradle test
```

Исходники: `src/main/java`; открытые проверки: `src/test/java`.
Отчёт JUnit: `build/reports/tests/test/index.html`. Открытые примеры служат
для подготовки; официальная проверка использует отдельный доверенный набор.
