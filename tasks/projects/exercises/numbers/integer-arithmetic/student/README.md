# Сумма и среднее целых чисел

Нужны JDK 25 и совместимый Gradle. Измените только
`src/main/java/IntegerArithmetic.java`, сохранив два public static метода.
Исходная реализация содержит ошибки: исследуйте отчёт JUnit и исправьте их.

```sh
gradle test
```

Открытые примеры не заменяют проверку всего контракта. Добавьте собственные
проверки границ int, отрицательных значений, нуля и половинного результата.
Отчёт находится в `build/reports/tests/test/index.html`.

Если класс или метод переименован либо сигнатура изменена, JUnit покажет,
какой API ожидается. Синтаксическая ошибка останется ошибкой компилятора
с именем файла и строкой; её нужно исправить до запуска тестов.
