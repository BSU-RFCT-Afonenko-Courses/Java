# Лабораторная: целочисленные вычисления

Условие: [Числа и вычисления](../../../../exercises/numbers.qmd).
`student/` — скачиваемая заготовка с открытыми JUnit-примерами,
`reference/` — авторская реализация, `tests/junit/` — полный контракт.

Из корня проекта:

```sh
gradle -p student test
gradle -p student -Preference -Pgrading test
```

Тесты компилируются без ссылок на типы студенческого кода: API проверяется
через public reflection и сообщения JUnit. Поэтому отсутствующий метод
не ломает компиляцию проверяющего проекта. Ошибки синтаксиса Java проверяются
компилятором, с отдельной диагностикой файла и строки.

Для PrairieLearn подходят стандартные tests/junit и Java grader на JUnit 5;
привязка среды выполнения и способ загрузки задаются дополнительной
конфигурацией поставки, а не реализацией тестов.
