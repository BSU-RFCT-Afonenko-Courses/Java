# Разработка проверок контракта строкового диапазона

Реализуйте `SliceChecks.verify(CodePointSlice operation)`. Переданная операция
выделяет диапазон кодовых точек `[from, to)` непустой или пустой корректной строки
UTF-16. Допустимы ровно индексы `0 <= from <= to <= число кодовых точек`;
остальные сочетания должны приводить к `IndexOutOfBoundsException`. Входная
строка не равна `null`. Метод `verify` должен завершаться нормально для
корректной операции и выбрасывать `AssertionError` при обнаружении нарушения.

Набор проверок должен различать три реализации с одиночной ошибкой: использование
индексов UTF-16 вместо позиций кодовых точек, включение правой границы диапазона
и отказ для пустого диапазона. Проверки должны обнаруживать каждую из трёх
ошибок; дополнительно проверьте хотя бы один недопустимый диапазон. Выбор примеров
и способ построения проверок остаются за вами. Изменяйте только `SliceChecks.java`;
проверки должны использовать результаты вызова операции, без анализа её класса
или исходного текста.

## Локальный запуск

Нужны JDK 25 и совместимый Gradle. Из корня этого архива выполните:

```sh
gradle test
```

Исходники: `src/main/java`; открытые проверки: `src/test/java`.
Отчёт JUnit: `build/reports/tests/test/index.html`. Открытые примеры служат
для подготовки; официальная проверка использует отдельный доверенный набор.
