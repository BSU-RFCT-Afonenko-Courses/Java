# Построение воспроизводимого примера для двух мер длины

Реализуйте `UnicodeEvidence.examples()`, возвращающий массив из двух записей
`Example(String text, int utf16Units, int codePoints, String firstCodePoint)`.
Первая строка должна начинаться с дополнительной кодовой точки Unicode
(U+10000–U+10FFFF); вторая должна состоять из одного или нескольких печатных
ASCII-символов (U+0020–U+007E). Обе строки должны быть корректными строками UTF-16.
В каждой записи укажите число кодовых единиц UTF-16, число кодовых точек и
подстроку, содержащую ровно первую кодовую точку. Проверяется соответствие
заявленных наблюдений выбранным строкам; вычислять наблюдения программно
разрешено. Изменяйте только `UnicodeEvidence.java`.

## Локальный запуск

Нужны JDK 25 и совместимый Gradle. Из корня этого архива выполните:

```sh
gradle test
```

Исходники: `src/main/java`; открытые проверки: `src/test/java`.
Отчёт JUnit: `build/reports/tests/test/index.html`. Открытые примеры служат
для подготовки; официальная проверка использует отдельный доверенный набор.
