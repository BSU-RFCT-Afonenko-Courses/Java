# Реализация диапазона, сохраняющего кодовые точки

Реализуйте `UnicodeSlice.slice(String text, int from, int to)`, возвращающий
кодовые точки строки `text` с позиции `from` включительно до позиции `to`
исключительно. Позиции отсчитываются от нуля по кодовым точкам. Допустимы ровно
`0 <= from <= to <= число кодовых точек`; при иных индексах выбрасывайте
`IndexOutOfBoundsException`. Пустой диапазон даёт пустую строку, полный диапазон
сохраняет содержимое исходной строки. Вход не равен `null` и не содержит непарных
суррогатов. Графемная сегментация и идентичность возвращаемого объекта не
проверяются. Изменяйте только `UnicodeSlice.java`.

## Локальный запуск

Нужны JDK 25 и совместимый Gradle. Из корня этого архива выполните:

```sh
gradle test
```

Исходники: `src/main/java`; открытые проверки: `src/test/java`.
Отчёт JUnit: `build/reports/tests/test/index.html`. Открытые примеры служат
для подготовки; официальная проверка использует отдельный доверенный набор.
