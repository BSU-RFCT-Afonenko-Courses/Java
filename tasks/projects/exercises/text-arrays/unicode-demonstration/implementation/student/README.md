# Учебный проект

Требуются JDK 25 или новее и установленный Gradle, совместимый с выбранным JDK.
Из каталога проекта выполните `gradle test`. Исходный шаблон намеренно не проходит
все проверки: замените `UnsupportedOperationException` решением задачи.

Условие приведено на странице демонстрационного реферата. Проверки для запуска
находятся в `src/test/java`; их изменение не является решением задачи.
