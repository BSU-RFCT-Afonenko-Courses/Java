# Диапазон кодовых точек Unicode

Требуются **JDK 25 или новее** и Gradle с поддержкой используемого JDK.
Для JDK 25 подойдёт [Gradle 9.1 или новее](https://docs.gradle.org/current/userguide/compatibility.html).
Gradle загружает JUnit 5.11.4
из Maven Central при первом запуске; нужен доступ к сети.

Реализуйте `UnicodeSlice.slice(String text, int from, int to)`:

- Результат содержит кодовые точки полуоткрытого диапазона `[from, to)`.
- Для `null` выбрасывается `NullPointerException`.
- Для отрицательных, перепутанных или слишком больших границ выбрасывается `IndexOutOfBoundsException`.
- Допустимый пустой диапазон возвращает пустую строку.

```sh
gradle test
```

Запускайте команду из каталога `student`. Открытые примеры находятся в
`src/test/java/UnicodeSliceExamplesTest.java`. В стартовой заготовке проверка
сигнатуры проходит, а проверки поведения завершаются ошибками: метод ещё
не реализован. Составьте собственные проверки границ, пустой строки и
дополнительной кодовой точки.

Если компилятор принимает решение, отсутствие класса или требуемого метода,
неверные `static`, `public` и возвращаемый тип показываются как понятные ошибки
JUnit. Проверки находят метод через reflection и не требуют его правильной
сигнатуры для своей компиляции. Синтаксические ошибки остаются ошибками
компилятора. Подробный отчёт локального запуска — `build/reports/tests/test/index.html`.

Для авторской проверки из каталога `student`:

```sh
gradle clean test -Pgrading
gradle clean test -Preference -Pgrading
```

`-Pgrading` добавляет проверочные тесты из `../tests/junit`;
`-Preference` использует эталон из `../reference` вместо заготовки.
Без этих флагов доступны только открытые примеры и решение ученика.
Все исходники компилируются с `--release 25`.

Git можно использовать локально. В поле Java-кода PrairieLearn передаётся
только содержимое `UnicodeSlice.java` из корня каталога `student`.
