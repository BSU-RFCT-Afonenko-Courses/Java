# Расстояние до места вспышки молнии

Вычислите расстояние в метрах между наблюдателем и местом вспышки молнии. Скорость звука в воздухе — 335 метров в секунду; интервал между вспышкой и звуком — 7,2 секунды. Задайте эти константы в программе и используйте значения с плавающей точкой.

Вход и результат: запуск `java Main` не требует входных данных; первая непустая строка стандартного вывода содержит только расстояние в метрах. Ожидаемый результат — `2412`.

Дополнительная неоцениваемая часть: вычислите расстояние до крупного объекта, если указанный интервал означает время до прихода эхо. Её результат можно вывести после первой строки. Объясните различие двух временных интервалов; автоматическая оценка относится только к молнии.

Вещественные результаты можно выводить в десятичной или экспоненциальной форме с точкой. Автоматическая проверка допускает абсолютную погрешность `1e-8`; количество знаков после точки не фиксируется.

## Исходник и запуск

В `src/main/java/Main.java` находится заготовка с `TODO`. Успешная
компиляция заготовки не означает, что решение готово: требуемое поведение
ещё нужно реализовать. Сохраните
точку входа `Main.main(String[] args)`; вспомогательные методы и классы
разрешены.

Откройте каталог, содержащий этот `README.md` и `src`. Выполните команды
инструментами JDK 25. После изменения исходника повторите компиляцию:

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/*.java
java -cp out Main
```

Первая непустая строка должна содержать только `2412` либо вещественное число, отличающееся от него не больше чем на заданный допуск. Константы находятся в программе; чтение ввода для этого запуска не требуется.

Публичные примеры находятся в `src/test/java/PublicExamplesTest.java`
и используют JUnit 5. Они охватывают часть случаев; полные требования
задаёт условие выше. Компиляция не проверяет соответствие поведения
программы условию.
