## Функциональный интерфейс: дискриминант

Определите собственный функциональный интерфейс: его единственный абстрактный метод принимает три `double` — коэффициенты `a`, `b`, `c` — и возвращает `double`. Реализуйте его лямбдой, вычисляющей дискриминант `b² − 4ac`. Имена интерфейса и метода свободны.

Коэффициенты конечны, модуль каждого не превышает `1000`. Нулевой `a` допустим: в этой задаче вычисляется само выражение дискриминанта. Требуемый результат `r` — математическое значение выражения для переданных коэффициентов. Вычисленное конечное значение `v` принимается при `|v − r| ≤ 1e-8 + 1e-12 · |r|`. Здесь первая часть допуска ограничивает абсолютную погрешность около нуля, вторая учитывает масштаб результата.

Для `(1, -3, 2)`, `(1, 2, 1)`, `(1, 0, 1)` результаты соответственно `1`, `0`, `-4`. Покажите вызов через переменную своего интерфейса. [1]


Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения. Публичные ограничения отдельной карточки действуют вместе с её условием. Обязательное применение Stream API, лямбды или собственного интерфейса проверяется по исходному коду.

## Локальная работа

Используйте JDK 25. Добавьте собственные .java в src; компилируйте все исходники в отдельный каталог, например `javac -encoding UTF-8 -d out src/*.java`. Запускайте выбранный вами класс обычной командой `java -cp out <ваш.класс>` либо показывайте функцию из своей демонстрации. Имена запуска и методы этой поставкой не закрепляются. Примеры в examples/README.md доступны до сдачи. Объясните применение требуемого приёма по исходному коду.
