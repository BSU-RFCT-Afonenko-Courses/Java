## Точки по удалённости от начала координат

Отсортируйте упорядоченный список точек плоскости по возрастанию расстояния от начала координат. Примените Stream API и лямбда-компаратор; отсортированный результат выведите, обозначая каждую точку как `(X:Y)`. Между точками допустимы пробелы или переводы строк. Модель точки и способ её создания выберите самостоятельно.

Обе координаты — целые числа от `-10000` до `10000` включительно. Список и его элементы ненулевые; число точек может быть нулевым. Расстояния сравниваются по их геометрическому значению. Для этого диапазона квадрат расстояния `x * x + y * y` целый, не превышает `200000000` и точно представим в `int`: его порядок совпадает с порядком расстояний. Допустим любой способ сравнения, сохраняющий этот порядок и равенство расстояний.

Сортировка устойчивая: точки с равными геометрическими расстояниями сохраняют исходный взаимный порядок, включая повторяющиеся точки. Исходный список и точки не меняются. Для `(1:10)` и `(2:0)` первой должна быть `(2:0)`; точки `(3:4)` и `(0:5)` остаются в исходном порядке. Пустой список даёт пустой вывод. [1]

Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения.
Применение Stream API, лямбды или собственного интерфейса проверяется
по исходному коду там, где это требуется условием.

## Локальная работа

Используйте JDK 25. Разместите свои `.java` в `src` и из каталога проекта выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
```

Если демонстрация оформлена через `main`, запустите её командой
`java -cp out <ваш.класс>`, подставив выбранное полное имя класса.
Имена, форма демонстрации и способ передачи данных остаются вашим выбором
в пределах условия. Сценарии: [examples/README.md](examples/README.md).
Объясните применение требуемого приёма по исходному коду.
