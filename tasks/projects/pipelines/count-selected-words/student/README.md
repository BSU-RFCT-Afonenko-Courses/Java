## Количество вхождений заданных слов

Для готового текста и упорядоченного списка искомых слов выведите частоты в формате `[слово1-2, слово2-3, слово3-0]`. Используйте Stream API.

Текст — ненулевая строка. Слово в нём — максимальная непрерывная последовательность латинских букв `A`–`Z` и `a`–`z`; все остальные кодовые единицы служат разделителями. Регистр значим: `One` и `one` различаются. Искомые слова — ненулевые непустые строки только из этих букв; список ненулевой, может быть пустым и содержать повторы.

Записи результата следуют порядку искомых слов и сохраняют их повторы. Отсутствующему слову соответствует `0`. Для текста `"one, two two; One"` и списка `[one, two, absent, one]` результат `[one-1, two-2, absent-0, one-1]`. Пустой текст даёт нулевые частоты всех запросов; пустой список запросов — `[]`. Входные данные не меняются. Можно считать каждое запрошенное слово отдельным конвейером или сначала построить общий частотный словарь. [1]

Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения.
Применение Stream API, лямбды или собственного интерфейса проверяется
по исходному коду там, где это требуется условием.

## Локальная работа

Используйте JDK 25. Разместите свои `.java` в `src` и из каталога проекта выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
```

Если демонстрация оформлена через `main`, запустите её командой
`java -cp out <ваш.класс>`, подставив выбранное полное имя класса.
Имена, форма демонстрации и способ передачи данных остаются вашим выбором
в пределах условия. Сценарии: [examples/README.md](examples/README.md).
Объясните применение требуемого приёма по исходному коду.
