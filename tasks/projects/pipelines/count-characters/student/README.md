## Количество вхождений символов

Через Stream API постройте коллекцию частот всех кодовых единиц UTF-16 в готовой ненулевой строке. Каждая кодовая единица `char` учитывается отдельно, включая пробелы, переводы строк и суррогаты; дополнительные ограничения на содержимое строки отсутствуют. Пустой текст даёт пустую коллекцию.

Ключ можно представлять как `Character` или как целое значение кодовой единицы; частота — число её вхождений. Порядок перечисления и оформление вывода выберите самостоятельно, сохранив однозначность ключей. В `"ab a"` частоты: `a` — 2, `b` — 1, пробел — 1. В строке `"\uD83D\uDE00"` две разные кодовые единицы со значениями `55357` и `56832`, каждая встречается один раз.

Подготовка: [«Кодовые единицы строки как источник»](PREPARATION.md#справочник) и [«Источник кодовых единиц»](PREPARATION.md#практика). [1]

Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения.
Применение Stream API, лямбды или собственного интерфейса проверяется
по исходному коду там, где это требуется условием.

## Локальная работа

Используйте JDK 25. Разместите свои `.java` в `src` и из каталога проекта выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
```

Если демонстрация оформлена через `main`, запустите её командой
`java -cp out <ваш.класс>`, подставив выбранное полное имя класса.
Имена, форма демонстрации и способ передачи данных остаются вашим выбором
в пределах условия. Сценарии: [examples/README.md](examples/README.md).
Объясните применение требуемого приёма по исходному коду.
