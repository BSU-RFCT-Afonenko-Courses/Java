## Построение функции `ternaryOperator`

Напишите обобщённый метод `ternaryOperator`, который получает условие и две функции и возвращает функцию выбора результата. Его типовые параметры и параметры метода:

```java
<T, R> Function<T, R> ternaryOperator(
        Predicate<? super T> condition,
        Function<? super T, ? extends R> ifTrue,
        Function<? super T, ? extends R> ifFalse)
```

Это объявление задаёт имя метода и его типовой договор. Класс, пакет, видимость и наличие `static` выбирайте в своей программе. Все три переданные функции ненулевые. Ограничений на типы `T` и `R` нет; допустимые аргументы определяются переданными функциями. В частности, `null` допустим, если условие и выбранная ветвь его принимают. Результат выбранной ветви, включая `null`, передаётся вызывающему коду.

При создании результирующей функции условие и обе переданные функции не вызываются. Каждый последующий `apply` ровно один раз проверяет `condition` на переданном аргументе и ровно один раз вызывает на том же аргументе выбранную ветвь: `ifTrue` для `true`, `ifFalse` для `false`. Невыбранная ветвь не вызывается. Повторный `apply` выполняет выбор заново. Если условие или выбранная ветвь выбрасывает исключение времени выполнения, оно передаётся вызывающему коду без замены; дальнейшие вызовы условия и ветвей при этом прекращаются.

Покажите пример для ненулевых строк: условие проверяет пустоту, истинная ветвь возвращает `0`, ложная — длину. Покажите обе ветви, повторные вызовы и случай, в котором невыбранная ветвь выбросила бы исключение. Проверьте отдельно создание функции и её вызов. Вспомогательные методы свободны. [1]

Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения.
Применение Stream API, лямбды или собственного интерфейса проверяется
по исходному коду там, где это требуется условием.

## Локальная работа

Используйте JDK 25. Разместите свои `.java` в `src` и из каталога проекта выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
```

Если демонстрация оформлена через `main`, запустите её командой
`java -cp out <ваш.класс>`, подставив выбранное полное имя класса.
Имена, форма демонстрации и способ передачи данных остаются вашим выбором
в пределах условия. Сценарии: [examples/README.md](examples/README.md).
Объясните применение требуемого приёма по исходному коду.
