Реализуйте задание по полному условию. Минимальная заготовка содержит только обязательные объявления и TODO. Собственную модель, алгоритм и вспомогательные типы внутри фиксированного комплекта выберите в пределах условия.

Денежный тип любой корректный, HALF_UP/HALF_EVEN равно допустимы. Числовое представление и правило объявляются свободным текстом до наблюдений, без обязательного JSON или BigDecimal. Для floating oracle использует точное значение представимых битов после предусмотренных операций, не подменяет его кратчайшей десятичной записью. Для собственной модели проекция раскрывает данные без пересчёта результата.

Открытая проверка: JDK 25, `gradle test`. Два публичных случая входят в прежние 4 равных оценочных групп. Автоматическая часть: `80 × passed/total`, прежняя ручная часть — 20%. API баллов не даёт; инфраструктурный отказ оставляет результат неустановленным. Признанные прежние оценки и решения сохраняются.

До демонстрации объявите денежное представление и HALF_UP либо HALF_EVEN. Открытый преподавательский клиент MoneyPolicy настроен на BigDecimal/HALF_UP; для другого законного выбора он настраивается независимо от полученного ответа. Порт representation только раскрывает реально хранимое значение; собственные модели могут раскрывать пару [unscaled, scale].
