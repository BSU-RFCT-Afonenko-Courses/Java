Числовое представление и правило округления объявляются свободным текстом до наблюдений, без обязательного JSON или BigDecimal. Для вычислений с плавающей точкой проверка использует точное значение представимых битов после предусмотренных операций, без подмены кратчайшей десятичной записью. Для собственной модели проекция раскрывает данные без пересчёта результата.

Открытый преподавательский клиент MoneyPolicy настроен на BigDecimal/HALF_UP; для другого законного выбора он настраивается независимо от полученного ответа. Вход `representation` раскрывает реально хранимое значение; собственная модель может раскрывать пару [unscaled, scale].
