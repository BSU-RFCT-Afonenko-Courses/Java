## Преобразование списка цен

Через Stream API преобразуйте список цен без налога в новый список цен с налогом. Ставка — отдельный входной параметр от `0` до `1` включительно; `0.20` означает 20%. Цены конечны и находятся в диапазоне от `0` до `1000000`. Список ненулевой, без элементов `null`, может быть пустым.

Для каждой цены вычисляется `цена × (1 + ставка)`, затем результат округляется до двух десятичных знаков. Выберите денежный тип и одно из правил округления к ближайшему: при точной середине округлять вверх (`HALF_UP`) либо к чётной последней сохраняемой цифре (`HALF_EVEN`). До демонстрации явно укажите выбранные представление и правило; по ним объясняются случаи округления. Сохраните порядок, повторы и исходный список. Для цены `100` и ставки `0.20` результат `120.00`; нулевая цена остаётся нулевой, пустой список даёт пустой новый список.

Покажите случай точной середины на выбранном представлении чисел и объясните результат. Проверка учитывает опубликованный в решении выбор типа и округления. [1]

Имена классов, пакеты, вспомогательные методы и способ запуска демонстрации выбирает автор решения.
Применение Stream API, лямбды или собственного интерфейса проверяется
по исходному коду там, где это требуется условием.

## Локальная работа

Используйте JDK 25. Разместите свои `.java` в `src` и из каталога проекта выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
```

Если демонстрация оформлена через `main`, запустите её командой
`java -cp out <ваш.класс>`, подставив выбранное полное имя класса.
Имена, форма демонстрации и способ передачи данных остаются вашим выбором
в пределах условия. Сценарии: [examples/README.md](examples/README.md).
