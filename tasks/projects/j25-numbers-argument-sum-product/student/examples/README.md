# Примеры суммы и произведения

Числа передаются аргументами командной строки после имени класса.
Стандартный ввод в этой задаче не используется.

| Аргументы | Сумма | Произведение |
|---|---:|---:|
| Нет аргументов | 0 | 1 |
| `3 -2 4` | 5 | −24 |
| `7` | 7 | 7 |
| `3 0 -2` | 1 | 0 |

Все промежуточные значения выбранных примеров помещаются в `long`.
Пустой набор не содержит операции умножения на ноль: по условию его
произведение равно единице. Формат представления двух результатов
выберите самостоятельно. Команды — в [README.md](../README.md).
