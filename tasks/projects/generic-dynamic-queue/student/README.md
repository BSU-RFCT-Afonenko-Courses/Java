## Обобщённая растущая очередь

Реализуйте `DynQueue<T>` с методами `void put(T value)` и `T get()`
и порядком FIFO. Хранилище — массив; при исчерпании свободного места
создаётся больший массив с сохранением порядка оставшихся элементов.
Конструктор принимает непустой массив `T[]`; исходная очередь пуста,
после передачи клиент не использует массив напрямую. Фактический тип
компонента массива совпадает с аргументом типа очереди. Для увеличения
можно использовать `Arrays.copyOf`: [Arrays.copyOf для ссылочных компонентов](https://bsu-rfct-afonenko-courses.github.io/Java/handbook/entries/arrays.html#sec-api-arrays-copy-of).

Входные элементы отличны от `null`. При пустой очереди `get` выводит сообщение
и возвращает `null`, сохраняя состояние. Текст сообщения об отказе свободен;
коэффициент увеличения массива выберите самостоятельно. Продемонстрируйте несколько
увеличений вместимости, чередование добавления и извлечения и два типа
элементов. Готовая символьная реализация не требуется.
