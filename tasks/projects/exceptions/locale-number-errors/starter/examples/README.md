# Сценарии проверки

В [valid.txt](valid.txt) находятся две строки. Между полями — табуляция:

```text
1,5	ru-BY
2.5	en-US
```

Сумма равна `4.0`, среднее — `2.0`. Пустой файл даёт сообщение
об отсутствии данных; среднее для него не вычисляется.

Проверьте неверное число, пустое поле, неверный тег локали и слишком большое
число. Если корректна первая строка и ошибочна вторая, собственное исключение
сообщает номер `2` и причину отказа. После ошибки обработка прекращается.
Отсутствующий файл приводит к `IOException` этапа чтения.
