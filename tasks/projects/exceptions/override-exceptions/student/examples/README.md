# Проверка переопределения

[original.java.txt](original.java.txt) содержит заданный метод `A.f()`
и пустой подкласс `B`. Сохраните три версии переопределения независимо
и компилируйте каждую в отдельный каталог:

```bash
javac -encoding UTF-8 -d out <исходники-одной-версии>
```

Каждый вариант должен переопределять `f()` и компилироваться. Формат вывода программы условием не задан; предмет проверки —
допустимость объявления метода. Файлы с одинаковыми `A` и `B` из разных
версий компилируются отдельно.
