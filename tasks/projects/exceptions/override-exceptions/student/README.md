# Переопределение метода и исключения

## Фиксированный комплект сдачи

Изменяйте и сдавайте только следующие исходники из заготовки:

- `cases/narrow/src/main/java/Version.java`
- `cases/none/src/main/java/Version.java`
- `cases/same/src/main/java/Version.java`

Форма PrairieLearn: один ZIP с сохранением путей. В одной сдаче используется только эта форма.
Имена пакетов сохраняются по заготовке: `без объявления package`.
Не добавляйте, не удаляйте и не переименовывайте исходные файлы. Дополнительные
методы и типы внутри перечисленных файлов допустимы; алгоритм и внутреннее
устройство выбирайте в пределах условия, сохраняя обязательный API и учебные приёмы.
Имена файлов ответа соответствуют указанным путям в комплекте.
Тесты, README, Gradle и каталог результатов в состав исходников ответа не входят.

Каждый каталог `cases/<вариант>` — независимая программа. Одноимённые `A`, `B`
и `Version` из разных версий не объединяются в одну компиляцию. Для JDK 25:

```bash
javac --release 25 -encoding UTF-8 -d out/same cases/same/src/main/java/Version.java
javac --release 25 -encoding UTF-8 -d out/narrow cases/narrow/src/main/java/Version.java
javac --release 25 -encoding UTF-8 -d out/none cases/none/src/main/java/Version.java
```

После исправления заготовок каждая версия должна компилироваться отдельно.
Предъявите все версии, результаты компиляции и объяснение согласно условию.
Определённый вывод программы не требуется. Дополнительные типы и вызывающий
код размещайте в соответствующем `Version.java`; новых файлов ответа нет.
