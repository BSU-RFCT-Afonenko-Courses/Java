Исходный ручной профиль и полное условие сохранены. `gradle classes` компилирует подготовленные независимые программы раздельно; одноимённые A/B разных версий не смешиваются. Это техническое воспроизведение, а не автоматическая оценка.

Предъявите исходники, компиляционные опыты и объяснение по прежней рубрике. Обязательного Main, общего API и фиксированного вывода нет. Отрицательные примеры из examples компилируйте отдельно от корректного решения; причина отказа должна соответствовать условию. Прежние признанные результаты/код сохраняются.
