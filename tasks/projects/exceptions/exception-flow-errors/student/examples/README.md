# Сценарии проверки

| Программа | Исходные данные | Наблюдение |
|---|---|---|
| Индекс массива | Длина `10`, присваивание `vals[18] = 10` | Выполняется обработчик выхода за границы |
| Индекс массива | Длина `20`, то же присваивание | В компоненте `18` находится `10` |
| Иерархия исключений | Метод с `throws A` выбрасывает `A` | Выполняется обработчик `A` |
| Иерархия исключений | Тот же метод выбрасывает `B` | Выполняется обработчик `B` |
| Собственный тип | Выполняется `throw new MyClass()` | Проверяемое исключение обработано либо допустимо передано |

Формат сообщений и способ запуска выберите самостоятельно.
Для каждой программы объясните причину исходной ошибки компиляции
и путь выполнения исправленного варианта.
