# Проверка конструкторов

[original.java.txt](original.java.txt) содержит заданные классы `A` и `B`.
Сохраните две исправленные версии независимо и компилируйте исходники
каждой в отдельный каталог:

```bash
javac -encoding UTF-8 -d out <исходники-одной-версии>
```

В каждой версии вызывающий код обрабатывает объявленное проверяемое
исключение. Сопоставьте объявление конструктора `A`, объявление конструктора
`B` и допустимость вызова. Исправленный код должен компилироваться;
исходный вариант компилятор отвергает. Точный текст диагностики зависит от JDK.
