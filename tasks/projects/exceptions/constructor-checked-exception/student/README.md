# Конструктор подкласса и проверяемое исключение

В предоставленном комплекте незавершённые заготовки находятся
в `version1` и `version2`. Команды ниже выполняйте из каталога
соответствующей версии.

Разместите две независимые версии в отдельных каталогах.
В каждом используйте `src/main/java` и собственный каталог результатов `out`.
Имена дополнительных классов и пакеты выберите самостоятельно.

Нужен JDK 25. Для каждой версии откройте терминал в её каталоге с папкой `src`.
Скомпилируйте все Java-исходники под `src/main/java`, включая вложенные пакеты.

В Linux, Bash:

```bash
find src/main/java -type f -name '*.java' -exec javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java {} +
```

В PowerShell 7:

```powershell
$sources = @(Get-ChildItem -LiteralPath 'src/main/java' -Recurse -File -Filter '*.java' |
    ForEach-Object { $_.FullName })
javac --release 25 -encoding UTF-8 -d out -sourcepath src/main/java $sources
```

После изменения исходников повторите компиляцию. Каталог `out` создаётся
при компиляции и в исходный комплект не включается.

Заданные классы находятся в `examples/original.java.txt`.
Предъявите две независимые исправленные версии и их раздельную компиляцию.
Объясните объявления конструкторов и обработку в вызывающем коде.
Запуск можно использовать для собственной демонстрации; определённый
вывод или успешное завершение процесса условием не требуются.

Обязательные приёмы проверяются по исходнику, объяснение — в беседе.
Дополнительный письменный отчёт не требуется.
