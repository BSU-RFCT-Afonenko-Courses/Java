# Конструктор подкласса и проверяемое исключение

В двух независимых версиях программы исследуется объявление конструктора подкласса при
проверяемом исключении конструктора базового класса.

Данные, результаты и обязательные средства Java приведены в [условии
задания](../../../bank/exceptions.qmd#exr-exceptions-constructor-checked-exception).
[Инструкция к стартовому проекту](student/README.md) содержит порядок работы и требования к
предъявлению решения.

## Работа с проектом

Стартовый каталог `student/` содержит исходный учебный фрагмент `examples/original.java.txt`
и инструкции к независимым версиям. Компилируйте исходники с помощью JDK 25. Для каждой
версии используйте собственный каталог исходников и отдельный каталог результатов
компиляции. Исходный текст служит материалом для исправления и разбора.

## Проверка преподавателем

Для выдачи используется только `student/`. Независимые преподавательские версии находятся в
отдельных подкаталогах `reference/`; сценарии компиляции и ожидаемые результаты перечислены
в `tests/compiler-cases.json`. Каталог `tests/api/` содержит проверки заданных объявлений
для разных размещений классов.

Проверьте сохранение заданных классов, независимость версий и вызывающий код с обработкой
объявленного исключения. Условие не задаёт конкретного результата выполнения программы.

Компилируйте каждый контекст отдельно. После компиляции исходников проверяйте опубликованные
объявления для выбранного размещения классов. Допустимые вложенные и закрытые объявления,
для которых внешний клиент недоступен, разбираются в их собственном контексте. Имена
дополнительных методов и классов запуска выбирает автор решения.

Результат проверки здесь определяется допустимостью объявлений и объяснением. Запуск
программы может использоваться для демонстрации; успешное завершение процесса условием не
требуется. Ошибки настройки проверки рассматриваются отдельно от ошибок исходника.
