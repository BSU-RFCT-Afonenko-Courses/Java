## Вхождения слова без учета регистра и вариантов букв

Определить количество вхождений заданного слова в текст, игнорируя регистр
символов и считая буквы «е», «ё» и «и», «й» одинаковыми. Искомое слово
непустое и состоит только из букв. Сравнивайте целые слова по границам из
`sec-bank-text-input` (контекст ниже): для поиска `"елка"` текст
`"Ёлка, елка; елками"` даёт `2`. Приведение регистра и замены букв
выполняются только для сравнения, исходный текст не меняется. Без слов
результат равен нулю. [1]

## Данные и границы текста 

Если карточка не задаёт более узкий алфавит, входные строки состоят из
латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9,
знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные
сочетания Unicode не допускаются. Строки не равны `null`; пустая строка
допустима. Символ и единица длины здесь — один `char`.

Слово — максимальная непустая последовательность букв указанного алфавита.
Цифры и все небуквенные символы разделяют слова. В преобразованиях слов
сохраняйте исходный порядок и все разделители, если карточка не требует
иного. Регистр учитывается, кроме явно оговорённого сравнения без регистра.
В отсутствие слов преобразование слов оставляет текст прежним, поиск слов
по длине выводит сообщение «Слов нет», подсчёт вхождений слова возвращает ноль.



## Локальная работа

Используйте JDK25. Создайте свои .java в src/, компилируйте их в отдельный out: `javac -encoding UTF-8 -d out src/*.java`. Демонстрируйте решение обычным запуском выбранного класса `java -cp out <класс>`. Выбирайте класс запуска самостоятельно; заготовка RunExample (если есть) — заменяемый пример формы Java25, а не дополнительный API. Канал ввода и предметные результаты остаются из условия. Примеры в examples/README.md.
