# Подсчёт слова: примеры

| Текст | Искомое слово | Количество |
|---|---|---|
| `Ёлка, елка; елками` | `елка` | 2 |
| `май МАЙ, маи; маий` | `МАИ` | 3 |
| `x1X_xx` | `X` | 2 |
| `е Ё ёж е` | `ё` | 3 |
| `123!` | `я` | 0 |
| пустая строка | `е` | 0 |

Цифра и подчёркивание разделяют слова, а `xx` является отдельным словом
из двух букв. Исходные буквы и их регистр сохраняются в тексте;
преобразованные значения используются только для сравнения.
