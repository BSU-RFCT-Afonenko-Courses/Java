## Customer: покупатели и номера карточек

Создайте класс `Customer` со свойствами: id, фамилия, имя, отчество, адрес, номер кредитной карточки, номер банковского счёта. Поля класса закрытые. Предусмотрите два конструктора с разными наборами параметров, методы чтения и изменения свойств и `toString()`. Отбор оформите отдельными методами для массива объектов. Строковые критерии сравнивайте целиком с учётом регистра; покажите полученную подборку, включая случай без совпадений.

Создайте массив объектов. Выведите:

- список покупателей в алфавитном порядке;
- список покупателей, у которых номер кредитной карточки находится в заданном интервале.

Используйте вымышленные записи с положительным целым id и непустыми строковыми свойствами. Банковский счёт хранится строкой. Нижняя граница интервала не больше верхней; обе имеют тот же формат, что номер карточки. Проверять неверные исходные данные не требуется. Номера карточек — строки из 16 цифр; сравнение границ включительно и лексикографически, что для одинаковой длины совпадает с числовым порядком. Алфавитный порядок задайте по фамилии, затем имени и отчеству через `String.compareTo` ([String.compareTo и знак порядка](https://bsu-rfct-afonenko-courses.github.io/Java/handbook/entries/strings.html#sec-api-strings-compare-to)). При полном совпадении фамилии, имени и отчества сохраните исходный порядок записей. Сортировка результата не меняет исходный массив.

Массив может быть пустым; он, его элементы и текстовые значения не равны `null`. Отбор сохраняет исходный массив и объекты. Если один объект встречается в массиве несколько раз, каждое подходящее вхождение остаётся в результате. Имена методов отбора, тип возвращаемой подборки и оформление вывода выбирайте самостоятельно: результат должен позволять различить записи и проверить их порядок. Для пустой подборки достаточно явного сообщения об отсутствии совпадений; его текст свободен. [Источник 1]

## Работа с проектом

Разместите исходные Java-файлы в `src/`. Требуемые классы и методы указаны
в условии выше; остальные имена, пакеты, вспомогательные методы и способ
запуска выбирайте самостоятельно. В `examples/scenarios.json` приведены
данные и наблюдения для демонстрации. Формат ввода определяется вашим решением
в пределах условия.

Для компиляции нужен JDK 25. Если исходники находятся непосредственно
в `src/`, а демонстрация — в `src/Main.java` без объявления пакета,
команды имеют вид:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Main
```

Подставьте фактическое имя своего класса запуска. Для вложенных каталогов
перечислите нужные исходные файлы в команде компиляции.
Для класса в пакете команда запуска использует полное имя, например
`java -cp out demo.Main`.

Представьте исходники и демонстрацию обычных и существенных граничных случаев,
описанных в условии. Объясните выбранные типы, порядок действий и результат.
Обязательные приёмы проверяются по коду и в беседе с преподавателем.

Задача доступна как самостоятельный добровольный вариант.
