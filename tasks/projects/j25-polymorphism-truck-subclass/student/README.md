## Расширение класса Vehicle: Truck

Создайте `Vehicle` с закрытыми целочисленными полями `passengers`, `fuelcap`, `mpg`: число пассажиров неотрицательно, запас топлива в галлонах и пробег в милях на галлон положительны. Предусмотрите конструктор, чтение и изменение характеристик с проверкой этих ограничений, `range()` для дальности и `fuelNeeded(int miles)` для расхода топлива типа `double`. Расстояние неотрицательно; произведения помещаются в `int`. Для базовых операций используйте открытые сигнатуры из [Интерфейс IVehicle](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/bank/polymorphism.html#exr-j25-polymorphism-vehicle-interface); дальность равна `fuelcap * mpg`, топливо — отношению `miles` к `mpg` с абсолютной погрешностью не больше `1e-6`. Реализация самого интерфейса `IVehicle` в этой карточке необязательна.

Подкласс `Truck` добавляет закрытое поле `cargocap` — неотрицательную грузоподъёмность в фунтах. Реализуйте конструктор `Truck(int p, int f, int m, int c)`, методы `int getCargo()` и `void putCargo(int c)`. Покажите использование унаследованных операций без открытия базовых полей. [Источник 1]

Неверные параметры конструктора, метода изменения или отрицательное расстояние отклоняются через `IllegalArgumentException`. Метод изменения проверяет значение до записи: после отказа все характеристики прежние.

Покажите обычный `Vehicle(2, 10, 25)`: дальность 250, топливо для 50 миль 2.0; отказ изменения `fuelcap` на `0` сохраняет дальность 250, отрицательное расстояние вызывает исключение. Для `Truck` отдельно покажите отказ отрицательной грузоподъёмности.

## Базовые публичные сигнатуры Vehicle

В связанной карточке дан открытый конструктор `Vehicle(int passengers, int fuelcap, int mpg)` и следующие операции. Реализация `IVehicle` для `Truck` необязательна.

```java
int getPassengers();
void setPassengers(int value);
int getFuelcap();
void setFuelcap(int value);
int getMpg();
void setMpg(int value);
int range();
double fuelNeeded(int miles);
```

## Работа с проектом

Это отдельная добровольная задача. Другие задачи резервной работы перед ней выполнять не требуется.

Разместите Java-файлы в `src/`. Имена вспомогательных классов, методы и пакеты выбирайте самостоятельно в пределах явно заданного API. Нужен JDK 25.

Например, если вы назвали свой класс демонстрации `Demo` и расположили все исходники непосредственно в `src/` без объявления пакета, из корня проекта выполните:

```bash
javac --release 25 -encoding UTF-8 -d out src/*.java
java -cp out Demo
```

При другом имени укажите его в команде запуска. При использовании пакетов перечислите нужные исходники и укажите в команде запуска полное имя класса с пакетом.

Открытые сценарии в `examples/scenarios.json` описывают действия и ожидаемые наблюдения. Способ ввода данных для собственной демонстрации выбирайте самостоятельно.
