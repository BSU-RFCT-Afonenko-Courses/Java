Повторы и модель результата

вход:       [a, b, a]
множество:  {a, b}
частоты:    a → 2, b → 1

Множество сохраняет наличие каждого значения. Карта частот сохраняет число вхождений; список сохраняет также их исходные позиции.

Равенство и порядок

HashSet и HashMap ищут по согласованным equals и hashCode. Равные ключи имеют одинаковые хеши; совпадение хешей допускает разные ключи. TreeSet использует ноль своего сравнения как совпадение элемента.

Поля, участвующие в равенстве и хеше ключа, сохраняют значения во время хранения: Глава 17.

Разберите два отдельно созданных ключа одного кода. Попросите назвать ожидаемые результаты ==, equals и сравнения хешей.

Замена значения и новая пара

В каждом варианте карта сначала получила s1 → 90:

Второй вызов Возвращённое значение size() get("s1")
put("s1", 95) 90 1 95
put("s2", 95) null 2 90

Запись по равному ключу заменяет значение и возвращает прежнее. Запись по новому ключу добавляет пару. В этом опыте null сообщает, что у нового ключа прежде не было значения; пара s1 → 90 сохраняется.

Представление и прежний состав

var source = new ArrayList<>(List.of("Ann"));
var view = Collections.unmodifiableList(source);
var copy = new ArrayList<>(source);
var snapshot = List.copyOf(source);
source.add("Bob");
System.out.println(view);
System.out.println(copy);
System.out.println(snapshot);

Предскажите состав трёх результатов после source.add. На схеме отметьте, какой список читает текущую основу и где сохранён прежний состав.

До выполнения выписать три ожидаемых размера и нарисовать связи source/view, copy и snapshot. Зафиксировать прогноз до открытия следующего экрана.

Состав после изменения источника

После source.add("Bob"):

Результат Состав Размер

copy [Ann] 1

Общие элементы копии списка

Готовый Book хранит название и признак выдачи. Новый объект доступен; borrow() делает borrowed() истинным. Повторный вызов бросает IllegalStateException, сохраняя состояние.

Book book = new Book("Java");
var source = new ArrayList<>(List.of(book));
var snapshot = List.copyOf(source);
book.borrow();
System.out.println(snapshot.get(0) == book);      // true
System.out.println(snapshot.get(0).borrowed());   // true

Снимок состава хранит ссылку на ту же книгу. Операция borrow меняет книгу; число и порядок элементов снимка сохраняются.

Исходник course.examples.objects.Book находится в комплекте опытов; импортировать нужно именно этот класс. Конструктор отвергает null и название, для которого isBlank() возвращает true, через IllegalArgumentException. Попросите показать единственный объект Book и обе ссылки на него. Затем предложите source.add другой книги и отдельно предскажите размер snapshot.

Защита входного состава

var clientList = new ArrayList<>(List.of("Ann"));
var owned = new ArrayList<>(clientList);
clientList.clear();
System.out.println(clientList.size()); // 0
System.out.println(owned.size());      // 1

У владельца независимый состав. Для класса со списком книг этот выбор определяет, сможет ли клиент изменить его состав через первоначальный вход.

Измените опыт на owned = clientList и проследите другой результат. Попросите применить причину к конструктору собственного владельца книг, сохраняя общие ссылки на сами книги.
