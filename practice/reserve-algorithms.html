Число и его представление

Отрицательный остаток

int size = 3;
System.out.println(-1 % size);              // -1
System.out.println(Math.floorMod(-1, size)); // 2

Для положительного size второй результат находится в [0, size). У массива нулевой длины допустимых индексов нет. Деление и остаток

Разместить индексы 0, 1, 2 на кольце. Шаг назад от нуля должен привести к двум; остаток Java от отрицательного делимого даёт другое значение. Для положительного делителя floorMod возвращает подходящий диапазон. Попросить проверить смещение, равное нескольким полным оборотам. Нулевая длина исключает само множество допустимых индексов.

Модуль граничного int

int value = Integer.MIN_VALUE;
System.out.println(Math.abs(value));        // -2147483648
System.out.println(Math.abs((long) value)); // 2147483648

Положительный модуль не помещается в int. Приведение после abs не восстановит ожидаемое положительное число. Этот случай нужен, если алгоритм цифр допускает любой int.

Выписать минимальное и максимальное значения int: отрицательных значений на одно больше. Поэтому модуль минимума требует более широкого типа. Вторая строка расширяет исходное число до вызова abs. Предложить поменять порядок расширения и вычисления модуля и объяснить, какое отрицательное значение при этом сохранится.

Исходные данные и новый результат

Координата до изменения

Для перестройки матрицы назовите отображение исходной позиции в новую. Проверьте его на углах с разными числами, затем на внутреннем элементе.

При удалении сначала фиксируют признаки в исходной структуре. Удаление во время поиска сдвигает оставшиеся координаты. Проектирование обработки массива

На небольшой схеме матрицы отметить верхний левый элемент и предполагаемое новое место после выбранного преобразования. Попросить проверить правило на противоположном углу. Для удаления максимумов обсуждать принадлежность строк и столбцов исходным позициям: сдвиг во время поиска меняет смысл следующих индексов. Предложить студенту самостоятельно вывести формулу поворота.

Замена ссылки на строку

int[][] source = {{5, 7}, {4}};
int[][] copy = source.clone();
copy[0] = new int[]{1};
System.out.println(source[0][0]); // 5

Заменён компонент нового внешнего массива. Если бы изменили copy[0][0] до переназначения строки, запись затронула бы общий объект.

Сопоставить запись copy[0] = ... с записью copy[0][0] = .... Первая меняет компонент нового внешнего массива, вторая — компонент объекта строки. Нарисовать стрелки до и после переназначения. Вывод 5 соответствует прежнему значению первого компонента исходной строки.

Размеры пустой матрицы

int[][] rows = new int[0][3];
System.out.println(rows.length); // 0

Внешний массив не содержит строк. Число столбцов 3 нельзя восстановить из его компонентов. Если после удаления получено 0×3, отчёту требуется отдельно сохранённое число столбцов. Прямоугольная матрица и размеры

Сопоставить с new int[2][0]: две строки существуют, обе имеют длину ноль. Попросить назвать две размерности для 0×3 и 2×0. Затем вернуться к условию удаления: количество сохранившихся строк и столбцов нужно определить независимо. Форму хранения и показа студент выбирает сам.

Числовой фрагмент текста

String token = "a12";
String digits = token.substring(1);
System.out.println(Integer.parseInt(digits)); // 12

Сначала найдены границы числа, затем выполнен разбор. Один знак цифры и многозначное число — разные данные. Для распаковки нужно самостоятельно найти конец числового фрагмента.

Строка digits содержит два знака, но после разбора получается одно число 12. Попросить назвать место, где алгоритм распаковки должен остановить чтение цифр, если за ними идёт следующая буква. Карточка гарантирует корректную сжатую запись.

Объяснение выбранного решения

Данные для проверки

Для поворота одинаковые элементы скрывают направление. Для удаления один максимум не проверяет повторные позиции. Для распаковки однозначные счётчики не проверяют многозначные. Для поиска слова одинаковый регистр скрывает правило сравнения.

Выберите один случай, различающий правильное и правдоподобное неверное решение.

Попросить связать свой вход с конкретной возможной ошибкой. Матрица с различными углами обнаруживает неверное направление; повторный максимум выявляет удаление только одной позиции; число 12 — чтение лишь одной цифры. Студент должен объяснить ожидаемый результат, прежде чем сравнивать его с запуском.

Правило сравнения слов

NFC приводит "ё" и "е\u0308" к одной канонической форме. Буквы "е" и "ё" при этом остаются различными.

У задачи подсчёта задано дополнительное правило: объединить пары «е/ё» и «и/й» и не учитывать регистр. Одинаковый ключ сравнения нужен для искомого слова и для найденного слова текста. Каноническая форма и правило поиска

Предложить сравнить слова «май» и «маи» по условию карточки, затем по обычному String.equals. Результаты различаются из-за выбранного отношения эквивалентности. Границы выделяются у исходных слов; поиск подстроки мог бы посчитать лишнее совпадение внутри более длинного слова.
