Для сборки нужен JDK 25 и установленный Gradle 9.8. Откройте извлечённую папку с `settings.gradle` как Gradle-проект в IDE. Зависимость JUnit объявлена только в `build.gradle`; первое получение зависимости требует сети, последующие сборки доступны с `--offline` после заполнения кеша.

Из корня проекта можно выполнить `gradle classes`, `gradle apiCheck` и, по желанию, `gradle test`. Самопроверка доступна для работы над решением; её запуск и установка Gradle не являются условием зачёта. Незавершённая заготовка компилируется и проходит допуск API, но ожидаемо не проходит предметные тесты.

Для консольного решения: `gradle --console=plain -q run`; передайте данные в стандартный ввод и завершите его. Для собственного демонстрационного класса: `gradle --console=plain -q run -PmainClass=ИмяКласса`. Это удобство локального запуска, а не обязательное имя класса для задач без заданной точки входа.

Сдавайте свой исходный код. Не включайте `.gradle`, `build`, кеши IDE и скачанные зависимости.
