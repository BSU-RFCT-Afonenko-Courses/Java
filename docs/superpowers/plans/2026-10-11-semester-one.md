# Полная программа первого семестра Java

> Исполнение: superpowers:subagent-driven-development. Пользователь поручил выполнить программу по утверждённой методике с внутренним рецензированием; дополнительное согласование начала этапов не требуется.

**Цель:** связный первый семестр: 23 главы теории, 9 лекций, предметный справочник, 127 заданий, 10 основных и 3 резервные лабораторные с практиками, 30 тем рефератов.
**Основа:** утверждённый образец и методика из `3049956`; предыдущая полная итерация `9e5a510` служит источником охвата и условий, а не готовым учебным текстом.
**Архитектура:** первичная тематическая книга и четыре производных проекта. Общая библиография; новые идентификаторы; самостоятельное владение тематическими блоками и последующая общая редактура.
**Средства:** штатные проекты Quarto, QRC, citeproc; Java 25 без preview.
**Спецификация:** [Методические правила](../../authoring-methodology.md) и последнее указание пользователя о полном первом семестре, отменяющее ограничение одним комплектом.

## Общие требования

- Теория — связное самостоятельное объяснение, выбранное из прочитанных книг и проверенных первичных источников. Не склеивать разнородные фрагменты.
- Теория и лекции сочетают предметные заголовки с шагами объяснения. Справочник использует предметные названия; границы определяются всем семестром.
- Rule first + example first; результат и причина видимы студенту. Продолжения группы слайдов без нового видимого заголовка.
- Девять лекций по 40–50 содержательных слайдов на 80 минут. System Practice — отдельное десятое занятие-заглушка.
- 127 канонических заданий предыдущего согласованного банка, 10 основных + 3 резервные лабораторные. Текстовые условия без starter, graders и решений. 30 тем рефератов; защита и нагрузка на студента не считаются готовыми.
- Все библиографические ключи `bib-*`, ссылки `@bib-*`; страницы в записи. По одной странице источников в каждой книге; источники презентации в конце.
- Новая схема целей: теория `sec-t-<тема>`, справочник `sec-h-<предмет>`, лекция `sec-l-<тема>`, практика `sec-p-<работа>`, лабораторная `sec-lab-<работа>`, банк `exr-<смысл>`, реферат `exr-research-<смысл>`. Aliases и прежние IDs не переносить.
- Java 25 без preview; точные правила сверять по JLS/JVMS/API. Если веб-инструмент недоступен, попробовать браузер. Книги читать непосредственно.
- Не менять `_extensions`, инструменты, CI, manifests и платформу. Допустимы штатная конфигурация состава, учебный CSS и источники.
- Только текущий worktree. Рабочие исследования и проверки вне публикуемого курса. Коммиты выполняет координатор по точному списку файлов; исполнители не трогают общий индекс Git.

## Карта материала

| Блок | Главы theory/chapters | Лекции lectures | Лабораторные и practice |
|---|---|---|---|
| Основания | languages, platform, types, expressions, control, methods, arrays, text | 01-platform, 02-values | numbers, control, arrays, text; reserve-algorithms |
| Объекты | objects, classes, inheritance, interfaces, data-classes, type-parameters, type-relations | 03-classes, 04-object-design, 05-generics | objects, polymorphism, generics; reserve-models |
| Обработка данных | equality, collections, functions, streams, exceptions, resources, io, application | 06-collections, 07-functions, 08-exceptions, 09-application | collections, pipelines, files; reserve-data |

Теоретические главы соответствуют порядку утверждённого предметного оглавления. Лекция 9 опирается также на главу text; лекция 6 — на границы обобщённых типов. Лабораторные выбирают задачи по prerequisites, а не по последнему номеру лекции.

## Проверка содержания

Рецензент проверяет связность переходов, полноту объяснения, точность источников и отсутствие неподготовленных понятий. Особые риски: формальный набор 45 пустых слайдов; повторение одного текста во всех проектах; исторические интерпретации как факты; заголовки, скрывающие разнородные темы; служебные блоки длиннее условия. Техническая проверка: примеры, оба профиля, QRC, bib, видимость слайдов в браузере.
