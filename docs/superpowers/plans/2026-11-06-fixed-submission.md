# Явный комплект сдачи Java: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Согласовать условия, исходники и штатные формы сдачи всех 128 задач Java до 18:00 по Минску.

**Architecture:** Форма фиксируется задачей по согласованному авторскому комплекту. Используются существующие editor/upload/ZIP и существующий контракт проверки, без динамического переключателя.

**Tech Stack:** Quarto/Pandoc, TypeScript-экспортер, Java, Gradle/JUnit, штатные компоненты PrairieLearn.

**Spec:** `docs/superpowers/specs/2026-11-06-fixed-submission-design.md` — согласованное в чате решение и прямое поручение приступить.

## Global Constraints

- Срок: 6 ноября, 18:00 Europe/Minsk. Только уточнение поставленного объёма.
- Учебные условия пишет Terra; технические изменения и рецензии — Sol. Не более двух тяжёлых рабочих сессий.
- У одного файла один владелец; отдельные рабочие деревья, каноническую интеграцию ведёт root.
- Сохраняются API, результаты, примеры, веса, UUID, состав лабораторных и доступ к закрытым работам.
- Нет нового формата тестов, UI, сервиса, парсера, хеширования, массового отключения проверок.

## Review Focus

- Условие не требует демонстрацию в третьем файле при двух редакторах.
- Упражнение на пакеты и дерево сохраняет свою учебную цель и ZIP.
- Дополнительные методы и классы внутри разрешённого комплекта не запрещаются без предметной причины.
- Публичные и преподавательские проверки вызывают прежний реальный API; альтернативный алгоритм сохраняется после переноса файлов.
- Ручные задачи, README стартера и сохранённые ответы не остаются со старым обещанием свободного состава.
