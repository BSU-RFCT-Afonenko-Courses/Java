# Java в контексте программирования: редакция материалов

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Пользователь утвердил содержательный план и поручил приступить; повторное согласование начала не требуется.

**Goal:** расширить связное объяснение теории и пересобрать девять лекций вокруг идей программирования, сохранив точную основу Java и связь практик с лабораторными.
**Architecture:** тематическая книга остаётся первоосновой; лекции отбирают её идеи, справочник уточняет средства, практики готовят конкретные лабораторные. Сначала рецензируются примеры нового подхода — типы данных и обработка ошибок; затем подход распространяется на остальные главы.
**Tech Stack:** Quarto, QRC, citeproc, Java 25 без preview; существующие расширения без изменений.
**Spec:** утверждённый в чате план от 11 октября 2026 года и уточнения пользователя о нумерации Quarto и техническом содержании практик; постоянные правила — `docs/authoring-methodology.md`.
