# Перенос курса Java на общий шаблон

Пользователь выбрал перенос структуры и оформления общего шаблона с сохранением
материалов Java. Основа: `quarto-template-course` на коммите
`a5939b4f06e88e80a63eca61ee7ff71ef841f061`.

Курс получает корневую страницу и пять native-проектов: `theory` (основная
книга), `tasks` (исследования и их задания), `lectures` и `practice` (слайды
с маршрутами по существующим материалам), `handbook` (прежние приложения).
По указанию пользователя каталог `test` удаляется из итогового дерева. HTML использует Cosmo,
слайды — стандартную тему Reveal и Navigation из шаблона.

Все исходные материалы, проекты Java, include, ID, списки исследований и
ограничения student/full сохраняются. Межкнижные ссылки меняют namespace в
соответствии с размещением темы. Задания принадлежат `tasks` и сохраняют
исходную авторскую разметку и семантику.
Открытые демонстрации остаются открытыми, контроль и заметки — только в full.
После уточнения пользователя задача ограничена оформлением. Core, Publisher,
QRC, Download и PrairieLearn сохраняются целыми пакетами. Presentation и Navigation
поставляют общее оформление; визуальные изменения вносятся в репозитории
поставщиков и подключаются целыми пакетами. Корневой портал использует
поддерживаемый существующим Publisher обычный native website. Проверка
включает сохранность материалов, inspect всех частей, сборку full и student,
локальные ссылки, каталог, архивы, поиск и изоляцию преподавательских данных.
Оптимизация запуска оставлена пользователем для отдельной сессии.

Уточнение структуры слайдов: лекции и практикумы — самостоятельные презентации
с исходниками `01-intro.qmd`, `02-language.qmd` и подобными. Суффиксы `01a`/`01b`
допустимы для отдельных частей. Их состав и порядок заданы явно в
`project.render`. Каждая презентация имеет собственные слайды и навигацию.
На главной странице размещена общая таблица «План курса» по образцу
https://www.kgeorgiy.info/courses/java-advanced/: девять тем связывают лекции,
практику, теорию, исследования и справочник. Все презентации возвращаются
к этой таблице. На узком экране таблица прокручивается по горизонтали.
Разметка помещается в публичный контейнер `.course-plan`, который обрабатывает
фильтр `course-presentation`. Стили и проверочные инструменты принадлежат общим
расширениям; в курсе остаются разметка и конфигурация. Разовые миграционные
скрипты удаляются из дерева курса. CI выполняет внешнюю проверку авторского
формата и сборку обоих профилей с проверками расширений.
