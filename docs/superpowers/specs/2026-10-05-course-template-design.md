# Перенос курса Java на общий шаблон

Пользователь выбрал перенос структуры и оформления общего шаблона с сохранением
материалов Java. Основа: `quarto-template-course` на коммите
`a5939b4f06e88e80a63eca61ee7ff71ef841f061`.

Курс получает корневую страницу и пять native-проектов: `theory` (основная
книга), `tasks` (исследования и их задания), `lectures` и `practice` (слайды
с маршрутами по существующим материалам), `handbook` (прежние приложения).
По указанию пользователя каталог `test` удаляется из итогового дерева. HTML использует Cosmo,
слайды — стандартную тему Reveal и Navigation из шаблона.

Все исходные материалы, проекты Java, include, ID, списки исследований и
ограничения student/full сохраняются. Межкнижные ссылки меняют namespace в
соответствии с размещением темы. Задания принадлежат `tasks` и сохраняют
исходную авторскую разметку и семантику.
Открытые демонстрации остаются открытыми, контроль и заметки — только в full.
После уточнения пользователя задача ограничена оформлением. Исходные Core,
Presentation, Publisher, QRC, Download и PrairieLearn сохраняются целыми
пакетами. Добавляется только Navigation для слайдов. Корневой портал использует
поддерживаемый существующим Publisher обычный native website. Проверка
включает сохранность материалов, inspect всех частей, сборку full и student,
локальные ссылки, каталог, архивы, поиск и изоляцию преподавательских данных.
Оптимизация запуска оставлена пользователем для отдельной сессии.
