# Пробный комплект по обобщённым типам

Дата: 11 октября 2026 года. Основа: PR7, commit `960af5a`.
Пользователь утвердил предметное оглавление из 23 глав и девять лекций Java,
затем ограничил пробную редакцию одним связанным комплектом.

## Состав и границы

- Один цельный раздел теории «Обобщённые типы», объединяющий содержание глав 14–15.
- Одна полная лекция Л5: 40–50 содержательных слайдов на 80 минут.
- Одна лабораторная с несколькими связанными заданиями, только текстовые условия.
- Одна практика: повторение необходимых тезисов → адресный справочник → ввод в лабораторную.
- Справочные статьи только для этого комплекта.
- Все остальные темы: предметные заголовки и стандартные библиографические ссылки Quarto.
- Общие источники в нескольких файлах bibliography/*.bib; числовые ссылки через CSL.
- Страницы и разделы источника входят в bib-запись; в тексте только [n].
- У каждой книги Quarto отдельная страница «Источники»; у презентации — последний слайд.
- Java 25 без preview; инструменты, расширения, CI, providers, installed-packages, UPSTREAM не изменять.
- Новые смысловые ID без старых aliases и без сохранения совместимости.
- System Practice обозначается ссылочной заглушкой; содержание другого курса не разрабатывается.
- Принятые методические решения собраны в [правилах подготовки материалов](authoring-methodology.md).

## Содержательная основа

Теория первична. История, объяснение моделей, сравнение Java/C++/C# и опыт
использования входят в основной рассказ. Текст не содержит отчёта о его
редактировании, OCR или переносе из книг. Источники обозначаются краткими
цитатами. Предоставленные PDF используются для связных объяснений и примеров;
исторические утверждения сверяются с первичными материалами.

Лекция адаптирует готовый текст, а не определяет его объём. Заголовки теории
и лекций сочетают названия предметов с шагами объяснения; справочник использует
предметные названия. Продолжения группы слайдов могут не иметь нового видимого
заголовка. Границы статей справочника уточняются по темам всего семестра. Причины
результатов видны на слайде. Rule first + example first задаёт развитие мысли,
но не порождает механических заголовков «Правило», «Прогноз», «Обратная связь».

## Рабочие файлы и связи

- theory/generics.qmd — полный раздел, корень sec-theory-generics.
- lectures/generics.qmd — Л5, корень sec-lectures-generics.
- tasks/labs/generics.qmd — единственная лабораторная, sec-lab-generics;
  условия упражнений имеют exr-generics-* и находятся здесь один раз.
- practice/generics.qmd — опора этой работы, sec-practice-generics.
- handbook/type-parameters.qmd, wildcards.qmd, erasure.qmd, comparison.qmd,
  java-tools.qmd — адресные статьи sec-handbook-<имя>.
- bibliography/books.bib, java.bib, languages.bib, history.bib — общий каталог.
- bibliography/numeric.csl — числовой стиль на основе IEEE со стабильной сортировкой.
- docs/generics-sample-status.md — фактическое состояние и проверки, не методические правила.

## Этапы

1. Подготовить изолированную ветку, минимальный состав пяти проектов и библиографию.
2. Прочитать книги и первичные источники; написать связный теоретический раздел.
3. На его основе подготовить лекцию и необходимые справочные статьи.
4. Подготовить лабораторную и краткую практику, связывающую её с теорией и справочником.
5. Проверить примеры, цитаты, связи и отображение; провести независимое содержательное чтение.
6. Сохранить отдельными коммитами и представить отдельный draft PR для пользовательской оценки.

## Проверка результата

Оценивать прежде всего связность, глубину, последовательность предпосылок и
соответствие утверждённым заголовкам. Число файлов и успешный рендер не доказывают
редакционную готовность. Технические проверки: Java25/C++20-примеры, штатный render
student/full без предупреждений, корректные ссылки QRC и citeproc, просмотр
теории/лекции/практики. Не добавлять собственный инструментарий курса или обвязку лабораторной.
