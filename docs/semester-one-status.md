# Состояние редакции первого семестра

Дата: 10 октября 2026 года. Этот документ фиксирует готовность материалов,
редакционную очередь и вопросы нагрузки. Он не является расписанием занятий.

## Принятые границы

- Первый семестр: 11 предметных тем Java 25 без preview.
- Пять проектов: theory, lectures, practice, tasks, handbook; теория первична.
- Канонический банк: 127 задач — 124 коротких и 3 проектных.
- Распределение: 10 основных и 3 резервные лабораторные; резерв доброволен.
- Каталог исследований: 30 тем первого семестра. Второй семестр — отдельная редакция.
- Сети, многопоточность, JDBC и XML не входят в предметный маршрут первого семестра.
- System Practice: отдельная подготовка и 26 исходных карточек; не входит в 127 задач Java.
- Новое решение пользователя: структуру и идентификаторы выстроить заново;
  прежние ID, aliases, постановки и проверки ради совместимости не переносить.
  Полезное содержание прежних материалов — источник авторской редакции.

## Схема тематических страниц

Namespace QRC совпадает с проектом: `theory`, `lectures`, `practice`, `tasks`,
`handbook`. Идентификатор содержит проект, семестр и смысловую тему.
Подраздел добавляет смысловой суффикс к ID страницы. Номер исходной карточки
не является ID нового задания или реферата.

Таблица ниже задаёт **планируемые** адреса, а не опубликованные QRC-цели.
Действующие адреса темы в карте имеют префикс `sec-theory-s1-map-` и тот же slug.

| Тема | Slug | Будущая теория: файл и ID |
|---|---|---|
| Типы данных и операторы | `types-operators` | `theory/semester-one/types-operators.qmd` → `sec-theory-s1-types-operators` |
| Операторы управления | `control-statements` | `theory/semester-one/control-statements.qmd` → `sec-theory-s1-control-statements` |
| Массивы | `arrays` | `theory/semester-one/arrays.qmd` → `sec-theory-s1-arrays` |
| Строки | `strings` | `theory/semester-one/strings.qmd` → `sec-theory-s1-strings` |
| Классы и методы | `classes-methods` | `theory/semester-one/classes-methods.qmd` → `sec-theory-s1-classes-methods` |
| Наследование и интерфейсы | `inheritance-interfaces` | `theory/semester-one/inheritance-interfaces.qmd` → `sec-theory-s1-inheritance-interfaces` |
| Обобщения | `generics` | `theory/semester-one/generics.qmd` → `sec-theory-s1-generics` |

Названия тем и ID не навязывают соответствие одной лекции одной лабораторной.

## Редакционная очередь

| Этап | Следующий результат | Условие готовности |
|---|---|---|
| 1. Карта | Карта, подготовка и схема новых адресов | Предпосылки ясны; все опубликованные QRC разрешаются; student/full проверены |
| 2. Банк и лабораторные | Все 127 задач и 13 текстовых работ | У каждой задачи одно место; резерв и замены не увеличивают обязанность; условия канонические |
| 3. Рефераты | Все 30 согласованных тем с новыми смысловыми ID | Исследовательский вопрос и границы ясны; нет переноса старой постановки ради проверки |
| 4. Основы Java | Введение/JDK, типы, управление, массивы, строки; справочные статьи | Полные объяснения, разобранные примеры, граничные случаи, источники; код проверен Java 25 |
| 5. Объектная модель | Классы, наследование, интерфейсы, generics; справочные статьи | Контракты и предпосылки ясны; содержательные сравнения с C++/Python; источники проверены |
| 6. Обработка данных | Коллекции, функциональные интерфейсы/streams, исключения, ввод-вывод | Последовательные сценарии обработки и отказа; API проверен по Java 25 |
| 7. Лекции и практика | Тематические презентации и опоры для работ | Пояснения видны студенту; справочные демонстрации адресны; новые слайды просмотрены |
| 8. Рецензия | Связный комплект и draft PR | Student/full, QRC и содержание проверены; открытые вопросы нагрузки обозначены |

Первые шесть прежних каталогов рефератов (`numbers`, `text-arrays`,
`object-model`, `generics-collections`, `functional-processing`,
`failures-boundaries`) используются как содержательные исходники,
а не как новая структура. Остальные шесть относятся ко второму семестру.

`lectures/04-development.qmd` содержит подробный материал о выборе методов,
инициализации классов, generics и коллекциях. Его прежнее название
«Разработка» не описывает содержание. Полезные объяснения, примеры и
сравнения перерабатываются в тематические лекции; прежний маршрут и IDs
не сохраняются. На новом портале эта лекция не представлена как инструменты.

Существующие предметные страницы пока остаются в оглавлениях как
промежуточные исходники редакции. При подготовке тематических партий
новые страницы заменяют их в активном учебном маршруте. Сохранение истории
материалов обеспечивается Git, а не ссылками совместимости в новом курсе.

## Нерешённые вопросы нагрузки

- Длительность занятия, календарные сроки и суммарный бюджет первого семестра.
- Наблюдение фактического времени утверждённых 10 основных и 3 резервных работ.
- Доля работы на занятии и дома; время вводного разбора 10–30 минут входит в бюджет занятия.
- Число рефератов на студента, срок подготовки и бюджет защиты.
- Отдельный объём вводного System Practice и возможность восполнить нехватку базовых навыков.
- Уточнение рабочих оценок времени после наблюдения за первой учебной группой.

Прежние 11 × 180 минут и статусы исходных карточек не считаются действующим
бюджетом. Положительные значения `time`, необходимые учебной модели,
сначала имеют статус рабочих оценок. Проектные задачи входят в общий банк,
а не автоматически совпадают с тремя резервными работами.

## Источники и проверка

Основа: согласованные решения пользователя, пакет передачи от 10 октября
2026 года, `COURSE-STRUCTURE.md`, A-05–A-13, программы Java и System Practice.
Последнее решение о новых структурах и ID отменяет положения пакета
о переносе идентификаторов и обратной совместимости.

Учебники EPAM и Герберта Шилдта используются адресно, с авторством и пометкой
адаптации. Аудит исходников выявил ошибки в материале EPAM: учебные
формулировки и код требуют независимой сверки с Java 25. Справочник
проверяется по официальной документации Java 25/API/JDK; авторские
объяснения отделяются от цитат. Веб-источник не заменяет полноценное изложение.

Task 1 не содержит новых Java-примеров или слайдов. Доказательства статической
проверки и общей сборки фиксируются в рабочем отчёте задачи; успешная
статическая проверка не означает успешную сборку student/full.

## Что опубликовано в Task 2

Канонический банк `tasks/bank/semester-one/`: 11 предметных страниц и
страница предметных проектов, 127 смысловых `exr-tasks-s1-*` без aliases.
Источники — `sources.qmd`; каждая карточка сохраняет атрибуцию и страницы.
В `tasks/labs/semester-one/` опубликованы 10 основных и 3 резервные работы.
Индекс — `tasks/index.qmd`, адрес `tasks:sec-tasks-s1-root`.

Распределение утверждено: 46 базовых + 12 альтернатив + 69 резервных задач.
Основной маршрут — 1845 минут задач и ориентир 200 минут разборов.
Текстовый контракт чтения локализованных чисел повысил одну резервную оценку
90 → 110 минут; полный резервный пул 4095 минут. Штатные optional-назначения
парных кандидатов не выражают выбор одного из двух: правило выбора и бюджет
задаются текстами работ, без автоматического назначения или проверки.

Прежняя лабораторная, Unicode-демонстрация и Java25-пилот вместе с их
проектными комплектами и пилотной delivery-конфигурацией удалены. Старые
каталоги рефератов и их контрольные работы остаются промежуточными до Task 3;
это не новая организация исследований. Tools, extensions и CI не изменены.

У задач, зависящих от старых классов, минимальный контекст задан текстом.
Корпуса стихотворений отсутствовали в handoff: студент выбирает краткий текст
названного автора и фиксирует источник. Отдельные сборочные заготовки не созданы.
Task 2 не содержит готовых Java-примеров или слайдов. Статические проверки
не заменяют общую сборку student/full; её результаты фиксируются в отчёте.
