# Работа над курсом Java

Это вход в авторскую и техническую документацию репозитория. Курс объясняет
Java студентам с опытом C++; Java 25 выбрана как среда проверки.

Пилот `62b7c8a` принят пользователем. Его редактура по отзыву от 15 октября
2026 года охватила пять форм: теорию, цельную лекцию, справочник, введение
к лабораторной и самостоятельные задания. Исходники прошли независимое
содержательное чтение, новые примеры — проверку, оба профиля сайта — полную
сборку. Лекция, введение и страницы приняты в пределах визуальной выборки.
[Документ пилота](java-course-pilot.md) сохраняет историю завершённого этапа,
локальные адреса, результаты проверок и их пределы. Принятые решения, история редакторских исправлений и пределы переноса
собраны в [контексте передачи](handoff/2026-10-15/CONTEXT.md).

Действующие устойчивые правила изложены в
[методике подготовки курса](authoring-methodology.md); масштаб и этапы —
в [плане полной переработки](handoff/2026-10-15/PLAN.md).
Пользователь принял подход с опорой на C++, инженерные задачи, причины
решений Java, самостоятельную книжно-справочную линию теории и композицию
девяти лекций. Текущее уточнение сохраняет содержательную полноту опоры
при упрощении объяснения: в основной рассказ первой лекции входят причины
устройства JVM, принципы исполнения и базовый разбор производительности.
Уточнение закреплено. Полная редактура начата в отдельной рабочей ветке
`codex/java-course-full-revision-20261015` от актуального продолжения пилота.
Первый этап — выполнение, значения и ссылки; его текущий объём и границы
проверок описывает [журнал редакции](full-revision-progress.md).
[Стартовый промпт и порядок входа](handoff/2026-10-15/START.md) сохраняют
принятое задание. Пилот остаётся содержательным основанием; новые части
получают собственные рецензии и технические проверки.
[Аудит PR](handoff/2026-10-15/PR-AUDIT.md) определяет пригодные технические
источники и пределы их прежних проверок.

Текущие прямые указания пользователя имеют приоритет над прежними планами
и примерами. История Git нужна для сравнения содержания; она не задаёт
действующее задание. Пользовательские рабочие деревья и открытые PR
сохраняются.

двух целых лекций и непосредственно связанных частей теории. Отправная точка —
`18c8f487869caf9f67fc81e0164164081b11ffbc`; принятый пилот обобщений и остальные
учебные формы сохранены. Первым содержательным изменением этого этапа стала
методика: видимая причинная связь, последовательность состояния, функция схем
и две роли лекционного текста.

- [Аннотированные образцы](authoring-examples.md) показывают применение
  методики к пилоту и передаче ссылочного значения.
- [Карта фактического чтения](lectures-1-2-reading.md) связывает прочитанные
  страницы книг и первичные документы с учебными решениями.
- [Отчёт редакции](lectures-1-2-editorial-revision.md) фиксирует изменения,
  изменения, свидетельства и границы проверенного состояния.

Редакция, проверки примеров, независимое содержательное чтение и настольный
визуальный просмотр завершены. Все замечания закрыты. Первый полный цикл
профилей завершился с кодом `0`; после визуальных исправлений сформированы
оба окончательных сайта, их отдельные проверки ссылок и хешей успешны.

этому вызову не приписывается; подробности сохранены в отчёте редакции.

Унаследованное уменьшение текста лекций на ширине 390 px остаётся
ограничением; полного мобильного PASS нет. Выборочная теория читается,
широкие блоки доступны фактически проверенной горизонтальной прокруткой.

Авторские исходники, локальные сайты и свидетельства сохранены в
[постоянном результате](/home/tolya/JavaBooks/java-lectures-1-2-editorial-result-2026-10-15/README.md).

не заменяют содержательную и техническую проверку новой редакции.
