# Работа над курсом Java

Это вход в авторскую и техническую документацию репозитория. Курс посвящён
Java в контексте программирования и IT; Java 25 выбрана как среда проверки.

Пилот отредактирован по пользовательскому отзыву от 15 октября 2026 года:
исходники прошли независимое содержательное чтение, новые примеры —
проверку, оба профиля сайта — полную сборку. Лекция, введение и страницы
приняты в пределах новой визуальной выборки. Пилот готов к локальному показу.
Основание работы — весь
[редакторский пакет](/home/tolya/JavaBooks/java-course-pilot-editorial-handoff-2026-10-15/START.md):
[принципы и методы](/home/tolya/JavaBooks/java-course-pilot-editorial-handoff-2026-10-15/editorial-principles.md)
и [адресные замечания](/home/tolya/JavaBooks/java-course-pilot-editorial-handoff-2026-10-15/revision-targets.md).
Действующие правила изложены в [методике подготовки курса](authoring-methodology.md)
и [документе пилота по обобщениям](java-course-pilot.md). Методика
определяет качество и назначение пяти учебных форм. Документ пилота фиксирует
границы текущей работы, результаты рецензий и технических проверок.

Методика уточнена до цельного анализа, независимой диагностики и редактуры
пяти форм. Текущий результат подтверждается новыми свидетельствами,
перечисленными в [документе пилота](java-course-pilot.md), вместе с
локальными адресами и пределами проверки. Работа охватывает одну тему
в пяти формах: теорию, цельную лекцию, справочник, введение к лабораторной
и самостоятельные задания. После локального показа работа останавливается
до рецензии пользователя. Общие
решения методики о курсе не означают разрешения сразу переписать все темы.

Текущие прямые указания пользователя имеют приоритет над прежними планами
и примерами. История Git нужна для сравнения содержания; она не задаёт
действующее задание. Пользовательские рабочие деревья и открытые PR
сохраняются.

## Инструкции по назначению

- [Использование источников](sources.md) — доступ к конкретным материалам
  и границы подтверждённых по ним утверждений.
- [Первые три лабораторные в PrairieLearn](prairielearn-labs.md) — поставка
  стартовых проектов, публичные и закрытые проверки, экспорт.
- [Источники установленных расширений](../UPSTREAM.md) — закреплённые
  версии и штатное обновление пакетов.
- [Состав инструментов](../CI/toolchain.json) и
  [сценарий сборки](../CI/render.sh) — техническая основа репозитория.
- [Устройство банка заданий](../tasks/README.md) — канонические условия,
  подборки лабораторных и проекты.

Инструкции инструментов описывают их действующее поведение. Они не выбирают
композицию учебного рассказа и не подтверждают педагогическое качество.
Результат сборки относится к конкретному проверенному состоянию.

Новые README, документацию и описания PR пишите по-русски по
[общему языковому правилу](https://github.com/Afonenko-Course-Tools/quarto-course/blob/main/docs/russian-language-policy.md).
Команды, идентификаторы API, пути, имена пакетов и URL сохраняйте буквально.
