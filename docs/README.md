Разрешены только `gpt-6.1-sol` и `gpt-6.1-terra` с явно назначенным усилием
по матрице и [решению 83](refactoring-plan.md#decision-83).
Standard обязателен; глобальную конфигурацию моделей не меняют.
Автор и независимый рецензент различаются; один владелец отвечает за файл
и публичный договор в каждой фазе.

Выпуск включает Pages, PrairieLearn, IDE-комплекты и действующую
Moodle/Gateway-связь в принятом объёме; Print/Cloud исключены.
Оба SP-маршрута — upload и native Workspace — сохраняются по задачам.
Признанный полный зачёт, успешный код и нужная выдача при однозначном
соответствии сохраняются; редкие split/merge ограничены принятым исключением.
По [решению 79](refactoring-plan.md#decision-79) тестовых студентов нет,
для SP переход из Moodle не требуется. Пользовательские деревья,
незакоммиченные изменения, PR и студенческие данные сохраняются.
В текущую ночь недоступный сервер, Moodle, сертификаты, аккаунты и ключи
не изменяются; статусы source, render, export, runtime и сервера различаются.
