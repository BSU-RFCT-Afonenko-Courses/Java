# Сверка выпуска Java и System Practice с планом вторника

Исходные требования взяты из [программы 3 ноября](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/dd5b76a0168133f0760ece6cb21f4bdf4f6203bb/docs/research/improvement-research-agenda-20261103.md) и [первого плана реализации](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/d3cd5e1accf25b81ef9d7fe6bdecff5cefcdb670/docs/release-cycle-20261110.md). Поздние прямые решения имеют приоритет. Эта сверка не возобновляет исторические сроки или очереди.

| Исходное направление | Что принято | Что остаётся |
| --- | --- | --- |
| Состав Java, лабораторные, баллы и UUID | Фактическая выдача всех 128 задач через десять лабораторных; обязательные слоты и веса сохранены, 87 дополнительных задач добровольные | Реальная добровольная сдача с нулевыми компонентами и повторное открытие |
| Названия и форма ответа | Русские названия, режим по допустимому составу ответа; 126 файловых/ZIP маршрутов и два обязательных ZIP | Настоящий Circle upload с разрешёнными помощниками; synthetic редакторы проверяются отдельно |
| JUnit, оценивание и feedback | Приняты исправления конкретных случаев, доставка публичного контекста, LF/diff, различение студентского отказа и инфраструктурного отсутствия оценки | Финальный UI и адресные остатки оформления тестов всего корпуса. Два известных примера: техническое имя leaf в таблице истинности; числовой boolean assertion среднего без структурированного expected/actual/delta. Это не отменяет принятую выдачу и не разрешает менять знаменатель или раскрывать закрытые данные |
| Самостоятельные комплекты и ссылки | Все Java ZIP/README и публичные байты проверены; реальные выбранные Gradle-комплекты и Circle с помощниками исполнялись. SP student теперь даёт 14 архивов | Общая готовность IDE-комплектов и живых маршрутов не выводится из нескольких примеров |
| YAML, наследование и пути | Компактный course-project loader, однократное чтение YAML за операцию, обычные project-relative пути и явный `base: config`; SP установлен на согласованный набор | Сохранять этот договор при дальнейшей интеграции; не возвращать старый resolver или совместимость собственных протоколов |
| Архитектура, типы и собственные доказательства свежести | Независимо приняты замкнутые пакеты Core/PL/Download/Platform/Gateway/Performance; CI PL/Download/SP зелёный | Отдельные технические приёмки не означают максимальную типизацию всей программы или завершённость всех оптимизаций |
| Native Quarto, исполняемые ячейки, cache/freeze | Прежний ограниченный опыт R и повторного кешированного исполнения сохраняется | Межпрофильная приватность, project freeze, обновление внешних данных и другие движки не квалифицированы всей программой. Собственная гарантия свежести не вводится |
| Стоимость цепочки и производительность | Удалены принятые лишние проверки; текущий ограниченный summary/TERM/recovery завершён | Измерения внутренних новых фаз Core, стоимость полного пути и сопоставимое подтверждение ускорения курса. Успешные 19:44 полного экспорта не являются сравнительным замером |
| Все семь задач SP и оба транспорта | Миграция путей и новая штатная student-сборка всего SP приняты | Реальные Git-history upload и Workspace save → close → resume → resubmit; контейнерный stop/start не заменяет эту цепочку |
| Принадлежность SP учреждению | Требование сохранено в общем выпускном списке | Фактическое соответствие БГУ не установлено текущим пакетом; действующая база и VM в этом окне не изменяются |
| Java Moodle/Gateway, данные и восстановление | Существующая схема входа и UUID сохраняются. SP не требует Moodle-входа. Перенос старых баллов второстепенен; история и файлы сохраняются | Реальная проверка существующего входа, принадлежности записей, восстановления и итогового переключения — отдельный разрешённый этап. Окончательное упрощение Gateway ещё не принято |
| Выпуск Pages/PL/IDE | Полная Java выдача, согласованные источники, новые CI и student SP приняты в своих областях | Финальная интеграция, оставшиеся UI-маршруты и общий просмотр перед публикацией. Техническая готовность отдельных пакетов не равна завершённому выпуску |
| Редактура, новая методика, лекция 9, Print/Cloud | Сохранены явно принятые ограничения | Исключены из текущего пакета прямыми решениями; не считаются выполненными или забытыми |

Новые результаты окна и ссылки на текущие проверки приведены в [отчёте](REPORT.md). Для дальнейших запусков требуется конкретная дельта, отказ или ещё не проверенное свойство; новая полная матрица ради зелёного статуса не требуется.
