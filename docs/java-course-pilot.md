# Пилот курса Java: обобщения

Документ фиксирует объём пилота, принятые результаты и фактические границы
проверки. Устойчивые правила находятся в [методике](authoring-methodology.md),
общий вход — в [рабочей документации](README.md).

На 15 октября 2026 года подготовлены и содержательно приняты все пять
учебных форм. Исправлены общие входные страницы; отдельно принято узкое
исправление Core, необходимое для заданий без оценки времени.
Штатная сборка student → full → student прошла. После правки подписей
ссылок подтверждены оба профиля, локальные ссылки и публичный архив.
Независимые визуальные проверки приняты в описанном ниже объёме.
После уточнения одной фразы на странице лабораторной последняя сборка
`full` → `student` завершилась непрерывно с кодом 0. Канонические условия
приняты после адресного просмотра основного пути по ссылкам; переход
проверен и в окончательной сборке. Пилот готов к локальному показу.

## Объём и рабочая ветка

Работа ограничена обобщённым программированием: связная теория,
одна цельная лекция, адресный справочник, одно введение к лабораторной
и самостоятельные задания. Другие темы сохраняют доступность;
их переработка и содержательная рецензия в пилот не входят.

Положительные и намеренно ошибочные программы проверены раздельно.
Подтверждены связь типов и сохранение результата, вывод для `Person`/`Student`,

Отказы изменяющих операций `List.of` проверены в случаях, где операция
действительно вызывается.

Фактический `javap -p -c -v` подтверждает клиентское `checkcast`
после чтения через стёртый результат. Мостовой getter имеет признаки
`ACC_BRIDGE` и `ACC_SYNTHETIC` и делегирует getter с результатом `String`.

в `.superpowers/sdd/pilot-plan/checks/`; публичные копии примеров
после подготовки справочника проверены повторно.

Для публичного проекта C# проверена точная команда
`dotnet run --project Dot.csproj` из его каталога. `global.json` выбирает
SDK 10.0.x, проект использует `net10.0` и `LangVersion` 11;
локальные настройки исключают загрузку внешних пакетов. Получены 11,
комплексное значение с частями 11 и 1. Ранняя попытка обычного restore

в чистой копии. На .NET 7 пример не запускался: выбор синтаксиса C# 11

## Необязательная оценка времени в Core

Штатный HTML-рендер банка обнаружил реальное препятствие:
`CORE.METADATA_INVALID`, поле `time`, объект `exr-range-maximum`.
Установленный Core требовал оценку времени даже при её отсутствии
в согласованных условиях. Подстановка фиктивного числа не использована.

Узкая адаптация меняет пять файлов реализации Core. `time` можно опустить,
собственная `difficulty` остаётся обязательной. Заданное время по-прежнему
должно быть положительным конечным целым. При отсутствии оценки любого
кандидата сводка времени работы не выводится; полностью оценённые работы
сохраняют прежний расчёт. Исходники Presentation и Navigation не изменены.

Сохранены [поправка и инструкция восстановления](../tools/provider-patches/core-optional-time/README.md),
[манифест](../tools/provider-patches/core-optional-time/manifest.json)
и `rebuild.py`. Точная база —
`9db360beec417b3798693026768262be2f7d3b18`, локальный commit —
`3d6015880b7327b11b6abc10af913d71c1b01236`, дерево исходного репозитория —
`1bd2b3d51044c5582caf90f3ed03eaae7a541541`.
Восстановление в новом каталоге подтвердило хеш поправки, commit и tree.
Режим `--install` выполнил существующий `tools/sync-providers.py`;
установленные расширения вручную не редактировались. Фактическое
содержимое областей установки сверено с восстановленным исходником
и `installed-packages.json`. Пользовательский checkout провайдера сохранён.
Это локальная адаптация; новый выпуск не публиковался.

Из восстановленного репозитория выполнен отдельный регрессионный тест:

## Полная сборка и окончательная проверка

Штатный маршрут из корня курса:

```sh
export JAVA_HOME=/usr/lib/jvm/java-25-openjdk
export PATH="$JAVA_HOME/bin:$PATH"
export CUE=/home/tolya/course-tools/local-tools/cue/cue
export XDG_CACHE_HOME=/tmp/java-pilot-quarto-cache
export XDG_DATA_HOME=/tmp/java-pilot-quarto-data
export CI_LOG_DIR=/tmp/java-pilot-render
bash CI/render.sh
```

Сценарий выполняет student → full → student, каждый проход —
