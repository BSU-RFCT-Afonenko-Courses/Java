# Java в контексте программирования: редакция первого семестра

Работа выполнена в отдельном worktree ветки `content/semester-one-revision-20261011`, поверх `71720c9`. Результат публикуется в существующем [PR #12](https://github.com/BSU-RFCT-Afonenko-Courses/Java/pull/12) на основе PR7. PR остаётся черновиком для редакторского чтения.

## Содержание и связи

Теоретическая книга сохраняет 23 тематические главы и точные основы Java 25. Новое объяснение связывает правила языка с задачами, ограничениями и эволюцией идей: представлением значений, абстракцией, совместным использованием объектов, контрактами типов, обработкой данных, отказами и временем жизни ресурсов. Сравнения с другими языками используют одну задачу и возвращают читателя к последствиям конкретного решения Java.

Из книги собираются девять лекций по 80 минут. Число слайдов определяется объяснением; 50 экранов не служат потолком или обязательной нормой. Причины и результаты примеров видны на слайдах, а заметки задают сценарий рассказа. Заголовки предметные и описательные; продолжения смысловых групп могут обходиться без видимого повторного заголовка.

Справочник содержит 25 предметных статей. В 13 практиках по 30 минут показаны технические приёмы, необходимые для конкретной лабораторной; более подробные правила доступны по адресным ссылкам. Банк сохраняет 127 условий, десять основных и три резервные лабораторные, 30 исследовательских тем. Алгоритмы обязательных заданий не раскрываются готовыми решениями.

На главной странице курса и заглавной странице книги размещена одна общая таблица «Тема · Теория · Лекции · Практика · Лабораторные». Её единый источник связывает все главы, девять лекций, десять основных и три резервных маршрута.

Порядок задаётся оглавлениями Quarto. Порядковые номера глав и слайдов формируются штатно; ручные «Л1», «П1» и ссылки на «пятую лекцию» удаляются из опубликованного материала. Связи между проектами используют содержательные QRC-цели. Новых совместимых aliases нет.

## Источники

Основные объяснения опираются на непосредственно прочитанные фрагменты Шилдта, Блинова/Романчика и Эккеля; действующие правила сверяются с JLS/JVMS и документацией Java 25. Первичные материалы об истории и других языках дополняют книжную основу. Выбор источника не обсуждается в студенческом изложении: читатель получает последовательное объяснение и числовую ссылку.

Литературные ключи имеют префикс `bib-`. Новые записи распределены по трём тематическим файлам `context-foundations.bib`, `context-objects.bib`, `context-data.bib`. Страницы и разделы находятся в записи; точные локаторы размещены в отображаемых полях, поскольку используемый стиль не печатает `note`. У каждой книги одна общая страница источников; у презентации — заключительный раздел литературы.

Если веб-инструмент не открывал оригинал, использовался браузер. Авторский PDF статьи о GJ удалось дополнительно получить прямой загрузкой: все 18 страниц доступны как изображения, нужные разделы проверены после отрисовки. Доступность файла не выдаётся за прочтение всей статьи. Неполученная книга Van Roy/Haridi и ограничения доступа к дословной расшифровке выступления Хоара перечислены в [отдельном списке](sources-to-obtain.md).

## Внутреннее рецензирование

Сначала отдельно проверены два комплекта: типы и значения; ошибки и ресурсы. Оба прошли независимую содержательную рецензию и адресную повторную проверку исправлений. Уточнены книжный локатор, границы сравнения CLR/Python, ручное закрытие двух ресурсов и потеря возвращаемого результата при ошибке закрытия. Затем подход распространён на остальные темы.

Блок оснований языка принят после исправления одной служебной фразы о книжном изложении; повторная рецензия прошла. Блок данных принят после добавления обещанной справки о групповых операциях множеств и исправления адресных переходов. В объектном блоке уточнены инвариант состояния, предусловие бронирования и ссылка на пример переноса элементов. Все три тематические рецензии и повторные проверки исправлений пройдены; итоговая связность и публикация проходят общую проверку.

## Проверки публикации

Новые примеры проверены настоящей Java 25.0.4.1 с `--release 25`, без preview; системная Java 27 не использовалась как замена.

- Основания: числовые преобразования, копии и отсутствие, 11 ожидаемых отказов компиляции; точные фрагменты практик, позднее переполнение без изменения входного массива, classpath и опыт с прежним клиентом после изменения библиотеки.
- Объекты: идентичность и общие ссылки, инварианты, защитная копия, композиция и частичная отправка, восемь ожидаемых отказов компиляции, raw/unchecked, `ClassCastException` и мостовой метод. Сумма произведений проверена также на C++20 и C# с SDK 10; это не проверка на установленной .NET 7.
- Ошибки и данные: 41 исходная и 33 дополнительные проверки путей исключений и ресурсов; 42 проверки коллекций/функций/потоков, 13 запусков приложения, 10 граничных сценариев, три ожидаемых отказа компиляции. Для сопоставимых моделей выполнены примеры Rust, Go и Python.

Полные сборки `student`/`full`, окончательный аудит опубликованных переходов и визуальная проверка находятся в работе. Эти проверки не объявляются успешными по результатам предыдущей редакции.

## Границы

Целевая среда — Java 25 без preview. Сравнения языков не подразумевают одинакового поведения всех их реализаций; исторические версии не подменяют современную спецификацию. Оценка 80/30 минут остаётся педагогическим сценарием, который нужно уточнять по темпу группы.

Лабораторные остаются текстовыми условиями без стартовых проектов, автопроверки и решений. Темы оболочек, Git и общего файлового практикума остаются заглушками System Practice. Инструменты, расширения и CI не меняются. Отдельный пакет защиты исследовательских тем и окончательная нагрузка на студента в эту редакцию не входят. Worktree сохраняется для дальнейшего чтения и правок.
