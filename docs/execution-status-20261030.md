## Прямое уточнение пользователя 30 октября

Тестовых студентов нет. Пользователь сообщил, что проблем со входом
основных студентов не было. Для System Practice ссылки из Moodle не будет.
Это [решение 79](refactoring-plan.md#decision-79), которое имеет приоритет
над прежними соответствующими проверками handoff и регламента.

- Java сохраняет действующую связь Moodle → Gateway → PrairieLearn.
  Проверяются доступные существующие записи входов, устойчивость UID
  и соответствие результатов без новых попыток от имени основных студентов.
- Для System Practice проверяется отдельный маршрут Pages/PrairieLearn
  без обязательного перехода из Moodle. Реальная Moodle-регистрация SP
  и два отсутствующих тестовых аккаунта не являются условиями выпуска.
- Сохранность результатов, кода и файлов, резервирование, восстановление
  и изоляция пользователей остаются обязательными. Проверки на изолированной
  восстановленной копии и наблюдения живого портала фиксируются раздельно.

Сообщение об отсутствии прежних проблем со входом не подтверждает
новые операции или сохранность при будущем переключении. Новые правила
аутентификации и новый сервис этим уточнением не вводятся.

## Текущие основания и границы

Подготовлены изолированные исходники Java, System Practice и общих владельцев.
Точные установленные версии и расходящиеся поведенческие линии разделены;
более высокий номер версии не означает переноса всех исправлений.
Quarto 1.11.5 использует постоянный доступный кеш через `XDG_CACHE_HOME`.

Статический инвентарь Java содержит 128 задач и 97 активных выдач;
System Practice — семь задач. Он определяет состав дальнейшей работы,
а не подтверждает сквозное исполнение или выпуск. Ранние четыре случая
сохраняют назначение внутреннего контроля, затем проверяется весь
активный состав. Print и Cloud исключены.

Архитектурный дизайн, предметные договоры ранних случаев и подготовка
резервирования выполняются отдельными владельцами. Независимая приёмка,
полные проверки, перенос и публикация ещё впереди. Подробные оперативные
свидетельства остаются в закрытой рабочей области исполнительной сессии;
учётные данные и студентские данные в репозиторий не включаются.
