- Это не завершённое удаление course SHA. Старые course delivery/provenance/bridge/Gateway readers ещё существуют. Hashless producer с ними несовместим; новый bypass или реестр взамен прежнего не введён.
- Gateway product не менялся. Подготовлено небольшое [предложение границы](runtime-gateway-boundary-20261104.md): Moodle identity/launch/score exchange, Native владеет курсами/попытками/файлами. Design имеет сохранённый independent APPROVE_DESIGN; новый auth/cutover/DB не выбирались и не реализовывались.
