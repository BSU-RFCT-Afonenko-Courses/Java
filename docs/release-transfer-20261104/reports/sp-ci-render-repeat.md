# Прямой повтор полного render в CI SP

В .github/workflows/ci.yml один job последовательно выполнял student, full, student на неизменном commit. После третьего render нет ни upload artifact, ни publish, ни проверки смены public/private состояния; workspace job уничтожается. Поэтому последний render не создаёт потребляемого результата или отдельного утверждения о поведении. Удалены только его две строки. Первые полноценные student/full сборки и все существующие договоры/production pins сохранены. Workflow запускается при pull_request либо push main; сохранение feature branch не запускает эти сборки.

Это устранение одного прямого лишнего whole-course child, не измерение доли времени и не изменение production publication. Новый render/build/test ради подтверждения удаления YAML step не запускался; diff check пройден. Смена профилей, выходные файлы и сохранность реальной публикации относятся к своему штатному release stage; удалённый CI child ничего из этого отдельно не проверял. Независимое чтение diff следует отдельно.
