Read-only сверка; единственное изменение — этот отчёт. Это предложение состава работ, не запуск, расписание или повтор R0–R6. **Основной недоучтённый результат — понятная обратная связь студенту по всему активному набору.** Удаление private/counter/SHA tests из CI и успешная типизация public API не заменяют переделку учебных JUnit cases и доставки failure. Нужны русское предметное имя, вход, expected/actual, допуск/место различия, честное различение failure/not-run/unknown и читаемый файловый diff. Circle/transpose — первые случаи, а не весь корпус; ordinary XML candidate ещё не принят целиком. Нельзя механически сохранить прежнее число leaf: действующее решение65 задаёт самостоятельный случай; изменение знаменателя/весов требует предметного решения.

Ещё три возможные потери фокуса: **самостоятельные комплекты и ссылки** вместе с редактором; **оба маршрута SP и Workspace lifecycle**, а не только Java export; **фазы полного пути**, а не итог маленького Performance summary. Native cache/freeze межпрофильная приватность остаётся открытой. Ошибку SP institution надо сохранить в выпускном списке как отдельный незакрытый вопрос, но не превращать ночь в DB-поиск.
