Установленная причина E06: `_extensions/course-prairielearn/application/native-check-inventory.ts:43` внутри nativeRawSourceSelection строит Map и повторяет safePath/duplicate checks **всех** sourceRows для каждого выбранного source/test/reference/fixture. В native-course.ts уже есть локальные maps по тому же witness; адресно посмотри пригодный lifetime.

Результат одного ограниченного diff: lookup источников готовится один раз для существующей неизменной партии/проекции и переиспользуется отдельными origin selections. Сохраняются отказы duplicate/unsafe same-S rows, missing/foreign/changed bytes, shared-origin v1/v2 и правильный submission path. Не переносить полный Map walk внутрь другого per-file helper, не создавать global cache/registry/proof/новый resolver или менять authority Core. Публичный standalone nativeRawSourceSelection при необходимости сохраняет прежний массивный input; production использует существующую адресную подготовку/closure. Конкретный минимальный внутренний интерфейс выбери по callers. Обещание «один index на весь курс» не нужно, если жизненный цикл сейчас per-project: честно назови фактическую границу.
