## Как различать статусы

- **Подтверждено источниками или малым опытом** — описывает нынешнее поведение в указанной области, не одобрение предлагаемой замены.
- **Предложено агентом** — варианты и рекомендации этого исследования. Они не приняты автоматически после подготовки, показа или просмотра.
- **Согласовано пользователем** — только прямое решение человека. Действующие решения сохраняет план; здесь их список не дублируется.

Независимая рецензия проверяет качество исследования, но не заменяет пользовательского согласия. Продуктовый рефакторинг, настройка сервера, массовая редактура курса и новый выпуск этим исследованием не выполняются.

## Несколько результатов которые меняют обсуждение

**Просто прочитать README кодового проекта как часть книги недостаточно.** В закреплённом Quarto книжный список глав перекрывает обычный список входов. Малый опыт показал поддерживаемую основу отдельного технического контекста; готовый адаптер Java ещё не реализован.

**Полное условие нельзя надёжно получить простым преобразованием исходного QMD.** Проверка writer сохранила ссылку, потеряв её явно заданный якорь; include не раскрылся, изображение не скопировалось. Поэтому сравниваются способы повторного использования уже разрешённого публичного условия и его ресурсов.

**Обычный JUnit уже умеет выдавать полезную диагностику.** В нашей цепочке часть сообщений теряется позже. Это даёт более узкий кандидат изменения, чем новый формат тестов или обязательный запуск всей сборки в PL.

**Для переименования не обязательно создавать все вопросы заново.** PL умеет сохранить объект по UUID в прежнем контексте. Но нынешний экспортёр выводит UUID из читаемого ID; слоты, работа, выдача назначения и внешние ссылки требуют согласованного перехода.

**Число 100 ещё не доказывает правильный перенос.** Штатный импорт отдельно влияет на компоненты оценки, статус и журнал; код прикрепляется другим путём. Проверка должна охватить видимый зачёт, доступность прежних файлов и сохранение результата после следующих действий.
