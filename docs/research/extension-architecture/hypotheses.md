# Гипотезы исследования расширений курса

Это реестр вопросов из обсуждения, а не список согласованных удалений.
Предварительный разбор дал статические наблюдения и несколько известных
отказов интеграции; конкретные реализации ещё изменяются. Каждая гипотеза
должна быть заново соотнесена с состоянием, выбранным при финальной передаче.
Версии, SHA, номера PR/CI и результаты будущих измерений здесь не закреплены.

R — обычный render/preview; E — специальные экспорты и materialization;
T — разработка, установка, CI и выпуск. Для каждого пункта итог может быть:
подтверждено; опровергнуто; частично; данных недостаточно. Требование,
необходимость механизма и качество реализации оцениваются раздельно.

## Правила закрытия всех пунктов

Итог связывает ID гипотезы с ledger, требованиями, конкретным evidence и
выбранным или отклонённым вариантом. Подтверждённый лишний callsite не означает
ненужность всей функции. Подтверждённая защита не означает обоснованность её
текущей частоты. Вывод по JSON export не переносится на обычный HTML.

Микроопыт допускается только для различения сформулированных объяснений.
Нет необходимости исполнять шестьдесят независимых benchmark suites:
один корректный сценарий может закрывать группу гипотез при явной связи.

Этот реестр не заменяет механический inventory всего собственного кода.
Если inventory обнаружил новое назначение или проблему, добавляется новый ID;
исследование не ограничивается только заранее найденными подозрительными местами.
