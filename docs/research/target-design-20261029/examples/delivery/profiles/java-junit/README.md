## Исходник и инструменты

Основные Java-файлы находятся в `src/main/java`. Для обычного исходника без пакета достаточно JDK 25; установку Gradle не требуется превращать в условие сдачи одного файла.

## IDE и необязательная самопроверка

Откройте папку как обычный Gradle-проект. Для запуска из консоли нужны установленный JDK 25 и совместимый установленный Gradle; Wrapper в комплект не входит. В исследовательском варианте рассматривается Gradle 9.8.2. Первая загрузка зависимостей требует сети либо уже заполненного cache.

Если в комплект явно включены демонстрационные тесты, запустите `gradle test` или соответствующий JUnit-тест в IDE. Их можно открыть в удобный момент работы. Они помогают проверить решение; их успех не означает прохождения всего оценочного набора. HTML-отчёт стандартного Test находится в `build/reports/tests/test/index.html`.
