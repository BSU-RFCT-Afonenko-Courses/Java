# Элементы массива в обратном порядке

Выведите элементы заданного `int[]` от последнего к первому,
не изменяя сам массив.

Стандартный ввод содержит неотрицательную длину `n`, затем ровно
`n` значений типа `int`, разделённых пробельными символами.
Выведите только элементы в обратном порядке через пробельные символы.
Для `4 7 -2 7 0` результат — `0 7 -2 7`; для `0` вывод не содержит чисел.
При пустом стандартном вводе используйте демонстрационный массив,
который выберите в исходнике.

## Исходник и инструменты

Основной исходник — `src/main/java/Main.java`, точка входа — `Main.main(String[] args)`. Для компиляции и запуска нужен JDK 25.

## IDE и необязательная самопроверка

Если хотите работать в IDE, откройте папку как обычный Gradle-проект. Для запуска Gradle из консоли нужны установленный JDK 25 и совместимый установленный Gradle; Wrapper в комплект не входит. Первая загрузка зависимостей требует сети либо уже заполненного cache.

Если в комплект явно включены демонстрационные тесты, запустите `gradle test` или соответствующий JUnit-тест в IDE. Их можно открыть в удобный момент работы. Они помогают проверить решение; их успех не означает прохождения всего оценочного набора. HTML-отчёт стандартного Test находится в `build/reports/tests/test/index.html`.

## Что отправлять

Отправьте один файл `Main.java`.
