# Элементы массива в обратном порядке

Выведите элементы заданного `int[]` от последнего к первому,
не изменяя сам массив.

Стандартный ввод содержит неотрицательную длину `n`, затем ровно
`n` значений типа `int`, разделённых пробельными символами.
Выведите только элементы в обратном порядке через пробельные символы.
Для `4 7 -2 7 0` результат — `0 7 -2 7`; для `0` вывод не содержит чисел.
При пустом стандартном вводе используйте демонстрационный массив,
который выберите в исходнике.

Используйте JDK 25. Точка входа — `Main.main(String[] args)`.
Алгоритм, вспомогательные методы и организацию программы выберите
самостоятельно.

Представьте исходники, команды и выбранные входы. Покажите обычный,
пустой и одноэлементный массивы, а также исходный массив после вывода.
Объясните его участие в алгоритме и сохранность компонентов:
один консольный результат не доказывает, что массив не изменялся.

## Необязательная самопроверка

Можно написать решение по условию и сдать один `Main.java`, не пользуясь Gradle или IDE.
Для готового проекта нужны JDK 25 и установленный Gradle; Wrapper не используется.
После первоначального разрешения зависимостей через сеть/cache запустите из этого каталога:

```console
gradle test
```

Готовый проект можно открыть в IDE как Gradle-проект. `ReverseArrayDemoTest` → `PublicChecks` —
переходная механическая адаптация прежних двух кейсов, не окончательный целевой вид JUnit
и не новый runner. Demo содержит только два существующих
сценария: обычный ввод и пустой массив; неизменённый TODO-стартер не обязан их проходить.
Эти проверки не доказывают сохранность массива, обработку пустого stdin или полный зачёт.
Полный автоматический набор, API-precheck, observations и ручная часть оценки проверяются отдельно.

Исходный файл находится в `src/main/java/Main.java`; для отдельной компиляции достаточно JDK:

```console
javac --release 25 -encoding UTF-8 -d out src/main/java/Main.java
java -cp out Main
```

Это исследовательская выдача для просмотра. Названия полей metadata и новый producer не реализованы.
