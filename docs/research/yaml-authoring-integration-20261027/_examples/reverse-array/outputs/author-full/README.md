# Элементы массива в обратном порядке

Выведите элементы заданного `int[]` от последнего к первому,
не изменяя сам массив.

Стандартный ввод содержит неотрицательную длину `n`, затем ровно
`n` значений типа `int`, разделённых пробельными символами.
Выведите только элементы в обратном порядке через пробельные символы.
Для `4 7 -2 7 0` результат — `0 7 -2 7`; для `0` вывод не содержит чисел.
При пустом стандартном вводе используйте демонстрационный массив,
который выберите в исходнике.

Используйте JDK 25. Точка входа — `Main.main(String[] args)`.
Алгоритм, вспомогательные методы и организацию программы выберите
самостоятельно.

Представьте исходники, команды и выбранные входы. Покажите обычный,
пустой и одноэлементный массивы, а также исходный массив после вывода.
Объясните его участие в алгоритме и сохранность компонентов:
один консольный результат не доказывает, что массив не изменялся.

## Авторский исследовательский IDE-контекст

**Это не полный фактический grader.** Полный выбранный teacher input и его данные
сейчас не материализованы; точный пробел перечислен в `MISSING-FULL-INPUT.yml`.
Каталог `solutions/reference` содержит исторический образец авторского решения,
а не подтверждённый финальный teacher input. Альтернативное решение не сочинялось.

Нужны JDK 25 и установленный Gradle без Wrapper. Первый `gradle test` разрешает внешние JUnit-зависимости через сеть/cache.
Из этого каталога существуют два независимых обычных JUnit-контекста:

```console
gradle test
gradle referenceTest
```

`test` компилирует TODO-стартер из `src/main/java`; его demo может завершиться провалом.
`referenceTest` отдельно компилирует `solutions/reference/src/main/java` и тот же demo.
Два `Main` не попадают в один compilation context или classpath тестового решения.
В IDE Gradle source sets показывают оба контекста; внешний API PL для них не требуется.

`assessment/prairielearn` сохраняет существующие observations/API-precheck adapters
вне обычных Gradle source sets. Для API-precheck нужен настоящий Platform API/runtime;
эта стадия не заменена локальным `gradle test` и здесь не запускалась.
Успех выбранного demo не равен полному автоматическому или ручному зачёту,
не доказывает сохранность массива и не подтверждает весь grader.

README получает полное условие из исследовательского канонического QMD;
launch-инструкция добавлена отдельно. Это материал для оценки раскладки, не выпуск курса.

`ReverseArrayDemoTest` → `PublicChecks` — переходная механическая адаптация прежних
normal/boundary, не окончательный целевой вид обычного JUnit и не новый runner.
