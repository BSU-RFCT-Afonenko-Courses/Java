## Сохранность

Первоначальный пользовательский checkout не переключался. Исходники, старые worktrees, неуспехи и закрытые материалы сохранены. Java и выбранная Performance восстановлены из переносимых копий в новые каталоги; содержимое и состояние совпали с исходными. Архив преподавательских материалов восстановлен отдельно: все 5379 файлов совпали, лишних нет. Проверка сохранности не является проверкой корректности эталонов.

Сведения о закрытых путях и содержимое teacher root в текстовый PR не включены.

## Среда и сопоставимость

Малые опыты выполнены на i7-8750H, 6 ядер/12 потоков, около 31 GiB RAM, с питанием от сети и governor powersave. Quarto 1.11.5 использует встроенные Deno 2.7.14/Pandoc 3.10. Правильные CUE 0.17.1 и JDK 25 найдены по явным локальным путям; глобальная конфигурация не менялась.

Cybersecurity matrix получена на другом процессоре и с меньшим объёмом памяти. Её секунды нельзя сравнивать с нынешними как эффект изменения одного расширения. Ограничения sandbox для Docker/Gradle не превращены в утверждение отсутствия этих runtimes.

Публичный head и merge CI Java завершились успешно. Это публичная сборка, проверка pins/assembly и declared inventory; приватные runtime scenarios и реальная сдача студентом этим не подтверждаются.
