# Независимое review: результат и ограничения

Основные ограниченные выводы отчёта обоснованы: выбор фактических исходников, авторская модель всех подпроектов, проблемы студенческой выдачи, границы контрактов и измеренные baseline. Полная необходимость каждой инструкции и минимальность всех проверок не объявлены доказанными.

Review выполнялось чтением документов, выбранного кода и локальных проверочных материалов. Продукт, большая сборка, qualification и сервер не запускались.

## Проверенные выводы

- Подтверждены структура 17 ledgers, уникальность записей, caller/operation refs и неизменность исходников.
- Пересчитаны пять пар direct/off и совпадение результатов выбранной страницы; устойчивый малый overhead не установлен.
- Проверены досье функций и исходные диапазоны; их добавление не повышало semantic/runtime статусы.
- Разделены исходники курса, исторический Native, runtime, host tools, assembly, qualification, admission и server import.
- Проверены объяснения редактора, ZIP, группировки лабораторных, равных баллов, System Workspace и Git-state transport.

Сильные прежние подозрения были проверены контрпримерами: stock PrairieLearn собирает модель один раз; selected root Publisher не запускает всех children; Core уже имеет batch extraction и regular reuse; все десять Java лабораторных присутствуют в Native. Это не отменяет других конкретных повторов, неудобной группировки и неизвестной реальной видимости UI.

## Исправленные замечания

В начале fixture manifest оставался исторический статус подготовки после завершённых опытов. Он заменён актуальным состоянием с отдельной историей отказов.

Исследовательский binder пропускал удаление метода через `delete`. Оба отрицательных случая воспроизведены, исправление прошло 30 проверочных примеров; реальные выбранные bindings не изменились.

Автоматически составленные function descriptions не приняты как полное обоснование. Исправлены конкретные объяснения uniqueness predicate и subprocess effects API precheck; остальные досье остаются источником фактов и гипотез с указанной областью.

## Что review не закрывает

Остаются независимая необходимость механизмов и частот, полные косвенные эффекты, actual producer→consumer equivalence, устойчивое scaling сравнение, завершение Body export, полный qualification долг и реальная LMS сдача. Для Workspace неизвестна готовность текущего host; внешняя GitHub/SSH identity и Windows проверяются отдельно.

Исходники, worktrees и закрытые материалы сохранены. Итог review не разрешает новую публикацию курса, продление допуска или ослабление integrity/privacy/currentness guards.
