## Как использовать отчёт

- Подтверждённые наблюдения использовать как основание конкретной правки.
- Статическую оценку числа операций не принимать за измеренное время.
- Предлагаемый вариант проверять на малом случае с сохранением учебного поведения.
- Исторические вопросы этого снимка перечислены в [88 статусов A/H/B](hypothesis-decisions.md), сохраняя их ограничения.
- Результат отдельного компонента не переносить на весь выпуск, реальную сдачу или другой набор версий.

[Независимое review](review.md) подтверждает ограниченные выводы. Необходимость каждого внутреннего механизма, все межпроцедурные эффекты и полная квалификация выпуска не объявлены доказанными.

## Область отчёта

В PR включены только текстовые документы. По просьбе пользователя hashes, JSON, ledgers, трассы, архивы и тяжёлые досье функций не приложены. Они сохранены в локальном исследовательском комплекте вместе с исходниками, предыдущими рабочими деревьями и закрытыми материалами. Упоминания проверочных сводок в тексте относятся к этому локальному комплекту.

Публикуемая редакция сохраняет выводы, числа, ограничения и предложения; технические идентификаторы снимков и локальные пути опущены. Версии и происхождение компонентов описаны в [выборе исходников](source-selection.md). Это исследовательская документация: курс, расширения, releases, допуск, сервер и опубликованные задания данным PR не меняются.

Дополнительные разборы владельцев находятся в `owners/`, подробная хронология — в [sections/release-history.md](sections/release-history.md).
