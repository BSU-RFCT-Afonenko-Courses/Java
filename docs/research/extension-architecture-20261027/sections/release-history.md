# Хронология выпуска и изменения стратегии

Перед исследованием прочитан завершённый чат «Выполни план публикации банков»: все 28 ходов, итог, неуспехи и настоящие документы решений. Завершение чата не принято за успешную квалификацию. Здесь сохранена смысловая хронология без локальных путей, hashes и тяжёлых приложений.

## Основные этапы

## Фактическое состояние

Сохранённые receipts подтверждают импорт 128 Java и 7 System вопросов, доступность HTTPS и healthy PrairieLearn на последней проверке. У Java 118 включённых auto/mixed и 10 manual, у System — 7 manual. Реальный Moodle launch, сдача, save/reopen, feedback и начисление баллов не проверены.

Final runtime qualification Java — 0/672. Исторический route — package-integrity-user-deferred, состояние DEFERRED_BY_USER / NOT_VERIFIED. Policy истекла 26 октября в 19:00 UTC (22:00 Минск). Более поздняя execution lease относилась к продолжению уже admitted экземпляра и не продлевала policy.

Пользователь ранее согласовал неограниченные попытки во время открытой работы и лучший результат. В прочитанных 28 ходах не найдено позднего человеческого согласования лимита в три попытки, присутствующего в source. Это подтверждённое расхождение источников; фактическое серверное поведение отдельно неизвестно.
