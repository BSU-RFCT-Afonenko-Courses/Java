## Platform и новая среда Java JUnit

Незавершённые исходники сохранены коммитом [`769d6f39`](https://github.com/Afonenko-Course-Tools/prairielearn-platform/commit/769d6f393dea11c3ce5fdd6bf0283b661e52f013). Последний подготовительный пакет включал 221 файл; совокупная дельта ветки включает и более ранние коммиты. Все 54 исторических файла сохранены в Git, их удаление не выполнено.

| Область | Подтверждённый результат | Граница |
| --- | --- | --- |
| Python | 113 текущих файлов, 0 диагностик строгого анализатора | Общая проверка 119 файлов: 952 ошибки в шести исторических файлах |
| Java | 23 различные единицы строгой компиляции, 144 класса; 12 случаев initializer | Компиляция не подтверждает выполнение JUnit |
| Отмена backend | 27 успешных проверок с подменённой внешней границей | Фактический полный курсовой Docker-прогон не выполнен |
| Proxmox preflight | Исправление и две успешные проверки | Настоящие VM, API и сервер не квалифицированы |
| JS, C, shell, fish и конфигурации | Согласованные ограниченные проверки приняты | Для Docker сохранены шесть исключений и ограничение воспроизводимости APT; Nginx проверен в отдельной локальной конфигурации |
| Новая среда JUnit | State: **1 PASS, 1 FAIL, 9 ERROR** | Две другие группы не запущены; runtime не принят |

У девяти ошибок нет одной доказанной общей причины. Установлены следующие отдельные факты:

1. Диагностический режим использует разрешённый `--add-opens`; защита ошибочно считает это недопустимым экспортом внутреннего пакета. Предложение исправления независимо проверено по исходникам, но не применено.
2. Обычное задание нового runtime останавливается на `Untrusted JUnit lifecycle intermediary` при `testPlanExecutionStarted`. Затем каскад ошибок фазы заполняет ограниченный вывод. Точный отвергнутый скрытый класс пока неизвестен; предполагаемое имя не является установленной причиной.
3. Последняя попытка наблюдения завершилась ошибкой компиляции частной копии из-за её размещения. Это ошибка инструмента наблюдения. Исправленная копия SOURCE04 независимо проверена по исходникам, но не запускалась.
4. Единственный FAIL группы State касается неверного диагностического сообщения при устаревшем мосте. Ошибочная нулевая оценка студенту этими данными не подтверждается.

Сохранены [независимая проверка красного запуска](night-session-20261107/evidence/N4/junit-named-implementation/runtime177-04-independent-actual-review.md), [состояние Platform](night-session-20261107/evidence/N4/current-status.json) и [неприменённые предложения](https://github.com/Afonenko-Course-Tools/prairielearn-platform/tree/codex/night-20261107-prairielearn-platform/docs/night-session-20261107).

`VERSION` подготовительной ветки остаётся `2.5.9`; предложение `2.5.10` не применено. Наличие тега 2.5.9 не означает его использования курсом. В проверенном `CI/toolchain.json` Java закреплён Platform `2.5.2`, последний проверенный нами опубликованный релиз Platform — `2.5.3`. **Ошибки нового runtime не доказывают поломку действующего курса.** Использование окончательных новых материалов с прежним runtime требует проверки совместимости.
