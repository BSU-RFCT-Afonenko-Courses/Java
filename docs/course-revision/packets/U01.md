## Обязательные последовательности и замороженные контракты

1. `theory/chapters/platform.qmd#sec-j25-theory-platform-first-program`: `src/course/reading/Reading.java`, `package course.reading`, `public class Reading`, main не индексирует args. Исходные 5/2 → `Average: 2.5`; source изменён на 7 → старый class всё ещё 2.5; source launch и повторная компиляция →3.5. Корень поиска out, полный класс course.reading.Reading. Source launch требует согласованного package path; именно этот путь приведён студенту.
2. `theory/chapters/types.qmd#sec-j25-theory-types-array-minimum` предшествует initialization/copying/absence/final: переменная/объект/компонент, initializer/new, fixed length, index0, default numeric0/reference null, empty index error. До него нет mutation контейнера. `practice/numbers.qmd#sec-j25-practice-numbers-s5` повторяет String[] minimum, `#sec-j25-practice-numbers-input` показывает один переданный token, `#sec-j25-practice-numbers-argument-boundary` локально вводит if/return до guarded чтения. Неверная запись числа остаётся отдельным parse отказом.
3. `theory/chapters/types.qmd#sec-j25-theory-types-absence`: null — присвоенное значение; empty — строковый объект длины0; неприсвоенная локальная — compile error. Затем проверка пути, `#sec-j25-theory-types-wrappers` с NPE unboxing и `#sec-j25-theory-types-final` с изменяемым компонентом неизменяемой ссылки. `#sec-j25-theory-types-nullness-comparison` разделяет аннотацию, выбранный анализатор и runtime. Java всегда передаёт ссылочные значения; никакой переменной caller-by-reference не обещается.
4. `theory/chapters/control.qmd#sec-j25-theory-control-nested` использует два scalar счётчика, первое int[][] — `theory/chapters/arrays.qmd#sec-j25-theory-arrays-nested`. Первое независимое возвращаемое int[] в `methods.qmd#sec-j25-theory-methods-return-reference` создаётся через new; clone вводится в arrays-copying. Матрица clone имеет независимый внешний массив и общие строки; row reassignment и row component mutation проверены отдельно.
5. `theory/chapters/text.qmd#sec-j25-theory-text-early-lab`: String immutable, equals, UTF-16 indices, byte/encoding различие, insertAt без изменения original, позиции0/end/empty и отказ5 для Java. Алфавит слова фиксирован Latin+Cyrillic+Ё/ё; digit/tab/punctuation — разделители. Regex `\b` не заменяет его. Код поиска границ не реализует обязательное преобразование слова.

Точное тело `insertAt` возвращает `text.substring(0, position) + fragment + text.substring(position)`, требует non-null text/fragment и `0<=position<=text.length()`. Позиция описывает границу UTF-16; для ограниченного task alphabet один допустимый символ занимает один char. `StringBuilder.insert` остаётся другой возможной реализацией метода; явная исходная строка сохраняется при обеих стратегиях.

## Приложение: полный executable context каждого Java fence

Номер — Java-fence ordinal внутри конкретного QMD, не номер всякого bash/text блока. Каждый sample компилируется отдельно в собственном каталоге. Общая команда: `javac --release 25 -encoding UTF-8 -proc:none -d out <имя-файла>.java`; затем `java -cp out <main-class> <args>`. Все imports и вспомогательные объявления содержатся в полном коде. Для NullnessDemo/NullnessSafe дополнительно `-cp checker-qual-4.3.1.jar` при компиляции; для отдельного анализатора команды полностью приведены в handbook values-nullness. Нормализованное обозначение stdout ниже использует JSON `\n`/`\t`; фактический Linux вывод сохранён в evidence, PrintStream%n соответствует platform newline.

Дополнительный observer после декларативного фрагмента помечен явно; он показывает значение, а не добавляет вывод в исходный алгоритм. Methods fragments располагаются на уровне класса, остальные — в main. Вставки `throws Exception` в wrapper — техническое разрешение уже названного Reader IOException; они не предъявляют новую lab обязанность. Схемы синтаксиса отдельно помечены и не входят в115.

## Приложение: отдельные отрицательные проверки

Закомментированная неверная строка в QMD называет отдельный опыт: сама она не выполняется в положительном sample. Compile-fail — исходник отвергается до запуска. Runtime-fail — обычный javac принимает исходник, затем конкретный вход завершает запуск исключением. Проверки сравнивают класс ошибки/категорию диагностики, не полную платформенно изменчивую JVM трассу.

| Case | Статус и ожидаемая диагностика | Причина |
|---|---|---|
| `assignment-string-to-int` | compile-fail: `incompatible types` | String не является int |
| `unassigned-local` | compile-fail: `might not have been initialized` | null не подменяет definite assignment |
| `var-null` | compile-fail: `cannot infer type` | нет типа для вывода |
| `final-reassignment` | compile-fail: `final variable` | final ограничивает переменную, не компонент |
| `null-to-int` | compile-fail: `incompatible types` | примитив не допускает null |
| `long-wrapper-int` | compile-fail: `incompatible types` | нет произвольной цепочки int→long→Long |
| `byte-promotion` | compile-fail: `possible lossy conversion` | операция даёт int |
| `array-index-double` | compile-fail: `possible lossy conversion` | тип индекса после promotion должен быть int |
| `local-label-minus` | compile-fail: `bad operand types` | String не поддерживает numeric minus |
| `switch-expression-return` | compile-fail: `attempt to return out of a switch expression` | return пересекает границу switch expression |
| `missing-null-string` | runtime-fail: `NullPointerException` | нет объекта-получателя метода |
| `null-unboxing` | runtime-fail: `NullPointerException` | нет Integer для получения int |
| `empty-array-index` | runtime-fail: `ArrayIndexOutOfBoundsException` | компонент0 отсутствует |
| `array-index-length` | runtime-fail: `ArrayIndexOutOfBoundsException` | верхняя граница исключена |
| `negative-array-size` | runtime-fail: `NegativeArraySizeException` | размер отрицателен |
| `division-zero` | runtime-fail: `ArithmeticException` | integer divisor0 |
| `checked-add-overflow` | runtime-fail: `ArithmeticException` | Math.addExact сообщает выход int диапазона |
| `both-logical-operands` | runtime-fail: `NullPointerException` | & вычисляет опасный правый операнд |
| `reference-copy-null` | runtime-fail: `NullPointerException` | отсутствует массив |
| `reference-copy-empty` | runtime-fail: `ArrayIndexOutOfBoundsException` | changeFirst требует компонент0 |
| `average-zero-days` | runtime-fail: `IllegalArgumentException` | условие метода отвергает days0 до деления |
| `arraycopy-component-type` | runtime-fail: `ArrayStoreException` | runtime array type String[] сохраняется у copyOf |
| `copyof-null` | runtime-fail: `NullPointerException` | original отсутствует |
| `copyof-negative` | runtime-fail: `NegativeArraySizeException` | newLength отрицательна |
| `insert-position-outside` | runtime-fail: `IndexOutOfBoundsException` | position5 вне0..4 |
| `parse-space` | runtime-fail: `NumberFormatException` | parseInt не удаляет пробелы |
| `parse-overflow` | runtime-fail: `NumberFormatException` | decimal int вне диапазона |
| `compare-null` | runtime-fail: `NullPointerException` | anotherString отсутствует |

Каждый отрицательный case ниже — полная независимая единица компиляции; её имя файла соответствует публичному классу.
