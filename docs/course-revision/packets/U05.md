## Канонические интерфейсы и помощь

`grade.Student` ровно `record Student(String id,String name,int score)`:
исходник SHA256 `19199e9d72a3c789c021c7bc24c00c847c916bc382577f43ff2c64403f4e6eb9`
совпадает с принятыми U02/U04. null id/name → NPE; strip нормализует
поля, пустота/внутренние `;`/CR/LF и score вне0..100 → IAE. Конструктор
защищает одну запись; loader проверяет уникальность id всего каталога.
`StudentParser.parse(String,long) throws DataFormatException` получает
ненулевую строку и физический номер от loader, split с пределом−1,
сохраняет cause парсинга/инварианта. Extra field и duplicate —
собственный отказ без искусственно придуманного cause.
`StudentFiles.read(Path) throws IOException,DataFormatException` читает
UTF8, увеличивает счётчик каждой физической строки до skipblank,
case-sensitive id uniqueness после strip, возвращает List.copyOf после
закрытия. Локальный частичный результат не публикуется.

`Reports.selected(List<Student>,int)` принимает nonnull каталог из
nonnull допустимых Student и порог0..100; score>=threshold, score↓,
String id natural↑. Source состав/порядок не меняет; результат допускает
чтение и запрещает add/set/sort. `Reports.line(Student)` — id;name;score.
Stream и loop+sort нового списка оба приняты. Структуры независимы,
значения record можно разделять. U04 fix1 pure-map/ordered terminal
семантика принята: не делать вывод из mapper trace/anyMatch debug о
гарантированном эффекте; здесь печать находится после полной валидации.

CLI ровно `grade.Main input threshold` → stdout без header, status0/2/3/4.
Пустой успешный ввод/отбор → stdout пуст/status0. Args/threshold/pathsyntax
проверяются до чтения; data/read refusal не печатает полезный результат.
Output refusal возможен после префикса, checkError →4; stdout не
транзакционен, System streams не закрываются. Main.run(String[]) и
printReport предоставлены; student `static int run(Path input,int threshold)
throws IOException,DataFormatException` связывает read→selected→helper.

package grade;

import java.util.Comparator;
import java.util.List;

public final class Reports {
    private Reports() {}

    public static List<Student> selected(List<Student> students, int threshold) {
        if (threshold < 0 || threshold > 100) {
            throw new IllegalArgumentException("порог вне диапазона 0..100");
        }
        Comparator<Student> order = Comparator.comparingInt(Student::score)
            .reversed().thenComparing(Student::id);
        return students.stream()
            .filter(student -> student.score() >= threshold)
            .sorted(order)
            .toList();
    }

    public static String line(Student student) {
        return student.id() + ";" + student.name() + ";" + student.score();
    }
}

package grade;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;

public final class StudentFiles {
    private StudentFiles() {}

    public static List<Student> read(Path path)
            throws IOException, DataFormatException {
        var result = new ArrayList<Student>();
        var ids = new HashSet<String>();
        try (var reader = Files.newBufferedReader(path, StandardCharsets.UTF_8)) {
            long number = 0;
            String line;
            while ((line = reader.readLine()) != null) {
                number++;
                if (line.isBlank()) continue;
                Student student = StudentParser.parse(line, number);
                if (!ids.add(student.id())) {
                    throw new DataFormatException(
                        "строка " + number + ": повтор кода " + student.id());
                }
                result.add(student);
            }
        }
        return List.copyOf(result);
    }
}

package grade;

public final class StudentParser {
    private StudentParser() {}

    public static Student parse(String line, long number)
            throws DataFormatException {
        String[] fields = line.split(";", -1);
        if (fields.length != 3) {
            throw new DataFormatException("строка " + number + ": нужно три поля");
        }
        try {
            int score = Integer.parseInt(fields[2].strip());
            return new Student(fields[0], fields[1], score);
        } catch (IllegalArgumentException ex) {
            throw new DataFormatException(
                "строка " + number + ": " + ex.getMessage(), ex);
        }
    }
}
