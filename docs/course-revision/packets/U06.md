## Дописывание совместимых списков: PECS

Объявите и реализуйте метод `static <T> void copy(List<? extends T> source, List<? super T> target)`, дописывающий элементы в конец target в порядке source. Source сохраняется; прежний prefix target сохраняется; пустой source ничего не меняет.

Source и target — разные ненулевые независимые списки без общего представления; target поддерживает добавление, элементы ненулевые и допустимы для приёмника. ## Отчёт по студентам: завершение gradeapp

Завершите предоставленную заготовку gradeapp на Java 25 без preview. Это одно приложение с ручным предъявлением. Оценка 120 минут — гипотеза для проверки на учебной группе, а не измеренный срок.

Команда `grade.Main input threshold` получает ровно два аргумента: путь UTF-8-файла и целый порог 0..100. Относительный input относится к рабочему каталогу; результат идёт в stdout, путь выхода аргументом не передаётся. Предоставленная CLI-граница проверяет количество аргументов, порог и синтаксис пути до чтения.

Непустая запись — `id;name;score` с ровно тремя полями, без экранирования. `strip()` удаляет краевые пробельные символы всех полей; score разбирается как int. Record равенство сравнивает все три компонента и не заменяет уникальность id каталога.

Blank физические строки пропускаются через isBlank; физический номер увеличивается для каждой строки до пропуска. Id уникален после strip с учётом регистра: `s1`/` s1 ` — дубль, `s1`/`S1` — разные. Полностью прочитайте и проверьте весь файл до полезного вывода; частичный каталог при ошибке не возвращается.

Реализуйте следующие предоставленные сигнатуры, не меняя их:

- StudentParser: `public static Student parse(String line, long number) throws DataFormatException`: ненулевая строка, положительный физический номер; ровно три поля, включая возможное пустое последнее поле.
