# Отчёты исполнения и независимой проверки

Здесь сохранены точные копии замороженных отчётов принятых этапов M00, M01 и U00–U06, а также ранних технических подзадач M02. Контрольные суммы и исходные пути находятся в `manifest.json`.

Исходная рецензия может содержать найденный дефект; окончательное решение соответствующего этапа записано в `fix-1-review.md`. Отчёты исполнителя сохраняют историю проверок и последующих исправлений.

Полная техническая и педагогическая приёмка курса ещё впереди: U07–U08 и M02–M05. Полные журналы команд и временные проверочные исходники находятся вне курса в `/tmp/java-course-revision-checks/`; наличие отчёта раннего M02 не завершает M02 целиком.

Назначенные модели и усилия фиксируются в `../model-routing.jsonl`. Интерфейс запуска не сообщил фактические настройки; отчёты не выдают назначение за подтверждение runtime. Материалы этой папки исключены из ресурсов сайта конфигурацией проекта.
