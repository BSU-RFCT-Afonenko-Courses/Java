# Перенос материалов Java для нового оформления

Исходный Java-курс: `c32d3f24612f050eea5e90bac8abeefd587bf971`.
Первоначальное оформление следовало шаблону `a5939b4f06e88e80a63eca61ee7ff71ef841f061`. Текущая конфигурация и пакеты обновлены по [шаблону `e2cad0930ab4315228388f0b43b3ec6088ed418f`](https://github.com/Afonenko-Course-Tools/quarto-template-course/tree/e2cad0930ab4315228388f0b43b3ec6088ed418f).

| Прежний путь | Новый путь |
|---|---|
| `book/`, кроме приложений | `theory/` |
| `book/appendices/` | `handbook/appendices/` |
| `essay/` | `tasks/` |

Предметные тексты, структура тем, include, каталоги проектов, исходные ID и атрибуты учебных блоков сохранены. Межкнижные ссылки `@book:…` теперь указывают на `@theory:…` или `@handbook:…`, а `@essay:…` — на `@tasks:…`. Стартовая страница курса, вводная страница справочника и слайды лекций/практики добавлены как маршруты по существующим материалам.

Вопросы Unicode используют display-ID `exm-essay-unicode-prediction` и `exm-essay-unicode-self-check`. Сохранены оба ID объяснений `sol-*`, их текст и открытая видимость; `for` указывает на новые ID вопросов. Контроль в `.when-full`, заметки оценивания и преподавательские архивы сохраняют прежние ограничения профиля.

HTML-книги используют Cosmo, лекции и практика — стандартную тему Reveal.js с Navigation. Конфигурация подключает текущие native-контракты инструментов курса. Общие визуальные изменения поставляются целыми пакетами расширений из репозиториев поставщиков.

Лекции разделены на восемь самостоятельных презентаций, практика — на шесть. Каждый исходник `01-intro.qmd`, `02-…qmd` и далее создаёт собственную HTML-презентацию со своими слайдами. Части `01a-intro.qmd` и `01b-cont.qmd` допустимы и также собираются отдельно. Их порядок задаётся явным списком `project.render`. Таблица «План курса» на главной странице объединяет девять тем с лекциями, практикой, теорией, исследованиями и справочником обычными Markdown-ссылками. Из каждой презентации доступны возврат к плану курса (`@portal:sec-course-plan`) и главной странице.

Разовая сверка при первоначальном переносе подтвердила сохранность 210 QMD, 1034 исходных ID, метаданных и атрибутов учебных блоков, а также 234 файлов проектов и ресурсов. Тогда же проверены оба профиля, пять частей, ссылки и якоря, архивы, поиск, возврат к порталу и изоляция контроля. Миграционные скрипты удалены из курса; текущая CI использует внешнюю проверку авторского формата и сборку обоих профилей с проверками расширений.

При первоначальном оформлении план курса использовал Presentation из PR #17. В текущем основном пакете этого оформления нет; таблица переведена на штатный контейнер Bootstrap `.table-responsive` и тему Cosmo. Строки таблицы, ссылки и атрибуты доступности сохранены.

Каталог `test/` удалён по указанию пользователя: отдельные письменные PDF-условия не входят в новую книгу. Проверки учебной модели выполняют установленные расширения.


## Обновление по текущему native-шаблону, 5 октября 2026 года

Корневой website использует Course Site, а пять частей — штатные проекты Quarto с явными обработчиками Core, Download, QRC и сбором текущего результата. Удалены прежний Publisher, собственный preview server и устаревший параметр `course.validate`. Оба профиля явно задают `course.view` и раздельные output-dir. Явный каталог дополнен экспортом портала и плана курса.

Каждый канонический `exr-*` теперь явно содержит назначение и сложность. Сложность перенесена из прежней метадаты страницы; самостоятельные исследования получили `independent-study`, скрытые проверочные задания — `control`. Открытый разбор Unicode получил `demonstration`, его практические задания — `independent-study` и начальный уровень. У заголовков контроля появились явные `sec-*-control` для связи задания с темой. Тексты условий, include, пути проектов и ограничения `.when-full` сохранены.

Поставщики и состав всех 23 установленных копий пакетов закреплены в `providers.json` и `installed-packages.json`. CI использует текущий шаблон и фиксированные Quarto 1.10.18/1.11.5, CUE v0.17.1; проверяет авторский формат и последовательность student → full → student.
