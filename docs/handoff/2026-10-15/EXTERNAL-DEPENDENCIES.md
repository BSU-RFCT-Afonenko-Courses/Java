# Внешние зависимости и пределы переноса

GitHub и `Java.bundle` содержат репозиторий Java и рабочие документы. Этот пакет не создаёт доступов, не переносит секреты и не подтверждает работу чужой машины. Ниже перечислены зависимости, которые существенны для продолжения.

| Зависимость | Что известно и что делать при необходимости |
|---|---|
| Книги и локальные источники | Личные PDF/книги прежней машины в пакет не включены. Библиографические записи уже находятся в [bibliography/](../../../bibliography/), границы доступа — в [docs/sources.md](../../sources.md). Для конкретной цитаты или страницы получить законный доступ к нужному изданию и прочитать соответствующий фрагмент; не восстанавливать содержание по названию, памяти или поисковой аннотации. Не требуется сначала читать весь книжный архив. |
| Старые редакторские пакеты и журналы | Исторические ссылки в `docs/java-course-pilot.md` могут вести к файлам и локальным URL прежней машины. Они сохранены как происхождение этапа и не нужны для запуска нового задания. Принятые выводы перенесены в [CONTEXT.md](CONTEXT.md), действующие правила — в методику. Старые `.superpowers/`-журналы и временные снимки не переносятся как обязательная опора. |
| Quarto, CUE, JDK и инструменты примеров | Версии и штатные команды указаны в [BOOTSTRAP.md](BOOTSTRAP.md) и актуальном `CI/toolchain.json`. Выбрать подходящие своей ОС пути. Для изменённых сравнительных примеров могут понадобиться соответствующие C++/C#/Python-инструменты и анализатор; проверять фактический состав примеров, не объявлять прежние результаты новой проверкой. |
| Исходники пакетов курса | Версии и источники закреплены в [UPSTREAM.md](../../../UPSTREAM.md), [providers.json](../../../providers.json) и [installed-packages.json](../../../installed-packages.json). Соседние локальные клоны инструментов в bundle Java не входят. При обновлении использовать штатную установку целых пакетов, не ручные правки vendored `_extensions`. |
| Core optional-time | В курсе сохранены patch, manifest и сценарий [восстановления](../../../tools/provider-patches/core-optional-time/README.md). Для восстановления нужен доступный клон `Afonenko-Course-Tools/quarto-course` с базой `9db360beec417b3798693026768262be2f7d3b18`, Python 3 и Git. Локальный commit `3d6015880b7327b11b6abc10af913d71c1b01236` не следует пытаться получать с remote как гарантированно опубликованный выпуск. Замените примерные пути в инструкции на собственные. |
| PrairieLearn, Gateway и OCI-образы | Поставка, пины и документы находятся в репозитории. Доступность закреплённых образов и права GHCR на новой машине проверить отдельно. Исторические candidate-проверки PR #14 и неудачный CI с `manifest unknown` не заменяют проверки итоговой установленной композиции. Копии токенов registry и `.env` не входят в handoff. |
| Действующие ссылки доступа и Moodle | Публичный адрес сайта в просмотренной технической ветке — `https://bsu-rfct-afonenko-courses.github.io/Java/`. Конкретные URL Moodle, идентификаторы активностей и связи действующей установки в изученных файлах не обнаружены. Перед изменением развёртывания получить у владельца или из доступной конфигурации несекретную карту URL входа/запуска и связей Moodle → Gateway → поставка. Начать авторскую работу можно до её получения. Не переносить студенческие данные; сохранение доступа не требует сохранять все внутренние учебные ID. |
| Частный CA учебного стенда | PR #8 и ветка `codex/windows-device-ca` содержат инструкции доверия, но не настоящий CA и не приватные ключи. Проверить действующий адрес, отпечаток и процедуру подключения только при работе со стендом. Эти инструкции не превращаются в обязательную тему курса Java. |
| Авторизация GitHub и подключения Codex | Новая машина использует свою аутентификацию и собственные подключения. В пакет не входят SSH-ключи, токены, cookies и состояние MCP/коннекторов. Для чтения публичного Java доступен HTTPS; возможность push и чтения закрытых внешних пакетов проверяется по факту. |
| Локальный просмотр | Старый `127.0.0.1:8765` относится к серверу прежней машины. После собственной сборки запустить локальный сервер на доступном порту. Наличие адреса в историческом документе не означает работающий просмотр на новой машине. |

При отсутствии зависимости сначала установите, какую конкретную операцию она блокирует. Недоступный источник нельзя использовать для неподтверждённых утверждений; недоступная конфигурация развёртывания не мешает читать и редактировать учебный корпус. Работу, не зависящую от этого доступа, следует продолжать.
