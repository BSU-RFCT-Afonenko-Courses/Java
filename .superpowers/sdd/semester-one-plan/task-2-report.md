## Текстовая самостоятельность и адаптация

Условия сохранены по предметной сути. Обещания будущих файлов/каркасов
исключены; минимальные данные, модели и интерфейсы описаны текстом.

`TwoDShape`, `Vehicle`, три реализации `ICharQ`, исходный стек, generic
очередь/стек и их отказные состояния имеют самостоятельные контракты.
Не требуется успешная сдача предыдущей задачи. Дополнительно заданы
фиксированные матрицы, текстовые входы, файловые форматы, предметное равенство,
параметры функций и основные пограничные случаи. Уточнения отделены от
исходного условия и помечены как авторская редакция курса.

Сохранён явный close в байтовом копировании; символьная версия использует
try с ресурсами. Кольцевые очереди повторно используют освободившиеся места,
динамические сохраняют FIFO-порядок при увеличении массива.
Для копирования между очередями явно разрешено извлечение с опустошением
источника: это редакционная политика для неоговорённого автором состояния,
а не дополнительный метод интерфейса.

Три проекта остаются текстовыми постановками. Для авиакомпании заданы
учебные данные/единицы; для расписания — минимальные сущности и конкретные
специализированные операции; для Хаффмена — корпус, кодирование слов,
равные частоты, пустой/однословный вход и текстовое представление битов.
Все исходные предметные операции сохранены.

## Нагрузка и ограничение учебной модели

Штатный Core поддерживает required/optional, но не выражает выбор одного
из двух. Поэтому обе карточки каждой пары — optional-кандидаты; непарные
основные задачи required, резерв optional. Текст явно обязывает выбрать
один вариант каждого слота. Это не автоматический выбор/оценивание,
новая машинная семантика не создавалась. Автоматически подсчитанное время
required-узлов не равно авторскому времени выбранного маршрута;
авторская таблица работ является основанием планирования.

Основной маршрут: 1845 минут задач + ориентир 200 минут разборов = 2045.
Замены равны времени своих базовых задач; их 590 минут не прибавляются.
Оценки первых девяти работ 200 минут, десятой 245 минут; это не обещание
одной встречи в 180 минут.

Решение родителя: отсутствовавший компонент локального чтения чисел
заменён полным текстовым контрактом самостоятельного минимального метода,
UTF-8 TSV входом и ошибочными случаями. Исходная оценка 90 минут сохранена
как исходная величина; рабочая time поднята до 110 (добавлены 20 минут).
Поэтому третий резервный пул 1210 вместо 1190, весь резерв 4095 вместо 4075,
полный арифметический банк 6530 вместо 6510. Основной бюджет неизменен.
115 выполнений без удвоения пар — 5940 минут до вводных разборов.
Это явное отклонение от исходной таблицы по новой адаптации, а не ошибка суммы.

## Ограничения источников

В handoff отсутствуют обещанные реализации и корпуса стихотворений.
Минимальные реализации заменены текстовыми определениями, а для стихотворений
сохранены указанные авторы и требуется самостоятельный выбор краткого текста
из общественного достояния с названием и источником. Никакая карточка не
исключена. Рабочие оценки требуют наблюдения за фактическим выполнением,
особенно там, где контекст теперь создаётся по описанию.

Адресное содержание полного учебника здесь не перепроверялось: источником
переноса являются сверенные карточки пользователя. Нет новых готовых
Java-листингов или слайдов, поэтому компиляция примеров и QA презентаций
к этой текстовой партии не относятся.
