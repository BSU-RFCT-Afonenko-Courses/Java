5  Объявление и вызов методов

java
java-core
java-methods

При вызове метода значения аргументов инициализируют новые переменные параметров. Присваивание параметру меняет эту локальную переменную; через ссылочный параметр доступен тот же объект, что и вызывающему коду. return передаёт значение результата. Объяснение механизма: Глава 7. [61], [70]

5.1 Форма объявления

Метод вычисляет среднее число страниц в день. Его объявление находится в классе Reading; вызов Reading.average(5, 2) даёт 2.5:

static double average(int pages, int days) {
    if (pages < 0 || days <= 0) {
        throw new IllegalArgumentException("Недопустимые данные о чтении");
    }
    return (double) pages / days;
}

double задаёт тип результата; average — имя; int pages, int days — параметры. Тело выполняется для каждого вызова с его значениями. При pages < 0 или days <= 0 метод завершается исключением; при допустимых данных возвращает частное с дробной частью.

static связывает метод с классом. Для вызова не требуется объект Reading, и в теле отсутствует this. Экземплярный метод получает объект-получатель, доступный через this; тело метода может обращаться к полям этого объекта. Создание объекта и экземплярные методы: Глава 11.

Объявление также может содержать модификатор доступа и throws. У метода с результатом каждый путь нормального завершения должен возвращать совместимое значение. Метод void выполняет действие и допускает досрочный выход return;; его вызов нельзя присвоить переменной.

5.2 Сигнатура и перегрузка

Для методов без параметров типа сигнатуру составляют имя и типы параметров. Имена параметров, результат, throws и модификаторы не различают перегрузки с одинаковой сигнатурой. Для обобщённых методов учитываются также параметры типа и адаптация типов. [70]

static String kind(long value) { return "long"; }
static String kind(Integer value) { return "Integer"; }

kind(5) выбирает kind(long): расширение int в long доступно в первой фазе поиска. Упаковка в Integer учитывается на следующей фазе, которая в этом вызове уже не требуется. Переменное число аргументов рассматривается после применимых вызовов с фиксированным числом аргументов. Выбор основан на статических типах выражений; неоднозначность вызывает ошибку компиляции.

Для параметра byte сужение нужно выразить явно: f((byte) 1). Вызов f(1) при единственном f(byte) отвергается, хотя присваивание byte b = 1 разрешено. Правила контекста вызова и контекста присваивания различаются. [67]

5.3 Передача аргументов

Аргументы вычисляются слева направо. Если один из них завершается исключением, оставшиеся аргументы и тело метода не вычисляются. Полученные значения после допустимых преобразований записываются в параметры нового вызова.

static void correctFirst(int[] data) {
    data[0] = 9;
}

static void replace(int[] data) {
    data = new int[]{1, 2};
}

Оба метода принимают ссылку на массив; correctFirst требует существующий непустой массив. Для int[] pages = {5, 7} вызов correctFirst(pages) меняет его на [9, 7]. Последующий replace(pages) присваивает новую ссылку параметру data. Переменная pages сохраняет доступ к [9, 7]. Схемы двух вызовов: Копирование ссылки и общий объект.

Параметр final int[] data также получает копию ссылки. final запрещает присвоить параметру другую ссылку; запись data[0] = 9 остаётся допустимой. Она меняет компонент объекта, доступного по сохранённой ссылке.

5.3.1 Результат и изменение состояния

static int nextCount(int count) {
    return Math.addExact(count, 1);
}

static int[] pair(int first, int second) {
    return new int[]{first, second};
}

count = nextCount(count) сохраняет возвращённое число в переменной вызывающего кода. pages = pair(1, 2) сохраняет ссылку на новый массив. У метода, возвращающего уже существующий массив, вызывающий код получает ещё один путь к тому же объекту. Тип int[] результата допускает оба случая; сохранность исходных данных определяется телом и договором метода. Пример независимого расчёта: Разделение расчёта и изменения данных.

5.4 Переменное число аргументов

static long sum(int... values) {
    long total = 0;
    for (int value : values) total += value;
    return total;
}

sum() даёт 0, sum(5, 7) — 12. В теле values имеет тип int[]. Для отдельных чисел вызов создаёт массив; готовый массив передаётся непосредственно. Поэтому запись в компонент внутри такого метода изменила бы переданный готовый массив. Явный (int[]) null остаётся null и у этого sum вызывает NullPointerException при обходе.

Параметр T... может быть один и должен быть последним. f(int[]) и f(int...) имеют одну сигнатуру и не образуют перегрузку. Рекурсивный вызов также получает новые параметры и локальные переменные; каждый незавершённый вызов занимает отдельный кадр. Конечность рекурсии и ограничение глубины: Простой рекурсивный вызов.
