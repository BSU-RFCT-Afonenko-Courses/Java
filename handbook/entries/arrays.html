6  Массивы и класс Arrays

java
java-core
java-arrays

Массив имеет фиксированную длину и единый тип компонентов. Тип объекта массива сохраняется при присваивании ссылки более общему типу. Полное объяснение: Глава 8. [43], [64]

6.1 Создание и доступ

Переменная, объект и компонент: Одномерный массив. Вложенные массивы int[][] и копирование через clone(): Массивы массивов.

int[] a = new int[3];       // [0, 0, 0]
int[] b = {5, 7, 4};
a = new int[]{1, 2};
String[] names = new String[2]; // [null, null]
int[][] rows = new int[3][];    // три null-ссылки

array.length — поле типа int с модификатором final; круглые скобки не нужны. Индексный тип после унарного повышения должен быть int; этому условию соответствуют byte, short, char, int и оболочки с подходящей распаковкой. Индексы типов long и double недопустимы.

Нулевая длина допустима. Отрицательный размер вызывает NegativeArraySizeException; индекс вне [0, length) — ArrayIndexOutOfBoundsException; доступ через null — NullPointerException; запись несовместимого объекта — ArrayStoreException. Создание массива может завершиться ошибкой из-за нехватки памяти.

new String[2] создаёт массив ссылок, не строки. int[][] — массив массивов: длины строк могут различаться, строки могут быть null. Присваивание a = b копирует ссылку. clone() создаёт новый внешний массив и копирует значения компонентов, включая ссылки на вложенные объекты.

6.2 Методы Arrays

Методы Arrays перегружены для разных примитивных и ссылочных типов; диапазонные формы принимают границы обрабатываемой части массива.

Сигнатура Результат и условия
static String toString(int[] a) Строка вроде [5, 7]; для null строка "null"
static String deepToString(Object[] a) Представление вложенного содержимого, включая примитивные массивы
static boolean equals(int[] a, int[] b) Равные длины и компоненты; два null равны
static boolean deepEquals(Object[] a, Object[] b) Равенство вложенного содержимого по правилам API
static int[] copyOf(int[] a, int newLength) Новый массив; при увеличении добавляются нули
static <T> T[] copyOf(T[] original, int newLength) Новый внешний массив того же фактического класса; добавляются null
static int[] copyOfRange(int[] a, int from, int to) Новый диапазон [from, to); to может превышать длину с добавлением нулей
static void fill(int[] a, int value) Изменяет все компоненты
static void sort(int[] a) Сортирует по возрастанию на месте
static int binarySearch(int[] a, int key) Индекс совпадения либо -(insertionPoint)-1; требуется сортировка по возрастанию
static int compare(int[] a, int[] b) Лексикографическое сравнение; знак определяет порядок, модуль не универсален

Обычные диапазонные перегрузки используют [fromIndex, toIndex), проверяют порядок и границы. Для copyOf отрицательная новая длина вызывает NegativeArraySizeException.

Для указанного copyOfRange(int[] a, int from, int to) требуются a != null, 0 <= from <= a.length и from <= to. Новый массив имеет длину to - from; to может превышать a.length, а недостающие компоненты заполняются нулями. При from == a.length допустимы как пустой результат, так и новый массив нулей.

Нарушение для copyOfRange Исключение
from < 0 или from > a.length ArrayIndexOutOfBoundsException
from > to IllegalArgumentException
a == null NullPointerException

Контракт copyOfRange не задаёт приоритет исключений при одновременном нарушении нескольких предусловий. Методы, требующие сам массив для обработки, обычно не принимают null; равенство и строковые представления имеют указанные особые правила.

binarySearch не гарантирует первое совпадение при повторениях. Для неотсортированного массива результат не определён контрактом поиска. Нельзя использовать отрицательный результат как индекс; точка вставки получается -result - 1.

6.3 Копирование диапазона

Метод класса System: static void arraycopy(Object src, int srcPos, Object dst, int dstPos, int length). Приёмник уже существует. Вызов копирует length компонентов из диапазона с началом srcPos в диапазон с началом dstPos:

int[] values = {5, 7, 4, 0};
System.arraycopy(values, 0, values, 1, 3);
System.out.println(java.util.Arrays.toString(values)); // [5, 5, 7, 4]

Диапазоны перекрываются. Результат сохраняет значения исходного диапазона на момент копирования; последовательный цикл записи слева направо затёр бы ещё не скопированные значения и получил [5, 5, 5, 5].

Метод возвращает void. При копировании проверяются совместимость типов, null, позиции и длина. При несовместимости ссылочных компонентов допустима частичная запись до первого неподходящего элемента; уже перенесённые значения сохраняются. Для создания независимой копии ссылочных объектов недостаточно перенести их ссылки. [57]

Arrays.asList(T... a) возвращает список фиксированного размера, связанный с массивом ссылок; set меняет соответствующий компонент, add и remove не поддерживаются. Arrays.asList(intArray) возвращает список с единственным элементом — самим массивом int[]: Глава 18.

6.4 Arrays.copyOf для ссылочных компонентов

Сигнатура: public static <T> T[] copyOf(T[] original, int newLength). Обозначение T связывает тип компонентов входа и результата; для String[] здесь получается String[]. Для исходного массива строк:

String[] source = {"Ada", "Lin"};
String[] grown = java.util.Arrays.copyOf(source, 3);
grown[0] = "Grace";
System.out.println(java.util.Arrays.toString(source)); // [Ada, Lin]
System.out.println(java.util.Arrays.toString(grown));  // [Grace, Lin, null]
System.out.println(source == grown);                  // false

Результат имеет заданную длину. Общий диапазон содержит копии ссылочных значений; хвост при увеличении содержит null. Уменьшение до 1 оставило бы только первый компонент, длина 0 дала бы существующий пустой массив. Исходник не меняется. Новый массив содержит скопированные ссылки; доступные по ним изменяемые объекты остаются общими.

Фактический класс массива сохраняется и при обращении через переменную более общего типа:

Object[] source = new String[]{"Ada"};
Object[] grown = java.util.Arrays.copyOf(source, 2);
System.out.println(grown.getClass() == String[].class); // true
// grown[1] = 42; // ArrayStoreException при выполнении

Тип переменной Object[] допускает такую запись при компиляции, но реальный результат остаётся массивом строк. Отрицательная newLength даёт NegativeArraySizeException, original == null — NullPointerException. Проверка null хвоста остаётся ответственностью последующего алгоритма. Arrays Java 25, copyOf.

6.5 Устойчивость сортировки строк массива

Для массива объектов Arrays.sort гарантирует устойчивую сортировку: элементы, сравнение которых даёт 0, сохраняют взаимный исходный порядок. Форма с выбранным правилом — public static <T> void sort(T[] a, Comparator<? super T> c); Comparator задаёт сравнение двух элементов, знак его результата выбирает порядок. При сортировке матрицы элементом внешнего массива служит строка int[]: правило сравнения вычисляет её ключ, затем алгоритм переставляет строки целиком, сохраняя порядок чисел внутри каждой строки. Прямой Arrays.sort(matrix) без правила сравнения не превращает массивы int[] в естественно сравнимые значения. Arrays Java 25, sort.

Если алгоритм переставляет строки только соседними обменами и обмен выполняется при строго большем левом ключе, равная пара не пересекается. При обмене по >= возможна перестановка равных строк. Для ключей 2(A), 2(B), 1(C) устойчивый результат — 1(C), 2(A), 2(B); подписи обозначают исходные разные строки. Результат 1(C), 2(B), 2(A) упорядочен по ключу. Исходный порядок равных строк в нём изменён.

6.6 Форма и копирование матрицы

matrix.clone() копирует внешний массив. Для int[][] его компоненты — ссылки на строки; запись copy[i][j] достигает прежнего массива int[]. Копирование каждой существующей строки создаёт независимые числовые компоненты. Отдельно определяется, нужно ли сохранять общую строку, встречающуюся в нескольких позициях: Глубина копирования.

У существующего непустого прямоугольного массива число столбцов равно matrix[0].length. У внешнего массива длины ноль строк нет; приложение, различающее 0×3 и 0×5, хранит число столбцов отдельно. Объяснение: Прямоугольная матрица и размеры.
