# Примеры интерфейсов

Примеры дополняют главу об интерфейсах и статью справочника.
Команды выполняются из этого каталога с JDK 25.

## Общий тип и композиция

В `course/examples/dispatch/` расположены отдельные исходники пакета
`course.examples.dispatch`. `Sender.java` содержит расширенное объявление
интерфейса: `send`, `sendAll`, фабрику `console` и методы с закрытыми
помощниками. Комплект также содержит реализации отправки в консоль
и буфер, напоминание, обёртку с префиксом и счётчик отправок.

```bash
javac --release 25 -encoding UTF-8 -d out course/examples/dispatch/*.java
java -cp out course.examples.dispatch.SenderDemo
```

Ожидаемый вывод:

```text
A
B
Return: Java
Return: C++
[library] Return: Java
B:A:X
2
A
[notice] A
[warning] B
```

Первые строки получены двумя реализациями `Sender`. Затем два напоминания
используют один буфер. Следующие строки показывают отдельную обёртку
и порядок двух вложенных префиксов. Число `2` — количество успешных
отправок через `CountingSender`. Строка `A` после числа остаётся
после отказа `sendAll` на втором элементе `null`. Последние строки
получены методами, использующими закрытые помощники интерфейса.

У `CountingSender` число успешных вызовов в опыте помещается в `int`.
Обычное увеличение за пределом `Integer.MAX_VALUE` переполнило бы счётчик.

## Отправка внутри класса

```bash
java ConsoleReminderDemo.java
```

Вывод — `Return: Java`. `ConsoleReminder` строит текст и вызывает
свой защищённый метод отправки.

## Наследование тел

```bash
java DefaultConflictDemo.java
```

Ожидаемые строки:

```text
AB
detail
base
completed
```

`Both` явно сочетает два независимых тела. `Detailed` получает
более конкретное интерфейсное тело, `FromClass` — метод суперкласса.
`Completed` реализует абстрактную операцию суперкласса.
В конце файла в комментариях приведены отдельные недопустимые
объявления. Если исследуете диагностику, включайте по одному:
конфликт двух тел, конкретный класс без реализации абстрактного
метода и запрещённый `default toString()`.

## Формы интерфейсных типов

```bash
java InterfaceApiDemo.java
```

Вывод:

```text
Java
100
9
Java
```

`Storage` объединяет чтение и запись одного объекта. `Limits` предоставляет
числовую константу, `SharedData` — общий массив с неизменяемой ссылкой
и изменяемыми компонентами. `Source<String>` задаёт тип результата
лямбда-выражения.
