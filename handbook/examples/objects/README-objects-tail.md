# Опыты с передачей ссылок и состоянием объектов

Java-примеры рассчитаны на JDK 25. Каждый каталог собирается отдельно:
в опытах используются самостоятельные классы с совпадающими именами.
Команды выполняются из указанного каталога. Вывод приведён в комментариях
рядом с соответствующими действиями.

`lecture-entry/ObjectsTailDemo.java` использует начальный `Book` без
объявленного конструктора. `theory-entry/ObjectsTailDemo.java` использует
вариант с конструктором `Book(String)`. Каждому опыту нужен свой
`Book.java`, находящийся рядом с программой. В каталоге выбранного опыта
выполните:

```bash
javac Book.java ObjectsTailDemo.java
java ObjectsTailDemo
```

Первый опыт прослеживает изменение общей книги, переназначение параметра,
копирование полей и сохранение доступа по другой ссылке. Второй добавляет
возврат ссылки, проверки `null` и самостоятельный массив меток.
Передаваемые в операции выдачи и копирования книги существуют; массивы
меток в опыте имеют два элемента.

В `lecture-details` находятся бронирование с сохранением состояния после
отказа, порядок инициализаторов, вызовы методов и пролог конструктора:

```bash
javac LectureDetailsDemo.java
java LectureDetailsDemo
```

Пример с `Child` требует Java 25: проверка аргумента выполняется до
`super(value)`. Для отрицательного аргумента конструктор `Parent`
не вызывается. У `Trace` вывод состоит из `field`, `block: 7`
и `constructor: 7`.

В `collections` находятся общие метки двух книг, снимок списка гостей
и представление его текущего состава:

```bash
javac CollectionsCopyDemo.java
java CollectionsCopyDemo
```

Список гостей и все имена в этом опыте ненулевые. `List.copyOf` отвергает
`null` среди элементов; прямой `add` через снимок или представление
бросает `UnsupportedOperationException`. Изменение через владельца
списка наблюдается в представлении и сохраняет состав прежнего снимка.

В каталоге `kotlin` файл `TitleLengths.kt` содержит функции с ненулевым
и допускающим отсутствие типом параметра. При установленном компиляторе
Kotlin выполните:

```bash
kotlinc TitleLengths.kt -include-runtime -d title-lengths.jar
java -jar title-lengths.jar
```

Результат — `4`, затем `null`.
