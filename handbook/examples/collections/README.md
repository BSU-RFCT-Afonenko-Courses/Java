# Опыты с равенством, порядком и коллекциями

Программы показывают отдельные изменения состояния. Перед запуском выпишите
прогноз вывода, затем сопоставьте его с результатом и найдите операцию,
которая изменила состав или объект элемента. Нужен JDK 25.

## Компиляция

Из каталога с этим README выполните:

```bash
javac --release 25 -encoding UTF-8 -d out StudentId.java grade/Student.java course/examples/objects/Book.java ReportOrder.java EqualityDemo.java MutableKeyDemo.java OrderingDemo.java ListDemo.java IteratorDemo.java MapDemo.java SnapshotsDemo.java ViewsDemo.java QueueDemo.java SetDemo.java ContainerEqualityDemo.java
```

`StudentId` — обычный неизменяемый класс с равенством по строке кода.
`grade.Student` содержит код, имя и балл: конструктор удаляет краевые пробелы
из кода и имени, отвергает пустые значения, разделители `;`, `\n`, `\r`
и балл вне `0..100`. Изменение балла представляют созданием нового объекта.

`course.examples.objects.Book` — готовый класс книги. Название не должно
быть `null` или пустым по `isBlank`; нарушение даёт `IllegalArgumentException`.
Новая книга доступна. `borrow()` меняет признак выдачи; повторный вызов
бросает `IllegalStateException` и сохраняет состояние. Пакеты этих двух
типов сохраняются при копировании исходников.

## Идентичность, ключ и версия данных

```bash
java -cp out EqualityDemo
```

Ожидаемый вывод:

```text
false
true
true
true
false
1
true
true
false
false
80
1
95
```

Первые три строки различают одинаковые символы и общий строковый объект.
Четыре следующие показывают добавление и поиск равных идентификаторов.
`Aa` и `BB` имеют одинаковые хеши и разные значения. Две версии студента
с разным баллом различаются по `equals`; запись второй версии под прежним
кодом заменяет значение карты и возвращает прежнюю версию с баллом 80.

## Изменяемый ключ

```bash
java -cp out MutableKeyDemo
```

Для реализации `HashMap` из OpenJDK 25 ожидается:

```text
null
null
1
запись
запись
```

При добавлении узел сохранил хеш 1. После изменения `code` поиск получает
хеш 2 и не находит прежний узел, хотя размер равен 1 и обход видит запись.
Договор `Map` не определяет поведение при таком изменении ключа; это опыт
с конкретной реализацией, объясняющий причину запрета. В независимой второй
части запись удаляется **до** изменения ключа и добавляется заново.

## Порядок списка и уникальность множества

```bash
java -cp out OrderingDemo
```

Ожидаемый вывод:

```text
s19
s18
s17
true
false
true
false
1
s17
s18
s19
0
false
```

Стабильная сортировка по баллу сохраняет исходный порядок `s18`, `s17`
при равных баллах. `TreeSet` считает эти объекты совпадающими по тому же
сравнению; `contains(b)` истинно, хотя сохранённый `a` не равен `b`.
`ReportOrder` сортирует по убыванию балла, затем по коду. Последние две
строки показывают его границу: разные имена при одном коде и балле дают
ноль сравнения и `false` у `equals`. Для множества полных значений порядок
нужно согласовать со всеми компонентами равенства.

## Позиции и тип элемента

```bash
java -cp out ListDemo
```

Ожидаемый вывод:

```text
20
true
[10]
10
[5, 7]
0
[2, 3, 0.5]
IndexOutOfBoundsException
```

Первое удаление получает индекс, второе — объект значения. `set` возвращает
прежний элемент; последующая вставка сдвигает его. Начальная вместимость 100
создаёт список размера 0. `addAll` читает `Integer` как подтип `Number`.

Отдельный файл предназначен для отказа компиляции:

```bash
javac --release 25 -encoding UTF-8 -d out rejected/WrongElement.java
```

Команда должна завершиться с ненулевым кодом: аргумент `25` нельзя передать
в `add(String)` списка `List<String>`. Точный текст диагностики зависит
от локализации и версии компилятора. В общую команду этот файл не включён.

## Удаление при обходе

```bash
java -cp out IteratorDemo
```

Ожидаемый вывод:

```text
IllegalStateException
[Ada, Lin]
NoSuchElementException
```

Удаление до `next` нарушает последовательность вызовов. Затем итератор
удаляет только уже выданные пустые строки; `next` после исчерпания
отвергается. Изменение списка посторонним путём здесь не используется:
обнаружение такого нарушения по принципу fail-fast не гарантировано.

## Значения и представления карты

```bash
java -cp out MapDemo
```

Ожидаемый вывод:

```text
90
1
95
true
null
0
NullPointerException
[a, b, c]
[10, 10, 20]
false
b=10
c=20
UnsupportedOperationException
```

`getOrDefault` различает отсутствие отображения и сохранённый `null`.
Распаковка сохранённого `null` в `int` вызывает `NullPointerException`.
Живые представления другой карты видят добавленную пару; удаление ключа через представление удаляет
пару из карты. Порядок печати здесь задан `LinkedHashMap`.

## Составы списков и общая книга

```bash
java -cp out SnapshotsDemo
```

Ожидаемый вывод:

```text
2/2/2/1/1
true
true
true
true
true
2/0
UnsupportedOperationException
UnsupportedOperationException
NullPointerException
0/1
```

Первые размеры относятся к основе, её псевдониму, живому представлению,
изменяемой копии и снимку. Все содержат одну и ту же первую книгу: её выдача
видна через каждую ссылку. Очистка копии сохраняет состав основы.
Представление отвергает `add`, снимок — `set`, а `List.copyOf` отвергает
элемент `null`. Последняя пара размеров показывает защиту состава
от последующего изменения первоначального списка клиента.

## Диапазон, обратный просмотр и массив

```bash
java -cp out ViewsDemo
```

Ожидаемый вывод:

```text
[a, B, c]
[a]
[z, a]
[Ann, Lin]
[Ann, Eva]
UnsupportedOperationException
```

`subList` изменяет основу. Добавление в конец обратного представления
попадает в начало основы. `Arrays.asList` связывает замены элементов
с исходным массивом в обе стороны, сохраняя фиксированный размер.
После стороннего структурного изменения основы прежний `subList`
использовать с расчётом на определённый результат нельзя.

## Очередь, стек и приоритет

```bash
java -cp out QueueDemo
```

Ожидаемый вывод:

```text
Ada
Lin
null
NoSuchElementException
Lin
Ada
NullPointerException
1
1
2
3
```

В очереди FIFO элементы добавляют в хвост и извлекают из головы. Стек
добавляет и извлекает с одного конца. `offer(null)` у `ArrayDeque` бросает
исключение. Последние четыре строки получены последовательными `poll`
из `PriorityQueue`; обход её итератором не обещает такой порядок.

## Состав, порядок и соседи множества

```bash
java -cp out SetDemo
```

Ожидаемый вывод:

```text
2
[b, a]
[a, b]
true
true
true
true
1
IllegalArgumentException
20
40
null
```

Первые три строки показывают размер `HashSet`, порядок первого добавления
в `LinkedHashSet` и естественный порядок `TreeSet`. Результаты объединения
и пересечения сравниваются по составу; печать
`HashSet` не используется как обещание порядка. `Set.copyOf` оставляет
одного представителя повторов, `Set.of` отвергает повтор. Последние три
строки показывают `floor`, `ceiling` и отсутствие меньшего соседа.

## Равенство контейнеров

```bash
java -cp out ContainerEqualityDemo
```

Ожидаемый вывод:

```text
true
false
true
true
false
```

Список сравнивает последовательность независимо от реализации, множество —
состав, карта — пары. У `ArrayDeque` унаследовано равенство по идентичности.
