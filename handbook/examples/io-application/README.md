# Файловые опыты и журнал поставок

`IoDemo` показывает путь и несколько способов чтения. `BlockReadDemo`
различает размер буфера и число новых байтов. Приложение `deliveries.Main`
суммирует поставки и сохраняет диагностику отвергнутых строк.
Для команд нужен установленный JDK 25. Выполняйте их из этого каталога.

## Чтение файла

```bash
javac --release 25 -encoding UTF-8 -d out IoDemo.java BlockReadDemo.java
java -cp out IoDemo path lines.txt
java -cp out IoDemo bytes bytes.bin
java -cp out IoDemo lines lines.txt
java -cp out IoDemo count lines.txt
java -cp out IoDemo text names.txt
java -cp out BlockReadDemo
```

Первый опыт печатает `false` и абсолютный адрес `lines.txt` от рабочего
каталога процесса; он не открывает файл. Байтовый опыт печатает 0 и 255.
Построчное чтение даёт:

```text
1: [first]
2: []
3: [last]
```

В `lines.txt` два LF и нет разделителя после `last`. `lines-crlf.txt`
содержит те же строки с CRLF; результат построчного чтения совпадает.
Подсчёт непустых строк даёт 2, чтение `names.txt` — `Ада`.
`BlockReadDemo` печатает:

```text
n = 4, буфер = [10, 20, 30, 40]
новые байты = [10, 20, 30, 40]
n = 1, буфер = [50, 20, 30, 40]
новые байты = [50]
конец: -1
```

Источник этого опыта — `ByteArrayInputStream` с пятью байтами. Он даёт
воспроизводимое деление на порции. Файловый источник вправе вернуть
меньшую порцию; алгоритм использует фактическое число в каждой итерации.

`malformed-utf8.bin` содержит байты `C3 28`, недопустимые вместе в UTF-8.
Вызов `IoDemo text malformed-utf8.bin` завершится через `IOException`;
в `IoDemo count malformed-utf8.bin` отказ чтения оборачивается в
`UncheckedIOException`. У `IoDemo.main` объявлен `throws IOException`:
этот демонстрационный клиент оставляет печать трассировки среде исполнения.
В приложении поставок ниже те же отказы сопровождаются короткими
сообщениями и кодами завершения.

## Сборка приложения поставок

```bash
javac --release 25 -encoding UTF-8 -d out src/main/java/deliveries/*.java
jar --create --file deliveries.jar --main-class deliveries.Main -C out deliveries
java -jar deliveries.jar input.txt
```

Пакет `deliveries` содержит шесть исходных файлов. JAR получает их классы
и имя точки входа. Команда принимает один аргумент — путь UTF-8-файла.
Значимая строка имеет вид `товар;количество`, без экранирования;
краевые пробельные символы полей удаляются через `strip`.
Название непустое, количество — положительный `long`.
Пустые и пробельные строки пропускаются с сохранением физического
номера. Повтор товара увеличивает его сумму, регистр названия значим.

Для `input.txt` stdout содержит:

```text
тетрадь;7
ручка;2
альбом;1
```

Stderr содержит `строка 4: количество: нужно целое в диапазоне long`.
Код завершения — 3. Для POSIX-оболочки код последней команды доступен
как `$?`, для PowerShell — `$LASTEXITCODE`. Перенаправления сохраняют
оба канала отдельно:

```bash
java -jar deliveries.jar input.txt > report.txt 2> problems.txt
```

| Вход | Ожидаемый stdout | Ожидаемая диагностика | Код |
|---|---|---|---|
| `input-ok.txt` | `тетрадь;7`, `ручка;7`, `альбом;1` | Пусто | 0 |
| `empty.txt` | Пусто | Пусто | 0 |
| `input-blank-line.txt` | `ручка;5` | Ошибка количества строки 3 | 3 |
| `input-normalized.txt` | `ручка;5`, `Ручка;1` | Пусто | 0 |
| `input-overflow.txt` | `товар;9223372036854775807` | Переполнение суммы в строке 2 | 3 |
| `malformed-utf8.bin` | Пусто | Ошибка чтения | 4 |
| Отсутствующий путь | Пусто | Ошибка чтения | 4 |
| Запуск без аргумента | Пусто | Использование команды | 2 |

Порядок строк отчёта определяется первым принятым появлением товара.
При неверной строке прежняя сумма сохраняется. При отказе открытия,
чтения, декодирования или закрытия готовый результат не возвращается,
поэтому печать отчёта не начинается. Отказ stdout или stderr даёт код 4;
уже переданные байты могут остаться у получателя. Системные потоки
приложение оставляет открытыми.

Для запуска из другого каталога передайте реальные абсолютные пути:

```bash
java -jar /absolute/path/io-application/deliveries.jar "/absolute/path/io-application/input.txt"
```

Если имя собственного файла содержит пробел, кавычки позволяют передать
путь одним аргументом. Относительный путь, созданный через `Path.of`,
разрешается от рабочего каталога процесса, даже когда JAR находится
в другом месте.
