# Наследование и выбор методов

Программы воспроизводят опыты с подтипами, конструированием,
переопределением и композицией из теории и справочника. Начальные
данные заданы в `main`; ввод с клавиатуры и аргументы не требуются.

## Запуск

Нужен JDK 25: примеры конструирования используют пролог перед `super(...)`.
Сохраните выбранный `.java`-файл и выполните команду из его каталога:

```bash
java DocumentDemo.java
```

Каждый файл в этом каталоге запускается самостоятельно. Его вспомогательные
классы объявлены внутри класса запуска. Для предварительной компиляции
основных программ и запуска сохранённого класса:

```bash
javac --release 25 -encoding UTF-8 -d out *.java
java -cp out DocumentDemo
```

Файлы `rejected/` предназначены для отдельных опытов с ошибками компиляции.

## Документы и статический тип

`DocumentDemo` создаёт `Document("Guide")` и
`TextDocument("Notes", 120)`. Переменные `text` и `value` хранят
ссылку на один текстовый документ и имеют разные статические типы.
Вывод:

```text
Guide
Notes: 120 chars
Document overload
Text overload
Notes: 120 chars
Notes: 120 chars
120
true
16
NullPointerException
Empty: 0 chars
```

Первые строки получены общим методом `print(Document)`. Две перегрузки
`kind` выбираются по типам аргументов. Вызовы `summary()` на том же объекте
выполняют переопределение `TextDocument`. Проверка `instanceof` открывает
доступ к `characters()` и сохраняет идентичность объекта.

Значение `16` — длина строки `Notes: 120 chars`. `SilentDocument`
возвращает `null`, поэтому вызов `length()` завершается исключением
`NullPointerException`; обработчик печатает имя этого исключения.
Последний документ создан одноаргументным конструктором,
делегирующим `this(title, 0)`.

## Порядок создания

```bash
java ConstructorOrderDemo.java
```

```text
prologue
parent: 3
field
epilogue: 7
отказ
```

`new Child(3)` выполняет пролог, конструктор `Parent`, инициализатор
`marker` и эпилог. `new Child(-1)` бросает исключение при проверке
параметра; второе создание не печатает ни одной строки из конструкторов.
Строку `отказ` печатает обработчик в `main`.

## Связывание и подстановка

Стрелки в столбце вывода разделяют последовательные строки.

| Команда | Вывод | Причина |
|---|---|---|
| `java BindingDemo.java` | `base field` → `child field` → `child method` → `child method` → `base static` → `child static` → `base method` | Поля выбираются по статическим типам; приведение к `Base` сохраняет динамический вызов; `super.label()` выбирает базовое тело |
| `java OverrideRulesDemo.java` | `120` → `true` | Ковариантный `load()` возвращает тот же `TextDocument` при вызовах через конкретный и базовый типы |
| `java SubstitutionDemo.java` | `28` → `49` → `7 4` → `7 7` | `setWidth(7)` у прямоугольника сохраняет высоту 4; подкласс квадрата изменяет её до 7 |
| `java ShapeDemo.java` | `area=9.0` → `Infinity` | Готовый `report()` вызывает формулу квадрата; сторона `1e200` конечна, её квадрат выходит за диапазон конечного `double` |
| `java InheritanceApiDemo.java` | `Item: Java` → `4` → `ClassCastException` → `false` → `null` → `3` → `true` | Абстрактная операция, удачная проверка строки, несовместимое приведение, обработка `null`, раннее присваивание поля и экземпляр разрешённого варианта `Ok` |

В `OverrideRulesDemo` метод `main` объявляет `throws IOException`
из-за вызова через `DocumentSource`. Сам `MemorySource.load()`
возвращает заранее сохранённый документ и не объявляет проверяемых
исключений. Если присвоить `source.load()` переменной `TextDocument`
без приведения, компилятор отвергнет присваивание: статический тип
этого выражения — `Document`.

## Вызов из базового конструктора

```bash
java ConstructionRiskDemo.java
```

```text
0
7
7
7
0
7
```

У `ChildState` вызов `show()` из базового конструктора читает `value`
до инициализатора, а вызов после `new` — после него. У `EarlyChild`
присваивание выполнено в прологе до `super()`, поэтому оба чтения дают 7. У `FinalChild`
поле `final` присваивается в эпилоге; раннее чтение снова даёт 0.

## Композиция

```bash
java CompositionDemo.java
```

```text
3
6
3
3
отказ
3
3
```

Подкласс `CountingCounter` считает `add(3)` один раз на входе
и ещё три раза через переопределённый `increment()`. Его базовое
значение равно 3, а дополнительный счётчик равен 6.

У `CounterMeter` внутренний `Counter` — отдельный объект. Вызовы
`increment()` из его `add()` остаются внутри компонента,
поэтому оболочка учитывает добавление один раз. Отрицательное
приращение вызывает отказ до изменения обоих счётчиков.
Значения хранятся как `int`; суммы за пределами его диапазона
подчиняются целочисленному переполнению.

## Ошибки объявлений

Каждая команда должна завершиться ошибкой компиляции. Текст сообщения
зависит от языка диагностики JDK; существенна причина отказа.

| Команда | Причина |
|---|---|
| `javac --release 25 -encoding UTF-8 -d out/rejected rejected/WrongParameter.java` | `@Override` поставлен на перегрузку с параметром `TextDocument` вместо `Document` |
| `javac --release 25 -encoding UTF-8 -d out/rejected rejected/ReducedAccess.java` | Переопределение уменьшает доступ с `protected` до доступа внутри пакета |
| `javac --release 25 -encoding UTF-8 -d out/rejected rejected/WiderThrows.java` | Проверяемое `Exception` шире разрешённого `IOException` |
| `javac --release 25 -encoding UTF-8 -d out/rejected rejected/EarlyRead.java` | Поле текущего экземпляра читается в прологе перед `super(...)` |
| `javac --release 25 -encoding UTF-8 -d out/rejected rejected/FinalOverride.java` | Переопределяется метод, объявленный как `final` |
