# Методы, массивы и текст: полные примеры

Программы показывают изменение локальных переменных и общих объектов,
копирование массивов и границы текстовых операций. Все входные данные
заданы в `main`; команды не требуют аргументов и стандартного ввода.

## Сборка и запуск

В каталоге примеров с JDK 25:

```bash
javac --release 25 -encoding UTF-8 -d out *.java
java -cp out MethodValues
java -cp out MethodCalls
java -cp out ArrayStructure
java -cp out ArrayAlgorithms
java -cp out TextValues
java -cp out WordRanges
```

Каждый файл содержит собственный класс запуска. Можно скомпилировать
отдельный файл, заменив `*.java` его именем.

## Аргумент и результат

[MethodValues.java](MethodValues.java) получает следующий вывод:

```text
Среднее: 2.5
После addPage: 5
После присваивания результата: 6
После записи в компонент: [9, 7]
После присваивания параметру: [9, 7]
После возврата новой ссылки: [1, 2]
Источник: [9, 7]
Отдельные компоненты: [100, 7]
Через final-параметр: [11, 7]
С поправкой: [6, 8]
Сохранённый вход: [5, 7]
После переполнения: [5, 2147483647]
```

Методы `correctFirst`, `correctFinal` требуют непустого массива;
`firstTwo` — массива длины хотя бы два. Все массивы должны существовать.
`withBonus` записывает числа в новый массив: переполнение второго результата
оставляет весь исходный массив прежним. Исключение перехватывается
в демонстрации, чтобы напечатать его состояние.

[MethodCalls.java](MethodCalls.java) выводит:

```text
Для int: long
Для Integer: Integer
Пустая сумма: 0
Два значения: 12
Готовый массив: 12
После stamp: [9, 7]
Обратный отсчёт:
3
2
1
Вызов с нулём:
```

Вызов `stamp(pages)` передаёт готовый массив. `countDown` определён
для неотрицательного числа; большой отсчёт требует цикла, если глубина
рекурсии превышает доступные ресурсы стека.

## Объекты массивов

[ArrayStructure.java](ArrayStructure.java) выводит:

```text
Общий массив: [9, 7]
Копия чисел: [100, 7]
После записи в строку: [[9, 7], [4]]
После замены ссылки: [[9, 7], [4]]
Внешняя копия: [[1, 2], [4]]
Скопированные строки: [[9, 7], [20]]
Прежние строки: [[9, 7], [4]]
Общая исходная строка: true
Общая строка копии: false
0:0=5
0:1=7
1:0=4
Отсутствующая строка: true
Пустая строка: 0
Количество строк: 0
```

Рваный массив содержит существующие строки разной длины. У `new int[2][]`
компоненты внешнего массива равны `null`; у `new int[2][0]` они ссылаются
на пустые строки. Из состояния `new int[0][3]` доступна только нулевая
длина внешнего массива: строки длины три не создавались.

[ArrayAlgorithms.java](ArrayAlgorithms.java) выводит:

```text
Положительные: [5, 7]
Исходник: [5, -2, 0, 7]
Без положительных: []
Пустой вход: []
Транспонирование: [[1, 4], [2, 5], [3, 6]]
Исходная матрица: [[1, 2, 3], [4, 5, 6]]
Перекрывающиеся диапазоны: [5, 5, 7, 4]
```

`positiveValues` принимает существующий массив любой длины.
`transpose` принимает существующий прямоугольный массив с хотя бы одной
существующей строкой. При нуле столбцов результат имеет ноль строк;
если приложению нужно его число столбцов, эту размерность следует хранить
отдельно. Проверка произвольной формы входа не входит в тело этого метода.

## Строковые значения и границы

[TextValues.java](TextValues.java) выводит:

```text
Новое значение: Java course
Сохранённая строка: Java
Одинаковая ссылка: false
Одинаковый текст: true
Длина UTF-16: 4
Кодовые точки: 3
0: 65
1: 128512
3: 66
Одна кодовая точка: 😀
До NFC: false
После NFC: true
Равенство е и ё после NFC: false
Буквальная точка: a-b
Точка в шаблоне: ---
Буквальная замена через шаблон: a$1b
Пустые поля: [a, , ]
Вставка: Ja-va
Накопитель: Java course
Полученная строка: Java
```

В `insertAt` обе строки должны существовать; индекс измеряется в единицах
UTF-16. Для произвольного Unicode границу вставки выбирают с учётом
суррогатных пар и нужной текстовой единицы.

[WordRanges.java](WordRanges.java) выводит:

```text
Java:0:4
код:6:9
Со скобками: [Java]2\t[код]!
Исходник: Java2\tкод!
Без слов: 123!
Пустой текст: <>
Слово в конце: [я], [код]
```

В последних строках печати табуляция показана как `\t`. В исходнике
и в результате `markWords` она остаётся одной табуляцией. Метод определяет
слово как последовательность латинских или русских букв с Ё/ё;
цифры и другие единицы сохраняет как разделители. Параметр `text`
должен ссылаться на существующую строку.
