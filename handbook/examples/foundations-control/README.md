# Примеры значений, выражений и управления

Файлы этого каталога воспроизводят опыты из теории и справочника. Для Java-примеров нужен JDK 25. Каждый файл верхнего уровня содержит самостоятельную программу без внешних библиотек. Сохраните нужный `.java` под указанным именем и выполняйте команды из каталога, где он лежит.

```bash
javac -encoding UTF-8 -d out ValueSemantics.java
java -cp out ValueSemantics
```

В других опытах замените `ValueSemantics` на имя выбранного класса. Параметр `-d out` создаёт каталог результата. После изменения исходника повторите `javac`.

| Исходник | Данные и ожидаемое наблюдение |
|---|---|
| `ValueSemantics.java` | Без ввода: `7 5`, `9 9 5`, `10`, `4`, затем коды `65`, `1071`, `55357`, `56898`, каждый на новой строке. Копия числа независима; две ссылки ведут к общему массиву; локальная переменная инициализируется при каждом входе в блок; эмодзи занимает две единицы UTF-16. |
| `NumericOperations.java` | Без ввода: `-1794967296`, `2500000000`, `3`, `3.5`, `-3`, `-1`, `-4`, `1`, `-2147483648`, `-128`, по строке. Приведение операнда должно предшествовать вычислению, а округление к нулю отличается от округления вниз. |
| `EvaluationOrder.java` | Без ввода: `32 3`, `false 0`, `false 1`, `false`. Приоритет умножения сохраняется, но левый операнд сложения вычисляется первым. Короткое замыкание пропускает изменение счётчика и деление на ноль. |
| `SwitchForms.java` | Без ввода: `Среднее`, `30`, `Выбор завершён`, `30`, `AB`, `B`, `C`, `10`, по строке. `yield` завершает выражение; `return` завершает метод; двоеточие допускает переход к следующей группе. |
| `LoopState.java` | Без ввода: `16`, `1`, `3`, `1:1`, `1:2`, `2:1`, `2:2`, по строке. Ноль имеет одну десятичную цифру; внутренний цикл начинается заново для каждого дня. |
| `CountArgument.java` | Аргумент `12`: строки `121` и `13`. Без аргументов: `Укажите количество страниц`. Первый аргумент при наличии должен быть допустимой десятичной записью `int`; дополнительные аргументы не используются. |
| `CountUnits.java` | UTF-8 во вводе до `#` или EOF. `AЯ#tail` даёт `2`, `AЯ🙂#` — `4`, пустой завершённый поток — `0`. |
| `ReadOne.java` | Одно чтение UTF-16: `Я` в UTF-8 даёт `Код UTF-16: 1071`; пустой завершённый поток — `Конец ввода`. |
| `ReadNumber.java` | Первый токен: `+17` даёт `17`, `abc` — `Не целое число: abc`, EOF — `Конец ввода`. |
| `ReadDecimal.java` | Первый токен с десятичной точкой: `7.5` даёт `8.5`, `NaN` — `Неконечное число`, `7,5` — `Не число: 7,5`. |

Для подачи точного ввода без добавленного перевода строки команды ниже используют `printf` оболочки POSIX (например, bash). Текст команды и терминал должны передавать UTF-8. В другой оболочке сохраните тот же текст в UTF-8-файл и перенаправьте его в стандартный ввод.

```bash
javac -encoding UTF-8 -d out CountUnits.java ReadOne.java ReadNumber.java ReadDecimal.java CountArgument.java
printf 'AЯ#tail' | java -cp out CountUnits
printf '' | java -cp out CountUnits
printf 'Я' | java -cp out ReadOne
printf '+17' | java -cp out ReadNumber
printf '7.5' | java -cp out ReadDecimal
java -cp out CountArgument 12
```

`printf ''` создаёт завершённый поток без данных. Ожидание клавиатуры без ввода не равнозначно EOF. Нажатие Enter добавляет окончание строки.

## Отдельные статические анализаторы

Подкаталог `python` содержит целый `pages.py` и `pyrightconfig.json`. Он сопоставляет выполнение Python с отдельной проверкой аннотаций. При выполнении файла выводятся `7` и `seven`; Pyright в строгом режиме сообщает несовместимое присваивание строки переменной с аннотацией `int`. Команды и версии приведены в разделе справочника «Python-аннотация и отдельный анализатор».

В `nullness/unsafe` и `nullness/safe` находятся два варианта `NullnessDemo.java`. Компилируйте их по отдельности: у них одно имя класса. Это примеры с внешней зависимостью от Checker Framework, которая в комплект не включена. `unsafe` при обычном запуске получает `NullPointerException`, а `safe` печатает `0`; анализатор должен отвергнуть опасное обращение первого варианта. Подготовка зависимостей и полная команда анализа приведены в разделе справочника «Java: аннотация отсутствия и анализатор».
