# Программирование на Java

Пробная редакция посвящена обобщённым типам. В ней подготовлен один связанный
комплект: теоретический раздел, лекция, лабораторная, практика и необходимые
статьи справочника. Остальное содержание представлено предметным оглавлением.

| Проект | Содержание |
|---|---|
| `theory/` | Тематическая книга из шести частей; полный раздел объединяет главы 14–15 об обобщениях |
| `lectures/` | Программа девяти лекций и полная лекция об обобщённых типах |
| `tasks/` | Оглавление заданий и одна лабораторная с текстовыми условиями |
| `practice/` | Оглавление практических занятий и ввод к лабораторной по обобщениям |
| `handbook/` | Параметры типов, wildcards, стирание, сравнение объектов и Java-инструменты |
| `bibliography/` | Общие библиографические записи и числовой стиль цитирования |

Портал `index.qmd` связывает пять проектов. Теория организована по предметным
темам; семестровый маршрут представлен программой лекций. System Practice
обозначен отдельным занятием в общем календаре.

## Сборка

```sh
quarto render . --profile student --fail-if-warnings
quarto render . --profile full --fail-if-warnings
```

Результаты размещаются в `_site-student/` и `_site-full/`. Java-примеры рассчитаны
на Java 25 без preview-возможностей. Исходная инфраструктура курса сохранена.

## Источники

Записи подключаются из `bibliography/books.bib`, `java.bib`, `languages.bib`
и `history.bib`. Источник имеет один ключ для всех проектов; страницы и разделы
уточняются в записи соответствующего фрагмента. Между учебными материалами используются QRC-ссылки.

`bibliography/numeric.csl` основан на стиле [IEEE](https://www.zotero.org/styles/ieee)
из установленного TeX Live; добавлена стабильная сортировка записей. Авторство
исходного стиля и лицензия CC BY-SA 3.0 сохранены внутри файла.

В каждой книге список находится в отдельной главе «Источники». Страницы и
разделы входят в библиографическую запись, поэтому в тексте остаются только
номера. Общий `nocite` в конфигурации книги перечисляет используемые записи и
согласует их номера между главами. В презентациях список вынесен на последний
прокручиваемый слайд средствами Quarto.
