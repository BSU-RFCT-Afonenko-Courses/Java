# Программирование на Java

Курс Java 25 без preview строится вокруг самостоятельной тематической книги.
Она объясняет значения, объекты, обобщения, коллекции, функции и приложение;
лекции выбирают связный рассказ, справочник даёт точные формы API, а практики
подводят к лабораторным.

| Проект | Содержание новой редакции |
|---|---|
| `theory/` | 23 главы в шести предметных частях |
| `lectures/` | 11 лекционных сценариев по 80 минут: план для репетиции |
| `handbook/` | 25 статей о языке, API и инструментах JDK |
| `practice/` | 10 основных и 3 добровольных резервных введения |
| `tasks/` | Канонический банк, 10 основных и 3 резервные лабораторные |
| `bibliography/` | Общие и тематические источники, отдельные локаторы заданий |

Портал `index.qmd` и индекс теории используют общую карту
`_includes/semester-map.qmd`. Календарь лекций не задаёт оглавление книги.
Текст нужен перед строковой лабораторной, короткий минимум checked-исключений —
перед обобщёнными контейнерами; обе подготовки явно отмечены в маршруте.

Теоретический план составляет 880 минут против исходных 720 (+22,22%),
при верхней границе 936. Основные лабораторные сохраняют ориентир 1935 минут:
восемь по 180, работа о полиморфизме 270 и работа о файлах 225.
Десять вводных практик по 30 минут дают отдельные 300 минут. Эти числа — оценки
для планирования, не измеренный темп. Резерв не увеличивает обязательную нагрузку.
System Practice отвечает за общие навыки оболочки, файлов и Git отдельно от Java.

Первые три лабораторные имеют публичные стартеры и примеры и отдельные закрытые
эталоны/проверки. PrairieLearn назначает 17 возможных вопросов в 14 обязательных
позициях 6/4/4; случайный вариант сохраняется при повторных отправках.
Остальные работы остаются ручными. Финальное приложение использует заготовку
`tasks/projects/gradeapp/`, единый Maven Wrapper маршрут и CLI
`grade.Main input threshold`; оно не добавляет автоматизированный вопрос.

## Авторство и структура

Перед правкой прочитайте [методические правила](docs/authoring-methodology.md) и
[договор структуры](docs/course-revision/structure-contract.md). Договор задаёт
новые ID, категории-теги, точные цели, владельцев файлов и общие примеры.
Технический исполнитель получает завершённый пакет; файл редактирует один
владелец в каждый момент. Новые ID заменяют прежние во всех текущих потребителях;
aliases, redirects и совместимость прежней разметки не создаются.

## Сборка и проверка

```sh
quarto render . --profile student --fail-if-warnings
quarto render . --profile full --fail-if-warnings
```

Результаты находятся в `_site-student/` и `_site-full/`. При недоступном
пользовательском кэше задайте `XDG_CACHE_HOME` на доступный временный каталог
в окружении команды. Для приёмки редакции выполняется свежая последовательность
student → full → student и проверка утечки закрытых материалов. Старая успешная
сборка PR13 не подтверждает новую редакцию. Промежуточные авторские пакеты до
согласования всех новых целей не являются готовой публикацией.

## Источники и связи

Библиографические ключи имеют префикс `bib-`, ссылки — `[@bib-…]`.
Локаторы страниц и разделов находятся в библиографических записях. Ключи общие
для пяти проектов, номера формирует Quarto/citeproc внутри каждой книги.
Каждая книга имеет одну страницу источников; презентация — заключительный слайд.
Списки `nocite` согласуются с используемыми записями. Изменения общего каталога
источников передаются одному владельцу конфигурации по договору структуры.

QRC связывает собственные материалы; библиография указывает источник знания.
Лекции ведут главным образом к теории, изредка к нужной команде справочника.
Практики и лабораторные связаны на портале и в собственных маршрутах.
Порядковые номера формирует Quarto, названия не содержат ручных «Л 1» и «Глава 3».

`bibliography/numeric.csl` основан на IEEE; авторство и CC BY-SA 3.0 сохранены
в файле. Условия доступа описаны в [документации источников](docs/sources.md),
поставка первых трёх работ — в [документации PrairieLearn](docs/prairielearn-labs.md).
