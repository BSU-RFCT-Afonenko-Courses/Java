# Программирование на Java

Курс получил оформление пятичастного [шаблона курса](https://github.com/Afonenko-Course-Tools/quarto-template-course): портал связывает теорию, задания, лекции, практику и справочник. Книги используют Cosmo, слайды — стандартную тему Reveal.js с навигацией курса. Предметные материалы Java и структура тем сохранены; разметка заданий согласована с текущим Core.

| Каталог | Содержание |
|---|---|
| `theory/` | Основная книга Java, прежде `book/` |
| `tasks/` | Исследовательские рефераты, задания и проекты, прежде `essay/` |
| `lectures/` | Отдельные презентации лекций со ссылками на материалы |
| `practice/` | Отдельные презентации практических занятий и самопроверки |
| `handbook/` | Прежние приложения книги: библиотека, инструменты и справочные материалы |
| `index.qmd` | Портал и переходы к пяти частям |

## Сборка

Нужны Quarto 1.11.5 и CUE v0.17.1; исполняемые Java-проекты требуют JDK 25 или новее. Расширения включены в репозиторий. Команды выполняются из корня курса:

```sh
quarto render . --profile student --fail-if-warnings
quarto render . --profile full --fail-if-warnings
quarto preview --profile student --no-watch-inputs --no-browser --port 4200
```

Результаты — `_site-full/` и `_site-student/`; публикуйте студенческий сайт. `subprojects: [theory, tasks, lectures, practice, handbook]` задаёт пять самостоятельных проектов Quarto. Корневая сборка запускает их штатный render, собирает текущие результаты и согласует ссылки и поиск. Core проверяет учебную модель, Download создаёт объявленные стартовые ZIP-архивы. Каждую часть можно собрать непосредственно из её каталога; например, `cd tasks && quarto render . --profile student`. Повторные сборки сохраняют кэши `.quarto` и `_freeze`; после ошибки исправьте исходник и повторите команду.

## Материалы и ссылки

Внутри книги используются ссылки Quarto `@sec-id`, между частями — `@theory:sec-id`, `@tasks:sec-id`, `@handbook:sec-id` и `@portal:sec-portal`. Все задания остаются в `tasks/`; лекции и практика ссылаются на их исходные условия. `reference-catalog.exports` корневого `_quarto.yml` задаёт явный публичный каталог глав.

В `lectures/` и `practice/` каждый QMD — самостоятельная презентация Reveal.js со своими слайдами и HTML-страницей. Исходники нумеруются: `01-intro.qmd`, `02-language.qmd` и так далее. Допустимы части `01a-intro.qmd` и `01b-cont.qmd`: они также открываются отдельно.

Раздел презентации начинается заголовком `##`; слайды внутри него — заголовками `###`. Текст под `##` остаётся на начальном слайде раздела. Если за `##` сразу следует `###`, раздел начинается заставкой. Название группы навигации берётся из заголовка, без дополнительного атрибута. Идентификаторы `{#sec-…}` сохраняют ссылки. Только для Reveal настроены `shift-heading-level-by: -1`, `slide-level: 2` и `navigation-mode: linear`: штатные H1/H2 определяют разделы и слайды, стрелки проходят их последовательно. В книге исходные уровни заголовков сохраняются.

Порядок презентаций задаётся явным списком `project.render` в `_quarto.yml` соответствующей части, например:

```yaml
project:
  type: default
  render:
    - 01a-intro.qmd
    - 01b-cont.qmd
    - 02-language.qmd
```

Главная страница содержит таблицу «План курса»: каждая тема связывает лекцию, практику, теорию, исследования и справочник. В ней представлены все лекции и практические занятия. Из каждой презентации можно вернуться к плану курса (`@portal:sec-course-plan`) или на главную страницу курса. При добавлении презентации укажите её в `project.render`, добавьте ID в `reference-catalog.exports` и ссылку на неё в таблицу `index.qmd`.

Таблица с обычными Markdown-ссылками помещается в стандартный контейнер Bootstrap `.table-responsive`, сохраняющий горизонтальную прокрутку на узком экране. Оформление таблицы задаётся темой Quarto Cosmo.

Канонический банк включён явно через `_metadata.yml` только в каталогах 60 исследовательских тем. У каждой банковской задачи есть собственные `difficulty` и положительное целое `time` в минутах. Метаданные `semester` и `difficulty` глав продолжают служить указателям, но не заменяют обязательные поля задач. Начальные оценки времени записаны в [реестре оценок](docs/prairielearn-time-estimates.json) и допускают авторскую корректировку.

Самостоятельные исследования имеют `statement-visibility="open"`, контрольные задачи — `restricted`. Core удаляет restricted условия, решения и ссылки назначений из student сайта; full сохраняет полный банк. Работы используют `.task-items`, их назначения по умолчанию required/individual. Профильные обёртки вокруг контрольных задач не нужны. Обычный дополнительный преподавательский текст может использовать нативные условия Quarto.

Открытая демонстрация Unicode находится вне банка: её обычные `exr`/`exm`/`sol`, пояснения и стартовые проекты сохраняют нативную публичную семантику. Банковские решения, если они добавляются, используют suffix-пару в том же QMD либо вложенную анонимную `.solution`; атрибут `for` к ним не применяется. ZIP выбирает только `student/`, исключая соседние reference/tests и результаты сборки. Исходники открытого Git доступны независимо от аудитории сайта.

PrairieLearn экспортирует явно выбранные вопросы отдельной командой. Наличие платформенных параметров у старого задания не означает готовности его проекта к автоматической проверке. [Текущая авторская модель](docs/current-authoring.md) описывает границы банка, решений, работ и публикации.

## Проверки

Проверки учебной модели выполняются расширениями при сборке. Core проверяет модель курса и контракты заданий, Reference Catalog разрешает межкнижные ссылки и проверяет экспорт целей, Download проверяет объявленные ресурсы и создаёт архивы. Реализация этих механизмов поставляется целыми пакетами расширений.

CI собирает student → full → student на Quarto 1.11.5/CUE 0.17.1; установленные текущие pre/post hooks владельцев проверяют учебную модель, назначения, ресурсы и межпроектные ссылки в каждом запуске. Источники пакетов и полный состав установленных файлов записаны в [UPSTREAM.md](UPSTREAM.md), `providers.json` и `installed-packages.json`; перемещения и адаптация разметки — в [карте переноса](docs/original-author-migration.md).
