# Программирование на Java

Курс объясняет Java в контексте программирования и IT: понятия языка,
устройство программ, причины принятых решений и их ограничения. Java 25
используется как LTS/JDK для проверки примеров без preview.

| Проект | Назначение |
|---|---|
| [Теория](theory/index.qmd) | Связная книга для самостоятельного чтения |
| [Лекции](lectures/index.qmd) | Устный рассказ с развивающимися примерами |
| [Справочник](handbook/index.qmd) | Точные правила, формы API и команды |
| [Практика](practice/index.qmd) | Введения к конкретным лабораторным |
| [Задания](tasks/index.qmd) | Канонические условия самостоятельной работы |

[Главная курса](index.qmd) связывает эти пять форм по темам.

## Работа над материалами

Начните с [рабочей документации](docs/README.md). Она ведёт к устойчивой
методике, принятому плану полной редакции и техническим инструкциям.
Пилот по обобщениям принят. Текущий этап — выполнение, значения и ссылки;
остальные части плана ожидают собственной редакции. Статус и пределы
проверок записаны в [журнале редакции](docs/full-revision-progress.md).

## Локальная сборка

Штатный маршрут из корня репозитория:

```sh
bash CI/render.sh
```

Сценарий выполняет сборки student → full → student с отказом при
предупреждениях. Результаты находятся в `_site-student/` и `_site-full/`.
Корневая сборка включает пять учебных проектов. Версии инструментов
закреплены в [CI/toolchain.json](CI/toolchain.json); подготовка расширений
описана в [UPSTREAM.md](UPSTREAM.md).

Фактические результаты и ограничения проверок текущей работы фиксируются
в [журнале редакции](docs/full-revision-progress.md); прежняя приёмка пилота
сохранена отдельно в [рабочей документации](docs/README.md).

## Доступ к учебным устройствам

Если преподаватель подключает внешнее учебное устройство, используйте
[инструкцию доступа](docs/student-device-certificates.md) или
[шаги для Windows](docs/student-windows-certificates.md). Точный адрес и
публичный сертификат выдаёт преподаватель; локальный запуск примеров Java
такого подключения не требует.
