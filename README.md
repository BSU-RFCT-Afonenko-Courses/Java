# Программирование на Java

Редакция первого семестра строится вокруг самостоятельной тематической книги.
Лекции выбирают из неё материал для рассказа; справочник фиксирует точные
правила и API; практики подводят к конкретным лабораторным работам.

| Проект | Содержание |
|---|---|
| `theory/` | 23 главы в шести тематических частях |
| `lectures/` | Девять лекций по 80 минут |
| `tasks/` | 127 условий, десять основных и три резервные лабораторные, 30 исследований |
| `practice/` | Введение в каждую из 13 работ |
| `handbook/` | 25 предметных статей о языке, API и инструментах JDK |
| `bibliography/` | Общие и тематические источники; отдельные каталоги заданий и исследований |

Портал `index.qmd` связывает пять проектов. В книге нет искусственного раздела
«Первый семестр»: семестровый маршрут задан программой лекций и лабораторных.
Оболочки, файлы и Git обозначены заглушками System Practice; собственная
семантика Java остаётся в этом курсе. Java-примеры используют Java 25 без preview.
Лабораторные содержат текстовые условия без стартовых проектов и автопроверки.

## Сборка

```sh
quarto render . --profile student --fail-if-warnings
quarto render . --profile full --fail-if-warnings
```

Результаты находятся в `_site-student/` и `_site-full/`. В среде с недоступным
каталогом пользовательского кэша можно задать `XDG_CACHE_HOME` на доступный
временный каталог при запуске Quarto. Инструменты и расширения курса в этой
содержательной редакции не меняются.

## Источники и связи

Все библиографические ключи имеют префикс `bib-`; в тексте используются ссылки
вида `[@bib-…]`. Страницы и разделы включены в запись источника. Ключи общие для
пяти проектов, номера внутри разных книг могут различаться. В каждой книге
есть одна страница «Источники», в презентациях — заключительный слайд.
`nocite` книги перечисляет используемые записи, чтобы номера совпадали между
главами и общей страницей. При добавлении источника нужно обновить этот список.

Сведения о книгах и документации хранятся в тематических `.bib`-файлах;
`bibliography/tasks/` и `bibliography/research/` содержат локаторы условий и
исследований. Между собственными материалами используются QRC-ссылки с новыми
идентификаторами; прежние цели и aliases не поддерживаются.

`bibliography/numeric.csl` основан на стиле IEEE; авторство и лицензия
CC BY-SA 3.0 сохранены в файле. Стиль задаёт стабильную сортировку записей.
