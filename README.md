# Программирование на Java

Курс получил оформление пятичастного [шаблона курса](https://github.com/Afonenko-Course-Tools/quarto-template-course): портал связывает теорию, задания, лекции, практику и справочник. Книги используют Cosmo, слайды — стандартную тему Reveal.js с навигацией курса. Предметные материалы Java, ID и учебная разметка сохранены.

| Каталог | Содержание |
|---|---|
| `theory/` | Основная книга Java, прежде `book/` |
| `tasks/` | Исследовательские рефераты, задания и проекты, прежде `essay/` |
| `lectures/` | Слайды обсуждения со ссылками на материалы |
| `practice/` | Слайды практической работы и самопроверки |
| `handbook/` | Прежние приложения книги: библиотека, инструменты и справочные материалы |
| `index.qmd` | Портал и переходы к пяти частям |

## Сборка

Нужны Quarto и CUE. Расширения включены в репозиторий. Команды выполняются из корня курса:

```sh
quarto render --profile full --fail-if-warnings
quarto render --profile student --fail-if-warnings
quarto run tests/check-preservation.ts
quarto run tests/check-publication.ts
quarto preview --profile student --no-browser --port 4200
```

Результаты — `_site-full/` и `_site-student/`; публикуйте студенческий сайт. Корневая сборка согласует пять частей и ссылки, проверяет учебную модель и создаёт выбранные стартовые ZIP-архивы.

## Материалы и ссылки

Внутри книги используются ссылки Quarto `@sec-id`, между частями — `@theory:sec-id`, `@tasks:sec-id`, `@handbook:sec-id` и `@portal:sec-portal`. Все задания остаются в `tasks/`; лекции и практика ссылаются на их исходные условия. `reference-catalog.exports` корневого `_quarto.yml` задаёт явный публичный каталог глав.

Профили сохраняют прежнюю видимость: контроль в `.when-full`, заметки оценивания и преподавательские архивы исключены из студенческого сайта и поиска. Открытая демонстрация Unicode, оба её объяснения и стартовые проекты доступны в обоих профилях. ZIP содержит выбранный `student/` без соседних `reference/`, `tests/` и результатов сборки. Исходники открытого Git-репозитория доступны независимо от профиля. PrairieLearn сохраняет прежнюю роль описания заданий; экспорт на платформу остаётся отдельной работой.

## Проверки

`tests/check-preservation.ts` сверяет с коммитом `c32d3f2` исходные QMD, ID, атрибуты учебных блоков, метаданные тем и неизменность Java-проектов и ресурсов. Ему нужна Git-история с этим коммитом. `tests/check-publication.ts` проверяет уже построенные оба профиля: пять частей, главы и возврат к порталу, экспорт, архивы, ссылки и якоря, поиск и изоляцию закрытого контроля.

CI сохраняет историю, проверяет авторский формат по прежней совместимой версии шаблона, собирает оба профиля на стабильном и предварительном Quarto и проверяет публикации. Версии Core, Presentation, Publisher, Reference Catalog, Download и PrairieLearn сохранены; добавлена только навигация слайдов. Источники пакетов записаны в [UPSTREAM.md](UPSTREAM.md), перемещения — в [карте переноса](docs/original-author-migration.md).
