# Программирование на Java

Курс рассчитан на студентов с опытом программирования на C++. Он объясняет
понятия Java, устройство программ, причины языковых решений и последствия
их применения. Примеры и задания используют JDK 25.

| Проект | Назначение |
|---|---|
| [Теория](theory/index.qmd) | Связное теоретическое изложение для самостоятельного чтения |
| [Лекции](lectures/index.qmd) | Материал устных занятий и последовательные разборы примеров |
| [Справочник](handbook/index.qmd) | Правила, формы объявлений, операции API и команды |
| [Введения к лабораторным](practice/index.qmd) | Повторение знакомых решений перед самостоятельной работой |
| [Задания](tasks/index.qmd) | Условия лабораторных, отдельные задачи и темы исследований |

[Главная курса](index.qmd) связывает эти пять форм по темам.

## Локальная сборка

Команда сборки из корня репозитория:

```sh
bash CI/render.sh
```

По умолчанию сценарий выполняет одну student-сборку; при предупреждениях
сборка завершается ошибкой. Результат находится в `_site-student/`.
Полную авторскую выдачу можно собрать отдельно: `bash CI/render.sh full`
в `_site-full/`.
Корневая сборка включает пять учебных проектов. Quarto 1.11.5 выбирается в workflow;
подготовка расширений описана в [UPSTREAM.md](UPSTREAM.md).

## Доступ к учебным устройствам

Если преподаватель подключает внешнее учебное устройство, используйте
[инструкцию доступа](docs/student-device-certificates.md) или
[шаги для Windows](docs/student-windows-certificates.md). Точный адрес и
публичный сертификат выдаёт преподаватель; локальный запуск примеров Java
такого подключения не требует.
