Сложность: Средний

Для матрицы 3×3 вычтите из каждого элемента среднее арифметическое его строки. Результат храните как double[][]; исходную матрицу не изменяйте.

Обязательный исходный пример: строки (−3, 0, 3), (2, −1, 0), (1, 3, −2). При пустом стандартном вводе используйте именно его. Для дополнительной проверки разрешены любые матрицы 3×3 с целыми значениями −3…3: передайте девять чисел через стандартный ввод построчно. Другие размеры, null, рваные матрицы и значения вне указанного диапазона не проверяются.

Выведите результат тремя строками по три числа, без подписей. Для обязательного примера строки результата: (−3, 0, 3), (5/3, −4/3, −1/3), (1/3, 7/3, −8/3); дроби выводятся десятичными числами.

Покажите новый массив double[][] и состояние исходной матрицы после расчёта.

Вещественные результаты можно выводить в десятичной или экспоненциальной форме с точкой. Допустимая абсолютная погрешность — 1e-8; количество знаков после точки не фиксируется.
