Сложность: Начальный

Выведите элементы заданного int[] от последнего к первому, не изменяя сам массив. Покажите обычный массив, пустой массив и массив из одного элемента.

Вход и результат: стандартный ввод содержит неотрицательную длину n, затем ровно n значений int. Выведите только элементы в обратном порядке через пробельные символы. Для 4 7 -2 7 0 вывод — 0 7 -2 7, для 0 вывод не содержит чисел. При пустом стандартном вводе используйте демонстрационный массив из исходника.

Сохранение исходного массива и его использование проверяет преподаватель: по одному выводу нельзя доказать, что исходные данные не переставлялись.
