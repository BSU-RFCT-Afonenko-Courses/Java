Сложность: Средний

Изображение имеет width столбцов и height строк пикселей. Каждый пиксель занимает bytesPerPixel байт; сжатие и служебные заголовки отсутствуют. Вычислите точное количество байтов и размер в мебибайтах: 1 МиБ = 1 048 576 байт.

Стандартный ввод содержит три целых числа: width height bytesPerPixel. Ширина и высота находятся в диапазоне от 1 до 100 000, число байтов на пиксель — от 1 до 8. Вход заведомо соответствует этим условиям. Выведите количество байтов как целое число, затем размер в МиБ как дробное число с точкой. Для второго результата допустима абсолютная ошибка 1e-8.

Примеры: 1024 1024 4 даёт 4194304 4.0; 50000 50000 3 — 7500000000 7152.557373046875. Также проверьте один пиксель. Выберите типы промежуточных вычислений так, чтобы результат оставался точным на всём объявленном входе.

Необязательный ZIP дополнительных .java: additional-sources.zip. Основные файлы остаются в редакторах. Относительные пути пакетов допускаются; основные и доверенные файлы перезаписывать нельзя. Пределы: 128 файлов, 1048576 байт на файл, 4194304 байт распакованных исходников, 2097152 байт ZIP. Штатный общий предел PrairieLearn — 5 MB на весь ответ, включая редакторные файлы; доступный размер ZIP зависит от остального ответа. При превышении используйте ручную сдачу.
