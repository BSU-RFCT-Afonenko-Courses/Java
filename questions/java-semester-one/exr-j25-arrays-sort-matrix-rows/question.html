Сложность: Высокий

Перестройте матрицу 3×3, переставляя целые строки по неубыванию суммы их элементов. При одинаковых суммах сохраняйте исходный взаимный порядок строк. Порядок элементов внутри строки не изменяется.

Можно написать собственную устойчивую сортировку строк или использовать устойчивую сортировку массива объектов; конкретный алгоритм не предписан.

Обязательный исходный пример: строки (−3, 0, 3), (2, −1, 0), (1, 3, −2). При пустом стандартном вводе используйте именно его. Для дополнительной проверки разрешены любые матрицы 3×3 с целыми значениями −3…3: передайте девять чисел через стандартный ввод построчно. Другие размеры, null, рваные матрицы и значения вне указанного диапазона не проверяются.

Выведите три строки по три числа, без подписей. Обязательный пример уже упорядочен; дополнительно проверьте перестановку его строк. Например, строки (2, −1, 0), (0, 1, 0), (0, 0, 0) должны дать (0, 0, 0), (2, −1, 0), (0, 1, 0) — равные суммы сохраняют порядок.
