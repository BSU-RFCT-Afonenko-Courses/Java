Для целых n, m, k, где n < m, определите принадлежность k каждому из интервалов (n, m], [n, m), (n, m), [n, m]. Проверьте обе границы, внутреннюю точку и значения снаружи.

Вход и результат: стандартный ввод содержит n m k типа int, разделённые пробельными символами. Выведите четыре значения true или false в указанном порядке. Например, -2 4 -2 даёт false true false true; -2 4 4 — true false false true. Некорректный ввод и случай n >= m не проверяются.
