# Историческая адаптация optional-time

`optional-time.patch` и `manifest.json` сохраняют исходники прежней адаптации.
Текущая установка выбирается в корневом `providers.json` и описана
в `docs/provider-installation.md`. Утилита восстановления старого immutable
дерева удалена вместе с прежним `sync-providers.py`.
